Flight#

class Flight#

Flight telemetry for a vehicle, relative to the surface of the body it orbits. Obtained from Vehicle.Flight.

double MeanAltitude { get; }#

The altitude above the mean radius of the body, in meters.

Game Scenes:

Flight

double SurfaceAltitude { get; }#

The altitude above the terrain or the ocean surface, whichever is higher, in meters.

Game Scenes:

Flight

double BedrockAltitude { get; }#

The altitude above the terrain, in meters. Over the sea, this is the altitude above the sea floor.

Game Scenes:

Flight

double Elevation { get; }#

The height of the terrain below the vehicle, in meters above the mean radius of the body. Below the sea, this is the height of the sea floor.

Game Scenes:

Flight

float TimeToImpact { get; }#

The time until the vehicle hits the surface on its current trajectory, in seconds. Not a number if its trajectory does not hit the surface.

Game Scenes:

Flight

Note

The game predicts the trajectory on a worker thread, so a change to it shows here shortly after.
