UI#

class UI#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see KSA.ShowMessage.

static Window AddWindow (IConnection connection, string title, bool visible = true)#

Add a window, with no widgets.

Parameters:

  • title – The text in the title bar.

  • visible – Whether the window is visible.

Game Scenes:

All

static void Clear (IConnection connection, bool clientOnly = false)#

Remove the windows.

Parameters:

  • clientOnly – Whether to remove only the windows added by the calling client.

class Window#

A window, holding widgets one per line. Created using UI.AddWindow.

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.
