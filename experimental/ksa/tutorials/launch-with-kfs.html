Launching with kFS#

This tutorial launches the game’s Rocket with a kFS program flying the ascent. kFS is the game’s flight software: programs in kC, a subset of C, that run on a vehicle’s flight computer. The kRPC script loads the program, reads its telemetry, and tells it when to lift off and when to stage, so the two talk in both directions.

The complete script is launch_with_kfs.py, and the program is ascent.c. Save them in the same folder.

Note

kFS is a prototype in the game. The script turns it on, as the game’s kfs on console command does.

The Program#

The program runs a task ten times a second. It subscribes to two of the messages the game publishes to it: the flight data, with the altitude and apoapsis, and the vehicle’s properties, with its engines:

#pragma kfs tick_hz 10
#pragma kfs subscribe MSG_FLIGHT_DATA flight
#pragma kfs subscribe MSG_VEHICLE_PROPS props
#pragma kfs task ascent rate_hz=10

The program shares two global variables with the script. The script reads the telemetry, and writes the request:

/* The telemetry, which the client reads */
typedef struct {
    uint32_t phase;
    float altitude;
    float apoapsis;
    float pitch;
    float thrust;
    uint32_t stages;
} telemetry_t;

telemetry_t telemetry;

/* The client's requests: lift off, and a count of the stagings it wants */
typedef struct {
    uint32_t launch;
    uint32_t stages;
} request_t;

request_t request;

The program waits on the pad until the script asks it to lift off. It then points the rocket straight up and lights the first stage, with the game’s flight computer services. Once the engine has thrust, the ascent starts. The program steers along the same gravity turn as Launching into Orbit, and cuts the engines once the apoapsis reaches 400 km. The first stage runs dry on the way, at an apoapsis of about 360 km:

    if (telemetry.phase == PHASE_LAUNCH) {
        if (!request.launch) {
            /* Wait on the pad */
        } else if (!launched) {
            kfs_hold_heading(HEADING, 90.0f * DEG2RAD, KFS_ROLL_UP);
            kfs_set_throttle(1.0f);
            kfs_engines_on();
            kfs_stage();
            launched = 1u;
        } else if (thrust > 0.0f) {
            kfs_logf("lift off");
            telemetry.phase = PHASE_ASCENT;
        }
    } else if (telemetry.phase == PHASE_ASCENT) {
        /* Drop the spent stage and light the next one */
        if (request.stages != staged) {
            kfs_stage();
            kfs_stage();
            staged = request.stages;
            kfs_logf("staged %u", staged);
        }
        /* Acknowledge a staging once the next stage has thrust */
        if (thrust > 0.0f)
            telemetry.stages = staged;
        telemetry.pitch = pitch_at(flight.altitude_m);
        kfs_hold_heading(HEADING, telemetry.pitch * DEG2RAD, KFS_ROLL_UP);
        if (flight.apoapsis_m >= TARGET_ALTITUDE) {
            kfs_engines_off();
            kfs_hold_direction(KFS_VLF_PROGRADE, KFS_ROLL_FREE);
            kfs_logf("target apoapsis reached");
            telemetry.phase = PHASE_COAST;
        }
    }

    telemetry.altitude = flight.altitude_m;
    telemetry.apoapsis = flight.apoapsis_m;
    telemetry.thrust = thrust;

The program stages only when the script asks. It acknowledges a staging in its telemetry once the next stage has thrust, so the script never asks twice for the same stage.

Loading the Program#

The script launches the vehicle, and seats a kitten in it. The flight computer obeys a program only while the vehicle is under control, and the Rocket launches with an empty seat. The script then loads the program onto the flight computer. load builds the program, and throws an exception with the compiler’s errors if it has any:

kfs.available = True
vehicle = ksa.launch_vehicle("Rocket", "CCSFS LC-39A")

# The flight computer obeys a program only on a vehicle under control,
# so a kitten takes the Rocket's seat
kitten = next(
    k
    for k in ksa.kittens.values()
    if k.vehicle is None and not k.on_eva and not k.killed_in_action
)
vehicle.seats[0].kitten = kitten

# The game updates the rocket's control state at its next frame
deadline = time.monotonic() + 5
while vehicle.control_state != ksa.ControlState.controllable:
    if time.monotonic() > deadline:
        raise RuntimeError(
            f"Cannot control the rocket: {vehicle.control_state}"
        )
    time.sleep(0.1)

print("Loading the program")
computer = kfs.computer(vehicle)
computer.load({"ascent.c": PROGRAM.read_text()})
computer.start()

Reading the Telemetry#

Each field of the telemetry is a stream of read_global. The server reads the program’s memory after each of its ticks:

def telemetry(name: str) -> Any:
    """A stream of a field of the program's telemetry."""
    return conn.add_stream(computer.read_global, "telemetry." + name)


phase = telemetry("phase")
altitude = telemetry("altitude")
apoapsis = telemetry("apoapsis")
pitch = telemetry("pitch")
thrust = telemetry("thrust")
stages = telemetry("stages")

Lifting Off#

The script counts down, and writes the lift off request to the program. write_globals returns once the program can see the new value:

for count in range(3, 0, -1):
    print(f"{count}...")
    time.sleep(1)
print("Lift off")
computer.write_globals({"request.launch": 1})

Staging#

The script watches the thrust the program reports. When the first stage runs dry, it counts up the stagings it wants in the program’s request. It also streams the computer’s state, and stops if the program halts, such as on a trap:

state = conn.add_stream(getattr, computer, "state")
requested = 0
last_report = 0.0
while phase() != COAST:
    if state() == kfs.ComputerState.halted:
        raise RuntimeError(f"The program halted: {computer.trap}")
    # Stage once the program reports no thrust, and has done the
    # stagings asked for so far
    if phase() == ASCENT and thrust() == 0 and stages() == requested:
        requested += 1
        print(f"Staging at apoapsis {apoapsis() / 1000:.0f} km")
        computer.write_globals({"request.stages": requested})

Handing Back#

Once the engines are off, the script waits for the rocket to leave the atmosphere. It then stops the program, which hands the rocket back to the pilot, and prints the program’s log:

# Hand the rocket back to the pilot
computer.stop()
print("The program's log:")
for line in computer.log:
    print("  " + line)

The rocket is on its way to a 400 km apoapsis. Executing a Burn makes the orbit circular.
