Debug#

public class Debug#

Changes the state of the simulation directly, as the game’s debug windows and console commands do: teleporting a vehicle, setting its attitude, refilling its tanks.

static void setCircularOrbit(Connection connection, Vehicle vehicle, Body body, double altitude)#

Move a vehicle onto a circular orbit around a body, and return once it is there.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • body (Body) – The body to orbit.

  • altitude (double) – The altitude of the orbit above the mean radius, in meters.

Note

Throws an exception if the game cannot compute the vehicle’s trajectory on the orbit.

static void setOrbit(Connection connection, Vehicle vehicle, Body body, double semiMajorAxis, double eccentricity, double inclination, double longitudeOfAscendingNode, double argumentOfPeriapsis, double meanAnomalyAtEpoch, double epoch)#

Move a vehicle onto the orbit with the given elements, and return once it is there. The angles are those of Orbit.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • body (Body) – The body to orbit.

  • semiMajorAxis (double) – The semi-major axis, in meters.

  • eccentricity (double) – The eccentricity.

  • inclination (double) – The inclination, in radians.

  • longitudeOfAscendingNode (double) – The longitude of the ascending node, in radians.

  • argumentOfPeriapsis (double) – The argument of periapsis, in radians.

  • meanAnomalyAtEpoch (double) – The mean anomaly at the epoch, in radians.

  • epoch (double) – The universal time of the epoch, in seconds.

Note

Throws an exception if the game cannot compute the vehicle’s trajectory on the orbit.

static void setLanded(Connection connection, Vehicle vehicle, Body body, double latitude, double longitude)#

Place a vehicle on the surface of a body, as the game’s teleport window does, and return once it is there.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • body (Body) – The body to land on.

  • latitude (double) – The latitude, in degrees.

  • longitude (double) – The longitude, in degrees.

Note

Throws an exception if the body has no surface.

static void setPosition(Connection connection, Vehicle vehicle, org.javatuples.Triplet<Double, Double, Double> position, ReferenceFrame referenceFrame)#

Move a vehicle to the given position, keeping its velocity, and return once it is there.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • position (org.javatuples.Triplet) – The position of the vehicle, in meters.

  • referenceFrame (ReferenceFrame) – The reference frame of the position.

Note

This is the inverse of Vehicle.position(ReferenceFrame). The vehicle keeps orbiting the same body.

static void setVelocity(Connection connection, Vehicle vehicle, org.javatuples.Triplet<Double, Double, Double> velocity, ReferenceFrame referenceFrame)#

Set the velocity of a vehicle, keeping its position, and return once it is set.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • velocity (org.javatuples.Triplet) – The velocity of the vehicle, in meters per second.

  • referenceFrame (ReferenceFrame) – The reference frame of the velocity.

Note

This is the inverse of Vehicle.velocity(ReferenceFrame). The vehicle keeps orbiting the same body.

static void setRotation(Connection connection, Vehicle vehicle, org.javatuples.Quartet<Double, Double, Double, Double> rotation, ReferenceFrame referenceFrame)#

Set the rotation of a vehicle, and return once it is set.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • rotation (org.javatuples.Quartet) – The rotation of the vehicle, as a quaternion of the form (x, y, z, w).

  • referenceFrame (ReferenceFrame) – The reference frame of the rotation.

Note

This is the inverse of Vehicle.rotation(ReferenceFrame).

static void setAngularVelocity(Connection connection, Vehicle vehicle, org.javatuples.Triplet<Double, Double, Double> angularVelocity, ReferenceFrame referenceFrame)#

Set the angular velocity of a vehicle, and return once it is set.

Parameters:

  • vehicle (Vehicle) – The vehicle.

  • angularVelocity (org.javatuples.Triplet) – The angular velocity, in radians per second. The vector points along the axis of rotation, and its length is the rate.

  • referenceFrame (ReferenceFrame) – The reference frame of the angular velocity.

Note

This is the inverse of Vehicle.angularVelocity(ReferenceFrame).

static void fillResources(Connection connection, Vehicle vehicle)#

Fill the propellant, batteries and other consumables of a vehicle, as the game’s refill command does.

Parameters:

  • vehicle (Vehicle) – The vehicle.

static void emptyResources(Connection connection, Vehicle vehicle)#

Empty the propellant, batteries and other consumables of a vehicle, as the game’s empty command does.

Parameters:

  • vehicle (Vehicle) – The vehicle.

static Vehicle duplicateVehicle(Connection connection, Vehicle vehicle, String name)#

Create a copy of a vehicle beside it, as the game’s duplicate command does, and return once it is created.

Parameters:

  • vehicle (Vehicle) – The vehicle to copy.

  • name (String) – The name of the copy.

Returns:

The copy.

Note

Throws an exception if the name is in use.

static void explodeVehicle(Connection connection, Vehicle vehicle)#

Destroy a vehicle in an explosion, as the game’s explode command does, and return once the vehicle is gone. Its crew are killed.

Parameters:

  • vehicle (Vehicle) – The vehicle.

static void showVelocityArrows(Connection connection, boolean visible)#

Show or hide the game’s debug arrows for the velocities of the vehicles.

Parameters:

  • visible (boolean) – Whether to show the arrows.

static java.util.List<String> runCommand(Connection connection, String command)#

Run a command in the game’s console, as typed in the console.

Parameters:

  • command (String) – The command and its arguments.

Returns:

The console output of the command, one line per message.

Note

Most commands write their messages to the game’s log, not the returned output. Throws an exception if the console has no such command, or the arguments are not valid.
