Parts#

public class Part#

A part of a vehicle. Obtained from Vehicle.getParts().

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

String getName()#

The id of the part’s template.

String getTitle()#

The name of the part, as shown in the game.

Vehicle getVehicle()#

The vehicle the part belongs to.

Part getParent()#

The part this part is attached to, or null for the root part.

java.util.List<Part> getChildren()#

The parts attached to this part.

int getSequence()#

The number of the sequence that activates the part, or -1 if no sequence does.

double getMass()#

The mass of the part, including its propellant, in kilograms.

double getDryMass()#

The mass of the part without its propellant, in kilograms.

java.util.List<Resource> getResources()#

The resources the part holds, one for each substance.

org.javatuples.Triplet<Double, Double, Double> position(ReferenceFrame referenceFrame)#

The position of the part’s origin, in meters.

Parameters:

  • referenceFrame (ReferenceFrame) – The reference frame of the position.

org.javatuples.Quartet<Double, Double, Double, Double> rotation(ReferenceFrame referenceFrame)#

The rotation of the part’s axes, relative to the given frame.

Parameters:

  • referenceFrame (ReferenceFrame) – The reference frame of the rotation.

Engine getEngine()#

The part’s engine, or null if it has none.

RCS getRCS()#

The part’s RCS thrusters, or null if it has none.

Decoupler getDecoupler()#

The part’s decoupler, or null if it has none.

Parachute getParachute()#

The part’s parachute, or null if it has none.

DockingPort getDockingPort()#

The part’s docking port, or null if it has none.

public class Engine#

An engine. Obtained from Part.getEngine().

Note

An active engine fires when the vehicle’s engines are on, at the vehicle’s throttle. See Control.getEngineOn() and Control.getThrottle().

Part getPart()#

The part the engine is in.

boolean getActive()#
void setActive(boolean value)#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

boolean getHasPropellant()#

Whether the engine has propellant to burn.

double getThrust()#

The thrust of the engine at its current throttle and the current atmospheric pressure, in Newtons. Zero when it is not firing.

double getAvailableThrust()#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

double getSpecificImpulse()#

The specific impulse of the engine at the current atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

public class RCS#

The RCS thrusters of a part. Obtained from Part.getRCS().

Note

Active thrusters fire when the vehicle’s RCS is on. See Control.getRCS().

Part getPart()#

The part the thrusters are in.

boolean getActive()#
void setActive(boolean value)#

Whether the thrusters are active. Setting it returns once the change has applied.

public class Decoupler#

A decoupler. Obtained from Part.getDecoupler().

Part getPart()#

The part the decoupler is in.

boolean getEnabled()#

Whether the decoupler can fire.

boolean getDecoupled()#

Whether the decoupler has fired, or is attached to nothing.

void decouple()#

Fire the decoupler, separating the vehicle into two. Returns once it has fired. Throws an exception if the decoupler is disabled or Decoupler.getDecoupled().

public class Parachute#

A parachute. Obtained from Part.getParachute().

Part getPart()#

The part the parachute is in.

ParachuteState getState()#

The state of the parachute.

float getFill()#

How far the canopy is open, from 0 to 1.

float getDeployAltitude()#

The height above the terrain at which an armed parachute deploys, in meters.

boolean getCanCut()#

Whether the parachute can be cut away. Main parachutes cannot.

void deploy()#

Arm the parachute, so that it deploys at Parachute.getDeployAltitude(). Returns once it is armed. Throws an exception if it is not stowed.

void cut()#

Cut the parachute away. Returns once it is cut. Throws an exception if it cannot be cut. See Parachute.getCanCut().

public enum ParachuteState#

The state of a parachute. See Parachute.getState().

public ParachuteState STOWED#

Packed away.

public ParachuteState ARMED#

Waiting to deploy at Parachute.getDeployAltitude().

public ParachuteState LINE_STRETCH#

Leaving the pack.

public ParachuteState REEFED#

Partly open, to limit the opening load.

public ParachuteState DISREEFING#

Opening from reefed to full.

public ParachuteState FULL#

Fully open.

public ParachuteState CUT#

Cut away.

public ParachuteState RIPPED#

Torn by too much dynamic pressure.

public ParachuteState SEVERED_LINES#

Lost after its lines broke under too much load.

public class DockingPort#

A docking port. Obtained from Part.getDockingPort().

Part getPart()#

The part the docking port is in.

boolean getDocked()#

Whether the port is docked.

Part getDockedPart()#

The part the port is docked to, or null if it is not docked.

void undock()#

Undock the port, separating the vehicle into two. Returns once it has undocked. Throws an exception if the port is not docked.

Note

Docking and undocking replace the vehicles involved. See Vehicle.
