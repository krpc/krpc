UI#

public class UI#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see showMessage(String, float, boolean).

static Window addWindow(Connection connection, String title, boolean visible)#

Add a window, with no widgets.

Parameters:

  • title (String) – The text in the title bar.

  • visible (boolean) – Whether the window is visible.

static void clear(Connection connection, boolean clientOnly)#

Remove the windows.

Parameters:

  • clientOnly (boolean) – Whether to remove only the windows added by the calling client.

public class Window#

A window, holding widgets one per line. Created using UI.addWindow(String, boolean).

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.
