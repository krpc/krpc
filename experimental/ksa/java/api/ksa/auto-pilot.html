Auto-Pilot#

public class AutoPilot#

The vehicle’s flight computer, which steers the vehicle with its reaction control thrusters and engine gimbals. Obtained from Vehicle.getAutoPilot().

Note

The auto-pilot points the vehicle in the direction set by AutoPilot.getMode(), once engaged. It is the game’s own flight computer, so the game’s flight computer controls change the same settings.

The direction the auto-pilot points the vehicle in.

Game Scenes:

Flight

Note

Setting AutoPilotMode.ATTITUDE targets the vehicle’s current pitch, heading and roll. Setting AutoPilotMode.OTHER throws an exception.

float getTargetPitch()#
void setTargetPitch(float value)#

The target pitch, in degrees, between -90° and +90°.

Game Scenes:

Flight

Note

Setting it sets AutoPilot.getMode() to AutoPilotMode.ATTITUDE. Returns NaN in any other mode.

float getTargetHeading()#
void setTargetHeading(float value)#

The target heading, in degrees, between 0° and 360°.

Game Scenes:

Flight

Note

Setting it sets AutoPilot.getMode() to AutoPilotMode.ATTITUDE. Returns NaN in any other mode.

float getTargetRoll()#
void setTargetRoll(float value)#

The target roll, in degrees. NaN when the auto-pilot does not control roll.

Game Scenes:

Flight

Note

Setting a number sets AutoPilot.getMode() to AutoPilotMode.ATTITUDE. Setting NaN leaves roll free, in every mode. Returns NaN in modes other than AutoPilotMode.ATTITUDE.

void targetPitchAndHeading(float pitch, float heading)#

Set the target pitch and heading, and the mode to AutoPilotMode.ATTITUDE.

Parameters:

  • pitch (float) – Target pitch, in degrees, between -90° and +90°.

  • heading (float) – Target heading, in degrees, between 0° and 360°.

Game Scenes:

Flight

void targetDirection(org.javatuples.Triplet<Double, Double, Double> direction, ReferenceFrame referenceFrame)#

Point the vehicle in a direction, and set the mode to AutoPilotMode.ATTITUDE. Sets AutoPilot.getTargetPitch() and AutoPilot.getTargetHeading() to the direction at the time of the call, so the target stays fixed relative to the surface.

Parameters:

  • direction (org.javatuples.Triplet) – The direction to point in.

  • referenceFrame (ReferenceFrame) – The reference frame of the direction.

Game Scenes:

Flight

float getError()#

The angle between the direction the vehicle points in and the target direction, in degrees. NaN when the auto-pilot is not engaged.

Game Scenes:

Flight

float getRollError()#

The angle between the vehicle’s roll and the target roll, in degrees. NaN when the auto-pilot is not engaged.

Game Scenes:

void wait_()#

Wait until the vehicle points in the target direction, and has the target roll if it has one. Returns when the errors are within twice the flight computer’s angle deadband, which defaults to 1°. Throws an exception if the auto-pilot is not engaged.

Game Scenes:

Flight

boolean getAutoBurn()#
void setAutoBurn(boolean value)#

Whether the flight computer executes the next burn in Vehicle.getBurns(). It points the vehicle along the burn, fires the engines at Burn.getIgnitionTime(), and stops once the burn is complete.

Game Scenes:

Flight

Note

The flight computer clears it when the burn completes, and removes the burn if another follows it. The engines fire only at normal speed, so warp to shortly before the burn with warpTo(double). Setting it with no burn planned throws an exception.

public enum AutoPilotMode#

The direction the auto-pilot points the vehicle in. See AutoPilot.getMode().

public AutoPilotMode ATTITUDE#

The pitch, heading and roll set by AutoPilot.getTargetPitch(), AutoPilot.getTargetHeading() and AutoPilot.getTargetRoll().

public AutoPilotMode HOLD#

Holds the vehicle’s rotation at zero, relative to the stars.

public AutoPilotMode PROGRADE#

The direction of the vehicle’s orbital velocity.

public AutoPilotMode RETROGRADE#

The opposite of AutoPilotMode.PROGRADE.

public AutoPilotMode NORMAL#

Normal to the orbital plane, along the orbit’s angular momentum.

public AutoPilotMode ANTI_NORMAL#

The opposite of AutoPilotMode.NORMAL.

public AutoPilotMode RADIAL_OUT#

Away from the center of the body being orbited.

public AutoPilotMode RADIAL_IN#

Toward the center of the body being orbited.

public AutoPilotMode SURFACE_PROGRADE#

The direction of the vehicle’s velocity relative to the surface.

public AutoPilotMode SURFACE_RETROGRADE#

The opposite of AutoPilotMode.SURFACE_PROGRADE.

public AutoPilotMode OTHER#

A target set in the game, which the API does not cover.
