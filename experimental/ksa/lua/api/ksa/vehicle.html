Vehicle#

class KSA.Vehicle#

A vehicle in the current system. Obtained from KSA.active_vehicle or KSA.vehicles.

Note

Docking and undocking replace the vehicles involved, so an object for one of them throws an exception afterwards.

name: string#

The name of the vehicle, which is unique in the system.

Attribute:

Can be read or written

Return type:

string

situation: KSA.Situation#

The situation of the vehicle.

Attribute:

Read-only, cannot be set

Return type:

KSA.Situation

has_launched: boolean#

Whether the vehicle has launched.

Attribute:

Read-only, cannot be set

Return type:

boolean

launch_time: number#

The universal time the vehicle was created, in seconds.

Attribute:

Read-only, cannot be set

Return type:

number

mass: number#

The total mass of the vehicle, including propellant, in kilograms.

Attribute:

Read-only, cannot be set

Return type:

number

propellant_mass: number#

The mass of the propellant in the vehicle, in kilograms.

Attribute:

Read-only, cannot be set

Return type:

number

thrust: number#

The thrust of the engines at their current throttle and the current atmospheric pressure, in Newtons.

Attribute:

Read-only, cannot be set

Return type:

number

available_thrust: number#

The thrust of the active engines that have propellant, at full throttle and the current atmospheric pressure, in Newtons.

Attribute:

Read-only, cannot be set

Return type:

number

specific_impulse: number#

The combined specific impulse of the active engines that have propellant, at the current atmospheric pressure, in seconds. Zero when no engine is active.

Attribute:

Read-only, cannot be set

Return type:

number

parts: List#

The vehicle’s parts.

Attribute:

Read-only, cannot be set

Return type:

List

root_part: KSA.Part#

The vehicle’s root part, which the other parts are attached to.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

resources: List#

The resources the vehicle holds, one for each substance, totaled over its parts.

Attribute:

Read-only, cannot be set

Return type:

List

delta_v: number#

The change in velocity of all the vehicle’s sequences, in meters per second.

Attribute:

Read-only, cannot be set

Return type:

number

sequences: List#

The vehicle’s sequences, in activation order.

Attribute:

Read-only, cannot be set

Return type:

List

target_vehicle: KSA.Vehicle#

The vehicle targeted by this vehicle, or nil. Setting it replaces the target, and nil clears it.

Attribute:

Can be read or written

Return type:

KSA.Vehicle or Types.none

target_body: KSA.Body#

The body targeted by this vehicle, or nil. Setting it replaces the target, and nil clears it.

Attribute:

Can be read or written

Return type:

KSA.Body or Types.none

Note

Setting a body that orbits nothing, such as the star, throws an exception.

burns: List#

The vehicle’s planned burns, in time order.

Attribute:

Read-only, cannot be set

Return type:

List

add_burn(ut[, prograde = 0.0][, normal = 0.0][, radial = 0.0])#

Plan a burn, and add it to the vehicle’s burn plan.

Parameters:

  • ut (number) – Universal time of the burn, in seconds.

  • prograde (number) – Change in velocity in the prograde direction, in meters per second.

  • normal (number) – Change in velocity along the orbit normal, in meters per second.

  • radial (number) – Change in velocity radially outward, in meters per second.

Returns:

The burn.

Return type:

KSA.Burn

Note

Returns once the flight computer has timed the burn, if it is the next one. Throws an exception if the time is in the past, or beyond the vehicle’s predicted trajectory.

orbit: KSA.Orbit#

The current orbit of the vehicle.

Attribute:

Read-only, cannot be set

Return type:

KSA.Orbit

flight: KSA.Flight#

Flight telemetry for the vehicle, relative to the surface of the body it orbits.

Attribute:

Read-only, cannot be set

Return type:

KSA.Flight

control: KSA.Control#

The controls of the vehicle.

Attribute:

Read-only, cannot be set

Return type:

KSA.Control

auto_pilot: KSA.AutoPilot#

The auto-pilot of the vehicle.

Attribute:

Read-only, cannot be set

Return type:

KSA.AutoPilot

reference_frame: KSA.ReferenceFrame#

The reference frame fixed to the vehicle, with its origin at the vehicle’s position. The x axis points forward, the y axis to the right and the z axis down, relative to the vehicle’s control point.

Attribute:

Read-only, cannot be set

Return type:

KSA.ReferenceFrame

surface_reference_frame: KSA.ReferenceFrame#

The reference frame with its origin at the vehicle’s position, and axes aligned with the surface below it. The x axis points east, the y axis north and the z axis up. The frame rotates with the body.

Attribute:

Read-only, cannot be set

Return type:

KSA.ReferenceFrame

orbital_reference_frame: KSA.ReferenceFrame#

The reference frame with its origin at the vehicle’s position, and axes aligned with its orbit. The x axis points prograde, the y axis along the orbit normal and the z axis radially outward, perpendicular to the x axis.

Attribute:

Read-only, cannot be set

Return type:

KSA.ReferenceFrame

position(reference_frame)#

The position of the vehicle, in meters.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

Return type:

Tuple

velocity(reference_frame)#

The velocity of the vehicle, in meters per second.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the velocity.

Return type:

Tuple

direction(reference_frame)#

The unit vector in which the vehicle points, the x axis of KSA.Vehicle.reference_frame.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the direction.

Return type:

Tuple

rotation(reference_frame)#

The rotation of KSA.Vehicle.reference_frame relative to the given frame.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Return type:

Tuple

angular_velocity(reference_frame)#

The angular velocity of the vehicle, in radians per second. The vector points along the axis of rotation, and its length is the rate of rotation.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the angular velocity.

Return type:

Tuple

class KSA.Situation#

The situation of a vehicle: its contact with the surface, and whether the game is simulating it with physics or propagating it along its orbit. See KSA.Vehicle.situation.

maneuvering#

No surface contact, simulated with physics.

freefall#

No surface contact, on rails.

rolling#

On terrain, simulated with physics.

landed#

At rest on terrain.

sailing#

In the ocean, simulated with physics.

floating#

At rest in the ocean.

dragging#

On terrain and in the ocean, simulated with physics.

bottomed#

At rest on terrain and in the ocean.
