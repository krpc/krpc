UI#

class KSA.UI#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see KSA.show_message().

staticmethod add_window(title: string, visible?: boolean): KSA.Window#

Add a window, with no widgets.

Parameters:

  • title – The text in the title bar.

  • visible – Whether the window is visible. Defaults to true.

staticmethod clear(client_only?: boolean)#

Remove the windows.

Parameters:

client_only – Whether to remove only the windows added by the calling client. Defaults to false.

class KSA.Window#

A window, holding widgets one per line. Created using KSA.UI.add_window().

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.

title: string#

The text in the title bar.

Attribute:

Can be read or written

position: Tuple#

The position of the top left corner of the window, from the top left corner of the game window, in pixels.

Attribute:

Can be read or written

size: Tuple#

The width and height of the window, in pixels.

Attribute:

Can be read or written

Note

Throws an exception if the width or height is not positive.

visible: boolean#

Whether the widget is visible.

Attribute:

Can be read or written

enabled: boolean#

Whether the widget responds to input. A disabled widget is drawn dimmed.

Attribute:

Can be read or written

add_slider(
    label?: string,
    minimum?: number,
    maximum?: number,
    visible?: boolean
): KSA.Slider#

Add a slider, at its minimum value.

Parameters:

  • label – The text shown next to the slider. Defaults to ''.

  • minimum – The minimum value. Defaults to 0.0.

  • maximum – The maximum value. Defaults to 1.0.

  • visible – Whether the slider is visible. Defaults to true.

Note

Throws an exception if the minimum is not less than the maximum.
