UI#

class KSA.UI#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see KSA.show_message().

static add_window(title[, visible = true])#

Add a window, with no widgets.

Parameters:

  • title (string) – The text in the title bar.

  • visible (boolean) – Whether the window is visible.

Return type:

KSA.Window

static clear([client_only = false])#

Remove the windows.

Parameters:

client_only (boolean) – Whether to remove only the windows added by the calling client.

class KSA.Window#

A window, holding widgets one per line. Created using KSA.UI.add_window().

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.

The text in the title bar.
