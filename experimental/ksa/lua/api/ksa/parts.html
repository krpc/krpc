Parts#

class KSA.Part#

A part of a vehicle. Obtained from KSA.Vehicle.parts.

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

name: string#

The id of the part’s template.

Attribute:

Read-only, cannot be set

Return type:

string

title: string#

The name of the part, as shown in the game.

Attribute:

Read-only, cannot be set

Return type:

string

vehicle: KSA.Vehicle#

The vehicle the part belongs to.

Attribute:

Read-only, cannot be set

Return type:

KSA.Vehicle

parent: KSA.Part#

The part this part is attached to, or nil for the root part.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part or Types.none

children: List#

The parts attached to this part.

Attribute:

Read-only, cannot be set

Return type:

List

sequence: number#

The number of the sequence that activates the part, or -1 if no sequence does.

Attribute:

Read-only, cannot be set

Return type:

number

mass: number#

The mass of the part, including its propellant, in kilograms.

Attribute:

Read-only, cannot be set

Return type:

number

dry_mass: number#

The mass of the part without its propellant, in kilograms.

Attribute:

Read-only, cannot be set

Return type:

number

resources: List#

The resources the part holds, one for each substance.

Attribute:

Read-only, cannot be set

Return type:

List

tanks: List#

The part’s propellant tanks. Empty if it has none.

Attribute:

Read-only, cannot be set

Return type:

List

batteries: List#

The part’s batteries.

Attribute:

Read-only, cannot be set

Return type:

List

solar_panels: List#

The part’s solar panels.

Attribute:

Read-only, cannot be set

Return type:

List

generators: List#

The part’s generators.

Attribute:

Read-only, cannot be set

Return type:

List

power_consumers: List#

The part’s power consumers.

Attribute:

Read-only, cannot be set

Return type:

List

lights: List#

The part’s lights.

Attribute:

Read-only, cannot be set

Return type:

List

deployables: List#

The part’s deployable sections. A part can have several, such as the doors of a service module.

Attribute:

Read-only, cannot be set

Return type:

List

magnetic_scoops: List#

The part’s magnetic scoops. Empty if it has none.

Attribute:

Read-only, cannot be set

Return type:

List

position(reference_frame)#

The position of the part’s origin, in meters.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

Return type:

Tuple

velocity(reference_frame)#

The velocity of the part’s origin, in meters per second.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the velocity.

Return type:

Tuple

rotation(reference_frame)#

The rotation of the part’s axes, relative to the given frame.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Return type:

Tuple

engine: KSA.Engine#

The part’s engine, or nil if it has none.

Attribute:

Read-only, cannot be set

Return type:

KSA.Engine or Types.none

gimbals: List#

The part’s gimbals. An engine part can have several, each steering one nozzle.

Attribute:

Read-only, cannot be set

Return type:

List

rcs: KSA.RCS#

The part’s RCS thrusters, or nil if it has none.

Attribute:

Read-only, cannot be set

Return type:

KSA.RCS or Types.none

decoupler: KSA.Decoupler#

The part’s decoupler, or nil if it has none.

Attribute:

Read-only, cannot be set

Return type:

KSA.Decoupler or Types.none

parachute: KSA.Parachute#

The part’s parachute, or nil if it has none.

Attribute:

Read-only, cannot be set

Return type:

KSA.Parachute or Types.none

docking_port: KSA.DockingPort#

The part’s docking port, or nil if it has none.

Attribute:

Read-only, cannot be set

Return type:

KSA.DockingPort or Types.none

seats: List#

The part’s crew seats.

Attribute:

Read-only, cannot be set

Return type:

List

crew: List#

The kittens in the part’s seats.

Attribute:

Read-only, cannot be set

Return type:

List

class KSA.Engine#

An engine. Obtained from KSA.Part.engine.

Note

An active engine fires when the vehicle’s engines are on, at the vehicle’s throttle. See KSA.Control.engine_on and KSA.Control.throttle.

part: KSA.Part#

The part the engine is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

gimbals: List#

The gimbals that steer the engine’s nozzles. Empty if the engine has none.

Attribute:

Read-only, cannot be set

Return type:

List

active: boolean#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

Attribute:

Can be read or written

Return type:

boolean

has_propellant: boolean#

Whether the engine has propellant to burn.

Attribute:

Read-only, cannot be set

Return type:

boolean

minimum_throttle: number#

The lowest throttle the engine runs at, between 0 and 1.

Attribute:

Read-only, cannot be set

Return type:

number

propellants: List#

The names of the substances the engine burns. See KSA.Resource.name.

Attribute:

Read-only, cannot be set

Return type:

List

thrust: number#

The thrust of the engine at its current throttle and the current atmospheric pressure, in Newtons. Zero when it is not firing.

Attribute:

Read-only, cannot be set

Return type:

number

available_thrust: number#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

Attribute:

Read-only, cannot be set

Return type:

number

specific_impulse: number#

The specific impulse of the engine at the current atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

Attribute:

Read-only, cannot be set

Return type:

number

class KSA.Gimbal#

A gimbal that steers an engine nozzle. Obtained from KSA.Part.gimbals or KSA.Engine.gimbals.

Note

A gimbal turns about the y and z axes of its mount, which KSA.Gimbal.rotation() gives. The flight computer steers it while an engine it belongs to is KSA.Gimbal.active.

part: KSA.Part#

The part the gimbal is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

angle_y: number#

The angle of the gimbal about its y axis, in degrees.

Attribute:

Read-only, cannot be set

Return type:

number

angle_z: number#

The angle of the gimbal about its z axis, in degrees.

Attribute:

Read-only, cannot be set

Return type:

number

max_angle_y: number#

The largest angle of the gimbal about its y axis, in degrees. Zero if it does not turn about that axis.

Attribute:

Read-only, cannot be set

Return type:

number

max_angle_z: number#

The largest angle of the gimbal about its z axis, in degrees. Zero if it does not turn about that axis.

Attribute:

Read-only, cannot be set

Return type:

number

active: boolean#

Whether an engine the gimbal steers is active.

Attribute:

Read-only, cannot be set

Return type:

boolean

rotation(reference_frame)#

The rotation of the gimbal’s mount, whose y and z axes the gimbal turns about.

Parameters:

reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Return type:

Tuple

part: KSA.Part#

The part the thrusters are in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

active: boolean#

Whether the thrusters are active. Setting it returns once the change has applied.

Attribute:

Can be read or written

Return type:

boolean

class KSA.Decoupler#

A decoupler. Obtained from KSA.Part.decoupler.

part: KSA.Part#

The part the decoupler is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

enabled: boolean#

Whether the decoupler can fire.

Attribute:

Read-only, cannot be set

Return type:

boolean

decoupled: boolean#

Whether the decoupler has fired, or is attached to nothing.

Attribute:

Read-only, cannot be set

Return type:

boolean

decouple()#

Fire the decoupler, separating the vehicle into two. Returns once it has fired. Throws an exception if the decoupler is disabled or KSA.Decoupler.decoupled.

Returns:

The vehicles that separated from this one.

Return type:

List

class KSA.Parachute#

A parachute. Obtained from KSA.Part.parachute.

part: KSA.Part#

The part the parachute is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

state: KSA.ParachuteState#

The state of the parachute.

Attribute:

Read-only, cannot be set

Return type:

KSA.ParachuteState

fill: number#

How far the canopy is open, from 0 to 1.

Attribute:

Read-only, cannot be set

Return type:

number

deploy_altitude: number#

The height above the terrain at which an armed parachute deploys, in meters.

Attribute:

Read-only, cannot be set

Return type:

number

can_cut: boolean#

Whether the parachute can be cut away. Main parachutes cannot.

Attribute:

Read-only, cannot be set

Return type:

boolean

deploy()#

Arm the parachute, so that it deploys at KSA.Parachute.deploy_altitude. Returns once it is armed. Throws an exception if it is not stowed.

cut()#

Cut the parachute away. Returns once it is cut. Throws an exception if it cannot be cut. See KSA.Parachute.can_cut.

class KSA.ParachuteState#

The state of a parachute. See KSA.Parachute.state.

stowed#

Packed away.

armed#

Waiting to deploy at KSA.Parachute.deploy_altitude.

line_stretch#

Leaving the pack.

reefed#

Partly open, to limit the opening load.

disreefing#

Opening from reefed to full.

full#

Fully open.

cut#

Cut away.

ripped#

Torn by too much dynamic pressure.

severed_lines#

Lost after its lines broke under too much load.

class KSA.DockingPort#

A docking port. Obtained from KSA.Part.docking_port.

part: KSA.Part#

The part the docking port is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

docked: boolean#

Whether the port is docked.

Attribute:

Read-only, cannot be set

Return type:

boolean

docked_part: KSA.Part#

The part the port is docked to, or nil if it is not docked.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part or Types.none

undock()#

Undock the port, separating the vehicle into two. Returns once it has undocked. Throws an exception if the port is not docked.

Returns:

Note

class KSA.Deployable#

A part that deploys and retracts, such as a landing leg, a solar panel or a service module door. Obtained from KSA.Part.deployables.

Note

Deploying or retracting a part moves its symmetric copies with it, as the part’s menu in the game does.

part: KSA.Part#

The part the deployable is in.

Attribute:

Read-only, cannot be set

Return type:

KSA.Part

state: KSA.DeployableState#

The state of the part.

Attribute:

Read-only, cannot be set

Return type:

KSA.DeployableState

deploy()#

Deploy the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

retract()#

Retract the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

class KSA.DeployableState#

The state of a deployable part. See KSA.Deployable.state.

deployed#

Fully deployed.

retracted#

Fully retracted.

deploying#

Moving toward deployed.

retracting#

Moving toward retracted.

broken#

Broken, so it can no longer move.
