Debug#

class KSA.Debug#

Changes the state of the simulation directly, as the game’s debug windows and console commands do: teleporting a vehicle, setting its attitude, refilling its tanks.

static set_circular_orbit(vehicle, body, altitude)#

Move a vehicle onto a circular orbit around a body, and return once it is there.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • body (KSA.Body) – The body to orbit.

  • altitude (number) – The altitude of the orbit above the mean radius, in meters.

Note

Throws an exception if the game cannot compute the vehicle’s trajectory on the orbit.

static set_orbit(vehicle, body, semi_major_axis, eccentricity, inclination, longitude_of_ascending_node, argument_of_periapsis, mean_anomaly_at_epoch, epoch)#

Move a vehicle onto the orbit with the given elements, and return once it is there. The angles are those of KSA.Orbit.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • body (KSA.Body) – The body to orbit.

  • semi_major_axis (number) – The semi-major axis, in meters.

  • eccentricity (number) – The eccentricity.

  • inclination (number) – The inclination, in radians.

  • longitude_of_ascending_node (number) – The longitude of the ascending node, in radians.

  • argument_of_periapsis (number) – The argument of periapsis, in radians.

  • mean_anomaly_at_epoch (number) – The mean anomaly at the epoch, in radians.

  • epoch (number) – The universal time of the epoch, in seconds.

Note

Throws an exception if the game cannot compute the vehicle’s trajectory on the orbit.

static set_landed(vehicle, body, latitude, longitude)#

Place a vehicle on the surface of a body, as the game’s teleport window does, and return once it is there.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • body (KSA.Body) – The body to land on.

  • latitude (number) – The latitude, in degrees.

  • longitude (number) – The longitude, in degrees.

Note

Throws an exception if the body has no surface.

static set_position(vehicle, position, reference_frame)#

Move a vehicle to the given position, keeping its velocity, and return once it is there.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • position (Tuple) – The position of the vehicle, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

Note

This is the inverse of KSA.Vehicle.position(). The vehicle keeps orbiting the same body.

static set_velocity(vehicle, velocity, reference_frame)#

Set the velocity of a vehicle, keeping its position, and return once it is set.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • velocity (Tuple) – The velocity of the vehicle, in meters per second.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the velocity.

Note

This is the inverse of KSA.Vehicle.velocity(). The vehicle keeps orbiting the same body.

static set_rotation(vehicle, rotation, reference_frame)#

Set the rotation of a vehicle, and return once it is set.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • rotation (Tuple) – The rotation of the vehicle, as a quaternion of the form (x, y, z, w).

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Note

This is the inverse of KSA.Vehicle.rotation().

static set_angular_velocity(vehicle, angular_velocity, reference_frame)#

Set the angular velocity of a vehicle, and return once it is set.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle.

  • angular_velocity (Tuple) – The angular velocity, in radians per second. The vector points along the axis of rotation, and its length is the rate.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the angular velocity.

Note

This is the inverse of KSA.Vehicle.angular_velocity().

static fill_resources(vehicle)#

Fill the propellant, batteries and other consumables of a vehicle, as the game’s refill command does.

Parameters:

vehicle (KSA.Vehicle) – The vehicle.

static empty_resources(vehicle)#

Empty the propellant, batteries and other consumables of a vehicle, as the game’s empty command does.

Parameters:

vehicle (KSA.Vehicle) – The vehicle.

static duplicate_vehicle(vehicle, name)#

Create a copy of a vehicle beside it, as the game’s duplicate command does, and return once it is created.

Parameters:

  • vehicle (KSA.Vehicle) – The vehicle to copy.

  • name (string) – The name of the copy.

Returns:

The copy.

Return type:

KSA.Vehicle

Note

Throws an exception if the name is in use.

static explode_vehicle(vehicle)#

Destroy a vehicle in an explosion, as the game’s explode command does, and return once the vehicle is gone. Its crew are killed.

Parameters:

vehicle (KSA.Vehicle) – The vehicle.

static show_velocity_arrows(visible)#

Show or hide the game’s debug arrows for the velocities of the vehicles.

Parameters:

visible (boolean) – Whether to show the arrows.

static run_command(command)#

Run a command in the game’s console, as typed in the console.

Parameters:

command (string) – The command and its arguments.

Returns:

The console output of the command, one line per message.

Return type:

List

Note

Most commands write their messages to the game’s log, not the returned output. Throws an exception if the console has no such command, or the arguments are not valid.
