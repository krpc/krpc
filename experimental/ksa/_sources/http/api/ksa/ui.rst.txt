UI
==


.. _http-KSA.UI:

.. rubric:: UI

Adds windows of buttons, text fields and other widgets to the game's UI.

.. note::

   The windows are removed when the client that added them disconnects. For messages on
   the screen, see :http:post:`/ksa/show-message`.


A ``UI`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:post:: /ksa/ui/add-window

   Add a window, with no widgets.


   :reqjson string title: The text in the title bar.
   :reqjson bool visible: Whether the window is visible. Optional, defaults to ``true``.
   :resjson KSA.Window value:





.. http:post:: /ksa/ui/clear

   Remove the windows.


   :reqjson bool client_only: Whether to remove only the windows added by the calling client. Optional, defaults to ``false``.






.. _http-KSA.Window:

.. rubric:: Window

A window, holding widgets one per line. Created using :http:post:`/ksa/ui/add-window`.

.. note::

   The window fits its widgets until its size is set. Closing the window makes it
   invisible. The window is hidden with the game's UI.


A ``Window`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /ksa/window/(id)/title

   The text in the title bar.


   :param id: The identifier of the :ref:`Window <http-KSA.Window>` object.

   :resjson string value:

.. http:put:: /ksa/window/(id)/title

   :param id: The identifier of the :ref:`Window <http-KSA.Window>` object.

   :reqjson string value: The new value.

   game window, in pixels.
