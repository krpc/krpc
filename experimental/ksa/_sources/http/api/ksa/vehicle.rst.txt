Vehicle
=======


.. _http-KSA.Vehicle:

.. rubric:: Vehicle

A vehicle in the current system. Obtained from :http:get:`/ksa/active-vehicle`
or :http:get:`/ksa/vehicles`.

.. note::

   Docking and undocking replace the vehicles involved, so an object for one of them
   throws an exception afterwards.


A ``Vehicle`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

   :param id: The identifier of the :ref:`Vehicle <http-KSA.Vehicle>` object.

   :resjson string value:

.. _http-KSA.Situation:

.. rubric:: Situation

The situation of a vehicle: its contact with the surface, and whether the game is
simulating it with physics or propagating it along its orbit.
See :http:get:`/ksa/vehicle/(id)/situation`.

Passed and returned as the name of one of its values:


``"maneuvering"``
   No surface contact, simulated with physics.


``"freefall"``
   No surface contact, on rails.


``"rolling"``
   On terrain, simulated with physics.


``"landed"``
   At rest on terrain.


``"sailing"``
   In the ocean, simulated with physics.


``"floating"``
   At rest in the ocean.


``"dragging"``
   On terrain and in the ocean, simulated with physics.


``"bottomed"``
   At rest on terrain and in the ocean.



.. _http-KSA.ControlState:

.. rubric:: ControlState

Whether a vehicle can be flown, or why not. See :http:get:`/ksa/vehicle/(id)/control-state`.

Passed and returned as the name of one of its values:


``"controllable"``
   The vehicle can be flown.


``"no_control_module"``
   The vehicle has no control module, such as a capsule or a probe core.


``"no_crew"``
   The capsules have no crew, and no probe core is on.


``"crew_incapacitated"``
   Every kitten in the capsules is incapacitated, and no probe core is on.


``"probe_core_unpowered"``
   The probe core has no power.


``"probe_core_off"``
   The probe core is switched off.


``"probe_core_failed"``
   The probe core has failed from its radiation dose.


``"probe_core_storm_standby"``

.. _http-KSA.VehicleDesign:

.. rubric:: VehicleDesign

A vehicle design that can be launched: one of the game's default vehicles, or a vehicle
saved by the player in the editor. Obtained from :http:get:`/ksa/vehicle-designs`.

.. note::

   The mass and delta-v are those the editor shows for the design.


A ``VehicleDesign`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /ksa/vehicle-design/(id)/name

   The name of the design, as passed to :http:post:`/ksa/launch-vehicle`.


   :param id: The identifier of the :ref:`VehicleDesign <http-KSA.VehicleDesign>` object.

   :resjson string value:




.. http:get:: /ksa/vehicle-design/(id)/is-default

   Whether the design is one of the game's default vehicles.


   :param id: The identifier of the :ref:`VehicleDesign <http-KSA.VehicleDesign>` object.

   :resjson bool value:




.. http:get:: /ksa/vehicle-design/(id)/part-count

   :param id: The identifier of the :ref:`VehicleDesign <http-KSA.VehicleDesign>` object.

   :resjson int32 value:




.. http:get:: /ksa/vehicle-design/(id)/mass

   :param id: The identifier of the :ref:`VehicleDesign <http-KSA.VehicleDesign>` object.
