Drawing
=======


.. _http-KSA.Drawing:

.. rubric:: Drawing

Draws lines, shapes and text in the scene, each placed in a reference frame.

.. note::

   The objects are drawn every frame until removed, and are removed when the client that
   added them disconnects. Lines are drawn at the game's fixed gizmo width.


A ``Drawing`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:post:: /ksa/drawing/add-line

   Draw a line between two positions.


   :reqjson tuple<double, double, double> start: The position of the start of the line, in meters.
   :reqjson tuple<double, double, double> end: The position of the end of the line, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the positions.
   :reqjson bool visible: Whether the line is visible. Optional, defaults to ``true``.
   :resjson KSA.Line value:





.. http:post:: /ksa/drawing/add-direction

   Draw a line from the origin of a reference frame in a direction.


   :reqjson tuple<double, double, double> direction: The direction of the line.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the direction.
   :reqjson float length: The length of the line, in meters. Optional, defaults to ``1e+01``.
   :reqjson bool visible: Whether the line is visible. Optional, defaults to ``true``.
   :resjson KSA.Line value:





.. http:post:: /ksa/drawing/add-polyline

   Draw a line through a list of positions.


   :reqjson list<tuple<double, double, double>> vertices: The positions the line passes through, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the positions.
   :reqjson bool closed: Whether the line joins the last position back to the first. Optional, defaults to ``false``.
   :reqjson bool visible: Whether the line is visible. Optional, defaults to ``true``.
   :resjson KSA.Polyline value:





.. http:post:: /ksa/drawing/add-circle

   Draw a circle.


   :reqjson tuple<double, double, double> center: The position of the center of the circle, in meters.
   :reqjson tuple<double, double, double> normal: The direction normal to the plane of the circle.
   :reqjson float radius: The radius of the circle, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the position and direction.
   :reqjson bool visible: Whether the circle is visible. Optional, defaults to ``true``.
   :resjson KSA.Circle value:





.. http:post:: /ksa/drawing/add-arc

   Draw an arc of a circle.


   :reqjson tuple<double, double, double> center: The position of the center of the arc's circle, in meters.
   :reqjson tuple<double, double, double> normal: The direction normal to the plane of the arc.
   :reqjson tuple<double, double, double> start_direction: The direction from the center to the start of the arc.
   :reqjson float angle: The angle the arc turns through, counterclockwise about the normal, in radians.
   :reqjson float radius: The radius of the arc, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the position and directions.
   :reqjson bool visible: Whether the arc is visible. Optional, defaults to ``true``.
   :resjson KSA.Arc value:





.. http:post:: /ksa/drawing/add-box

   Draw the edges of a box.


   :reqjson tuple<double, double, double> center: The position of the center of the box, in meters.
   :reqjson tuple<double, double, double> size: The lengths of the box's edges along its x, y and z axes, in meters.
   :reqjson tuple<double, double, double, double> rotation: The rotation of the box's axes, as a quaternion of the form ``(x, y, z, w)``.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the position and rotation.
   :reqjson bool visible: Whether the box is visible. Optional, defaults to ``true``.
   :resjson KSA.Box value:





.. http:post:: /ksa/drawing/add-sphere

   Draw a solid sphere.


   :reqjson tuple<double, double, double> center: The position of the center of the sphere, in meters.
   :reqjson float radius: The radius of the sphere, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the position.
   :reqjson bool visible: Whether the sphere is visible. Optional, defaults to ``true``.
   :resjson KSA.Sphere value:





.. http:post:: /ksa/drawing/add-text

   Draw text over the scene, centered on a position.


   :reqjson string text: The text.
   :reqjson tuple<double, double, double> position: The position of the center of the text, in meters.
   :reqjson KSA.ReferenceFrame reference_frame: The reference frame of the position.
   :reqjson float size: The height of the font, in pixels. Optional, defaults to ``16.0``.
   :reqjson bool visible: Whether the text is visible. Optional, defaults to ``true``.
   :resjson KSA.Text value:





.. http:post:: /ksa/drawing/clear

   Remove the drawing objects.


   :reqjson bool client_only: Whether to remove only the objects added by the calling client. Optional, defaults to ``false``.
