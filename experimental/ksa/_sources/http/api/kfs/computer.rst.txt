Computer
========


.. _http-KFS.Computer:

.. rubric:: Computer

A vehicle's flight computer, which runs a kFS program. Obtained from
:http:post:`/kfs/computer`.

.. note::

   A program is written in kC, a subset of C, or in kASM. The calls that change the
   computer, and :http:post:`/kfs/computer/(id)/write-globals`, take effect before the computer's next tick, and
   return once they have. The computer ticks while the game is running and the vehicle is
   in the physics bubble, so until then they wait. The game does not save a program.


A ``Computer`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:post:: /kfs/computer/(id)/build

   Build a program, without loading it.


   :param id: The identifier of the :ref:`Computer <http-KFS.Computer>` object.

   :reqjson dictionary<string, string> files: The source files, by name. A program with a ``.c`` file is kC, and one with only ``.kasm`` files is kASM.
   :resjson list<KFS.Diagnostic> value: The errors and warnings.





.. http:post:: /kfs/computer/(id)/load

   Build a program and load it onto the computer. Throws an exception if the program has
   errors, or the computer rejects it.

   .. note::

      The program is in standby once loaded. See :http:post:`/kfs/computer/(id)/start`.


   :param id: The identifier of the :ref:`Computer <http-KFS.Computer>` object.

   :reqjson dictionary<string, string> files: The source files, by name, as for :http:post:`/kfs/computer/(id)/build`.





.. http:post:: /kfs/computer/(id)/start

   :param id: The identifier of the :ref:`Computer <http-KFS.Computer>` object.

.. http:post:: /kfs/computer/(id)/kill

   :param id: The identifier of the :ref:`Computer <http-KFS.Computer>` object.

.. http:post:: /kfs/computer/(id)/write-globals

   Write the program's global variables. The program sees all of them from the same
   tick.

   .. note::

      A value is converted to the variable's type. Throws an exception if a value does not
      fit, such as a fraction for an integer.


   :param id: The identifier of the :ref:`Computer <http-KFS.Computer>` object.

   :reqjson dictionary<string, double> values: The values, by the paths in :http:get:`/kfs/computer/(id)/globals`.

.. _http-KFS.ComputerState:

.. rubric:: ComputerState

The state of a flight computer. See :http:get:`/kfs/computer/(id)/state`.

Passed and returned as the name of one of its values:


``"no_software"``
   No program is loaded.


``"standby"``
   A program is loaded, and not running.


``"boot"``
   The program is running its initialization.


``"running"``
   The program is running.


``"idle"``
   The program is running, with no task to run.


``"halted"``
   The program has stopped, after a trap, a halt or the kill switch.



.. _http-KFS.ControlMode:

.. rubric:: ControlMode

The control a program has of a vehicle. See :http:get:`/kfs/computer/(id)/mode`.

Passed and returned as the name of one of its values:


``"pilot"``
   The game's flight computer flies the vehicle, and the program steers it.


``"full_control"``
   The program commands the thrusters, engines and gimbals itself. A program claims it
   with ``#pragma kfs claim ALLOCATION``.



.. _http-KFS.Diagnostic:

.. rubric:: Diagnostic

An error or warning from building a program. See :http:post:`/kfs/computer/(id)/build`.

Passed and returned as an object with these fields:


``error`` (bool)
   Whether it is an error. An error stops the program from being built.


``code`` (string)
   The diagnostic's code, such as ``KC-E016``.


``file`` (string)
   The source file.


``line`` (int32)
   The line in the source file, from 1. Zero for the whole file.


``column`` (int32)
   The column in the line, from 1.


``message`` (string)
   The message.


``hint`` (string?)
   A hint at the fix, or ``null`` if there is none.



.. _http-KFS.Trap:

.. rubric:: Trap

The error that halted a program, and where it happened. See :http:get:`/kfs/computer/(id)/trap`.

Passed and returned as an object with these fields:


``code`` (KFS.TrapCode)
   The error.


``function`` (string)
   The function that was running.


``file`` (string?)
   The source file, or ``null`` if it is not known.


``line`` (int32)
   The line in the source file, or zero if it is not known.



.. _http-KFS.TrapCode:

.. rubric:: TrapCode

The error that halted a program. See ``code``.

Passed and returned as the name of one of its values:


``"illegal_opcode"``
   An instruction the processor does not have.


``"operand_overflow"``
   The operand stack overflowed.


``"operand_underflow"``
   The operand stack underflowed.


``"return_overflow"``
   The return stack overflowed.


``"init_overrun"``
   The initialization ran past its budget.


``"stack_overflow"``
   The stack overflowed.


``"null_access"``
   A read or write through a null pointer.


``"bad_address"``
   A read or write outside memory.


``"read_only"``
   A write to read-only memory.


``"misaligned"``
   A misaligned read or write.


``"division_by_zero"``
   A division by zero.


``"bounds"``
   An array index out of bounds.


``"user"``
   A trap raised by the program.


``"bad_jump"``
   A jump to an invalid address.


``"bad_syscall"``
   A call to a service that does not exist.


``"bad_yield"``
   A task yielded where it may not.


``"memory_error"``
   A memory error, such as a radiation upset.
