Drawing
=======


.. type:: krpc_KSA_Drawing_t

   Draws lines, shapes and text in the scene, each placed in a reference frame.

   .. note::

      The objects are drawn every frame until removed, and are removed when the client that
      added them disconnects. Lines are drawn at the game's fixed gizmo width.

   .. function:: krpc_error_t krpc_KSA_Drawing_AddLine(krpc_connection_t connection, krpc_KSA_Line_t * returnValue, const krpc_tuple_double_double_double_t * start, const krpc_tuple_double_double_double_t * end, krpc_KSA_ReferenceFrame_t referenceFrame, bool visible)

      Draw a line between two positions.

      :Parameters:

       * **start** -- The position of the start of the line, in meters.
       * **end** -- The position of the end of the line, in meters.
       * **referenceFrame** -- The reference frame of the positions.
       * **visible** -- Whether the line is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddDirection(krpc_connection_t connection, krpc_KSA_Line_t * returnValue, const krpc_tuple_double_double_double_t * direction, krpc_KSA_ReferenceFrame_t referenceFrame, float length, bool visible)

      Draw a line from the origin of a reference frame in a direction.

      :Parameters:

       * **direction** -- The direction of the line.
       * **referenceFrame** -- The reference frame of the direction.
       * **length** -- The length of the line, in meters.
       * **visible** -- Whether the line is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddPolyline(krpc_connection_t connection, krpc_KSA_Polyline_t * returnValue, const krpc_list_tuple_double_double_double_t * vertices, krpc_KSA_ReferenceFrame_t referenceFrame, bool closed, bool visible)

      Draw a line through a list of positions.

      :Parameters:

       * **vertices** -- The positions the line passes through, in meters.
       * **referenceFrame** -- The reference frame of the positions.
       * **closed** -- Whether the line joins the last position back to the first.
       * **visible** -- Whether the line is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddCircle(krpc_connection_t connection, krpc_KSA_Circle_t * returnValue, const krpc_tuple_double_double_double_t * center, const krpc_tuple_double_double_double_t * normal, float radius, krpc_KSA_ReferenceFrame_t referenceFrame, bool visible)

      Draw a circle.

      :Parameters:

       * **center** -- The position of the center of the circle, in meters.
       * **normal** -- The direction normal to the plane of the circle.
       * **radius** -- The radius of the circle, in meters.
       * **referenceFrame** -- The reference frame of the position and direction.
       * **visible** -- Whether the circle is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddArc(krpc_connection_t connection, krpc_KSA_Arc_t * returnValue, const krpc_tuple_double_double_double_t * center, const krpc_tuple_double_double_double_t * normal, const krpc_tuple_double_double_double_t * startDirection, float angle, float radius, krpc_KSA_ReferenceFrame_t referenceFrame, bool visible)

      Draw an arc of a circle.

      :Parameters:

       * **center** -- The position of the center of the arc's circle, in meters.
       * **normal** -- The direction normal to the plane of the arc.
       * **startDirection** -- The direction from the center to the start of the arc.
       * **angle** -- The angle the arc turns through, counterclockwise about the normal, in radians.
       * **radius** -- The radius of the arc, in meters.
       * **referenceFrame** -- The reference frame of the position and directions.
       * **visible** -- Whether the arc is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddBox(krpc_connection_t connection, krpc_KSA_Box_t * returnValue, const krpc_tuple_double_double_double_t * center, const krpc_tuple_double_double_double_t * size, const krpc_tuple_double_double_double_double_t * rotation, krpc_KSA_ReferenceFrame_t referenceFrame, bool visible)

      Draw the edges of a box.

      :Parameters:

       * **center** -- The position of the center of the box, in meters.
       * **size** -- The lengths of the box's edges along its x, y and z axes, in meters.
       * **rotation** -- The rotation of the box's axes, as a quaternion of the form ``(x, y, z, w)``.
       * **referenceFrame** -- The reference frame of the position and rotation.
       * **visible** -- Whether the box is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddSphere(krpc_connection_t connection, krpc_KSA_Sphere_t * returnValue, const krpc_tuple_double_double_double_t * center, float radius, krpc_KSA_ReferenceFrame_t referenceFrame, bool visible)

      Draw a solid sphere.

      :Parameters:

       * **center** -- The position of the center of the sphere, in meters.
       * **radius** -- The radius of the sphere, in meters.
       * **referenceFrame** -- The reference frame of the position.
       * **visible** -- Whether the sphere is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_AddText(krpc_connection_t connection, krpc_KSA_Text_t * returnValue, const char * text, const krpc_tuple_double_double_double_t * position, krpc_KSA_ReferenceFrame_t referenceFrame, float size, bool visible)

      Draw text over the scene, centered on a position.

      :Parameters:

       * **text** -- The text.
       * **position** -- The position of the center of the text, in meters.
       * **referenceFrame** -- The reference frame of the position.
       * **size** -- The height of the font, in pixels.
       * **visible** -- Whether the text is visible.

   

   .. function:: krpc_error_t krpc_KSA_Drawing_Clear(krpc_connection_t connection, bool clientOnly)

      Remove the drawing objects.

      :Parameters:

       * **clientOnly** -- Whether to remove only the objects added by the calling client.
