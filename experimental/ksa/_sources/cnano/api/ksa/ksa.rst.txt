KSA
===


Provides functionality to interact with Kitten Space Agency.


.. function:: krpc_error_t krpc_KSA_ActiveVehicle(krpc_connection_t connection, krpc_KSA_Vehicle_t * returnValue)
.. function:: krpc_error_t krpc_KSA_set_ActiveVehicle(krpc_connection_t connection, krpc_KSA_Vehicle_t value)

   The vehicle under the player's control, or ``nullptr`` if the player controls a
   kitten on EVA.

   

   .. note::

      Setting it moves the camera to the vehicle, as the switch vehicle key does. See
      :func:`krpc_KSA_ActiveKitten` for a kitten on EVA.




.. function:: krpc_error_t krpc_KSA_Vehicles(krpc_connection_t connection, krpc_list_object_t * returnValue)

   The vehicles in the current system, excluding kittens on EVA.

   




.. function:: krpc_error_t krpc_KSA_ActiveKitten(krpc_connection_t connection, krpc_KSA_Kitten_t * returnValue)
.. function:: krpc_error_t krpc_KSA_set_ActiveKitten(krpc_connection_t connection, krpc_KSA_Kitten_t value)

   The kitten on EVA under the player's control, or ``nullptr`` if the player
   controls a vehicle.

   

   .. note::

      Setting it moves the camera to the kitten. Throws an exception if the kitten is not
      on EVA. See :func:`krpc_KSA_ActiveVehicle` for a vehicle.

   The kittens in the agency's roster, including those killed in action, keyed by name.

   The planets, moons and stars in the current system, keyed by name.

   




.. function:: krpc_error_t krpc_KSA_UT(krpc_connection_t connection, double * returnValue)

.. function:: krpc_error_t krpc_KSA_SimulationSpeed(krpc_connection_t connection, float * returnValue)
.. function:: krpc_error_t krpc_KSA_set_SimulationSpeed(krpc_connection_t connection, float value)

   The simulation speed, as a multiple of real time. Zero when paused.

   




.. function:: krpc_error_t krpc_KSA_WarpTo(krpc_connection_t connection, double ut)

   Warp to the given universal time, and return once the warp has finished.
   The game slows the warp down to normal speed toward the end.

   :Parameters:

    * **ut** -- The universal time to warp to, in seconds.

   

   .. note::

      Does nothing when the time is in the past. Returns early if the game stops the
      warp, for example when its menu pauses the game.




.. function:: krpc_error_t krpc_KSA_VehicleDesigns(krpc_connection_t connection, krpc_dictionary_string_object_t * returnValue)

   The vehicle designs that can be launched, keyed by name.

   




.. function:: krpc_error_t krpc_KSA_LaunchVehicle(krpc_connection_t connection, krpc_KSA_Vehicle_t * returnValue, const char * name, const char * site)

   Launch a vehicle from a launch site, and make it the active vehicle. Returns once
   the vehicle is on the launch site.

   :Parameters:

    * **name** -- The name of the vehicle design. See :func:`krpc_KSA_VehicleDesigns`.
    * **site** -- The name of the launch site. See :func:`krpc_KSA_Body_LaunchSites`.

   :returns: The vehicle. Its name is the vehicle's name, with a number appended if another vehicle has that name.
   

   .. note::

      Throws an exception if there is no such vehicle or launch site, or the name is one
      of the game's kittens.

    * **name** -- Name of the save.

   




.. function:: krpc_error_t krpc_KSA_Save(krpc_connection_t connection, const char * name)

   :Parameters:

    * **name** -- Name of the save.

   




.. function:: krpc_error_t krpc_KSA_Load(krpc_connection_t connection, const char * name)

   Load a save, and return once it has loaded. The game is paused after loading.

   :Parameters:

    * **name** -- Name of the save.

   

   .. note::

      Throws an exception if the save does not exist.




.. function:: krpc_error_t krpc_KSA_TakeScreenshot(krpc_connection_t connection, char * * returnValue, int32_t scale, bool ui)

   Save a screenshot, as the screenshot key does, and return once the file is written.

   :Parameters:

    * **scale** -- The size of the image, as a multiple of the window size, from 1 to 8. The game reduces it to fit the graphics memory.
    * **ui** -- Whether to include the game's windows. The image is then the size of the window.

   :returns: The path of the PNG file, in the game's screenshots folder.
   

   .. note::

      Throws an exception in the vehicle editor, or if a screenshot is already being taken.




.. function:: krpc_error_t krpc_KSA_ShowMessage(krpc_connection_t connection, const char * text, float duration, bool warning)

   Show a message in the middle of the screen.

   :Parameters:

    * **text** -- The message.
    * **duration** -- How long to show the message for, in seconds. The game shows a message for at least 2 seconds.
    * **warning** -- Whether to show the message in the warning color.

   




.. function:: krpc_error_t krpc_KSA_TransformPosition(krpc_connection_t connection, krpc_tuple_double_double_double_t * returnValue, const krpc_tuple_double_double_double_t * position, krpc_KSA_ReferenceFrame_t from, krpc_KSA_ReferenceFrame_t to)

   Convert a position from one reference frame to another.

.. function:: krpc_error_t krpc_KSA_TransformVelocity(krpc_connection_t connection, krpc_tuple_double_double_double_t * returnValue, const krpc_tuple_double_double_double_t * position, const krpc_tuple_double_double_double_t * velocity, krpc_KSA_ReferenceFrame_t from, krpc_KSA_ReferenceFrame_t to)

   Convert a velocity from one reference frame to another. The velocity of a point
   depends on its position in a rotating frame, so the position is also needed.

   :Parameters:

    * **position** -- Position, in meters, in the frame *from*.
    * **velocity** -- Velocity, in meters per second, in the frame *from*.
    * **from** -- The reference frame the position and velocity are in.
    * **to** -- The reference frame to convert the velocity to.

   :returns: The velocity in the frame *to*.
