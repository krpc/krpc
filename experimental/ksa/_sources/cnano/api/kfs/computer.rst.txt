Computer
========


.. type:: krpc_KFS_Computer_t

   A vehicle's flight computer, which runs a kFS program. Obtained from
   :func:`krpc_KFS_Computer`.

   .. note::

      A program is written in kC, a subset of C, or in kASM. The calls that change the
      computer, and :func:`krpc_KFS_Computer_WriteGlobals`, take effect before the computer's next tick, and
      return once they have. The computer ticks while the game is running and the vehicle is
      in the physics bubble, so until then they wait. The game does not save a program.

   .. macro:: KRPC_CLASS_KFS_COMPUTER

      The service and class ids of the class, for :func:`krpc_KRPC_Type_ClassTypeById`.

   .. function:: krpc_error_t krpc_KFS_Computer_Build(krpc_connection_t connection, krpc_list_KFS_Diagnostic_t * returnValue, krpc_KFS_Computer_t instance, const krpc_dictionary_string_string_t * files)

      Build a program, without loading it.

      :Parameters:

       * **files** -- The source files, by name. A program with a ``.c`` file is kC, and one with only ``.kasm`` files is kASM.

      :returns: The errors and warnings.
      :Game Scenes: Flight

   .. function:: krpc_error_t krpc_KFS_Computer_Load(krpc_connection_t connection, krpc_KFS_Computer_t instance, const krpc_dictionary_string_string_t * files)

      Build a program and load it onto the computer. Throws an exception if the program has
      errors, or the computer rejects it.

      :Parameters:

       * **files** -- The source files, by name, as for :func:`krpc_KFS_Computer_Build`.

      :Game Scenes: Flight


      .. note::

         The program is in standby once loaded. See :func:`krpc_KFS_Computer_Start`.

      :func:`krpc_KRPC_Type_EnumerationTypeById` and :func:`krpc_KRPC_Expression_ConstantEnumById`.
