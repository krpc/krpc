Drawing
=======


.. class:: Drawing

   Draws lines, shapes and text in the scene, each placed in a reference frame.

   .. note::

      The objects are drawn every frame until removed, and are removed when the client that
      added them disconnects. Lines are drawn at the game's fixed gizmo width.

   .. function:: static Line add_line(Client& connection, std::tuple<double, double, double> start, std::tuple<double, double, double> end, ReferenceFrame reference_frame, bool visible = true)

      Draw a line between two positions.

      :Parameters:

       * **start** -- The position of the start of the line, in meters.
       * **end** -- The position of the end of the line, in meters.
       * **reference_frame** -- The reference frame of the positions.
       * **visible** -- Whether the line is visible.

   

   .. function:: static Line add_direction(Client& connection, std::tuple<double, double, double> direction, ReferenceFrame reference_frame, float length = 1e+01f, bool visible = true)

      Draw a line from the origin of a reference frame in a direction.

      :Parameters:

       * **direction** -- The direction of the line.
       * **reference_frame** -- The reference frame of the direction.
       * **length** -- The length of the line, in meters.
       * **visible** -- Whether the line is visible.

   

   .. function:: static Polyline add_polyline(Client& connection, std::vector<std::tuple<double, double, double>> vertices, ReferenceFrame reference_frame, bool closed = false, bool visible = true)

      Draw a line through a list of positions.

      :Parameters:

       * **vertices** -- The positions the line passes through, in meters.
       * **reference_frame** -- The reference frame of the positions.
       * **closed** -- Whether the line joins the last position back to the first.
       * **visible** -- Whether the line is visible.

   

   .. function:: static Circle add_circle(Client& connection, std::tuple<double, double, double> center, std::tuple<double, double, double> normal, float radius, ReferenceFrame reference_frame, bool visible = true)

      Draw a circle.

      :Parameters:

       * **center** -- The position of the center of the circle, in meters.
       * **normal** -- The direction normal to the plane of the circle.
       * **radius** -- The radius of the circle, in meters.
       * **reference_frame** -- The reference frame of the position and direction.
       * **visible** -- Whether the circle is visible.

   

   .. function:: static Arc add_arc(Client& connection, std::tuple<double, double, double> center, std::tuple<double, double, double> normal, std::tuple<double, double, double> start_direction, float angle, float radius, ReferenceFrame reference_frame, bool visible = true)

      Draw an arc of a circle.

      :Parameters:

       * **center** -- The position of the center of the arc's circle, in meters.
       * **normal** -- The direction normal to the plane of the arc.
       * **start_direction** -- The direction from the center to the start of the arc.
       * **angle** -- The angle the arc turns through, counterclockwise about the normal, in radians.
       * **radius** -- The radius of the arc, in meters.
       * **reference_frame** -- The reference frame of the position and directions.
       * **visible** -- Whether the arc is visible.

   

   .. function:: static Box add_box(Client& connection, std::tuple<double, double, double> center, std::tuple<double, double, double> size, std::tuple<double, double, double, double> rotation, ReferenceFrame reference_frame, bool visible = true)

      Draw the edges of a box.

      :Parameters:

       * **center** -- The position of the center of the box, in meters.
       * **size** -- The lengths of the box's edges along its x, y and z axes, in meters.
       * **rotation** -- The rotation of the box's axes, as a quaternion of the form ``(x, y, z, w)``.
       * **reference_frame** -- The reference frame of the position and rotation.
       * **visible** -- Whether the box is visible.

   

   .. function:: static Sphere add_sphere(Client& connection, std::tuple<double, double, double> center, float radius, ReferenceFrame reference_frame, bool visible = true)

      Draw a solid sphere.

      :Parameters:

       * **center** -- The position of the center of the sphere, in meters.
       * **radius** -- The radius of the sphere, in meters.
       * **reference_frame** -- The reference frame of the position.
       * **visible** -- Whether the sphere is visible.

   

   .. function:: static Text add_text(Client& connection, std::string text, std::tuple<double, double, double> position, ReferenceFrame reference_frame, float size = 16.0f, bool visible = true)

      Draw text over the scene, centered on a position.

      :Parameters:

       * **text** -- The text.
       * **position** -- The position of the center of the text, in meters.
       * **reference_frame** -- The reference frame of the position.
       * **size** -- The height of the font, in pixels.
       * **visible** -- Whether the text is visible.

   

   .. function:: static void clear(Client& connection, bool client_only = false)

      Remove the drawing objects.

      :Parameters:

       * **client_only** -- Whether to remove only the objects added by the calling client.
