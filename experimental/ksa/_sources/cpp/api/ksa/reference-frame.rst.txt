Reference Frame
===============


.. class:: ReferenceFrame

   A reference frame, in which positions, directions, rotations and velocities are given.
   Obtained from the reference frame properties of :class:`Vehicle` and
   :class:`Body`, or created with :func:`ReferenceFrame::create_relative` and
   :func:`ReferenceFrame::create_hybrid`.

   .. note::

      Every reference frame is right-handed. Positions are in meters, velocities in meters
      per second, and angular velocities in radians per second. A rotation is a quaternion
      ``(x, y, z, w)``.

   .. function:: static ReferenceFrame create_relative(Client& connection, ReferenceFrame reference_frame, std::tuple<double, double, double> position = std::tuple<double, double, double>{0.0, 0.0, 0.0}, std::tuple<double, double, double, double> rotation = std::tuple<double, double, double, double>{0.0, 0.0, 0.0, 1.0}, std::tuple<double, double, double> velocity = std::tuple<double, double, double>{0.0, 0.0, 0.0}, std::tuple<double, double, double> angular_velocity = std::tuple<double, double, double>{0.0, 0.0, 0.0})

      Create a reference frame that is offset from a parent frame.

      :Parameters:

       * **reference_frame** -- The parent reference frame.
       * **position** -- The position of the origin in the parent frame, in meters. Defaults to ``(0, 0, 0)``.
       * **rotation** -- The rotation of the frame relative to the parent frame. Defaults to ``(0, 0, 0, 1)``, no rotation.
       * **velocity** -- The velocity of the origin in the parent frame, in meters per second. Defaults to ``(0, 0, 0)``.
       * **angular_velocity** -- The angular velocity of the frame relative to the parent frame, in radians per second, in the axes of the parent frame. Defaults to ``(0, 0, 0)``.

   

   .. function:: static ReferenceFrame create_hybrid(Client& connection, ReferenceFrame position, std::optional<ReferenceFrame> rotation = std::optional<ReferenceFrame>(), std::optional<ReferenceFrame> velocity = std::optional<ReferenceFrame>(), std::optional<ReferenceFrame> angular_velocity = std::optional<ReferenceFrame>())

      Create a reference frame that takes its components from other frames.

      :Parameters:

       * **position** -- The reference frame that gives the origin.
       * **rotation** -- The reference frame that gives the axes. Defaults to *position*.
       * **velocity** -- The reference frame that gives the velocity of the origin. Defaults to *position*.
       * **angular_velocity** -- The reference frame that gives the angular velocity. Defaults to *position*.
