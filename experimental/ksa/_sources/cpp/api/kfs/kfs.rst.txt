Service
=======


.. namespace:: krpc::services
.. class:: KFS : public krpc::RemoteService

   Provides access to kFS, the game's flight software: programs that run on a vehicle's
   flight computer.

   .. note::

      kFS is a prototype in the game, and is off until it is turned on, by setting
      :func:`available` or with the game's ``kfs on`` console command. This service
      follows the prototype, and changes with it.

   .. function:: KFS(krpc::Connection& connection)

      Construct an instance of this service.

   .. function:: bool available()
   .. function:: void set_available(bool value)

      Returns whether kFS is on, and turns it on or off.

      :Game Scenes: Flight


      .. note::

         Turning it off stops every program, and gives each vehicle back to the pilot, as the
         game's ``kfs off`` console command does.

   .. function:: Computer computer(KSA::Vehicle vehicle)

      The flight computer of a vehicle. Throws an exception if kFS is off.

      :Parameters:

       * **vehicle** -- The vehicle.

      :Game Scenes: Flight
