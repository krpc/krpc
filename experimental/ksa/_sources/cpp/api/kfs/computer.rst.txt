Computer
========


.. class:: Computer

   A vehicle's flight computer, which runs a kFS program. Obtained from
   :func:`computer`.

   .. note::

      A program is written in kC, a subset of C, or in kASM. The calls that change the
      computer, and :func:`Computer::write_globals`, take effect before the computer's next tick, and
      return once they have. The computer ticks while the game is running and the vehicle is
      in the physics bubble, so until then they wait. The game does not save a program.

   .. function:: std::vector<Diagnostic> build(std::map<std::string, std::string> files)

      Build a program, without loading it.

      :Parameters:

       * **files** -- The source files, by name. A program with a ``.c`` file is kC, and one with only ``.kasm`` files is kASM.

      :returns: The errors and warnings.
      :Game Scenes: Flight

   .. function:: void load(std::map<std::string, std::string> files)

      Build a program and load it onto the computer. Throws an exception if the program has
      errors, or the computer rejects it.

      :Parameters:

       * **files** -- The source files, by name, as for :func:`Computer::build`.

      :Game Scenes: Flight


      .. note::

         The program is in standby once loaded. See :func:`Computer::start`.

   .. function:: void start()

      Start the loaded program. Throws an exception if no program is loaded.


      :Game Scenes: Flight

   .. function:: void reset()

      Restart the loaded program, as the reset button does. Throws an exception if no
      program is loaded.


      :Game Scenes: Flight

   .. function:: void stop()

      Stop the program, and give the vehicle back to the pilot. The program stays loaded.


      :Game Scenes: Flight

   .. function:: void kill()

      Halt the program with the kill switch, and give the vehicle back to the pilot.


      :Game Scenes: Flight

   .. function:: ComputerState state()

      The state of the computer.

      :Game Scenes: Flight

   .. function:: ControlMode mode()

      The control mode the loaded program claims.

      :Game Scenes: Flight

   .. function:: bool under_control()

      Whether the program controls the vehicle: it is running, or halted with its last
      commands held.

      :Game Scenes: Flight

   .. function:: int32_t tick_rate()

      The ticks per second of the loaded program, or zero if no program is loaded.

      :Game Scenes: Flight

   .. function:: int64_t cycles_used()

      The processor cycles the latest tick used.

      :Game Scenes: Flight

   .. function:: int64_t cycle_budget()

      The processor cycles a tick may use.

      :Game Scenes: Flight

   .. function:: int64_t overruns()

      The number of ticks that ran past their budget since the program started.

      :Game Scenes: Flight

   .. function:: std::optional<Trap> trap()

      The error that halted the program, or ``NULL`` if no error halted it.

      :Game Scenes: Flight

   .. function:: std::optional<std::string> fault()

      The game's error that halted the computer, or ``NULL`` if there is none.

      :Game Scenes: Flight

   .. function:: std::vector<std::string> log()

      The computer's console: the lines the program logs, and the computer's own messages.

      :Game Scenes: Flight


      .. note::

         The computer keeps the last 4,096 lines, and a program logs at most 10 lines a
         second.

   .. function:: void clear_log()

      Clear the computer's console.


      :Game Scenes: Flight

   .. function:: std::vector<std::string> globals()

      The paths of the loaded program's global variables, one for each number in them,
      such as ``command.args[2]``.

      :Game Scenes: Flight

   .. function:: double read_global(std::string path)

      The value of one of the program's global variables, as of its latest tick.

      :Parameters:

       * **path** -- The path of the variable, as in :func:`Computer::globals`.

      :Game Scenes: Flight

   .. function:: void write_globals(std::map<std::string, double> values)

      Write the program's global variables. The program sees all of them from the same
      tick.

      :Parameters:

       * **values** -- The values, by the paths in :func:`Computer::globals`.

      :Game Scenes: Flight


      .. note::

         A value is converted to the variable's type. Throws an exception if a value does not
         fit, such as a fraction for an integer.

   .. function:: std::vector<std::string> trace_channels()

      The names of the channels the program has traced to.

      :Game Scenes: Flight

   .. function:: float trace(std::string channel)

      The latest value the program traced to a channel. Throws an exception if the program
      has not traced to it.

      :Parameters:

       * **channel** -- The name of the channel.

      :Game Scenes: Flight



.. namespace:: krpc::services::KFS
.. enum-struct:: ComputerState

   The state of a flight computer. See :func:`Computer::state`.


   .. enumerator:: no_software

      No program is loaded.


   .. enumerator:: standby

      A program is loaded, and not running.


   .. enumerator:: boot

      The program is running its initialization.


   .. enumerator:: running

      The program is running.


   .. enumerator:: idle

      The program is running, with no task to run.


   .. enumerator:: halted

      The program has stopped, after a trap, a halt or the kill switch.



.. namespace:: krpc::services::KFS
.. enum-struct:: ControlMode

   The control a program has of a vehicle. See :func:`Computer::mode`.


   .. enumerator:: pilot

      The game's flight computer flies the vehicle, and the program steers it.


   .. enumerator:: full_control

      The program commands the thrusters, engines and gimbals itself. A program claims it
      with ``#pragma kfs claim ALLOCATION``.



.. namespace:: krpc::services::KFS
.. struct:: Diagnostic

   An error or warning from building a program. See :func:`Computer::build`.


   .. member:: bool error

      Whether it is an error. An error stops the program from being built.

   .. member:: std::string code

      The diagnostic's code, such as ``KC-E016``.

   .. member:: std::string file

      The source file.

   .. member:: int32_t line

      The line in the source file, from 1. Zero for the whole file.

   .. member:: int32_t column

      The column in the line, from 1.

   .. member:: std::string message

      The message.

   .. member:: std::optional<std::string> hint

      A hint at the fix, or ``NULL`` if there is none.


.. namespace:: krpc::services::KFS
.. struct:: Trap

   The error that halted a program, and where it happened. See :func:`Computer::trap`.


   .. member:: TrapCode code

      The error.

   .. member:: std::string function

      The function that was running.

   .. member:: std::optional<std::string> file

      The source file, or ``NULL`` if it is not known.

   .. member:: int32_t line

      The line in the source file, or zero if it is not known.


.. namespace:: krpc::services::KFS
.. enum-struct:: TrapCode

   The error that halted a program. See :member:`Trap::code`.


   .. enumerator:: illegal_opcode

      An instruction the processor does not have.


   .. enumerator:: operand_overflow

      The operand stack overflowed.


   .. enumerator:: operand_underflow

      The operand stack underflowed.


   .. enumerator:: return_overflow

      The return stack overflowed.


   .. enumerator:: init_overrun

      The initialization ran past its budget.


   .. enumerator:: stack_overflow

      The stack overflowed.


   .. enumerator:: null_access

      A read or write through a null pointer.


   .. enumerator:: bad_address

      A read or write outside memory.


   .. enumerator:: read_only

      A write to read-only memory.


   .. enumerator:: misaligned

      A misaligned read or write.


   .. enumerator:: division_by_zero

      A division by zero.


   .. enumerator:: bounds

      An array index out of bounds.


   .. enumerator:: user

      A trap raised by the program.


   .. enumerator:: bad_jump

      A jump to an invalid address.


   .. enumerator:: bad_syscall

      A call to a service that does not exist.


   .. enumerator:: bad_yield

      A task yielded where it may not.


   .. enumerator:: memory_error

      A memory error, such as a radiation upset.
