Parts
=====


.. class:: Part

   A part of a vehicle. Obtained from :attr:`Vehicle.parts`.

   .. note::

      A part keeps its object when the vehicle it belongs to changes, for example when a
      decoupler separates it. Throws an exception once the part no longer exists.

   .. attribute:: name

      The id of the part's template.

      :Attribute: Read-only, cannot be set
      :rtype: str
   

   .. attribute:: title

      The name of the part, as shown in the game.

      :Attribute: Read-only, cannot be set
      :rtype: str
   

   .. attribute:: vehicle

      The vehicle the part belongs to.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Vehicle`
   

   .. attribute:: parent

      The part this part is attached to, or ``None`` for the root part.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part` or None
   

   .. attribute:: children

      The parts attached to this part.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Part`)
   

   .. attribute:: sequence

      The number of the sequence that activates the part, or -1 if no sequence does.

      :Attribute: Read-only, cannot be set
      :rtype: int
   

   .. attribute:: mass

      The mass of the part, including its propellant, in kilograms.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: dry_mass

      The mass of the part without its propellant, in kilograms.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: resources

      The resources the part holds, one for each substance.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Resource`)
   

   .. attribute:: tanks

      The part's propellant tanks. Empty if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Tank`)
   

   .. attribute:: batteries

      The part's batteries.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Battery`)
   

   .. attribute:: solar_panels

      The part's solar panels.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`SolarPanel`)
   

   .. attribute:: generators

      The part's generators.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Generator`)
   

   .. attribute:: power_consumers

      The part's power consumers.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`PowerConsumer`)
   

   .. attribute:: lights

      The part's lights.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Light`)
   

   .. attribute:: deployables

      The part's deployable sections. A part can have several, such as the doors of a
      service module.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Deployable`)
   

   .. attribute:: magnetic_scoops

      The part's magnetic scoops. Empty if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`MagneticScoop`)
   

   .. method:: position(reference_frame)

      The position of the part's origin, in meters.

      :param ReferenceFrame reference_frame: The reference frame of the position.
      :rtype: tuple(float, float, float)
   

   .. method:: velocity(reference_frame)

      The velocity of the part's origin, in meters per second.

      :param ReferenceFrame reference_frame: The reference frame of the velocity.
      :rtype: tuple(float, float, float)
   

   .. method:: rotation(reference_frame)

      The rotation of the part's axes, relative to the given frame.

      :param ReferenceFrame reference_frame: The reference frame of the rotation.
      :rtype: tuple(float, float, float, float)
   

   .. attribute:: engine

      The part's engine, or ``None`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Engine` or None
   

   .. attribute:: gimbals

      The part's gimbals. An engine part can have several, each steering one nozzle.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Gimbal`)
   

   .. attribute:: rcs

      The part's RCS thrusters, or ``None`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`RCS` or None
   

   .. attribute:: decoupler

      The part's decoupler, or ``None`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Decoupler` or None
   

   .. attribute:: parachute

      The part's parachute, or ``None`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Parachute` or None
   

   .. attribute:: docking_port

      The part's docking port, or ``None`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`DockingPort` or None
   

   .. attribute:: seats

      The part's crew seats.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Seat`)
   

   .. attribute:: crew

      The kittens in the part's seats.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Kitten`)
   



.. class:: Engine

   An engine. Obtained from :attr:`Part.engine`.

   .. note::

      An active engine fires when the vehicle's engines are on, at the vehicle's throttle.
      See :attr:`Control.engine_on` and :attr:`Control.throttle`.

   .. attribute:: part

      The part the engine is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: gimbals

      The gimbals that steer the engine's nozzles. Empty if the engine has none.

      :Attribute: Read-only, cannot be set
      :rtype: list(:class:`Gimbal`)
   

   .. attribute:: active

      Whether the engine is active, as when its sequence is activated. Setting it returns
      once the change has applied.

      :Attribute: Can be read or written
      :rtype: bool
   

   .. attribute:: has_propellant

      Whether the engine has propellant to burn.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. attribute:: minimum_throttle

      The lowest throttle the engine runs at, between 0 and 1.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: propellants

      The names of the substances the engine burns. See :attr:`Resource.name`.

      :Attribute: Read-only, cannot be set
      :rtype: list(str)
   

   .. attribute:: thrust

      The thrust of the engine at its current throttle and the current atmospheric
      pressure, in Newtons. Zero when it is not firing.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: available_thrust

      The thrust of the engine at full throttle and the current atmospheric pressure, in
      Newtons. Zero when it is inactive or has no propellant.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: specific_impulse

      The specific impulse of the engine at the current atmospheric pressure, in seconds.
      Zero when it is inactive or has no propellant.

      :Attribute: Read-only, cannot be set
      :rtype: float
   



.. class:: Gimbal

   A gimbal that steers an engine nozzle. Obtained from :attr:`Part.gimbals` or
   :attr:`Engine.gimbals`.

   .. note::

      A gimbal turns about the y and z axes of its mount, which :meth:`Gimbal.rotation` gives.
      The flight computer steers it while an engine it belongs to is :attr:`Gimbal.active`.

   .. attribute:: part

      The part the gimbal is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: angle_y

      The angle of the gimbal about its y axis, in degrees.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: angle_z

      The angle of the gimbal about its z axis, in degrees.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: max_angle_y

      The largest angle of the gimbal about its y axis, in degrees. Zero if it does not
      turn about that axis.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: max_angle_z

      The largest angle of the gimbal about its z axis, in degrees. Zero if it does not
      turn about that axis.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: active

      Whether an engine the gimbal steers is active.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. method:: rotation(reference_frame)

      The rotation of the gimbal's mount, whose y and z axes the gimbal turns about.

      :param ReferenceFrame reference_frame: The reference frame of the rotation.
      :rtype: tuple(float, float, float, float)
   



.. class:: RCS

   The RCS thrusters of a part. Obtained from :attr:`Part.rcs`.

   .. note::

      Active thrusters fire when the vehicle's RCS is on. See :attr:`Control.rcs`.

   .. attribute:: part

      The part the thrusters are in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: active

      Whether the thrusters are active. Setting it returns once the change has applied.

      :Attribute: Can be read or written
      :rtype: bool
   



.. class:: Decoupler

   A decoupler. Obtained from :attr:`Part.decoupler`.

   .. attribute:: part

      The part the decoupler is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: enabled

      Whether the decoupler can fire.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. attribute:: decoupled

      Whether the decoupler has fired, or is attached to nothing.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. method:: decouple()

      Fire the decoupler, separating the vehicle into two. Returns once it has fired.
      Throws an exception if the decoupler is disabled or :attr:`Decoupler.decoupled`.

      :returns: The vehicles that separated from this one.
      :rtype: list(:class:`Vehicle`)
   



.. class:: Parachute

   A parachute. Obtained from :attr:`Part.parachute`.

   .. attribute:: part

      The part the parachute is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: state

      The state of the parachute.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`ParachuteState`
   

   .. attribute:: fill

      How far the canopy is open, from 0 to 1.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: deploy_altitude

      The height above the terrain at which an armed parachute deploys, in meters.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: can_cut

      Whether the parachute can be cut away. Main parachutes cannot.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. method:: deploy()

      Arm the parachute, so that it deploys at :attr:`Parachute.deploy_altitude`. Returns once
      it is armed. Throws an exception if it is not stowed.

   

   .. method:: cut()

      Cut the parachute away. Returns once it is cut. Throws an exception if it cannot
      be cut. See :attr:`Parachute.can_cut`.

   



.. class:: ParachuteState

   The state of a parachute. See :attr:`Parachute.state`.


   .. data:: stowed

      Packed away.


   .. data:: armed

      Waiting to deploy at :attr:`Parachute.deploy_altitude`.


   .. data:: line_stretch

      Leaving the pack.


   .. data:: reefed

      Partly open, to limit the opening load.


   .. data:: disreefing

      Opening from reefed to full.


   .. data:: full

      Fully open.


   .. data:: cut

      Cut away.


   .. data:: ripped

      Torn by too much dynamic pressure.


   .. data:: severed_lines

      Lost after its lines broke under too much load.



.. class:: DockingPort

   A docking port. Obtained from :attr:`Part.docking_port`.

   .. attribute:: part

      The part the docking port is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: docked

      Whether the port is docked.

      :Attribute: Read-only, cannot be set
      :rtype: bool
   

   .. attribute:: docked_part

      The part the port is docked to, or ``None`` if it is not docked.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part` or None
   

   .. method:: undock()

      Undock the port, separating the vehicle into two. Returns once it has undocked.
      Throws an exception if the port is not docked.

      :returns: The new vehicles.
      :rtype: list(:class:`Vehicle`)
   

      .. note::

         Docking and undocking replace the vehicles involved. See :class:`Vehicle`.



.. class:: Deployable

   A part that deploys and retracts, such as a landing leg, a solar panel or a service
   module door. Obtained from :attr:`Part.deployables`.

   .. note::

      Deploying or retracting a part moves its symmetric copies with it, as the part's menu
      in the game does.

   .. attribute:: part

      The part the deployable is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: state

      The state of the part.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`DeployableState`
   

   .. method:: deploy()

      Deploy the part. Returns once it has started to move.

   

      .. note::

         Throws an exception if the part is broken.

   .. method:: retract()

      Retract the part. Returns once it has started to move.

   

      .. note::

         Throws an exception if the part is broken.



.. class:: DeployableState

   The state of a deployable part. See :attr:`Deployable.state`.


   .. data:: deployed

      Fully deployed.


   .. data:: retracted

      Fully retracted.


   .. data:: deploying

      Moving toward deployed.


   .. data:: retracting

      Moving toward retracted.


   .. data:: broken

      Broken, so it can no longer move.



.. class:: MagneticScoop

   A magnetic scoop, which collects gas from space into the vehicle's tanks. Obtained from
   :attr:`Part.magnetic_scoops`.

   .. attribute:: part

      The part the scoop is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Part`
   

   .. attribute:: active

      Whether the scoop is switched on.

      :Attribute: Can be read or written
      :rtype: bool
   

   .. attribute:: substance

      The name of the substance the scoop collects. See :attr:`Resource.name`.

      :Attribute: Read-only, cannot be set
      :rtype: str
   

   .. attribute:: collection_rate

      The rate the scoop collects gas at, in kilograms per second.

      :Attribute: Read-only, cannot be set
      :rtype: float
