KSA
===


.. module:: KSA

Provides functionality to interact with Kitten Space Agency.


.. attribute:: active_vehicle

   The vehicle under the player's control, or ``None`` if the player controls a
   kitten on EVA.

   :Attribute: Can be read or written
   :rtype: :class:`Vehicle` or None
   

   .. note::

      Setting it moves the camera to the vehicle, as the switch vehicle key does. See
      :attr:`active_kitten` for a kitten on EVA.




.. attribute:: vehicles

   The vehicles in the current system, excluding kittens on EVA.

   :Attribute: Read-only, cannot be set
   :rtype: list(:class:`Vehicle`)
   




.. attribute:: active_kitten

   The kitten on EVA under the player's control, or ``None`` if the player
   controls a vehicle.

   :Attribute: Can be read or written
   :rtype: :class:`Kitten` or None
   

   .. note::

      Setting it moves the camera to the kitten. Throws an exception if the kitten is not
      on EVA. See :attr:`active_vehicle` for a vehicle.




.. attribute:: kittens

   The kittens in the agency's roster, including those killed in action, keyed by name.

   :Attribute: Read-only, cannot be set
   :rtype: dict(str, :class:`Kitten`)
   




.. attribute:: camera

   The game's main camera.

   :Attribute: Read-only, cannot be set
   :rtype: :class:`Camera`
   




.. attribute:: bodies

   The planets, moons and stars in the current system, keyed by name.

   :Attribute: Read-only, cannot be set
   :rtype: dict(str, :class:`Body`)
   




.. attribute:: ut

   The universal time, in seconds.

   :Attribute: Read-only, cannot be set
   :rtype: float
   




.. attribute:: simulation_speed

   The simulation speed, as a multiple of real time. Zero when paused.

   :Attribute: Can be read or written
   :rtype: float
   




.. staticmethod:: warp_to(ut)

   Warp to the given universal time, and return once the warp has finished.
   The game slows the warp down to normal speed toward the end.

   :param float ut: The universal time to warp to, in seconds.
   

   .. note::

      Does nothing when the time is in the past. Returns early if the game stops the
      warp, for example when its menu pauses the game.




.. attribute:: vehicle_designs

   The vehicle designs that can be launched, keyed by name.

   :Attribute: Read-only, cannot be set
   :rtype: dict(str, :class:`VehicleDesign`)
   




.. staticmethod:: launch_vehicle(name, site)

   Launch a vehicle from a launch site, and make it the active vehicle. Returns once
   the vehicle is on the launch site.

   :param str name: The name of the vehicle design. See :attr:`vehicle_designs`.
   :param str site: The name of the launch site. See :attr:`Body.launch_sites`.
   :returns: The vehicle. Its name is the vehicle's name, with a number appended if another vehicle has that name.
   :rtype: :class:`Vehicle`
   

   .. note::

      Throws an exception if there is no such vehicle or launch site, or the name is one
      of the game's kittens.




.. staticmethod:: save_exists(name)

   Whether a save with the given name exists.

   :param str name: Name of the save.
   :rtype: bool
   




.. staticmethod:: save(name)

   Save the game, replacing any save with the same name.

   :param str name: Name of the save.
   




.. staticmethod:: load(name)

   Load a save, and return once it has loaded. The game is paused after loading.

   :param str name: Name of the save.
   

   .. note::

      Throws an exception if the save does not exist.




.. staticmethod:: take_screenshot([scale = 1], [ui = False])

   Save a screenshot, as the screenshot key does, and return once the file is written.

   :param int scale: The size of the image, as a multiple of the window size, from 1 to 8. The game reduces it to fit the graphics memory.
   :param bool ui: Whether to include the game's windows. The image is then the size of the window.
   :returns: The path of the PNG file, in the game's screenshots folder.
   :rtype: str
   

   .. note::

      Throws an exception in the vehicle editor, or if a screenshot is already being taken.




.. staticmethod:: show_message(text, [duration = 5.0], [warning = False])

   Show a message in the middle of the screen.

   :param str text: The message.
   :param float duration: How long to show the message for, in seconds. The game shows a message for at least 2 seconds.
   :param bool warning: Whether to show the message in the warning color.
   




.. staticmethod:: transform_position(position, from, to)

   Convert a position from one reference frame to another.

   :param tuple position: Position, in meters, in the frame *from*.
   :param ReferenceFrame from: The reference frame the position is in.
   :param ReferenceFrame to: The reference frame to convert the position to.
   :returns: The position in the frame *to*.
   :rtype: tuple(float, float, float)
   




.. staticmethod:: transform_direction(direction, from, to)

   Convert a direction from one reference frame to another.

   :param tuple direction: Direction in the frame *from*.
   :param ReferenceFrame from: The reference frame the direction is in.
   :param ReferenceFrame to: The reference frame to convert the direction to.
   :returns: The direction in the frame *to*.
   :rtype: tuple(float, float, float)
   




.. staticmethod:: transform_rotation(rotation, from, to)

   Convert a rotation from one reference frame to another.

   :param tuple rotation: Rotation in the frame *from*.
   :param ReferenceFrame from: The reference frame the rotation is in.
   :param ReferenceFrame to: The reference frame to convert the rotation to.
   :returns: The rotation in the frame *to*.
   :rtype: tuple(float, float, float, float)
   




.. staticmethod:: transform_velocity(position, velocity, from, to)

   Convert a velocity from one reference frame to another. The velocity of a point
   depends on its position in a rotating frame, so the position is also needed.

   :param tuple position: Position, in meters, in the frame *from*.
   :param tuple velocity: Velocity, in meters per second, in the frame *from*.
   :param ReferenceFrame from: The reference frame the position and velocity are in.
   :param ReferenceFrame to: The reference frame to convert the velocity to.
   :returns: The velocity in the frame *to*.
   :rtype: tuple(float, float, float)
