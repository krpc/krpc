Reference Frame
===============


.. class:: ReferenceFrame

   A reference frame, in which positions, directions, rotations and velocities are given.
   Obtained from the reference frame properties of :class:`Vehicle` and
   :class:`Body`, or created with :meth:`ReferenceFrame.create_relative` and
   :meth:`ReferenceFrame.create_hybrid`.

   .. note::

      Every reference frame is right-handed. Positions are in meters, velocities in meters
      per second, and angular velocities in radians per second. A rotation is a quaternion
      ``(x, y, z, w)``.

   .. staticmethod:: create_relative(reference_frame, [position = (0.0, 0.0, 0.0)], [rotation = (0.0, 0.0, 0.0, 1.0)], [velocity = (0.0, 0.0, 0.0)], [angular_velocity = (0.0, 0.0, 0.0)])

      Create a reference frame that is offset from a parent frame.

      :param ReferenceFrame reference_frame: The parent reference frame.
      :param tuple position: The position of the origin in the parent frame, in meters. Defaults to ``(0, 0, 0)``.
      :param tuple rotation: The rotation of the frame relative to the parent frame. Defaults to ``(0, 0, 0, 1)``, no rotation.
      :param tuple velocity: The velocity of the origin in the parent frame, in meters per second. Defaults to ``(0, 0, 0)``.
      :param tuple angular_velocity: The angular velocity of the frame relative to the parent frame, in radians per second, in the axes of the parent frame. Defaults to ``(0, 0, 0)``.
      :rtype: :class:`ReferenceFrame`
   

   .. staticmethod:: create_hybrid(position, [rotation = None], [velocity = None], [angular_velocity = None])

      Create a reference frame that takes its components from other frames.

      :param ReferenceFrame position: The reference frame that gives the origin.
      :param ReferenceFrame or None rotation: The reference frame that gives the axes. Defaults to *position*.
      :param ReferenceFrame or None velocity: The reference frame that gives the velocity of the origin. Defaults to *position*.
      :param ReferenceFrame or None angular_velocity: The reference frame that gives the angular velocity. Defaults to *position*.
      :rtype: :class:`ReferenceFrame`
