Orbit
=====


.. class:: Orbit

   An orbit. Obtained from :attr:`Vehicle.orbit`, :attr:`Body.orbit`,
   :attr:`Burn.orbit` or :attr:`Orbit.next_orbit`.

   .. note::

      An orbit follows the game's prediction as the trajectory changes. A predicted orbit, from
      :attr:`Orbit.next_orbit` or :attr:`Burn.orbit`, is a position in the vehicle's or the
      burn's predicted trajectory, and throws an exception while the trajectory is too short to
      reach it.

   .. attribute:: body

      The body being orbited.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Body`
   

   .. attribute:: apoapsis

      The apoapsis of the orbit, in meters, from the center of the body being orbited.
      Not a number for a parabolic or hyperbolic orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: periapsis

      The periapsis of the orbit, in meters, from the center of the body being orbited.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: apoapsis_altitude

      The apoapsis of the orbit, in meters, above the mean radius of the body being orbited.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: periapsis_altitude

      The periapsis of the orbit, in meters, above the mean radius of the body being orbited.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: semi_major_axis

      The semi-major axis of the orbit, in meters. Negative for a hyperbolic orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: semi_minor_axis

      The semi-minor axis of the orbit, in meters. Not a number for a parabolic or
      hyperbolic orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: speed

      The current orbital speed, in meters per second.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: radius

      The current distance from the center of the body being orbited, in meters.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: period

      The orbital period, in seconds. Not a number for a parabolic or hyperbolic orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: mean_motion

      The mean angular motion of the orbit, in radians per second.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: specific_energy

      The specific orbital energy, the sum of the kinetic and potential energy per unit
      mass, in joules per kilogram. Negative for an elliptical orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: time_to_apoapsis

      The time until the next apoapsis, in seconds. Not a number for a parabolic or
      hyperbolic orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: time_to_periapsis

      The time until the next periapsis, in seconds. Negative once a parabolic or
      hyperbolic orbit has passed it.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: eccentricity

      The `eccentricity <https://en.wikipedia.org/wiki/Orbital_eccentricity>`_
      of the orbit.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: inclination

      The `inclination <https://en.wikipedia.org/wiki/Orbital_inclination>`_
      of the orbit, in radians, against the equator of the body being orbited.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: longitude_of_ascending_node

      The `longitude of the ascending node <https://en.wikipedia.org/wiki/Longitude_of_the_ascending_node>`_, in radians.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: argument_of_periapsis

      The `argument of periapsis <https://en.wikipedia.org/wiki/Argument_of_periapsis>`_, in radians.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: true_anomaly

      The current `true anomaly <https://en.wikipedia.org/wiki/True_anomaly>`_,
      in radians.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: mean_anomaly

      The current `mean anomaly <https://en.wikipedia.org/wiki/Mean_anomaly>`_,
      in radians.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: eccentric_anomaly

      The current `eccentric anomaly <https://en.wikipedia.org/wiki/Eccentric_anomaly>`_, in radians. For a hyperbolic orbit, this is the hyperbolic anomaly.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: semi_latus_rectum

      The `semi-latus rectum <https://en.wikipedia.org/wiki/Conic_section#Conic_parameters>`_ of the orbit, in meters.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: specific_angular_momentum

      The specific angular momentum of the orbit, in :math:`\mathrm{m^{2}/s}`.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. method:: true_anomaly_at_ut(ut)

      The true anomaly at the given time, in radians.

      :param float ut: Universal time, in seconds.
      :rtype: float
   

   .. method:: mean_anomaly_at_ut(ut)

      The mean anomaly at the given time, in radians.

      :param float ut: Universal time, in seconds.
      :rtype: float
   

   .. method:: eccentric_anomaly_at_ut(ut)

      The eccentric anomaly at the given time, in radians. For a hyperbolic orbit, this
      is the hyperbolic anomaly.

      :param float ut: Universal time, in seconds.
      :rtype: float
   

   .. method:: ut_at_true_anomaly(true_anomaly)

      The next universal time, from now, at which the orbit reaches the given true
      anomaly, in seconds. Not a number if it never does, such as beyond the asymptote of
      a hyperbolic orbit.

      :param float true_anomaly: True anomaly, in radians.
      :rtype: float
   

   .. method:: true_anomaly_at_radius(radius)

      The true anomaly at which the orbit reaches the given distance from the center of
      the body, in radians, between 0 and :math:`\pi`. Not a number if the orbit
      never reaches it.

      :param float radius: The distance from the center of the body, in meters.
      :rtype: float
   

      .. note::

         The orbit also reaches the distance at the negative of this anomaly. Zero for a
         circular orbit at the distance. Throws an exception if the distance is not
         positive.

   .. method:: radius_at(ut)

      The distance from the center of the body being orbited at the given time, in
      meters.

      :param float ut: Universal time, in seconds.
      :rtype: float
   

   .. method:: speed_at(ut)

      The orbital speed at the given time, in meters per second.

      :param float ut: Universal time, in seconds.
      :rtype: float
   

   .. method:: position_at(ut, reference_frame)

      The position on the orbit at the given time, in meters, relative to where the body
      being orbited is now.

      :param float ut: Universal time, in seconds.
      :param ReferenceFrame reference_frame: The reference frame of the position.
      :rtype: tuple(float, float, float)
   

   .. method:: velocity_at(ut, reference_frame)

      The orbital velocity at the given time, in meters per second, relative to the body
      being orbited and along the axes of the given frame.

      :param float ut: Universal time, in seconds.
      :param ReferenceFrame reference_frame: The reference frame of the velocity.
      :rtype: tuple(float, float, float)
   

   .. method:: relative_inclination(orbit)

      The inclination of the orbit relative to another orbit, in radians.

      :param Orbit orbit: The other orbit.
      :rtype: float
   

   .. method:: true_anomaly_at_an(orbit)

      The true anomaly of the ascending node with another orbit, in radians.

      :param Orbit orbit: The other orbit.
      :rtype: float
   

      .. note::

         Throws an exception if the orbits are around different bodies.

   .. method:: true_anomaly_at_dn(orbit)

      The true anomaly of the descending node with another orbit, in radians.

      :param Orbit orbit: The other orbit.
      :rtype: float
   

      .. note::

         Throws an exception if the orbits are around different bodies.

   .. attribute:: time_of_closest_approach

      The universal time of the closest approach on this orbit to the vehicle's target,
      in seconds. Not a number if there is none.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

      .. note::

         Only the vehicle's current orbit has a target. The game predicts the trajectory on a
         worker thread, so a new target shows here shortly after it is set.

   .. attribute:: distance_at_closest_approach

      The distance at the closest approach on this orbit to the vehicle's target, in
      meters. Not a number if there is none.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

      .. note::

         Only the vehicle's current orbit has a target. The game predicts the trajectory on a
         worker thread, so a new target shows here shortly after it is set.

   .. attribute:: start_ut

      The universal time at which this orbit starts, in seconds. Not a number for the
      orbit of a body.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: end_ut

      The universal time at which this orbit ends, in seconds. Infinite for an orbit that
      does not end, such as the orbit of a body.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: end_transition

      How the orbit ends.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`OrbitTransition`
   

   .. attribute:: time_to_soi_change

      The time until the orbit enters or leaves a sphere of influence, in seconds. Not a
      number if it does neither.

      :Attribute: Read-only, cannot be set
      :rtype: float
   

   .. attribute:: next_orbit

      The orbit that follows this one after it enters or leaves a sphere of influence, or
      ``None`` if there is none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`Orbit` or None
   

   .. staticmethod:: create_from_elements(body, semi_major_axis, eccentricity, inclination, longitude_of_ascending_node, argument_of_periapsis, mean_anomaly_at_epoch, epoch)

      Create the orbit with the given elements around a body. The angles are those of
      :class:`Orbit`.

      :param Body body: The body being orbited.
      :param float semi_major_axis: The semi-major axis, in meters. Negative or positive for a hyperbolic orbit.
      :param float eccentricity: The eccentricity. Below 1 for an elliptical orbit, and above 1 for a hyperbolic one.
      :param float inclination: The inclination, in radians.
      :param float longitude_of_ascending_node: The longitude of the ascending node, in radians.
      :param float argument_of_periapsis: The argument of periapsis, in radians.
      :param float mean_anomaly_at_epoch: The mean anomaly at the epoch, in radians.
      :param float epoch: The universal time of the epoch, in seconds.
      :rtype: :class:`Orbit`
   

      .. note::

         The orbit is a single conic around *body*, with no
         :attr:`Orbit.next_orbit`. It is held until :meth:`Orbit.remove` is called on it, or
         the client that created it disconnects.

   .. staticmethod:: create_from_position_and_velocity(body, position, velocity, ut, reference_frame)

      Create the orbit around a body through the given position and velocity.

      :param Body body: The body being orbited.
      :param tuple position: The position, in meters, relative to where the body is now.
      :param tuple velocity: The velocity, in meters per second.
      :param float ut: The universal time of the position and velocity, in seconds.
      :param ReferenceFrame reference_frame: The reference frame of the position and velocity.
      :rtype: :class:`Orbit`
   

      .. note::

         The orbit is a single conic around *body*, with no
         :attr:`Orbit.next_orbit`. It is held until :meth:`Orbit.remove` is called on it, or
         the client that created it disconnects.

   .. method:: remove()

      Remove an orbit created by :meth:`Orbit.create_from_elements` or
      :meth:`Orbit.create_from_position_and_velocity`.

   

      .. note::

         Throws an exception if the orbit was not created by a client.



.. class:: OrbitTransition

   How an orbit ends. See :attr:`Orbit.end_transition`.


   .. data:: none

      The orbit does not end.


   .. data:: encounter

      The orbit enters the sphere of influence of another body.


   .. data:: escape

      The orbit leaves the sphere of influence of the body being orbited.


   .. data:: impact

      The orbit hits the surface of the body being orbited.


   .. data:: burn

      The orbit ends at a planned burn.
