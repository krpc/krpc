Lua
===

This page covers using the kRPC Lua client with the ``KSA`` service. The
`kRPC Lua client guide <https://krpc.github.io/krpc/0.7.0/lua/client.html>`_ covers the client in full.

.. note::

   kRPC for KSA is experimental. A later release will make the client easier to use with
   the ``KSA`` service.

Installing
----------

Install the kRPC Lua client 0.7.0 from `LuaRocks
<https://luarocks.org/modules/djungelorm/krpc>`_:

.. code-block:: bash

   luarocks install krpc 0.7.0

The `kRPC Lua client guide <https://krpc.github.io/krpc/0.7.0/lua/client.html#installing>`_ covers other ways to
install the client.

Connecting to the Server
------------------------

The client builds the ``KSA`` service from the definitions the server sends when it connects,
so the service is ``conn.ksa``:

.. code-block:: lua

   local krpc = require 'krpc'
   local conn = krpc.connect('Example')
   print(conn.ksa.active_vehicle.name)

The `kRPC Lua client guide <https://krpc.github.io/krpc/0.7.0/lua/client.html>`_ covers connecting, streams and the
client's other features.
