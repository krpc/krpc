Drawing
=======


.. type:: public class Drawing

   Draws lines, shapes and text in the scene, each placed in a reference frame.

   .. note::

      The objects are drawn every frame until removed, and are removed when the client that
      added them disconnects. Lines are drawn at the game's fixed gizmo width.

   .. method:: static Line addLine(Connection connection, org.javatuples.Triplet<Double,Double,Double> start, org.javatuples.Triplet<Double,Double,Double> end, ReferenceFrame referenceFrame, boolean visible)

      Draw a line between two positions.

      :param org.javatuples.Triplet<Double,Double,Double> start: The position of the start of the line, in meters.
      :param org.javatuples.Triplet<Double,Double,Double> end: The position of the end of the line, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the positions.
      :param boolean visible: Whether the line is visible.
   

   .. method:: static Line addDirection(Connection connection, org.javatuples.Triplet<Double,Double,Double> direction, ReferenceFrame referenceFrame, float length, boolean visible)

      Draw a line from the origin of a reference frame in a direction.

      :param org.javatuples.Triplet<Double,Double,Double> direction: The direction of the line.
      :param ReferenceFrame referenceFrame: The reference frame of the direction.
      :param float length: The length of the line, in meters.
      :param boolean visible: Whether the line is visible.
   

   .. method:: static Polyline addPolyline(Connection connection, java.util.List<org.javatuples.Triplet<Double,Double,Double>> vertices, ReferenceFrame referenceFrame, boolean closed, boolean visible)

      Draw a line through a list of positions.

      :param java.util.List<org.javatuples.Triplet<Double,Double,Double>> vertices: The positions the line passes through, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the positions.
      :param boolean closed: Whether the line joins the last position back to the first.
      :param boolean visible: Whether the line is visible.
   

   .. method:: static Circle addCircle(Connection connection, org.javatuples.Triplet<Double,Double,Double> center, org.javatuples.Triplet<Double,Double,Double> normal, float radius, ReferenceFrame referenceFrame, boolean visible)

      Draw a circle.

      :param org.javatuples.Triplet<Double,Double,Double> center: The position of the center of the circle, in meters.
      :param org.javatuples.Triplet<Double,Double,Double> normal: The direction normal to the plane of the circle.
      :param float radius: The radius of the circle, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the position and direction.
      :param boolean visible: Whether the circle is visible.
   

   .. method:: static Arc addArc(Connection connection, org.javatuples.Triplet<Double,Double,Double> center, org.javatuples.Triplet<Double,Double,Double> normal, org.javatuples.Triplet<Double,Double,Double> startDirection, float angle, float radius, ReferenceFrame referenceFrame, boolean visible)

      Draw an arc of a circle.

      :param org.javatuples.Triplet<Double,Double,Double> center: The position of the center of the arc's circle, in meters.
      :param org.javatuples.Triplet<Double,Double,Double> normal: The direction normal to the plane of the arc.
      :param org.javatuples.Triplet<Double,Double,Double> startDirection: The direction from the center to the start of the arc.
      :param float angle: The angle the arc turns through, counterclockwise about the normal, in radians.
      :param float radius: The radius of the arc, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the position and directions.
      :param boolean visible: Whether the arc is visible.
   

   .. method:: static Box addBox(Connection connection, org.javatuples.Triplet<Double,Double,Double> center, org.javatuples.Triplet<Double,Double,Double> size, org.javatuples.Quartet<Double,Double,Double,Double> rotation, ReferenceFrame referenceFrame, boolean visible)

      Draw the edges of a box.

      :param org.javatuples.Triplet<Double,Double,Double> center: The position of the center of the box, in meters.
      :param org.javatuples.Triplet<Double,Double,Double> size: The lengths of the box's edges along its x, y and z axes, in meters.
      :param org.javatuples.Quartet<Double,Double,Double,Double> rotation: The rotation of the box's axes, as a quaternion of the form ``(x, y, z, w)``.
      :param ReferenceFrame referenceFrame: The reference frame of the position and rotation.
      :param boolean visible: Whether the box is visible.
   

   .. method:: static Sphere addSphere(Connection connection, org.javatuples.Triplet<Double,Double,Double> center, float radius, ReferenceFrame referenceFrame, boolean visible)

      Draw a solid sphere.

      :param org.javatuples.Triplet<Double,Double,Double> center: The position of the center of the sphere, in meters.
      :param float radius: The radius of the sphere, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the position.
      :param boolean visible: Whether the sphere is visible.
   

   .. method:: static Text addText(Connection connection, String text, org.javatuples.Triplet<Double,Double,Double> position, ReferenceFrame referenceFrame, float size, boolean visible)

      Draw text over the scene, centered on a position.

      :param String text: The text.
      :param org.javatuples.Triplet<Double,Double,Double> position: The position of the center of the text, in meters.
      :param ReferenceFrame referenceFrame: The reference frame of the position.
      :param float size: The height of the font, in pixels.
      :param boolean visible: Whether the text is visible.
   

   .. method:: static void clear(Connection connection, boolean clientOnly)

      Remove the drawing objects.

      :param boolean clientOnly: Whether to remove only the objects added by the calling client.
