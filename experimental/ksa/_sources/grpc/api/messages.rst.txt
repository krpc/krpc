Messages
========

Tuples
------

.. grpc:package:: krpc.ksa

A tuple is a message holding item *i* in the field ``item<i>``.

.. grpc:message:: Tuple_double_double_double

   .. code-block:: protobuf

      message Tuple_double_double_double {
        double item1 = 1;
        double item2 = 2;
        double item3 = 3;
      }

.. grpc:message:: Tuple_double_double_double_double

   .. code-block:: protobuf

      message Tuple_double_double_double_double {
        double item1 = 1;
        double item2 = 2;
        double item3 = 3;
        double item4 = 4;
      }

.. grpc:message:: Tuple_float_float

   .. code-block:: protobuf

      message Tuple_float_float {
        float item1 = 1;
        float item2 = 2;
      }
