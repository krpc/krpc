Computer
========

.. grpc:service:: ComputerService

   A vehicle's flight computer, which runs a kFS program. Obtained from
   :grpc:rpc:`KFSService.Computer <krpc.kfs.KFSService.Computer>`.

   .. note::

      A program is written in kC, a subset of C, or in kASM. The calls that change the
      computer, and :grpc:rpc:`ComputerService.WriteGlobals <krpc.kfs.ComputerService.WriteGlobals>`, take effect before the computer's next tick, and
      return once they have. The computer ticks while the game is running and the vehicle is
      in the physics bubble, so until then they wait. The game does not save a program.

.. grpc:enum:: ComputerState

   The state of a flight computer. See :grpc:rpc:`ComputerService.GetState <krpc.kfs.ComputerService.GetState>`.

   .. grpc:value:: COMPUTER_STATE_NO_SOFTWARE

      No program is loaded.

   .. grpc:value:: COMPUTER_STATE_STANDBY

      A program is loaded, and not running.

   .. grpc:value:: COMPUTER_STATE_BOOT

      The program is running its initialization.

   .. grpc:value:: COMPUTER_STATE_RUNNING

      The program is running.

   .. grpc:value:: COMPUTER_STATE_IDLE

      The program is running, with no task to run.

   .. grpc:value:: COMPUTER_STATE_HALTED

      The program has stopped, after a trap, a halt or the kill switch.

.. grpc:enum:: ControlMode

   The control a program has of a vehicle. See :grpc:rpc:`ComputerService.GetMode <krpc.kfs.ComputerService.GetMode>`.

   .. grpc:value:: CONTROL_MODE_PILOT

      The game's flight computer flies the vehicle, and the program steers it.

   .. grpc:value:: CONTROL_MODE_FULL_CONTROL

      The program commands the thrusters, engines and gimbals itself. A program claims it
      with ``#pragma kfs claim ALLOCATION``.

.. grpc:message:: Diagnostic

   An error or warning from building a program. See :grpc:rpc:`ComputerService.Build <krpc.kfs.ComputerService.Build>`.

   .. grpc:field:: error

      Whether it is an error. An error stops the program from being built.

   .. grpc:field:: code

      The diagnostic's code, such as ``KC-E016``.

   .. grpc:field:: file

      The source file.

   .. grpc:field:: line

      The line in the source file, from 1. Zero for the whole file.

   .. grpc:field:: column

      The column in the line, from 1.

   .. grpc:field:: message

      The message.

   .. grpc:field:: hint

      A hint at the fix, or ``null`` if there is none.

.. grpc:message:: Trap

   The error that halted a program, and where it happened. See :grpc:rpc:`ComputerService.GetTrap <krpc.kfs.ComputerService.GetTrap>`.

   .. grpc:field:: code

      The error.

   .. grpc:field:: function

      The function that was running.

   .. grpc:field:: file

      The source file, or ``null`` if it is not known.

   .. grpc:field:: line

      The line in the source file, or zero if it is not known.

.. grpc:enum:: TrapCode

   The error that halted a program. See :grpc:field:`code <krpc.kfs.Trap.code>`.

   .. grpc:value:: TRAP_CODE_ILLEGAL_OPCODE

      An instruction the processor does not have.

   .. grpc:value:: TRAP_CODE_OPERAND_OVERFLOW

      The operand stack overflowed.

   .. grpc:value:: TRAP_CODE_OPERAND_UNDERFLOW

      The operand stack underflowed.

   .. grpc:value:: TRAP_CODE_RETURN_OVERFLOW

      The return stack overflowed.

   .. grpc:value:: TRAP_CODE_INIT_OVERRUN

      The initialization ran past its budget.

   .. grpc:value:: TRAP_CODE_STACK_OVERFLOW

      The stack overflowed.

   .. grpc:value:: TRAP_CODE_NULL_ACCESS

      A read or write through a null pointer.

   .. grpc:value:: TRAP_CODE_BAD_ADDRESS

      A read or write outside memory.

   .. grpc:value:: TRAP_CODE_READ_ONLY

      A write to read-only memory.

   .. grpc:value:: TRAP_CODE_MISALIGNED

      A misaligned read or write.

   .. grpc:value:: TRAP_CODE_DIVISION_BY_ZERO

      A division by zero.

   .. grpc:value:: TRAP_CODE_BOUNDS

      An array index out of bounds.

   .. grpc:value:: TRAP_CODE_USER

      A trap raised by the program.

   .. grpc:value:: TRAP_CODE_BAD_JUMP

      A jump to an invalid address.

   .. grpc:value:: TRAP_CODE_BAD_SYSCALL

      A call to a service that does not exist.

   .. grpc:value:: TRAP_CODE_BAD_YIELD

      A task yielded where it may not.

   .. grpc:value:: TRAP_CODE_MEMORY_ERROR

      A memory error, such as a radiation upset.
