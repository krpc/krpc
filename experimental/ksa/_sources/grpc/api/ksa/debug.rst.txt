Debug
=====

.. grpc:service:: DebugService

   Changes the state of the simulation directly, as the game's debug windows and console
   commands do: teleporting a vehicle, setting its attitude, refilling its tanks.

   .. grpc:rpc:: SetCircularOrbit (Debug.SetCircularOrbitRequest) returns (Debug.SetCircularOrbitResponse)

      Move a vehicle onto a circular orbit around a body, and return once it is there.

      :Debug.SetCircularOrbitRequest:
         * ``vehicle`` (:grpc:service:`Vehicle <krpc.ksa.VehicleService>`): The vehicle.
         * ``body`` (:grpc:service:`Body <krpc.ksa.BodyService>`): The body to orbit.
         * ``altitude`` (``double``): The altitude of the orbit above the mean radius, in meters.

      :Debug.SetCircularOrbitResponse: Empty

      .. note::

         Throws an exception if the game cannot compute the vehicle's trajectory on the
         orbit.

   .. grpc:rpc:: SetOrbit (Debug.SetOrbitRequest) returns (Debug.SetOrbitResponse)

      Move a vehicle onto the orbit with the given elements, and return once it is there.
      The angles are those of :grpc:service:`Orbit <krpc.ksa.OrbitService>`.

      :Debug.SetOrbitRequest:
         * ``vehicle`` (:grpc:service:`Vehicle <krpc.ksa.VehicleService>`): The vehicle.
         * ``body`` (:grpc:service:`Body <krpc.ksa.BodyService>`): The body to orbit.
         * ``semi_major_axis`` (``double``): The semi-major axis, in meters.
         * ``eccentricity`` (``double``): The eccentricity.
         * ``inclination`` (``double``): The inclination, in radians.
         * ``longitude_of_ascending_node`` (``double``): The longitude of the ascending node, in radians.
         * ``argument_of_periapsis`` (``double``): The argument of periapsis, in radians.
         * ``mean_anomaly_at_epoch`` (``double``): The mean anomaly at the epoch, in radians.
         * ``epoch`` (``double``): The universal time of the epoch, in seconds.

      :Debug.SetOrbitResponse: Empty

      .. note::

         Throws an exception if the game cannot compute the vehicle's trajectory on the
         orbit.

   .. grpc:rpc:: SetLanded (Debug.SetLandedRequest) returns (Debug.SetLandedResponse)

      Place a vehicle on the surface of a body, as the game's teleport window does, and
      return once it is there.

      :Debug.SetLandedRequest:
         * ``vehicle`` (:grpc:service:`Vehicle <krpc.ksa.VehicleService>`): The vehicle.

   .. grpc:rpc:: SetPosition (Debug.SetPositionRequest) returns (Debug.SetPositionResponse)

      Move a vehicle to the given position, keeping its velocity, and return once it is
      there.

      :Debug.SetPositionRequest:
         * ``vehicle`` (:grpc:service:`Vehicle <krpc.ksa.VehicleService>`): The vehicle.
         * ``position`` (:grpc:message:`Tuple_double_double_double <krpc.ksa.Tuple_double_double_double>`): The position of the vehicle, in meters.
         * ``reference_frame`` (:grpc:service:`ReferenceFrame <krpc.ksa.ReferenceFrameService>`): The reference frame of the position.

      :Debug.SetPositionResponse: Empty

      .. note::

         This is the inverse of :grpc:rpc:`VehicleService.Position <krpc.ksa.VehicleService.Position>`. The vehicle keeps orbiting
         the same body.

      :Debug.SetAngularVelocityResponse: Empty

      .. note::

         This is the inverse of :grpc:rpc:`VehicleService.AngularVelocity <krpc.ksa.VehicleService.AngularVelocity>`.

   .. grpc:rpc:: RunCommand (Debug.RunCommandRequest) returns (Debug.RunCommandResponse)

      Run a command in the game's console, as typed in the console.

      :Debug.RunCommandRequest:
         * ``command`` (``string``): The command and its arguments.

      :Debug.RunCommandResponse: ``value`` (``repeated string``): The console output of the command, one line per message.

      .. note::

         Most commands write their messages to the game's log, not the returned output.
         Throws an exception if the console has no such command, or the arguments are not
         valid.
