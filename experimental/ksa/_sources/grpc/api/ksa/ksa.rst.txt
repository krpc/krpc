   .. grpc:rpc:: WarpTo (KSA.WarpToRequest) returns (KSA.WarpToResponse)

      Warp to the given universal time, and return once the warp has finished.
      The game slows the warp down to normal speed toward the end.

      :KSA.WarpToRequest:
         * ``ut`` (``double``): The universal time to warp to, in seconds.

      :KSA.WarpToResponse: Empty

      .. note::

         Does nothing when the time is in the past. Returns early if the game stops the
         warp, for example when its menu pauses the game.

   .. grpc:rpc:: LaunchVehicle (KSA.LaunchVehicleRequest) returns (KSA.LaunchVehicleResponse)

      Launch a vehicle from a launch site, and make it the active vehicle. Returns once
      the vehicle is on the launch site.

      :KSA.LaunchVehicleRequest:
         * ``name`` (``string``): The name of the vehicle design. See :grpc:rpc:`KSAService.GetVehicleDesigns <krpc.ksa.KSAService.GetVehicleDesigns>`.
         * ``site`` (``string``): The name of the launch site. See :grpc:rpc:`BodyService.GetLaunchSites <krpc.ksa.BodyService.GetLaunchSites>`.

      :KSA.LaunchVehicleResponse: ``value`` (:grpc:service:`Vehicle <krpc.ksa.VehicleService>`): The vehicle. Its name is the vehicle's name, with a number appended if another vehicle has that name.

      .. note::

         Throws an exception if there is no such vehicle or launch site, or the name is one
         of the game's kittens.

   .. grpc:rpc:: TakeScreenshot (KSA.TakeScreenshotRequest) returns (KSA.TakeScreenshotResponse)

      Save a screenshot, as the screenshot key does, and return once the file is written.

      :KSA.TakeScreenshotRequest:
         * ``scale`` (``optional sint32``): The size of the image, as a multiple of the window size, from 1 to 8. The game reduces it to fit the graphics memory. Defaults to ``1``.
         * ``ui`` (``optional bool``): Whether to include the game's windows. The image is then the size of the window. Defaults to ``false``.

      :KSA.TakeScreenshotResponse: ``value`` (``string``): The path of the PNG file, in the game's screenshots folder.

      .. note::

         Throws an exception in the vehicle editor, or if a screenshot is already being taken.
