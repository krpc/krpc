Drawing
=======

.. grpc:service:: DrawingService

   Draws lines, shapes and text in the scene, each placed in a reference frame.

   .. note::

      The objects are drawn every frame until removed, and are removed when the client that
      added them disconnects. Lines are drawn at the game's fixed gizmo width.

   .. grpc:rpc:: AddLine (Drawing.AddLineRequest) returns (Drawing.AddLineResponse)

      Draw a line between two positions.

      :Drawing.AddLineRequest:

         * ``end`` (:grpc:message:`Tuple_double_double_double <krpc.ksa.Tuple_double_double_double>`): The position of the end of the line, in meters.
         * ``reference_frame`` (:grpc:service:`ReferenceFrame <krpc.ksa.ReferenceFrameService>`): The reference frame of the positions.
