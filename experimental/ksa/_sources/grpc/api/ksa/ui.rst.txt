UI
==

.. grpc:service:: UIService

   Adds windows of buttons, text fields and other widgets to the game's UI.

   .. note::

      The windows are removed when the client that added them disconnects. For messages on
      the screen, see :grpc:rpc:`KSAService.ShowMessage <krpc.ksa.KSAService.ShowMessage>`.

   .. grpc:rpc:: AddWindow (UI.AddWindowRequest) returns (UI.AddWindowResponse)

      Add a window, with no widgets.

      :UI.AddWindowRequest:
         * ``title`` (``string``): The text in the title bar.
         * ``visible`` (``optional bool``): Whether the window is visible. Defaults to ``true``.

      :UI.AddWindowResponse: ``value`` (:grpc:service:`Window <krpc.ksa.WindowService>`)

   .. grpc:rpc:: Clear (UI.ClearRequest) returns (UI.ClearResponse)

      Remove the windows.

      :UI.ClearRequest:
         * ``client_only`` (``optional bool``): Whether to remove only the windows added by the calling client. Defaults to ``false``.

      :UI.ClearResponse: Empty

.. grpc:service:: WindowService

   A window, holding widgets one per line. Created using :grpc:rpc:`UIService.AddWindow <krpc.ksa.UIService.AddWindow>`.

   .. note::

      The window fits its widgets until its size is set. Closing the window makes it
      invisible. The window is hidden with the game's UI.
