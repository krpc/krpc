Auto-Pilot
==========

.. grpc:service:: AutoPilotService

   The vehicle's flight computer, which steers the vehicle with its reaction control
   thrusters and engine gimbals. Obtained from :grpc:rpc:`VehicleService.GetAutoPilot <krpc.ksa.VehicleService.GetAutoPilot>`.

   .. note::

      The auto-pilot points the vehicle in the direction set by :grpc:rpc:`AutoPilotService.GetMode <krpc.ksa.AutoPilotService.GetMode>`, once
      engaged. It is the game's own flight computer, so the game's flight computer
      controls change the same settings.

   .. grpc:rpc:: GetAutoBurn (AutoPilot.GetAutoBurnRequest) returns (AutoPilot.GetAutoBurnResponse)

      Whether the flight computer executes the next burn in
      :grpc:rpc:`VehicleService.GetBurns <krpc.ksa.VehicleService.GetBurns>`. It points the vehicle along the burn, fires the
      engines at :grpc:rpc:`BurnService.GetIgnitionTime <krpc.ksa.BurnService.GetIgnitionTime>`, and stops once the burn is complete.

      :AutoPilot.GetAutoBurnRequest:
         * ``this`` (:grpc:service:`AutoPilot <krpc.ksa.AutoPilotService>`)

      :AutoPilot.GetAutoBurnResponse: ``value`` (``bool``)

      .. note::

         The flight computer clears it when the burn completes, and removes the burn if
         another follows it. The engines fire only at normal speed, so warp to shortly before
         the burn with :grpc:rpc:`KSAService.WarpTo <krpc.ksa.KSAService.WarpTo>`. Setting it with no burn planned throws an
         exception.

.. grpc:enum:: AutoPilotMode

   The direction the auto-pilot points the vehicle in.
   See :grpc:rpc:`AutoPilotService.GetMode <krpc.ksa.AutoPilotService.GetMode>`.

   .. grpc:value:: AUTO_PILOT_MODE_ATTITUDE

      The pitch, heading and roll set by :grpc:rpc:`AutoPilotService.GetTargetPitch <krpc.ksa.AutoPilotService.GetTargetPitch>`,
      :grpc:rpc:`AutoPilotService.GetTargetHeading <krpc.ksa.AutoPilotService.GetTargetHeading>` and :grpc:rpc:`AutoPilotService.GetTargetRoll <krpc.ksa.AutoPilotService.GetTargetRoll>`.

   .. grpc:value:: AUTO_PILOT_MODE_HOLD

      Holds the vehicle's rotation at zero, relative to the stars.

   .. grpc:value:: AUTO_PILOT_MODE_PROGRADE

      The direction of the vehicle's orbital velocity.

   .. grpc:value:: AUTO_PILOT_MODE_RETROGRADE

      The opposite of :grpc:value:`AUTO_PILOT_MODE_PROGRADE <krpc.ksa.AutoPilotMode.AUTO_PILOT_MODE_PROGRADE>`.

   .. grpc:value:: AUTO_PILOT_MODE_NORMAL

      Normal to the orbital plane, along the orbit's angular momentum.

   .. grpc:value:: AUTO_PILOT_MODE_ANTI_NORMAL

      The opposite of :grpc:value:`AUTO_PILOT_MODE_NORMAL <krpc.ksa.AutoPilotMode.AUTO_PILOT_MODE_NORMAL>`.

   .. grpc:value:: AUTO_PILOT_MODE_RADIAL_OUT

      Away from the center of the body being orbited.

   .. grpc:value:: AUTO_PILOT_MODE_RADIAL_IN

      Toward the center of the body being orbited.

   .. grpc:value:: AUTO_PILOT_MODE_SURFACE_PROGRADE

      The direction of the vehicle's velocity relative to the surface.

   .. grpc:value:: AUTO_PILOT_MODE_SURFACE_RETROGRADE

      The opposite of :grpc:value:`AUTO_PILOT_MODE_SURFACE_PROGRADE <krpc.ksa.AutoPilotMode.AUTO_PILOT_MODE_SURFACE_PROGRADE>`.

   .. grpc:value:: AUTO_PILOT_MODE_OTHER

      A target set in the game, which the API does not cover.
