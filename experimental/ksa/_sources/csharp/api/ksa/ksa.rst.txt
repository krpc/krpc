.. namespace:: KRPC.Client.Services.KSA

KSA
===


.. class:: KSA

   Provides functionality to interact with Kitten Space Agency.

   .. property:: Vehicle ActiveVehicle { get; set; }

      The vehicle under the player's control, or ``null`` if the player controls a
      kitten on EVA.

      :Game Scenes: All


      .. note::

         Setting it moves the camera to the vehicle, as the switch vehicle key does. See
         :prop:`KSA.ActiveKitten <KSA.KSA.ActiveKitten>` for a kitten on EVA.

   .. property:: System.Collections.Generic.IList<Vehicle> Vehicles { get; }

      The vehicles in the current system, excluding kittens on EVA.

      :Game Scenes: All

   .. property:: Kitten ActiveKitten { get; set; }

      The kitten on EVA under the player's control, or ``null`` if the player
      controls a vehicle.

      :Game Scenes: All


      .. note::

         Setting it moves the camera to the kitten. Throws an exception if the kitten is not
         on EVA. See :prop:`KSA.ActiveVehicle <KSA.KSA.ActiveVehicle>` for a vehicle.

   .. property:: System.Collections.Generic.IDictionary<string,Kitten> Kittens { get; }

      The kittens in the agency's roster, including those killed in action, keyed by name.

      :Game Scenes: All

   .. property:: Camera Camera { get; }

      The game's main camera.

      :Game Scenes: All

   .. property:: System.Collections.Generic.IDictionary<string,Body> Bodies { get; }

      The planets, moons and stars in the current system, keyed by name.

      :Game Scenes: All

   .. property:: double UT { get; }

      The universal time, in seconds.

      :Game Scenes: All

   .. property:: float SimulationSpeed { get; set; }

      The simulation speed, as a multiple of real time. Zero when paused.

      :Game Scenes: All

   .. function:: void WarpTo(double ut)

      Warp to the given universal time, and return once the warp has finished.
      The game slows the warp down to normal speed toward the end.

      :parameters:

       * **ut** -- The universal time to warp to, in seconds.

      :Game Scenes: All


      .. note::

         Does nothing when the time is in the past. Returns early if the game stops the
         warp, for example when its menu pauses the game.

   .. property:: System.Collections.Generic.IDictionary<string,VehicleDesign> VehicleDesigns { get; }

      The vehicle designs that can be launched, keyed by name.

      :Game Scenes: All

   .. function:: Vehicle LaunchVehicle(string name, string site)

      Launch a vehicle from a launch site, and make it the active vehicle. Returns once
      the vehicle is on the launch site.

      :parameters:

       * **name** -- The name of the vehicle design. See :prop:`KSA.VehicleDesigns <KSA.KSA.VehicleDesigns>`.
       * **site** -- The name of the launch site. See :prop:`Body.LaunchSites`.

      :returns: The vehicle. Its name is the vehicle's name, with a number appended if another vehicle has that name.
      :Game Scenes: All


      .. note::

         Throws an exception if there is no such vehicle or launch site, or the name is one
         of the game's kittens.

   .. function:: bool SaveExists(string name)

      Whether a save with the given name exists.

      :parameters:

       * **name** -- Name of the save.

      :Game Scenes: All

   .. function:: void Save(string name)

      Save the game, replacing any save with the same name.

      :parameters:

       * **name** -- Name of the save.

      :Game Scenes: All

   .. function:: void Load(string name)

      Load a save, and return once it has loaded. The game is paused after loading.

      :parameters:

       * **name** -- Name of the save.

      :Game Scenes: All


      .. note::

         Throws an exception if the save does not exist.

   .. function:: string TakeScreenshot(int scale = 1, bool ui = false)

      Save a screenshot, as the screenshot key does, and return once the file is written.

      :parameters:

       * **scale** -- The size of the image, as a multiple of the window size, from 1 to 8. The game reduces it to fit the graphics memory.
       * **ui** -- Whether to include the game's windows. The image is then the size of the window.

      :returns: The path of the PNG file, in the game's screenshots folder.
      :Game Scenes: All


      .. note::

         Throws an exception in the vehicle editor, or if a screenshot is already being taken.

   .. function:: void ShowMessage(string text, float duration = 5.0f, bool warning = false)

      Show a message in the middle of the screen.

      :parameters:

       * **text** -- The message.
       * **duration** -- How long to show the message for, in seconds. The game shows a message for at least 2 seconds.
       * **warning** -- Whether to show the message in the warning color.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> TransformPosition(System.Tuple<double,double,double> position, ReferenceFrame from, ReferenceFrame to)

      Convert a position from one reference frame to another.

      :parameters:

       * **position** -- Position, in meters, in the frame *from*.
       * **from** -- The reference frame the position is in.
       * **to** -- The reference frame to convert the position to.

      :returns: The position in the frame *to*.
      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> TransformDirection(System.Tuple<double,double,double> direction, ReferenceFrame from, ReferenceFrame to)

      Convert a direction from one reference frame to another.

      :parameters:

       * **direction** -- Direction in the frame *from*.
       * **from** -- The reference frame the direction is in.
       * **to** -- The reference frame to convert the direction to.

      :returns: The direction in the frame *to*.
      :Game Scenes: All

   .. function:: System.Tuple<double,double,double,double> TransformRotation(System.Tuple<double,double,double,double> rotation, ReferenceFrame from, ReferenceFrame to)

      Convert a rotation from one reference frame to another.

      :parameters:

       * **rotation** -- Rotation in the frame *from*.
       * **from** -- The reference frame the rotation is in.
       * **to** -- The reference frame to convert the rotation to.

      :returns: The rotation in the frame *to*.
      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> TransformVelocity(System.Tuple<double,double,double> position, System.Tuple<double,double,double> velocity, ReferenceFrame from, ReferenceFrame to)

      Convert a velocity from one reference frame to another. The velocity of a point
      depends on its position in a rotating frame, so the position is also needed.

      :parameters:

       * **position** -- Position, in meters, in the frame *from*.
       * **velocity** -- Velocity, in meters per second, in the frame *from*.
       * **from** -- The reference frame the position and velocity are in.
       * **to** -- The reference frame to convert the velocity to.

      :returns: The velocity in the frame *to*.
      :Game Scenes: All
