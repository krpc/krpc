Burn
====


.. class:: Burn

   A planned burn, the game's equivalent of a maneuver node. Obtained from
   :prop:`Vehicle.Burns` or :meth:`Vehicle.AddBurn`.

   .. note::

      The change in velocity is given along the vehicle's orbit at the time of the burn:
      prograde, along the orbit normal, and radially outward. An object for a burn throws an
      exception once the burn is removed. The flight computer removes a burn it completes
      when another burn follows it, and keeps the last one. The game removes a burn that
      stops part way, such as when the engines run out of propellant.

   .. property:: double UT { get; set; }

      The universal time of the burn, in seconds. The burn is centered on this time.

      :Game Scenes: All


      .. note::

         Setting it moves the burn along the vehicle's trajectory, as the game's burn
         editor does. The change in velocity keeps its prograde, normal and radial parts.
         Throws an exception if the time is in the past, or beyond the vehicle's predicted
         trajectory.

   .. property:: float TimeTo { get; }

      The time until :prop:`Burn.UT`, in seconds. Negative once that time has passed.

      :Game Scenes: All

   .. property:: float Prograde { get; set; }

      The change in velocity in the prograde direction, in meters per second.

      :Game Scenes: All

   .. property:: float Normal { get; set; }

      The change in velocity along the orbit normal, in meters per second.

      :Game Scenes: All

   .. property:: float Radial { get; set; }

      The change in velocity radially outward, in meters per second.

      :Game Scenes: All

   .. property:: float DeltaV { get; }

      The magnitude of the change in velocity, in meters per second.

      :Game Scenes: All

   .. property:: float RemainingDeltaV { get; }

      The change in velocity still to burn, in meters per second. Less than
      :prop:`Burn.DeltaV` once the vehicle has started the burn.

      :Game Scenes: All


      .. note::

         The flight computer tracks the progress of the next burn only. For later burns this
         is :prop:`Burn.DeltaV`.

   .. property:: double IgnitionTime { get; }

      The universal time at which to start the burn, in seconds. Not a number for a burn
      other than the next one, and until the flight computer has timed it.

      :Game Scenes: All

   .. property:: float BurnTime { get; }

      The time the remaining burn takes with the active engines, in seconds. Not a number
      for a burn other than the next one, and until the flight computer has timed it.

      :Game Scenes: All

   .. property:: Orbit Orbit { get; }

      The orbit after the burn.

      :Game Scenes: All


      .. note::

         The game predicts it in the solver step after the burn changes, so it reflects a
         change to the burn one update later.

   .. property:: float OrbitAverageDoseRate { get; }

      The radiation dose rate averaged over the orbit after the burn, in sieverts per
      second. Not a number if the body has no magnetosphere, or the orbit dips below the
      surface.

      :Game Scenes: All

   .. property:: ReferenceFrame ReferenceFrame { get; }

      The reference frame with its origin at the position of the burn, and axes along
      the orbit at the time of the burn. The x axis points prograde, the y axis along the
      orbit normal and the z axis radially outward, perpendicular to the x axis. The
      frame does not move or rotate relative to the body being orbited.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> Position(ReferenceFrame referenceFrame)

      The position of the burn, in meters, relative to where the body being orbited is
      now.

      :parameters:

       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> Direction(ReferenceFrame referenceFrame)

      The direction of the change in velocity at the time of the burn, as a unit vector.

      :parameters:

       * **referenceFrame** -- The reference frame of the direction.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> BurnVector(ReferenceFrame referenceFrame)

      The change in velocity of the burn, in meters per second.

      :parameters:

       * **referenceFrame** -- The reference frame of the vector.

      :Game Scenes: All


      .. note::

         The vector has the direction of :meth:`Burn.Direction` and the length of
         :prop:`Burn.DeltaV`.

   .. function:: System.Tuple<double,double,double> RemainingBurnVector(ReferenceFrame referenceFrame)

      The change in velocity still to burn, in meters per second.

      :parameters:

       * **referenceFrame** -- The reference frame of the vector.

      :Game Scenes: All


      .. note::

         The vector has the length of :prop:`Burn.RemainingDeltaV`. The flight computer
         tracks the progress of the next burn only. For later burns this is
         :meth:`Burn.BurnVector`.

   .. function:: void Remove()

      Remove the burn from the vehicle's burn plan.


      :Game Scenes: All
