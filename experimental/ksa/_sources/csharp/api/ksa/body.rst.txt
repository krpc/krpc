Body
====


.. class:: Body

   A planet, moon or star. See :prop:`KSA.Bodies <KSA.KSA.Bodies>`.

   .. property:: string Name { get; }

      The name of the body.

      :Game Scenes: All

   .. property:: bool IsStar { get; }

      Whether the body is a star.

      :Game Scenes: All

   .. property:: double Mass { get; }

      The mass of the body, in kilograms.

      :Game Scenes: All

   .. property:: double GravitationalParameter { get; }

      The standard gravitational parameter of the body, in cubic meters per second squared.

      :Game Scenes: All

   .. property:: double Radius { get; }

      The radius of the body, in meters.

      :Game Scenes: All

   .. property:: double AtmosphereRadius { get; }

      The radius of the top of the atmosphere, in meters. Zero for a body with no
      atmosphere.

      :Game Scenes: All

   .. property:: bool HasAtmosphere { get; }

      Whether the body has an atmosphere.

      :Game Scenes: All

   .. property:: float SeaLevelPressure { get; }

      The atmospheric pressure at the body's mean radius, in pascals. Zero for a body
      with no atmosphere.

      :Game Scenes: All

   .. property:: float SeaLevelDensity { get; }

      The density of the atmosphere at the body's mean radius, in kilograms per cubic
      meter. Zero for a body with no atmosphere.

      :Game Scenes: All

   .. property:: float ScaleHeight { get; }

      The height over which the atmospheric pressure falls by a factor of ``e`` at
      sea level, in meters. Zero for a body with no atmosphere.

      :Game Scenes: All

   .. function:: float PressureAt(double altitude)

      The atmospheric pressure at an altitude, in pascals. Zero for a body with no
      atmosphere.

      :parameters:

       * **altitude** -- Altitude above the body's mean radius, in meters.

      :Game Scenes: All

   .. function:: float DensityAt(double altitude)

      The density of the atmosphere at an altitude, in kilograms per cubic meter. Zero
      for a body with no atmosphere.

      :parameters:

       * **altitude** -- Altitude above the body's mean radius, in meters.

      :Game Scenes: All

   .. function:: float TemperatureAt(double altitude)

      The temperature of the atmosphere at an altitude, in kelvin. Zero for a body with
      no atmosphere, or above the atmosphere.

      :parameters:

       * **altitude** -- Altitude above the body's mean radius, in meters.

      :Game Scenes: All

   .. function:: float SpeedOfSoundAt(double altitude)

      The speed of sound in the atmosphere at an altitude, in meters per second. Zero for
      a body with no atmosphere, or above the atmosphere.

      :parameters:

       * **altitude** -- Altitude above the body's mean radius, in meters.

      :Game Scenes: All

   .. property:: float AtmosphereOxygenFraction { get; }

      The fraction of the atmosphere that is oxygen, by volume. Zero for a body with no
      atmosphere.

      :Game Scenes: All

   .. property:: float AtmosphereMolarMass { get; }

      The mean molar mass of the atmosphere, in kilograms per mole. Zero for a body with
      no atmosphere.

      :Game Scenes: All

   .. property:: bool HasOcean { get; }

      Whether the body has an ocean.

      :Game Scenes: All

   .. property:: float OceanDensity { get; }

      The density of the ocean, in kilograms per cubic meter. Zero for a body with no
      ocean.

      :Game Scenes: All

   .. property:: int GeomagneticStormLevel { get; }

      The level of the geomagnetic storm at the body, from 0 for none to 5 for the most
      severe. The G level of the game's space weather window. Zero for a body with no
      magnetosphere.

      :Game Scenes: All

   .. property:: float DstIndex { get; }

      The disturbance storm time index of the body, in teslas. It falls below zero in a
      geomagnetic storm. Zero for a body with no magnetosphere.

      :Game Scenes: All

   .. property:: float SolarActivity { get; }

      The activity of a star, from 0 at the minimum of its cycle to 1 at the maximum.
      Zero for a body that is not a star.

      :Game Scenes: All

   .. property:: bool SolarActivityRising { get; }

      Whether the activity of a star is rising toward the maximum of its cycle.
      False for a body that is not a star, or a star with no cycle.

      :Game Scenes: All

   .. property:: float TimeToSolarActivityTurn { get; }

      The time until the activity of a star reaches the maximum or minimum of its cycle,
      in seconds. Not a number for a body that is not a star, or a star with no cycle.

      :Game Scenes: All

   .. property:: float CoronalMassEjectionsPerDay { get; }

      The mean number of coronal mass ejections a star throws out per day, at its
      current activity. Zero for a body that is not a star.

      :Game Scenes: All

   .. property:: int ActiveRegionCount { get; }

      The number of active regions on a star, the sources of its eruptions. Zero for a
      body that is not a star.

      :Game Scenes: All

   .. property:: System.Collections.Generic.IList<CoronalMassEjection> RecentCoronalMassEjections { get; }

      The fast coronal mass ejections a star threw out in the last three days, as the
      game's space weather window lists them. Empty for a body that is not a star.

      :Game Scenes: All

   .. property:: float SurfaceGravity { get; }

      The acceleration due to gravity at the body's mean radius, in meters per second
      squared.

      :Game Scenes: All

   .. property:: float RotationalSpeed { get; }

      The rate at which the body rotates about its axis, in radians per second.

      :Game Scenes: All

   .. property:: float RotationalPeriod { get; }

      The time the body takes to rotate once about its axis, relative to the stars, in
      seconds. Infinite for a body that does not rotate.

      :Game Scenes: All

   .. property:: double SphereOfInfluence { get; }

      The radius of the body's sphere of influence, in meters. Not a number for a body
      that orbits nothing.

      :Game Scenes: All

   .. property:: Body Parent { get; }

      The body this body orbits, or ``null`` if it orbits nothing.

      :Game Scenes: All

   .. property:: System.Collections.Generic.IList<Body> Satellites { get; }

      The bodies that orbit this body.

      :Game Scenes: All

   .. property:: Orbit Orbit { get; }

      The orbit of the body, or ``null`` if it orbits nothing.

      :Game Scenes: All

   .. function:: double SurfaceHeight(double latitude, double longitude)

      The height of the terrain or the sea surface, whichever is higher, at a point on
      the body, in meters above the body's mean radius.

      :parameters:

       * **latitude** -- Latitude, in degrees.
       * **longitude** -- Longitude, in degrees.

      :Game Scenes: All

   .. function:: double BedrockHeight(double latitude, double longitude)

      The height of the terrain at a point on the body, in meters above the body's mean
      radius. Below the sea, this is the height of the sea floor.

      :parameters:

       * **latitude** -- Latitude, in degrees.
       * **longitude** -- Longitude, in degrees.

      :Game Scenes: All


      .. note::

         Zero for a body with no terrain, such as a gas giant.

   .. property:: System.Collections.Generic.IList<string> LaunchSites { get; }

      The names of the launch sites on the body. See :meth:`KSA.LaunchVehicle <KSA.KSA.LaunchVehicle>`.

      :Game Scenes: All

   .. property:: System.Collections.Generic.IList<string> Biomes { get; }

      The names of the body's biomes. Empty for a body with no biomes.

      :Game Scenes: All

   .. function:: string BiomeAt(double latitude, double longitude)

      The biome at a point on the body, or ``null`` if the body has no biomes.

      :parameters:

       * **latitude** -- Latitude, in degrees.
       * **longitude** -- Longitude, in degrees.

      :Game Scenes: All

   .. property:: ReferenceFrame ReferenceFrame { get; }

      The reference frame fixed to the body, with its origin at the body's center. The
      z axis points to the north pole, the x axis to latitude and longitude zero, and the
      y axis to latitude zero and longitude 90 degrees east. The frame rotates with the
      body.

      :Game Scenes: All

   .. property:: ReferenceFrame NonRotatingReferenceFrame { get; }

      The reference frame with its origin at the body's center that does not rotate. The
      z axis points to the north pole, and the x and y axes are fixed relative to the
      stars.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> Position(ReferenceFrame referenceFrame)

      The position of the center of the body, in meters.

      :parameters:

       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> Velocity(ReferenceFrame referenceFrame)

      The velocity of the body, in meters per second.

      :parameters:

       * **referenceFrame** -- The reference frame of the velocity.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double,double> Rotation(ReferenceFrame referenceFrame)

      The rotation of :prop:`Body.ReferenceFrame` relative to the given frame.

      :parameters:

       * **referenceFrame** -- The reference frame of the rotation.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> AngularVelocity(ReferenceFrame referenceFrame)

      The angular velocity of the body, in radians per second. The vector points along
      the axis of rotation, and its length is the rate of rotation.

      :parameters:

       * **referenceFrame** -- The reference frame of the angular velocity.

      :Game Scenes: All

   .. function:: System.Tuple<double,double,double> SurfacePosition(double latitude, double longitude, ReferenceFrame referenceFrame)

      The position of a point on the surface, at the body's mean radius, in meters.

      :parameters:

       * **latitude** -- Latitude, in degrees.
       * **longitude** -- Longitude, in degrees.
       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All

   .. function:: double LatitudeAtPosition(System.Tuple<double,double,double> position, ReferenceFrame referenceFrame)

      The latitude of a position, in degrees.

      :parameters:

       * **position** -- Position, in meters.
       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All

   .. function:: double LongitudeAtPosition(System.Tuple<double,double,double> position, ReferenceFrame referenceFrame)

      The longitude of a position, in degrees.

      :parameters:

       * **position** -- Position, in meters.
       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All

   .. function:: double AltitudeAtPosition(System.Tuple<double,double,double> position, ReferenceFrame referenceFrame)

      The altitude of a position above the body's mean radius, in meters.

      :parameters:

       * **position** -- Position, in meters.
       * **referenceFrame** -- The reference frame of the position.

      :Game Scenes: All
