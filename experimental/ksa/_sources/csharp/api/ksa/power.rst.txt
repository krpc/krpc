Power
=====


.. class:: Battery

   A battery, which stores electrical energy. Obtained from :prop:`Part.Batteries`.

   .. property:: Part Part { get; }

      The part the battery is in.

      :Game Scenes: All

   .. property:: float StoredEnergy { get; }

      The energy stored in the battery, in joules.

      :Game Scenes: All

   .. property:: float EnergyCapacity { get; }

      The energy the battery can store, in joules.

      :Game Scenes: All



.. class:: SolarPanel

   A solar panel, which turns sunlight into electrical power. Obtained from :prop:`Part.SolarPanels`.

   .. property:: Part Part { get; }

      The part the solar panel is in.

      :Game Scenes: All

   .. property:: bool Active { get; }

      Whether the solar panel can produce power, because it is deployed or does not deploy.

      :Game Scenes: All

   .. property:: float Power { get; }

      The power the solar panel produces, in watts.

      :Game Scenes: All

   .. property:: float SunAngle { get; }

      The angle between the solar panel's face and the direction to the sun, in degrees.
      Zero when the panel faces the sun.

      :Game Scenes: All

   .. property:: bool Occluded { get; }

      Whether a body blocks the sunlight to the solar panel.

      :Game Scenes: All

   .. property:: Deployable Deployable { get; }

      The deployable section that opens the solar panel, or ``null`` for a panel that
      does not deploy.

      :Game Scenes: All



.. class:: Generator

   A generator, which produces electrical power. Obtained from :prop:`Part.Generators`.

   .. note::

      A generator runs while its :prop:`Generator.Engine` is active, and produces power in
      proportion to the engine's throttle.

   .. property:: Part Part { get; }

      The part the generator is in.

      :Game Scenes: All

   .. property:: Engine Engine { get; }

      The engine that drives the generator, or ``null`` if it has none.

      :Game Scenes: All

   .. property:: bool Active { get; }

      Whether the generator is producing power.

      :Game Scenes: All

   .. property:: float Power { get; }

      The power the generator produces, in watts.

      :Game Scenes: All



.. class:: PowerConsumer

   A power consumer, which uses electrical power, such as a light. Obtained from
   :prop:`Part.PowerConsumers`.

   .. property:: Part Part { get; }

      The part the power consumer is in.

      :Game Scenes: All

   .. property:: bool Active { get; }

      Whether the part is using power.

      :Game Scenes: All

   .. property:: float Power { get; }

      The power the part uses, in watts.

      :Game Scenes: All



.. class:: Light

   A light. Obtained from :prop:`Part.Lights`.

   .. note::

      The vehicle's lights switch on and off together, see :prop:`Control.Lights`.
      Cabin lights are always on.

   .. property:: Part Part { get; }

      The part the light is in.

      :Game Scenes: All

   .. property:: bool Active { get; }

      Whether the light is on.

      :Game Scenes: All
