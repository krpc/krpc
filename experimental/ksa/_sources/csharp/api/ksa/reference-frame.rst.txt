Reference Frame
===============


.. class:: ReferenceFrame

   A reference frame, in which positions, directions, rotations and velocities are given.
   Obtained from the reference frame properties of :type:`Vehicle` and
   :type:`Body`, or created with :meth:`ReferenceFrame.CreateRelative` and
   :meth:`ReferenceFrame.CreateHybrid`.

   .. note::

      Every reference frame is right-handed. Positions are in meters, velocities in meters
      per second, and angular velocities in radians per second. A rotation is a quaternion
      ``(x, y, z, w)``.

   .. function:: static ReferenceFrame CreateRelative(IConnection connection, ReferenceFrame referenceFrame, System.Tuple<double,double,double> position = null, System.Tuple<double,double,double,double> rotation = null, System.Tuple<double,double,double> velocity = null, System.Tuple<double,double,double> angularVelocity = null)

      Create a reference frame that is offset from a parent frame.

      :parameters:

       * **referenceFrame** -- The parent reference frame.
       * **position** -- The position of the origin in the parent frame, in meters. Defaults to ``(0, 0, 0)``. If null, defaults to ``new System.Tuple<double,double,double>(0.0, 0.0, 0.0)``.
       * **rotation** -- The rotation of the frame relative to the parent frame. Defaults to ``(0, 0, 0, 1)``, no rotation. If null, defaults to ``new System.Tuple<double,double,double,double>(0.0, 0.0, 0.0, 1.0)``.
       * **velocity** -- The velocity of the origin in the parent frame, in meters per second. Defaults to ``(0, 0, 0)``. If null, defaults to ``new System.Tuple<double,double,double>(0.0, 0.0, 0.0)``.
       * **angularVelocity** -- The angular velocity of the frame relative to the parent frame, in radians per second, in the axes of the parent frame. Defaults to ``(0, 0, 0)``. If null, defaults to ``new System.Tuple<double,double,double>(0.0, 0.0, 0.0)``.

      :Game Scenes: All

   .. function:: static ReferenceFrame CreateHybrid(IConnection connection, ReferenceFrame position, ReferenceFrame rotation = null, ReferenceFrame velocity = null, ReferenceFrame angularVelocity = null)

      Create a reference frame that takes its components from other frames.

      :parameters:

       * **position** -- The reference frame that gives the origin.
       * **rotation** -- The reference frame that gives the axes. Defaults to *position*.
       * **velocity** -- The reference frame that gives the velocity of the origin. Defaults to *position*.
       * **angularVelocity** -- The reference frame that gives the angular velocity. Defaults to *position*.

      :Game Scenes: All
