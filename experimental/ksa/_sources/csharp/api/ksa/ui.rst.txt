UI
==


.. class:: UI

   Adds windows of buttons, text fields and other widgets to the game's UI.

   .. note::

      The windows are removed when the client that added them disconnects. For messages on
      the screen, see :meth:`KSA.ShowMessage <KSA.KSA.ShowMessage>`.

   .. function:: static Window AddWindow(IConnection connection, string title, bool visible = true)

      Add a window, with no widgets.

      :parameters:

       * **title** -- The text in the title bar.
       * **visible** -- Whether the window is visible.

      :Game Scenes: All

   .. function:: static void Clear(IConnection connection, bool clientOnly = false)

      Remove the windows.

      :parameters:

       * **clientOnly** -- Whether to remove only the windows added by the calling client.

      :Game Scenes: All



.. class:: Window

   A window, holding widgets one per line. Created using :meth:`UI.AddWindow`.

   .. note::

      The window fits its widgets until its size is set. Closing the window makes it
      invisible. The window is hidden with the game's UI.

   .. property:: string Title { get; set; }

      The text in the title bar.

      :Game Scenes: All

   .. property:: System.Tuple<float,float> Position { get; set; }

      The position of the top left corner of the window, from the top left corner of the
      game window, in pixels.

      :Game Scenes: All

   .. property:: System.Tuple<float,float> Size { get; set; }

      The width and height of the window, in pixels.

      :Game Scenes: All


      .. note::

         Throws an exception if the width or height is not positive.

   .. property:: bool Visible { get; set; }

      Whether the widget is visible.

      :Game Scenes: All

   .. property:: bool Enabled { get; set; }

      Whether the widget responds to input. A disabled widget is drawn dimmed.

      :Game Scenes: All

   .. function:: Label AddLabel(string content, bool visible = true)

.. class:: InputField

   A single line text input field. Added to a window or a row.

   .. note::

      While the field is being edited, the game clears the rotation and translation inputs
      of the controlled vehicle each frame.

   .. property:: string Label { get; set; }

      The text shown next to the field.

      :Game Scenes: All

   .. property:: string Value { get; set; }

      The text in the field.

      :Game Scenes: All

   .. property:: bool Changed { get; set; }

      Whether the text has been edited.

      :Game Scenes: All


      .. note::

         An edit sets this to ``true``, and it stays ``true`` until set to
         ``false``. Setting :prop:`InputField.Value` leaves it unchanged.

   .. property:: bool Visible { get; set; }

      Whether the widget is visible.

      :Game Scenes: All

   .. property:: bool Enabled { get; set; }

      Whether the widget responds to input. A disabled widget is drawn dimmed.

   .. property:: string Label { get; set; }

      The text shown next to the slider.

   .. property:: float Value { get; set; }

      :Game Scenes: All

   .. property:: float Minimum { get; set; }

      The minimum value.

      :Game Scenes: All


      .. note::

         Throws an exception if set to a value not less than the maximum.

   .. property:: float Maximum { get; set; }

      The maximum value.

      :Game Scenes: All

         Throws an exception if set to a value not greater than the minimum.

   .. property:: bool Changed { get; set; }

      Whether the value has been changed by dragging the slider.

      :Game Scenes: All


      .. note::

         A change sets this to ``true``, and it stays ``true`` until set to
         ``false``. Setting :prop:`Slider.Value` leaves it unchanged.

   .. property:: bool Visible { get; set; }

      Whether the widget is visible.

      :Game Scenes: All

   .. property:: bool Enabled { get; set; }
