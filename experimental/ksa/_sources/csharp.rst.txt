C#
==

This page covers using the kRPC C# client with the ``KSA`` service. The
`kRPC C# client guide <https://krpc.github.io/krpc/0.7.0/csharp/client.html>`_ covers the client in full.

.. note::

   kRPC for KSA is experimental, and the client package does not yet include the ``KSA``
   service stubs. You add them from the release archive, as below, until a later release makes
   this easier.

Installing
----------

Add the `KRPC.Client <https://www.nuget.org/packages/KRPC.Client>`_ 0.7.0 NuGet
package to the project, and ``csharp/KSA.cs`` from the ``stubs`` folder of the release
archive.

The `kRPC C# client guide <https://krpc.github.io/krpc/0.7.0/csharp/client.html#installing>`_ covers other ways to
install the client.

Connecting to the Server
------------------------

The service is ``connection.KSA ()``:

.. code-block:: csharp

   using KRPC.Client;
   using KRPC.Client.Services.KSA;

   var connection = new Connection ("Example");
   var vehicle = connection.KSA ().ActiveVehicle;
   Console.WriteLine (vehicle.Name);

The `kRPC C# client guide <https://krpc.github.io/krpc/0.7.0/csharp/client.html>`_ covers connecting, streams, events
and the client's other features.
