Parts
=====


.. class:: Part

   A part of a vehicle. Obtained from :attr:`KSA.Vehicle.parts`.

   .. note::

      A part keeps its object when the vehicle it belongs to changes, for example when a
      decoupler separates it. Throws an exception once the part no longer exists.

   .. attribute:: name: string

      The id of the part's template.

      :Attribute: Read-only, cannot be set
      :rtype: string

   .. attribute:: title: string

      The name of the part, as shown in the game.

      :Attribute: Read-only, cannot be set
      :rtype: string

   .. attribute:: vehicle: KSA.Vehicle

      The vehicle the part belongs to.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Vehicle`

   .. attribute:: parent: KSA.Part

      The part this part is attached to, or ``nil`` for the root part.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part` or ``Types.none``

   .. attribute:: children: List

      The parts attached to this part.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: sequence: number

      The number of the sequence that activates the part, or -1 if no sequence does.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: mass: number

      The mass of the part, including its propellant, in kilograms.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: dry_mass: number

      The mass of the part without its propellant, in kilograms.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: resources: List

      The resources the part holds, one for each substance.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: tanks: List

      The part's propellant tanks. Empty if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: batteries: List

      The part's batteries.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: solar_panels: List

      The part's solar panels.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: generators: List

      The part's generators.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: power_consumers: List

      The part's power consumers.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: lights: List

      The part's lights.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: deployables: List

      The part's deployable sections. A part can have several, such as the doors of a
      service module.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: magnetic_scoops: List

      The part's magnetic scoops. Empty if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. method:: position(reference_frame)

      The position of the part's origin, in meters.

      :param KSA.ReferenceFrame reference_frame: The reference frame of the position.
      :rtype: Tuple

   .. method:: velocity(reference_frame)

      The velocity of the part's origin, in meters per second.

      :param KSA.ReferenceFrame reference_frame: The reference frame of the velocity.
      :rtype: Tuple

   .. method:: rotation(reference_frame)

      The rotation of the part's axes, relative to the given frame.

      :param KSA.ReferenceFrame reference_frame: The reference frame of the rotation.
      :rtype: Tuple

   .. attribute:: engine: KSA.Engine

      The part's engine, or ``nil`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Engine` or ``Types.none``

   .. attribute:: gimbals: List

      The part's gimbals. An engine part can have several, each steering one nozzle.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: rcs: KSA.RCS

      The part's RCS thrusters, or ``nil`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.RCS` or ``Types.none``

   .. attribute:: decoupler: KSA.Decoupler

      The part's decoupler, or ``nil`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Decoupler` or ``Types.none``

   .. attribute:: parachute: KSA.Parachute

      The part's parachute, or ``nil`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Parachute` or ``Types.none``

   .. attribute:: docking_port: KSA.DockingPort

      The part's docking port, or ``nil`` if it has none.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.DockingPort` or ``Types.none``

   .. attribute:: seats: List

      The part's crew seats.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: crew: List

      The kittens in the part's seats.

      :Attribute: Read-only, cannot be set
      :rtype: List



.. class:: Engine

   An engine. Obtained from :attr:`KSA.Part.engine`.

   .. note::

      An active engine fires when the vehicle's engines are on, at the vehicle's throttle.
      See :attr:`KSA.Control.engine_on` and :attr:`KSA.Control.throttle`.

   .. attribute:: part: KSA.Part

      The part the engine is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: gimbals: List

      The gimbals that steer the engine's nozzles. Empty if the engine has none.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: active: boolean

      Whether the engine is active, as when its sequence is activated. Setting it returns
      once the change has applied.

      :Attribute: Can be read or written
      :rtype: boolean

   .. attribute:: has_propellant: boolean

      Whether the engine has propellant to burn.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. attribute:: minimum_throttle: number

      The lowest throttle the engine runs at, between 0 and 1.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: propellants: List

      The names of the substances the engine burns. See :attr:`KSA.Resource.name`.

      :Attribute: Read-only, cannot be set
      :rtype: List

   .. attribute:: thrust: number

      The thrust of the engine at its current throttle and the current atmospheric
      pressure, in Newtons. Zero when it is not firing.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: available_thrust: number

      The thrust of the engine at full throttle and the current atmospheric pressure, in
      Newtons. Zero when it is inactive or has no propellant.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: specific_impulse: number

      The specific impulse of the engine at the current atmospheric pressure, in seconds.
      Zero when it is inactive or has no propellant.

      :Attribute: Read-only, cannot be set
      :rtype: number



.. class:: Gimbal

   A gimbal that steers an engine nozzle. Obtained from :attr:`KSA.Part.gimbals` or
   :attr:`KSA.Engine.gimbals`.

   .. note::

      A gimbal turns about the y and z axes of its mount, which :meth:`KSA.Gimbal.rotation` gives.
      The flight computer steers it while an engine it belongs to is :attr:`KSA.Gimbal.active`.

   .. attribute:: part: KSA.Part

      The part the gimbal is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: angle_y: number

      The angle of the gimbal about its y axis, in degrees.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: angle_z: number

      The angle of the gimbal about its z axis, in degrees.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: max_angle_y: number

      The largest angle of the gimbal about its y axis, in degrees. Zero if it does not
      turn about that axis.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: max_angle_z: number

      The largest angle of the gimbal about its z axis, in degrees. Zero if it does not
      turn about that axis.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: active: boolean

      Whether an engine the gimbal steers is active.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. method:: rotation(reference_frame)

      The rotation of the gimbal's mount, whose y and z axes the gimbal turns about.

      :param KSA.ReferenceFrame reference_frame: The reference frame of the rotation.
      :rtype: Tuple



.. class:: RCS

   The RCS thrusters of a part. Obtained from :attr:`KSA.Part.rcs`.

   .. note::

      Active thrusters fire when the vehicle's RCS is on. See :attr:`KSA.Control.rcs`.

   .. attribute:: part: KSA.Part

      The part the thrusters are in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: active: boolean

      Whether the thrusters are active. Setting it returns once the change has applied.

      :Attribute: Can be read or written
      :rtype: boolean



.. class:: Decoupler

   A decoupler. Obtained from :attr:`KSA.Part.decoupler`.

   .. attribute:: part: KSA.Part

      The part the decoupler is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: enabled: boolean

      Whether the decoupler can fire.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. attribute:: decoupled: boolean

      Whether the decoupler has fired, or is attached to nothing.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. method:: decouple()

      Fire the decoupler, separating the vehicle into two. Returns once it has fired.
      Throws an exception if the decoupler is disabled or :attr:`KSA.Decoupler.decoupled`.

      :returns: The vehicles that separated from this one.
      :rtype: List



.. class:: Parachute

   A parachute. Obtained from :attr:`KSA.Part.parachute`.

   .. attribute:: part: KSA.Part

      The part the parachute is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: state: KSA.ParachuteState

      The state of the parachute.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.ParachuteState`

   .. attribute:: fill: number

      How far the canopy is open, from 0 to 1.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: deploy_altitude: number

      The height above the terrain at which an armed parachute deploys, in meters.

      :Attribute: Read-only, cannot be set
      :rtype: number

   .. attribute:: can_cut: boolean

      Whether the parachute can be cut away. Main parachutes cannot.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. method:: deploy()

      Arm the parachute, so that it deploys at :attr:`KSA.Parachute.deploy_altitude`. Returns once
      it is armed. Throws an exception if it is not stowed.

   .. method:: cut()

      Cut the parachute away. Returns once it is cut. Throws an exception if it cannot
      be cut. See :attr:`KSA.Parachute.can_cut`.



.. class:: ParachuteState

   The state of a parachute. See :attr:`KSA.Parachute.state`.


   .. data:: stowed

      Packed away.


   .. data:: armed

      Waiting to deploy at :attr:`KSA.Parachute.deploy_altitude`.


   .. data:: line_stretch

      Leaving the pack.


   .. data:: reefed

      Partly open, to limit the opening load.


   .. data:: disreefing

      Opening from reefed to full.


   .. data:: full

      Fully open.


   .. data:: cut

      Cut away.


   .. data:: ripped

      Torn by too much dynamic pressure.


   .. data:: severed_lines

      Lost after its lines broke under too much load.



.. class:: DockingPort

   A docking port. Obtained from :attr:`KSA.Part.docking_port`.

   .. attribute:: part: KSA.Part

      The part the docking port is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: docked: boolean

      Whether the port is docked.

      :Attribute: Read-only, cannot be set
      :rtype: boolean

   .. attribute:: docked_part: KSA.Part

      The part the port is docked to, or ``nil`` if it is not docked.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part` or ``Types.none``

   .. method:: undock()

      Undock the port, separating the vehicle into two. Returns once it has undocked.
      Throws an exception if the port is not docked.

      :returns: The new vehicles.
      :rtype: List

      .. note::

         Docking and undocking replace the vehicles involved. See :class:`KSA.Vehicle`.



.. class:: Deployable

   A part that deploys and retracts, such as a landing leg, a solar panel or a service
   module door. Obtained from :attr:`KSA.Part.deployables`.

   .. note::

      Deploying or retracting a part moves its symmetric copies with it, as the part's menu
      in the game does.

   .. attribute:: part: KSA.Part

      The part the deployable is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: state: KSA.DeployableState

      The state of the part.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.DeployableState`

   .. method:: deploy()

      Deploy the part. Returns once it has started to move.


      .. note::

         Throws an exception if the part is broken.

   .. method:: retract()

      Retract the part. Returns once it has started to move.


      .. note::

         Throws an exception if the part is broken.



.. class:: DeployableState

   The state of a deployable part. See :attr:`KSA.Deployable.state`.


   .. data:: deployed

      Fully deployed.


   .. data:: retracted

      Fully retracted.


   .. data:: deploying

      Moving toward deployed.


   .. data:: retracting

      Moving toward retracted.


   .. data:: broken

      Broken, so it can no longer move.



.. class:: MagneticScoop

   A magnetic scoop, which collects gas from space into the vehicle's tanks. Obtained from
   :attr:`KSA.Part.magnetic_scoops`.

   .. attribute:: part: KSA.Part

      The part the scoop is in.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`KSA.Part`

   .. attribute:: active: boolean

      Whether the scoop is switched on.

      :Attribute: Can be read or written
      :rtype: boolean

   .. attribute:: substance: string

      The name of the substance the scoop collects. See :attr:`KSA.Resource.name`.

      :Attribute: Read-only, cannot be set
      :rtype: string

   .. attribute:: collection_rate: number

      The rate the scoop collects gas at, in kilograms per second.

      :Attribute: Read-only, cannot be set
      :rtype: number
