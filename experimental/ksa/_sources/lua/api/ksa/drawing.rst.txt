Drawing
=======


.. class:: Drawing

   Draws lines, shapes and text in the scene, each placed in a reference frame.

   .. note::

      The objects are drawn every frame until removed, and are removed when the client that
      added them disconnects. Lines are drawn at the game's fixed gizmo width.

   .. staticmethod:: add_line(start: Tuple, end: Tuple, reference_frame: KSA.ReferenceFrame, visible?: boolean): KSA.Line

      Draw a line between two positions.

      :param start: The position of the start of the line, in meters.
      :param end: The position of the end of the line, in meters.
      :param reference_frame: The reference frame of the positions.
      :param visible: Whether the line is visible. Defaults to ``true``.

   .. staticmethod:: add_direction(direction: Tuple, reference_frame: KSA.ReferenceFrame, length?: number, visible?: boolean): KSA.Line

      Draw a line from the origin of a reference frame in a direction.

      :param direction: The direction of the line.
      :param reference_frame: The reference frame of the direction.
      :param length: The length of the line, in meters. Defaults to ``1e+01``.
      :param visible: Whether the line is visible. Defaults to ``true``.

   .. staticmethod:: add_polyline(vertices: List, reference_frame: KSA.ReferenceFrame, closed?: boolean, visible?: boolean): KSA.Polyline

      Draw a line through a list of positions.

      :param vertices: The positions the line passes through, in meters.
      :param reference_frame: The reference frame of the positions.
      :param closed: Whether the line joins the last position back to the first. Defaults to ``false``.
      :param visible: Whether the line is visible. Defaults to ``true``.

   .. staticmethod:: add_circle(center: Tuple, normal: Tuple, radius: number, reference_frame: KSA.ReferenceFrame, visible?: boolean): KSA.Circle

      Draw a circle.

      :param center: The position of the center of the circle, in meters.
      :param normal: The direction normal to the plane of the circle.
      :param radius: The radius of the circle, in meters.
      :param reference_frame: The reference frame of the position and direction.
      :param visible: Whether the circle is visible. Defaults to ``true``.

   .. staticmethod:: add_arc(center: Tuple, normal: Tuple, start_direction: Tuple, angle: number, radius: number, reference_frame: KSA.ReferenceFrame, visible?: boolean): KSA.Arc

      Draw an arc of a circle.

      :param center: The position of the center of the arc's circle, in meters.
      :param normal: The direction normal to the plane of the arc.
      :param start_direction: The direction from the center to the start of the arc.
      :param angle: The angle the arc turns through, counterclockwise about the normal, in radians.
      :param radius: The radius of the arc, in meters.
      :param reference_frame: The reference frame of the position and directions.
      :param visible: Whether the arc is visible. Defaults to ``true``.

   .. staticmethod:: add_box(center: Tuple, size: Tuple, rotation: Tuple, reference_frame: KSA.ReferenceFrame, visible?: boolean): KSA.Box

      Draw the edges of a box.

      :param center: The position of the center of the box, in meters.
      :param size: The lengths of the box's edges along its x, y and z axes, in meters.
      :param rotation: The rotation of the box's axes, as a quaternion of the form ``(x, y, z, w)``.
      :param reference_frame: The reference frame of the position and rotation.
      :param visible: Whether the box is visible. Defaults to ``true``.

   .. staticmethod:: add_sphere(center: Tuple, radius: number, reference_frame: KSA.ReferenceFrame, visible?: boolean): KSA.Sphere

      Draw a solid sphere.

      :param center: The position of the center of the sphere, in meters.
      :param radius: The radius of the sphere, in meters.
      :param reference_frame: The reference frame of the position.
      :param visible: Whether the sphere is visible. Defaults to ``true``.

   .. staticmethod:: add_text(text: string, position: Tuple, reference_frame: KSA.ReferenceFrame, size?: number, visible?: boolean): KSA.Text

      Draw text over the scene, centered on a position.

      :param text: The text.
      :param position: The position of the center of the text, in meters.
      :param reference_frame: The reference frame of the position.
      :param size: The height of the font, in pixels. Defaults to ``16.0``.
      :param visible: Whether the text is visible. Defaults to ``true``.

   .. staticmethod:: clear(client_only?: boolean)

      Remove the drawing objects.

      :param client_only: Whether to remove only the objects added by the calling client. Defaults to ``false``.



.. class:: Line

   A line. Created using :meth:`KSA.Drawing.add_line` or :meth:`KSA.Drawing.add_direction`.

   .. attribute:: start: Tuple

      The start position of the line, in meters.

      :Attribute: Can be read or written

   .. attribute:: end: Tuple

      The end position of the line, in meters.

      :Attribute: Can be read or written

   .. attribute:: reference_frame: KSA.ReferenceFrame

      The reference frame for the positions and directions of the object.

      :Attribute: Can be read or written

   .. attribute:: visible: boolean

      Whether the object is visible.

      :Attribute: Can be read or written

   .. attribute:: color: StdLib.ColorRGB

      The color of the object, as an RGB triple with components from 0 to 1.

      :Attribute: Can be read or written

   .. method:: remove()

      Remove the object.
