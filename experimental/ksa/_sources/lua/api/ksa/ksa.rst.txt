KSA
===


.. module:: KSA

Provides functionality to interact with Kitten Space Agency.


.. attribute:: active_vehicle: KSA.Vehicle

   The vehicle under the player's control.

   :Attribute: Can be read or written
   :rtype: :class:`KSA.Vehicle` or ``Types.none``

   .. note::

      Setting it moves the camera to the vehicle, as the switch vehicle key does.




.. attribute:: vehicles: List

   The vehicles in the current system, excluding kittens on EVA.

   :Attribute: Read-only, cannot be set
   :rtype: List




.. attribute:: bodies: Map

   The planets, moons and stars in the current system, keyed by name.

   :Attribute: Read-only, cannot be set
   :rtype: Map




.. attribute:: ut: number

   The universal time, in seconds.

   :Attribute: Read-only, cannot be set
   :rtype: number




.. attribute:: simulation_speed: number

   The simulation speed, as a multiple of real time. Zero when paused.

   :Attribute: Can be read or written
   :rtype: number




.. staticmethod:: warp_to(ut)

   Warp to the given universal time, and return once the warp has finished.
   The game slows the warp down to normal speed toward the end.

   :param number ut: The universal time to warp to, in seconds.

   .. note::

      Does nothing when the time is in the past. Returns early if the game stops the
      warp, for example when its menu pauses the game.




.. staticmethod:: launch_vehicle(name, site)

   Launch a vehicle from a launch site, and make it the active vehicle. Returns once
   the vehicle is on the launch site.

   :param string name: The name of the vehicle, one of the game's default vehicles or a vehicle saved by the player.
   :param string site: The name of the launch site. See :attr:`KSA.Body.launch_sites`.
   :returns: The vehicle. Its name is the vehicle's name, with a number appended if another vehicle has that name.
   :rtype: :class:`KSA.Vehicle`

   .. note::

      Throws an exception if there is no such vehicle or launch site.




.. staticmethod:: transform_position(position, from, to)

   Convert a position from one reference frame to another.

   :param Tuple position: Position, in meters, in the frame *from*.
   :param KSA.ReferenceFrame from: The reference frame the position is in.
   :param KSA.ReferenceFrame to: The reference frame to convert the position to.
   :returns: The position in the frame *to*.
   :rtype: Tuple




.. staticmethod:: transform_direction(direction, from, to)

   Convert a direction from one reference frame to another.

   :param Tuple direction: Direction in the frame *from*.
   :param KSA.ReferenceFrame from: The reference frame the direction is in.
   :param KSA.ReferenceFrame to: The reference frame to convert the direction to.
   :returns: The direction in the frame *to*.
   :rtype: Tuple




.. staticmethod:: transform_rotation(rotation, from, to)

   Convert a rotation from one reference frame to another.

   :param Tuple rotation: Rotation in the frame *from*.
   :param KSA.ReferenceFrame from: The reference frame the rotation is in.
   :param KSA.ReferenceFrame to: The reference frame to convert the rotation to.
   :returns: The rotation in the frame *to*.
   :rtype: Tuple




.. staticmethod:: transform_velocity(position, velocity, from, to)

   Convert a velocity from one reference frame to another. The velocity of a point
   depends on its position in a rotating frame, so the position is also needed.

   :param Tuple position: Position, in meters, in the frame *from*.
   :param Tuple velocity: Velocity, in meters per second, in the frame *from*.
   :param KSA.ReferenceFrame from: The reference frame the position and velocity are in.
   :param KSA.ReferenceFrame to: The reference frame to convert the velocity to.
   :returns: The velocity in the frame *to*.
   :rtype: Tuple
