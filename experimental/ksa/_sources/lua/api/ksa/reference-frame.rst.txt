Reference Frame
===============


.. class:: ReferenceFrame

   A reference frame, in which positions, directions, rotations and velocities are given.
   Obtained from the reference frame properties of :class:`KSA.Vehicle` and
   :class:`KSA.Body`, or created with :meth:`KSA.ReferenceFrame.create_relative` and
   :meth:`KSA.ReferenceFrame.create_hybrid`.

   .. note::

      Every reference frame is right-handed. Positions are in meters, velocities in meters
      per second, and angular velocities in radians per second. A rotation is a quaternion
      ``(x, y, z, w)``.

   .. staticmethod:: create_relative(reference_frame: KSA.ReferenceFrame, position?: Tuple, rotation?: Tuple, velocity?: Tuple, angular_velocity?: Tuple): KSA.ReferenceFrame

      Create a reference frame that is offset from a parent frame.

      :param reference_frame: The parent reference frame.
      :param position: The position of the origin in the parent frame, in meters. Defaults to ``(0, 0, 0)``. Defaults to ``{0.0, 0.0, 0.0}``.
      :param rotation: The rotation of the frame relative to the parent frame. Defaults to ``(0, 0, 0, 1)``, no rotation. Defaults to ``{0.0, 0.0, 0.0, 1.0}``.
      :param velocity: The velocity of the origin in the parent frame, in meters per second. Defaults to ``(0, 0, 0)``. Defaults to ``{0.0, 0.0, 0.0}``.
      :param angular_velocity: The angular velocity of the frame relative to the parent frame, in radians per second, in the axes of the parent frame. Defaults to ``(0, 0, 0)``. Defaults to ``{0.0, 0.0, 0.0}``.

   .. staticmethod:: create_hybrid(position: KSA.ReferenceFrame, rotation?: KSA.ReferenceFrame | Types.none, velocity?: KSA.ReferenceFrame | Types.none, angular_velocity?: KSA.ReferenceFrame | Types.none): KSA.ReferenceFrame

      Create a reference frame that takes its components from other frames.

      :param position: The reference frame that gives the origin.
      :param rotation: The reference frame that gives the axes. Defaults to *position*.
      :param velocity: The reference frame that gives the velocity of the origin. Defaults to *position*.
      :param angular_velocity: The reference frame that gives the angular velocity. Defaults to *position*.
