Debug
=====


.. class:: Debug

   Changes the state of the simulation directly, as the game's debug windows and console
   commands do: teleporting a vehicle, setting its attitude, refilling its tanks.

   .. staticmethod:: set_circular_orbit(vehicle: KSA.Vehicle, body: KSA.Body, altitude: number)

      Move a vehicle onto a circular orbit around a body, and return once it is there.

      :param vehicle: The vehicle.
      :param body: The body to orbit.
      :param altitude: The altitude of the orbit above the mean radius, in meters.

      .. note::

         Throws an exception if the game cannot compute the vehicle's trajectory on the
         orbit.

   .. staticmethod:: set_orbit(vehicle: KSA.Vehicle, body: KSA.Body, semi_major_axis: number, eccentricity: number, inclination: number, longitude_of_ascending_node: number, argument_of_periapsis: number, mean_anomaly_at_epoch: number, epoch: number)

      Move a vehicle onto the orbit with the given elements, and return once it is there.
      The angles are those of :class:`KSA.Orbit`.

      :param vehicle: The vehicle.
      :param body: The body to orbit.
      :param semi_major_axis: The semi-major axis, in meters. Negative or positive for a hyperbolic orbit.
      :param eccentricity: The eccentricity. Below 1 for an elliptical orbit, and above 1 for a hyperbolic one.
      :param inclination: The inclination, in radians.
      :param longitude_of_ascending_node: The longitude of the ascending node, in radians.
      :param argument_of_periapsis: The argument of periapsis, in radians.
      :param mean_anomaly_at_epoch: The mean anomaly at the epoch, in radians.
      :param epoch: The universal time of the epoch, in seconds.

      .. note::

         Throws an exception if the game cannot compute the vehicle's trajectory on the
         orbit.

   .. staticmethod:: set_landed(vehicle: KSA.Vehicle, body: KSA.Body, latitude: number, longitude: number)

      Place a vehicle on the surface of a body, as the game's teleport window does, and
      return once it is there.

      :param vehicle: The vehicle.
      :param body: The body to land on.
      :param latitude: The latitude, in degrees.
      :param longitude: The longitude, in degrees.

      .. note::

         Throws an exception if the body has no surface.

   .. staticmethod:: set_position(vehicle: KSA.Vehicle, position: Tuple, reference_frame: KSA.ReferenceFrame)

      Move a vehicle to the given position, keeping its velocity, and return once it is
      there.

      :param vehicle: The vehicle.
      :param position: The position of the vehicle, in meters.
      :param reference_frame: The reference frame of the position.

      .. note::

         This is the inverse of :meth:`KSA.Vehicle.position`. The vehicle keeps orbiting
         the same body.

   .. staticmethod:: set_velocity(vehicle: KSA.Vehicle, velocity: Tuple, reference_frame: KSA.ReferenceFrame)

      Set the velocity of a vehicle, keeping its position, and return once it is set.

      :param vehicle: The vehicle.
      :param velocity: The velocity of the vehicle, in meters per second.
      :param reference_frame: The reference frame of the velocity.

      .. note::

         This is the inverse of :meth:`KSA.Vehicle.velocity`. The vehicle keeps orbiting
         the same body.

   .. staticmethod:: set_rotation(vehicle: KSA.Vehicle, rotation: Tuple, reference_frame: KSA.ReferenceFrame)

      Set the rotation of a vehicle, and return once it is set.

      :param vehicle: The vehicle.
      :param rotation: The rotation of the vehicle, as a quaternion of the form ``(x, y, z, w)``.
      :param reference_frame: The reference frame of the rotation.

      .. note::

         This is the inverse of :meth:`KSA.Vehicle.rotation`.

   .. staticmethod:: set_angular_velocity(vehicle: KSA.Vehicle, angular_velocity: Tuple, reference_frame: KSA.ReferenceFrame)

      Set the angular velocity of a vehicle, and return once it is set.

      :param vehicle: The vehicle.
      :param angular_velocity: The angular velocity, in radians per second. The vector points along the axis of rotation, and its length is the rate.
      :param reference_frame: The reference frame of the angular velocity.

      .. note::

         This is the inverse of :meth:`KSA.Vehicle.angular_velocity`.

   .. staticmethod:: fill_resources(vehicle: KSA.Vehicle)

      Fill the propellant and other substances in the tanks of a vehicle, as the game's
      refill command does.

      :param vehicle: The vehicle.

      .. note::

         The batteries keep their charge.

   .. staticmethod:: empty_resources(vehicle: KSA.Vehicle)

      Empty the propellant and other substances in the tanks of a vehicle, as the game's
      empty command does.

      :param vehicle: The vehicle.

      .. note::

         The batteries keep their charge.

   .. staticmethod:: duplicate_vehicle(vehicle: KSA.Vehicle, name: string): KSA.Vehicle

      Create a copy of a vehicle beside it, as the game's duplicate command does, and
      return once it is created.

      :param vehicle: The vehicle to copy.
      :param name: The name of the copy.
      :returns: The copy.

      .. note::

         Throws an exception if the name is in use.

   .. staticmethod:: explode_vehicle(vehicle: KSA.Vehicle)

      Destroy a vehicle in an explosion, as the game's explode command does, and return
      once the vehicle is gone. Its crew are killed.

      :param vehicle: The vehicle.

   .. staticmethod:: show_velocity_arrows(visible: boolean)

      Show or hide the game's debug arrows for the velocities of the vehicles.

      :param visible: Whether to show the arrows.

   .. staticmethod:: run_command(command: string): List

      Run a command in the game's console, as typed in the console.

      :param command: The command and its arguments.
      :returns: The console output of the command, one line per message.

      .. note::

         Most commands write their messages to the game's log, not the returned output.
         Throws an exception if the console has no such command, or the arguments are not
         valid.
