Clients
=======

kRPC for KSA works with the kRPC @KRPC_VERSION@ client libraries. Each client has a guide to
installing and using it with the ``KSA`` service, and a reference for the procedures of the
``KSA`` and ``KFS`` services.

For any other language, the :doc:`gRPC server <grpc>` lets you control the game from a client
generated by `gRPC's <https://grpc.io>`_ own tools.

Service Stubs
-------------

Python and Lua build the services when they connect. JavaScript builds them too, and takes
their types and values from its stubs. The C#, C++, C-nano and Java clients compile against
their stubs. The stubs are in the ``stubs`` folder of the release archive. The folder also holds
``KRPC.KSA.json`` and ``KRPC.KSA.KFS.json``, the service definitions, from which
``krpc-clientgen`` in the ``krpctools`` package generates stubs for another client version.

.. note::

   The client packages do not yet include the ``KSA`` service stubs. A later release will add
   them, so you will no longer need to add the stubs by hand.
