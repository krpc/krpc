UI#

class UI#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see show_message().

static Window add_window(Client &connection, std::string title, bool visible = true)#

Add a window, with no widgets.

Parameters:

  • title – The text in the title bar.

  • visible – Whether the window is visible.

static void clear(Client &connection, bool client_only = false)#

Remove the windows.

Parameters:

  • client_only – Whether to remove only the windows added by the calling client.

class Window#

A window, holding widgets one per line. Created using UI::add_window().

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.

std::string title()#
void set_title(std::string value)#

The text in the title bar.

std::tuple<float, float> position()#
void set_position(std::tuple<float, float> value)#

The position of the top left corner of the window, from the top left corner of the game window, in pixels.

std::tuple<float, float> size()#
void set_size(std::tuple<float, float> value)#

The width and height of the window, in pixels.

Note

Throws an exception if the width or height is not positive.
