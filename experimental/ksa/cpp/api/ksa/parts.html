Parts#

class Part#

A part of a vehicle. Obtained from Vehicle::parts().

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

std::string name()#

The id of the part’s template.

std::string title()#

The name of the part, as shown in the game.

Vehicle vehicle()#

The vehicle the part belongs to.

std::optional<Part> parent()#

The part this part is attached to, or NULL for the root part.

std::vector<Part> children()#

The parts attached to this part.

int32_t sequence()#

The number of the sequence that activates the part, or -1 if no sequence does.

float mass()#

The mass of the part, including its propellant, in kilograms.

float dry_mass()#

The mass of the part without its propellant, in kilograms.

std::vector<Resource> resources()#

The resources the part holds, one for each substance.

std::vector<Tank> tanks()#

The part’s propellant tanks. Empty if it has none.

std::vector<Battery> batteries()#

The part’s batteries.

std::vector<SolarPanel> solar_panels()#

The part’s solar panels.

std::vector<Generator> generators()#

The part’s generators.

std::vector<PowerConsumer> power_consumers()#

The part’s power consumers.

std::vector<Light> lights()#

The part’s lights.

std::vector<Deployable> deployables()#

The part’s deployable sections. A part can have several, such as the doors of a service module.

std::vector<MagneticScoop> magnetic_scoops()#

The part’s magnetic scoops. Empty if it has none.

std::tuple<double, double, double> position(ReferenceFrame reference_frame)#

The position of the part’s origin, in meters.

Parameters:

  • reference_frame – The reference frame of the position.

std::tuple<double, double, double> velocity(ReferenceFrame reference_frame)#

The velocity of the part’s origin, in meters per second.

Parameters:

  • reference_frame – The reference frame of the velocity.

std::tuple<double, double, double, double> rotation(ReferenceFrame reference_frame)#

The rotation of the part’s axes, relative to the given frame.

Parameters:

  • reference_frame – The reference frame of the rotation.

std::optional<Engine> engine()#

The part’s engine, or NULL if it has none.

std::vector<Gimbal> gimbals()#

The part’s gimbals. An engine part can have several, each steering one nozzle.

std::optional<RCS> rcs()#

The part’s RCS thrusters, or NULL if it has none.

std::optional<Decoupler> decoupler()#

The part’s decoupler, or NULL if it has none.

std::optional<Parachute> parachute()#

The part’s parachute, or NULL if it has none.

std::optional<DockingPort> docking_port()#

The part’s docking port, or NULL if it has none.

std::vector<Seat> seats()#

The part’s crew seats.

std::vector<Kitten> crew()#

The kittens in the part’s seats.

class Engine#

An engine. Obtained from Part::engine().

Note

An active engine fires when the vehicle’s engines are on, at the vehicle’s throttle. See Control::engine_on() and Control::throttle().

Part part()#

The part the engine is in.

std::vector<Gimbal> gimbals()#

The gimbals that steer the engine’s nozzles. Empty if the engine has none.

bool active()#
void set_active(bool value)#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

bool has_propellant()#

Whether the engine has propellant to burn.

float minimum_throttle()#

The lowest throttle the engine runs at, between 0 and 1.

std::vector<std::string> propellants()#

The names of the substances the engine burns. See Resource::name().

float thrust()#

The thrust of the engine at its current throttle and the current atmospheric pressure, in Newtons. Zero when it is not firing.

float available_thrust()#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

float specific_impulse()#

The specific impulse of the engine at the current atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

class Gimbal#

A gimbal that steers an engine nozzle. Obtained from Part::gimbals() or Engine::gimbals().

Note

A gimbal turns about the y and z axes of its mount, which Gimbal::rotation() gives. The flight computer steers it while an engine it belongs to is Gimbal::active().

Part part()#

The part the gimbal is in.

float angle_y()#

The angle of the gimbal about its y axis, in degrees.

float angle_z()#

The angle of the gimbal about its z axis, in degrees.

float max_angle_y()#

The largest angle of the gimbal about its y axis, in degrees. Zero if it does not turn about that axis.

float max_angle_z()#

The largest angle of the gimbal about its z axis, in degrees. Zero if it does not turn about that axis.

bool active()#

Whether an engine the gimbal steers is active.

std::tuple<double, double, double, double> rotation(ReferenceFrame reference_frame)#

The rotation of the gimbal’s mount, whose y and z axes the gimbal turns about.

Parameters:

  • reference_frame – The reference frame of the rotation.

class RCS#

The RCS thrusters of a part. Obtained from Part::rcs().

Note

Active thrusters fire when the vehicle’s RCS is on. See Control::rcs().

Part part()#

The part the thrusters are in.

bool active()#
void set_active(bool value)#

Whether the thrusters are active. Setting it returns once the change has applied.

class Decoupler#

A decoupler. Obtained from Part::decoupler().

Part part()#

The part the decoupler is in.

bool enabled()#

Whether the decoupler can fire.

bool decoupled()#

Whether the decoupler has fired, or is attached to nothing.

std::vector<Vehicle> decouple()#

Fire the decoupler, separating the vehicle into two. Returns once it has fired. Throws an exception if the decoupler is disabled or Decoupler::decoupled().

Returns:

The vehicles that separated from this one.

class Parachute#

A parachute. Obtained from Part::parachute().

Part part()#

The part the parachute is in.

ParachuteState state()#

The state of the parachute.

float fill()#

How far the canopy is open, from 0 to 1.

float deploy_altitude()#

The height above the terrain at which an armed parachute deploys, in meters.

bool can_cut()#

Whether the parachute can be cut away. Main parachutes cannot.

void deploy()#

Arm the parachute, so that it deploys at Parachute::deploy_altitude(). Returns once it is armed. Throws an exception if it is not stowed.

void cut()#

Cut the parachute away. Returns once it is cut. Throws an exception if it cannot be cut. See Parachute::can_cut().

enum struct ParachuteState#

The state of a parachute. See Parachute::state().

enumerator stowed#

Packed away.

enumerator armed#

Waiting to deploy at Parachute::deploy_altitude().

enumerator line_stretch#

Leaving the pack.

enumerator reefed#

Partly open, to limit the opening load.

enumerator disreefing#

Opening from reefed to full.

enumerator full#

Fully open.

enumerator cut#

Cut away.

enumerator ripped#

Torn by too much dynamic pressure.

enumerator severed_lines#

Lost after its lines broke under too much load.

class DockingPort#

A docking port. Obtained from Part::docking_port().

Part part()#

The part the docking port is in.

bool docked()#

Whether the port is docked.

std::optional<Part> docked_part()#

The part the port is docked to, or NULL if it is not docked.

std::vector<Vehicle> undock()#

Undock the port, separating the vehicle into two. Returns once it has undocked. Throws an exception if the port is not docked.

Returns:

The new vehicles.

Note

Docking and undocking replace the vehicles involved. See Vehicle.

class Deployable#

A part that deploys and retracts, such as a landing leg, a solar panel or a service module door. Obtained from Part::deployables().

Note

Deploying or retracting a part moves its symmetric copies with it, as the part’s menu in the game does.

Part part()#

The part the deployable is in.

DeployableState state()#

The state of the part.

void deploy()#

Deploy the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

void retract()#

Retract the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

enum struct DeployableState#

The state of a deployable part. See Deployable::state().

enumerator deployed#

Fully deployed.

enumerator retracted#

Fully retracted.

enumerator deploying#

Moving toward deployed.

enumerator retracting#

Moving toward retracted.

enumerator broken#

Broken, so it can no longer move.

class MagneticScoop#

A magnetic scoop, which collects gas from space into the vehicle’s tanks. Obtained from Part::magnetic_scoops().

Part part()#

The part the scoop is in.

bool active()#
void set_active(bool value)#

Whether the scoop is switched on.

std::string substance()#

The name of the substance the scoop collects. See Resource::name().

float collection_rate()#

The rate the scoop collects gas at, in kilograms per second.
