Flight#

class Flight#

Flight telemetry for a vehicle, relative to the surface of the body it orbits. Obtained from Vehicle.flight.

mean_altitude#

The altitude above the mean radius of the body, in meters.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

surface_altitude#

The altitude above the terrain or the ocean surface, whichever is higher, in meters.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

bedrock_altitude#

The altitude above the terrain, in meters. Over the sea, this is the altitude above the sea floor.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

elevation#

The height of the terrain below the vehicle, in meters above the mean radius of the body. Below the sea, this is the height of the sea floor.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

time_to_impact#

The time until the vehicle hits the surface on its current trajectory, in seconds. Not a number if its trajectory does not hit the surface.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

Note

The game predicts the trajectory on a worker thread, so a change to it shows here shortly after.

str or None

float

float

float

float

float

float

The radiation dose rate at the vehicle, in sieverts per second. Includes any solar particle event under way.

Attribute:

Read-only, cannot be set

float

orbit_average_dose_rate#

The radiation dose rate averaged over the vehicle’s orbit, in sieverts per second. Includes any solar particle event under way. Not a number if the body has no magnetosphere, or the orbit dips below the surface.

Attribute:

Read-only, cannot be set

Return type:

float

Flight

Attribute:

Read-only, cannot be set

float

angle_of_attack#

The angle between the direction the vehicle points in and its velocity relative to the surface, in the vehicle’s pitch plane, in degrees. Positive when the nose is above the velocity.

Attribute:

Read-only, cannot be set

Return type:

float

Game Scenes:

Flight

Attribute:

Read-only, cannot be set

Return type:

float
