Computer#

service ComputerService#

A vehicle’s flight computer, which runs a kFS program. Obtained from KFSService.Computer.

Note

A program is written in kC, a subset of C, or in kASM. The calls that change the computer, and ComputerService.WriteGlobals, take effect before the computer’s next tick, and return once they have. The computer ticks while the game is running and the vehicle is in the physics bubble, so until then they wait. The game does not save a program.

rpc Build (Computer.BuildRequest) returns (Computer.BuildResponse)#

Build a program, without loading it.

Computer.BuildRequest:

  • this (Computer)

  • files (map<string, string>): The source files, by name. A program with a .c file is kC, and one with only .kasm files is kASM.

Computer.BuildResponse:

value (repeated Diagnostic): The errors and warnings.

rpc Load (Computer.LoadRequest) returns (Computer.LoadResponse)#

Build a program and load it onto the computer. Throws an exception if the program has errors, or the computer rejects it.

Computer.LoadRequest:

  • this (Computer)

  • files (map<string, string>): The source files, by name, as for ComputerService.Build.

Computer.LoadResponse:

Empty

Note

The program is in standby once loaded. See ComputerService.Start.

rpc Start (Computer.StartRequest) returns (Computer.StartResponse)#

Start the loaded program. Throws an exception if no program is loaded.

Computer.StartRequest:

  • this (Computer)

Computer.StartResponse:

Empty

rpc Reset (Computer.ResetRequest) returns (Computer.ResetResponse)#

Restart the loaded program, as the reset button does. Throws an exception if no program is loaded.

Computer.ResetRequest:

  • this (Computer)

Computer.ResetResponse:

Empty

rpc Stop (Computer.StopRequest) returns (Computer.StopResponse)#

Stop the program, and give the vehicle back to the pilot. The program stays loaded.

Computer.StopRequest:

  • this (Computer)

Computer.StopResponse:

Empty

rpc Kill (Computer.KillRequest) returns (Computer.KillResponse)#

Halt the program with the kill switch, and give the vehicle back to the pilot.

Computer.KillRequest:

  • this (Computer)

Computer.KillResponse:

Empty

rpc GetState (Computer.GetStateRequest) returns (Computer.GetStateResponse)#

The state of the computer.

Computer.GetStateRequest:

  • this (Computer)

Computer.GetStateResponse:

value (ComputerState)

rpc GetMode (Computer.GetModeRequest) returns (Computer.GetModeResponse)#

The control mode the loaded program claims.

Computer.GetModeRequest:

  • this (Computer)

Computer.GetModeResponse:

value (ControlMode)

rpc GetUnderControl (Computer.GetUnderControlRequest) returns (Computer.GetUnderControlResponse)#

Whether the program controls the vehicle: it is running, or halted with its last commands held.

Computer.GetUnderControlRequest:

  • this (Computer)

Computer.GetUnderControlResponse:

value (bool)

rpc GetTickRate (Computer.GetTickRateRequest) returns (Computer.GetTickRateResponse)#

The ticks per second of the loaded program, or zero if no program is loaded.

Computer.GetTickRateRequest:

  • this (Computer)

Computer.GetTickRateResponse:

value (sint32)

rpc GetCyclesUsed (Computer.GetCyclesUsedRequest) returns (Computer.GetCyclesUsedResponse)#

The processor cycles the latest tick used.

Computer.GetCyclesUsedRequest:

  • this (Computer)

Computer.GetCyclesUsedResponse:

value (sint64)

rpc GetCycleBudget (Computer.GetCycleBudgetRequest) returns (Computer.GetCycleBudgetResponse)#

The processor cycles a tick may use.

Computer.GetCycleBudgetRequest:

  • this (Computer)

Computer.GetCycleBudgetResponse:

value (sint64)

rpc GetOverruns (Computer.GetOverrunsRequest) returns (Computer.GetOverrunsResponse)#

The number of ticks that ran past their budget since the program started.

Computer.GetOverrunsRequest:

  • this (Computer)

Computer.GetOverrunsResponse:

value (sint64)

rpc GetTrap (Computer.GetTrapRequest) returns (Computer.GetTrapResponse)#

The error that halted the program, or null if no error halted it.

Computer.GetTrapRequest:

  • this (Computer)

Computer.GetTrapResponse:

value (Trap)

rpc GetFault (Computer.GetFaultRequest) returns (Computer.GetFaultResponse)#

The game’s error that halted the computer, or null if there is none.

Computer.GetFaultRequest:

  • this (Computer)

Computer.GetFaultResponse:

value (optional string)

rpc GetLog (Computer.GetLogRequest) returns (Computer.GetLogResponse)#

The computer’s console: the lines the program logs, and the computer’s own messages.

Computer.GetLogRequest:

  • this (Computer)

Computer.GetLogResponse:

value (repeated string)

Note

The computer keeps the last 4,096 lines, and a program logs at most 10 lines a second.

rpc ClearLog (Computer.ClearLogRequest) returns (Computer.ClearLogResponse)#

Clear the computer’s console.

Computer.ClearLogRequest:

  • this (Computer)

Computer.ClearLogResponse:

Empty

rpc GetGlobals (Computer.GetGlobalsRequest) returns (Computer.GetGlobalsResponse)#

The paths of the loaded program’s global variables, one for each number in them, such as command.args[2].

Computer.GetGlobalsRequest:

  • this (Computer)

Computer.GetGlobalsResponse:

value (repeated string)

rpc ReadGlobal (Computer.ReadGlobalRequest) returns (Computer.ReadGlobalResponse)#

The value of one of the program’s global variables, as of its latest tick.

Computer.ReadGlobalRequest:

  • this (Computer)

  • path (string): The path of the variable, as in ComputerService.GetGlobals.

Computer.ReadGlobalResponse:

value (double)

rpc WriteGlobals (Computer.WriteGlobalsRequest) returns (Computer.WriteGlobalsResponse)#

Write the program’s global variables. The program sees all of them from the same tick.

Computer.WriteGlobalsRequest:

  • this (Computer)

  • values (map<string, double>): The values, by the paths in ComputerService.GetGlobals.

Computer.WriteGlobalsResponse:

Empty

Note

A value is converted to the variable’s type. Throws an exception if a value does not fit, such as a fraction for an integer.

rpc GetTraceChannels (Computer.GetTraceChannelsRequest) returns (Computer.GetTraceChannelsResponse)#

The names of the channels the program has traced to.

Computer.GetTraceChannelsRequest:

  • this (Computer)

Computer.GetTraceChannelsResponse:

value (repeated string)

rpc Trace (Computer.TraceRequest) returns (Computer.TraceResponse)#

The latest value the program traced to a channel. Throws an exception if the program has not traced to it.

Computer.TraceRequest:

  • this (Computer)

  • channel (string): The name of the channel.

Computer.TraceResponse:

value (float)

enum ComputerState#

The state of a flight computer. See ComputerService.GetState.

value COMPUTER_STATE_NO_SOFTWARE#

No program is loaded.

value COMPUTER_STATE_STANDBY#

A program is loaded, and not running.

value COMPUTER_STATE_BOOT#

The program is running its initialization.

value COMPUTER_STATE_RUNNING#

The program is running.

value COMPUTER_STATE_IDLE#

The program is running, with no task to run.

value COMPUTER_STATE_HALTED#

The program has stopped, after a trap, a halt or the kill switch.

enum ControlMode#

The control a program has of a vehicle. See ComputerService.GetMode.

value CONTROL_MODE_PILOT#

The game’s flight computer flies the vehicle, and the program steers it.

value CONTROL_MODE_FULL_CONTROL#

The program commands the thrusters, engines and gimbals itself. A program claims it with #pragma kfs claim ALLOCATION.

message Diagnostic#

An error or warning from building a program. See ComputerService.Build.

field error#

Whether it is an error. An error stops the program from being built.

field code#

The diagnostic’s code, such as KC-E016.

field file#

The source file.

field line#

The line in the source file, from 1. Zero for the whole file.

field column#

The column in the line, from 1.

field message#

The message.

field hint#

A hint at the fix, or null if there is none.

message Trap#

The error that halted a program, and where it happened. See ComputerService.GetTrap.

field code#

The error.

field function#

The function that was running.

field file#

The source file, or null if it is not known.

field line#

The line in the source file, or zero if it is not known.

enum TrapCode#

The error that halted a program. See code.

value TRAP_CODE_ILLEGAL_OPCODE#

An instruction the processor does not have.

value TRAP_CODE_OPERAND_OVERFLOW#

The operand stack overflowed.

value TRAP_CODE_OPERAND_UNDERFLOW#

The operand stack underflowed.

value TRAP_CODE_RETURN_OVERFLOW#

The return stack overflowed.

value TRAP_CODE_INIT_OVERRUN#

The initialization ran past its budget.

value TRAP_CODE_STACK_OVERFLOW#

The stack overflowed.

value TRAP_CODE_NULL_ACCESS#

A read or write through a null pointer.

value TRAP_CODE_BAD_ADDRESS#

A read or write outside memory.

value TRAP_CODE_READ_ONLY#

A write to read-only memory.

value TRAP_CODE_MISALIGNED#

A misaligned read or write.

value TRAP_CODE_DIVISION_BY_ZERO#

A division by zero.

value TRAP_CODE_BOUNDS#

An array index out of bounds.

value TRAP_CODE_USER#

A trap raised by the program.

value TRAP_CODE_BAD_JUMP#

A jump to an invalid address.

value TRAP_CODE_BAD_SYSCALL#

A call to a service that does not exist.

value TRAP_CODE_BAD_YIELD#

A task yielded where it may not.

value TRAP_CODE_MEMORY_ERROR#

A memory error, such as a radiation upset.
