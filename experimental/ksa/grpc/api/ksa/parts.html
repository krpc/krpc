Parts#

service PartService#

A part of a vehicle. Obtained from VehicleService.GetParts.

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

enum ParachuteState#

The state of a parachute. See ParachuteService.GetState.

value PARACHUTE_STATE_STOWED#

Packed away.

value PARACHUTE_STATE_ARMED#

Waiting to deploy at ParachuteService.GetDeployAltitude.

value PARACHUTE_STATE_LINE_STRETCH#

Leaving the pack.

value PARACHUTE_STATE_REEFED#

Partly open, to limit the opening load.

value PARACHUTE_STATE_DISREEFING#

Opening from reefed to full.

value PARACHUTE_STATE_FULL#

Fully open.

value PARACHUTE_STATE_CUT#

Cut away.

value PARACHUTE_STATE_RIPPED#

Torn by too much dynamic pressure.

value PARACHUTE_STATE_SEVERED_LINES#

Lost after its lines broke under too much load.
