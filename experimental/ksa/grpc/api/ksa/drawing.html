Drawing#

service DrawingService#

Draws lines, shapes and text in the scene, each placed in a reference frame.

Note

The objects are drawn every frame until removed, and are removed when the client that added them disconnects. Lines are drawn at the game’s fixed gizmo width.

rpc AddLine (Drawing.AddLineRequest) returns (Drawing.AddLineResponse)#

Draw a line between two positions.

Drawing.AddLineRequest:

  • start (Tuple_double_double_double): The position of the start of the line, in meters.

  • end (Tuple_double_double_double): The position of the end of the line, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the positions.

  • visible (optional bool): Whether the line is visible. Defaults to true.

Drawing.AddLineResponse:

value (Line)

rpc AddDirection (Drawing.AddDirectionRequest) returns (Drawing.AddDirectionResponse)#

Draw a line from the origin of a reference frame in a direction.

Drawing.AddDirectionRequest:

  • direction (Tuple_double_double_double): The direction of the line.

  • reference_frame (ReferenceFrame): The reference frame of the direction.

  • length (optional float): The length of the line, in meters. Defaults to 10.0.

  • visible (optional bool): Whether the line is visible. Defaults to true.

Drawing.AddDirectionResponse:

value (Line)

rpc AddPolyline (Drawing.AddPolylineRequest) returns (Drawing.AddPolylineResponse)#

Draw a line through a list of positions.

Drawing.AddPolylineRequest:

  • vertices (repeated Tuple_double_double_double): The positions the line passes through, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the positions.

  • closed (optional bool): Whether the line joins the last position back to the first. Defaults to false.

  • visible (optional bool): Whether the line is visible. Defaults to true.

Drawing.AddPolylineResponse:

value (Polyline)

rpc AddCircle (Drawing.AddCircleRequest) returns (Drawing.AddCircleResponse)#

Draw a circle.

Drawing.AddCircleRequest:

  • center (Tuple_double_double_double): The position of the center of the circle, in meters.

  • normal (Tuple_double_double_double): The direction normal to the plane of the circle.

  • radius (float): The radius of the circle, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the position and direction.

  • visible (optional bool): Whether the circle is visible. Defaults to true.

Drawing.AddCircleResponse:

value (Circle)

rpc AddArc (Drawing.AddArcRequest) returns (Drawing.AddArcResponse)#

Draw an arc of a circle.

Drawing.AddArcRequest:

  • center (Tuple_double_double_double): The position of the center of the arc’s circle, in meters.

  • normal (Tuple_double_double_double): The direction normal to the plane of the arc.

  • start_direction (Tuple_double_double_double): The direction from the center to the start of the arc.

  • angle (float): The angle the arc turns through, counterclockwise about the normal, in radians.

  • radius (float): The radius of the arc, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the position and directions.

  • visible (optional bool): Whether the arc is visible. Defaults to true.

Drawing.AddArcResponse:

value (Arc)

rpc AddBox (Drawing.AddBoxRequest) returns (Drawing.AddBoxResponse)#

Draw the edges of a box.

Drawing.AddBoxRequest:

  • center (Tuple_double_double_double): The position of the center of the box, in meters.

  • size (Tuple_double_double_double): The lengths of the box’s edges along its x, y and z axes, in meters.

  • rotation (Tuple_double_double_double_double): The rotation of the box’s axes, as a quaternion of the form (x, y, z, w).

  • reference_frame (ReferenceFrame): The reference frame of the position and rotation.

  • visible (optional bool): Whether the box is visible. Defaults to true.

Drawing.AddBoxResponse:

value (Box)

rpc AddSphere (Drawing.AddSphereRequest) returns (Drawing.AddSphereResponse)#

Draw a solid sphere.

Drawing.AddSphereRequest:

  • center (Tuple_double_double_double): The position of the center of the sphere, in meters.

  • radius (float): The radius of the sphere, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the position.

  • visible (optional bool): Whether the sphere is visible. Defaults to true.

Drawing.AddSphereResponse:

value (Sphere)

rpc AddText (Drawing.AddTextRequest) returns (Drawing.AddTextResponse)#

Draw text over the scene, centered on a position.

Drawing.AddTextRequest:

  • text (string): The text.

  • position (Tuple_double_double_double): The position of the center of the text, in meters.

  • reference_frame (ReferenceFrame): The reference frame of the position.

  • size (optional float): The height of the font, in pixels. Defaults to 16.0.

  • visible (optional bool): Whether the text is visible. Defaults to true.

Drawing.AddTextResponse:

value (Text)

rpc Clear (Drawing.ClearRequest) returns (Drawing.ClearResponse)#

Remove the drawing objects.

Drawing.ClearRequest:

  • client_only (optional bool): Whether to remove only the objects added by the calling client. Defaults to false.

Drawing.ClearResponse:

Empty
