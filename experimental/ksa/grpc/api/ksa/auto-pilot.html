Auto-Pilot#

service AutoPilotService#

The vehicle’s flight computer, which steers the vehicle with its reaction control thrusters and engine gimbals. Obtained from VehicleService.GetAutoPilot.

Note

The auto-pilot points the vehicle in the direction set by AutoPilotService.GetMode, once engaged. It is the game’s own flight computer, so the game’s flight computer controls change the same settings.

rpc TargetDirection (AutoPilot.TargetDirectionRequest) returns (AutoPilot.TargetDirectionResponse)#

Point the vehicle in a direction, and set the mode to AUTO_PILOT_MODE_ATTITUDE. Sets AutoPilotService.GetTargetPitch and AutoPilotService.GetTargetHeading to the direction at the time of the call, so the target stays fixed relative to the surface.

AutoPilot.TargetDirectionRequest:

  • this (AutoPilot)

  • direction (Tuple_double_double_double): The direction to point in.

  • reference_frame (ReferenceFrame): The reference frame of the direction.

AutoPilot.TargetDirectionResponse:

Empty

Wait until the vehicle points in the target direction, and has the target roll if it has one. Returns when the errors are within twice the flight computer’s angle deadband, which defaults to 1°. Throws an exception if the auto-pilot is not engaged.

rpc GetAutoBurn (AutoPilot.GetAutoBurnRequest) returns (AutoPilot.GetAutoBurnResponse)#

Whether the flight computer executes the next burn in VehicleService.GetBurns. It points the vehicle along the burn, fires the engines at BurnService.GetIgnitionTime, and stops once the burn is complete.

AutoPilot.GetAutoBurnRequest:

  • this (AutoPilot)

AutoPilot.GetAutoBurnResponse:

value (bool)

Note

The flight computer clears it when the burn completes, and removes the burn if another follows it. The engines fire only at normal speed, so warp to shortly before the burn with KSAService.WarpTo. Setting it with no burn planned throws an exception.

enum AutoPilotMode#

The direction the auto-pilot points the vehicle in. See AutoPilotService.GetMode.

value AUTO_PILOT_MODE_ATTITUDE#

The pitch, heading and roll set by AutoPilotService.GetTargetPitch, AutoPilotService.GetTargetHeading and AutoPilotService.GetTargetRoll.

value AUTO_PILOT_MODE_HOLD#

Holds the vehicle’s rotation at zero, relative to the stars.

value AUTO_PILOT_MODE_PROGRADE#

The direction of the vehicle’s orbital velocity.

value AUTO_PILOT_MODE_RETROGRADE#

The opposite of AUTO_PILOT_MODE_PROGRADE.

value AUTO_PILOT_MODE_NORMAL#

Normal to the orbital plane, along the orbit’s angular momentum.

value AUTO_PILOT_MODE_ANTI_NORMAL#

The opposite of AUTO_PILOT_MODE_NORMAL.

value AUTO_PILOT_MODE_RADIAL_OUT#

Away from the center of the body being orbited.

value AUTO_PILOT_MODE_RADIAL_IN#

Toward the center of the body being orbited.

value AUTO_PILOT_MODE_SURFACE_PROGRADE#

The direction of the vehicle’s velocity relative to the surface.

value AUTO_PILOT_MODE_SURFACE_RETROGRADE#

The opposite of AUTO_PILOT_MODE_SURFACE_PROGRADE.

value AUTO_PILOT_MODE_OTHER#

A target set in the game, which the API does not cover.
