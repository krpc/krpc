A kitten in the agency’s roster. Obtained from KSAService.GetKittens, VehicleService.GetCrew or SeatService.GetKitten.

Kitten.GetTimeToRadiationSicknessRequest:

rpc GetTimeToLethalDose (Kitten.GetTimeToLethalDoseRequest) returns (Kitten.GetTimeToLethalDoseResponse)#

rpc CanCarry (Kitten.CanCarryRequest) returns (Kitten.CanCarryResponse)#

Whether the kitten can take supplies from or stow them in a habitat. See KittenService.Take and KittenService.Stow.

Kitten.CanCarryRequest:

  • this (Kitten)

  • habitat (Habitat): The habitat.

Kitten.CanCarryResponse:

value (bool)

rpc Take (Kitten.TakeRequest) returns (Kitten.TakeResponse)#

Take meals and canisters from a habitat within reach, and return once the kitten carries them. Takes fewer when the habitat holds fewer, or the kitten cannot carry more.

Kitten.TakeRequest:

  • this (Kitten)

  • habitat (Habitat): The habitat, which must store supplies.

  • meals (optional sint32): The number of meals to take. Defaults to 0.

  • canisters (optional sint32): The number of canisters to take. Defaults to 0.

Kitten.TakeResponse:

Empty

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See KittenService.CanCarry.

rpc Stow (Kitten.StowRequest) returns (Kitten.StowResponse)#

Stow the meals and canisters the kitten carries in a habitat within reach, and return once they are stowed. Stows fewer when the kitten carries fewer, or the habitat has less room.

Kitten.StowRequest:

  • this (Kitten)

  • habitat (Habitat): The habitat, which must store supplies.

  • meals (optional sint32): The number of meals to stow. Defaults to 0.

  • canisters (optional sint32): The number of canisters to stow. Defaults to 0.

Kitten.StowResponse:

Empty

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See KittenService.CanCarry.

enum LocomotionMode#

How a kitten on EVA is moving. See KittenService.GetLocomotionMode.

value LOCOMOTION_MODE_MMU#

Flying with the maneuvering unit, away from any surface.

value LOCOMOTION_MODE_GROUNDED#

Standing or walking on a surface.

value LOCOMOTION_MODE_AIRBORNE#

In the air above a surface, such as during a jump.

value LOCOMOTION_MODE_TUMBLING#

Tumbling after a fall or an impact.

value LOCOMOTION_MODE_RIGHTING#

Getting back up after tumbling.

value LOCOMOTION_MODE_LADDER#

Holding a ladder or grab rail.

value LOCOMOTION_MODE_SWIMMING#

Swimming in an ocean.

enum KittenCondition#

The effect on a kitten of going without a supply. See KittenService.Condition.

value KITTEN_CONDITION_HEALTHY#

Unaffected.

value KITTEN_CONDITION_WARNING#

Going without, with no effect yet.

value KITTEN_CONDITION_DEGRADED#

Weakened, and unable to go on EVA.

value KITTEN_CONDITION_INCAPACITATED#

Unable to fly the vehicle or move supplies.

value KITTEN_CONDITION_DEAD#

Dead.

enum DeathCause#

What killed a kitten. See KittenService.GetCauseOfDeath.

value DEATH_CAUSE_UNKNOWN#

Not recorded.

value DEATH_CAUSE_NO_OXYGEN#

Lack of oxygen.

value DEATH_CAUSE_NO_SCRUBBER#

Carbon dioxide, with no scrubber canisters left.

value DEATH_CAUSE_NO_WATER#

Lack of water.

value DEATH_CAUSE_NO_FOOD#

Lack of food.

value DEATH_CAUSE_RADIATION#

A lethal radiation dose.

value DEATH_CAUSE_GROUND_IMPACT#

Hitting the ground.

value DEATH_CAUSE_OCEAN_IMPACT#

Hitting the ocean.

value DEATH_CAUSE_COLLISION#

A collision.

value DEATH_CAUSE_EXCESSIVE_G_FORCE#

Excessive acceleration.

value DEATH_CAUSE_AERODYNAMIC_FORCES#

Aerodynamic forces breaking up the vehicle.

value DEATH_CAUSE_HYDRODYNAMIC_FORCES#

Hydrodynamic forces breaking up the vehicle.

value DEATH_CAUSE_FALL#

A fall on EVA.

value DEATH_CAUSE_ABANDONED#

Left in a vehicle that was abandoned.

service CrewEventService#

A kitten’s most urgent coming event: its supplies running low, or its condition worsening. Obtained from VehicleService.GetCrewEvents or VehicleService.GetNextCrewEvent.

Note

As the game’s crew clock, an event within a day is the worst stage the kitten reaches in that time, and a later event is the soonest. The event is the game’s forecast when it is read from the vehicle. Read it again for a new forecast.

enum CrewStage#
