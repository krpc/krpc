service KittenService#

The kitten’s name, which is unique in the roster.

rpc GetAcuteDose (Kitten.GetAcuteDoseRequest) returns (Kitten.GetAcuteDoseResponse)#

The kitten’s acute radiation dose, in sieverts. It heals over time, and causes radiation sickness from 1 sievert and death from 4 sieverts.

  • this (Kitten)

rpc GetLifetimeDose (Kitten.GetLifetimeDoseRequest) returns (Kitten.GetLifetimeDoseResponse)#

The kitten’s lifetime radiation dose, in sieverts. The kitten retires after a mission that takes it past 0.6 sieverts.

  • this (Kitten)

Kitten.GetLifetimeDoseResponse:

rpc GetDoseRate (Kitten.GetDoseRateRequest) returns (Kitten.GetDoseRateResponse)#

The radiation dose rate the kitten receives, in sieverts per second. The vehicle’s shielding reduces it in a seat, and on EVA the kitten is unshielded. Zero when the kitten is not on a mission.

rpc GoOnEva (Kitten.GoOnEvaRequest) returns (Kitten.GoOnEvaResponse)#

Leave the kitten’s vehicle through its EVA hatch, and return once the kitten is on EVA. The kitten becomes the controlled kitten, see KSAService.GetActiveKitten.

Kitten.GoOnEvaRequest:

  • this (Kitten)

Kitten.GoOnEvaResponse:

Empty

Note

Throws an exception if the kitten is not in a seat, or the vehicle has no EVA hatch.

rpc Board (Kitten.BoardRequest) returns (Kitten.BoardResponse)#

Board the nearest vehicle with a free seat, and return once the kitten is in the seat. The vehicle becomes the controlled vehicle.

Kitten.BoardRequest:

  • this (Kitten)

Kitten.BoardResponse:

value (Vehicle): The vehicle the kitten boarded.

Note

Throws an exception if the kitten is not on EVA, or no EVA hatch with a free seat is within one meter.

rpc Position (Kitten.PositionRequest) returns (Kitten.PositionResponse)#

The position of the kitten, in meters. For a kitten in a seat, the position of the seat’s part. Throws an exception if the kitten is neither in a seat nor on EVA.

Kitten.VelocityRequest:

  • this (Kitten)

  • reference_frame (ReferenceFrame): The reference frame of the velocity.

Kitten.VelocityResponse:

value (Tuple_double_double_double)

enum LocomotionMode#

How a kitten on EVA is moving. See KittenService.GetLocomotionMode.

value LOCOMOTION_MODE_MMU#

Flying with the maneuvering unit, away from any surface.

value LOCOMOTION_MODE_GROUNDED#

Standing or walking on a surface.

value LOCOMOTION_MODE_AIRBORNE#

In the air above a surface, such as during a jump.

value LOCOMOTION_MODE_TUMBLING#

Tumbling after a fall or an impact.

value LOCOMOTION_MODE_RIGHTING#

Getting back up after tumbling.

value LOCOMOTION_MODE_LADDER#

Holding a ladder or grab rail.

value LOCOMOTION_MODE_SWIMMING#

Swimming in an ocean.

rpc GetKitten (Seat.GetKittenRequest) returns (Seat.GetKittenResponse)#

Returns the kitten in the seat, or null if the seat is empty, and sets the kitten in the seat. Setting null empties the seat.

Seat.GetKittenRequest:

  • this (Seat)

Seat.GetKittenResponse:

value (Kitten)

Note

A kitten in another seat of the vehicle moves to this one. Throws an exception if the kitten is killed in action, on EVA, or in another vehicle.
