Vehicle#

service VehicleService#

A vehicle in the current system. Obtained from KSAService.GetActiveVehicle or KSAService.GetVehicles.

Note

Docking and undocking replace the vehicles involved, so an object for one of them throws an exception afterwards.

rpc AddBurn (Vehicle.AddBurnRequest) returns (Vehicle.AddBurnResponse)#

Plan a burn, and add it to the vehicle’s burn plan.

Vehicle.AddBurnRequest:

  • this (Vehicle)

  • ut (double): Universal time of the burn, in seconds.

  • prograde (optional float): Change in velocity in the prograde direction, in meters per second. Defaults to 0.0.

  • normal (optional float): Change in velocity along the orbit normal, in meters per second. Defaults to 0.0.

  • radial (optional float): Change in velocity radially outward, in meters per second. Defaults to 0.0.

Vehicle.AddBurnResponse:

value (Burn): The burn.

Note

Returns once the flight computer has timed the burn, if it is the next one. Throws an exception if the time is in the past, or beyond the vehicle’s predicted trajectory.

enum Situation#

The situation of a vehicle: its contact with the surface, and whether the game is simulating it with physics or propagating it along its orbit. See VehicleService.GetSituation.

value SITUATION_MANEUVERING#

No surface contact, simulated with physics.

value SITUATION_FREEFALL#

No surface contact, on rails.

value SITUATION_ROLLING#

On terrain, simulated with physics.

value SITUATION_LANDED#

At rest on terrain.

value SITUATION_SAILING#

In the ocean, simulated with physics.

value SITUATION_FLOATING#

At rest in the ocean.

value SITUATION_DRAGGING#

On terrain and in the ocean, simulated with physics.

value SITUATION_BOTTOMED#

At rest on terrain and in the ocean.
