Drawing#

class KSA.Drawing()#

Draws lines, shapes and text in the scene, each placed in a reference frame.

Note

The objects are drawn every frame until removed, and are removed when the client that added them disconnects. Lines are drawn at the game’s fixed gizmo width.

Drawing.addLine(start, end, referenceFrame[, visible])#

Draw a line between two positions.

Arguments:

  • start ([number, number, number]) – The position of the start of the line, in meters.

  • end ([number, number, number]) – The position of the end of the line, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the positions.

  • visible (boolean) – Whether the line is visible. Defaults to true.

Return type:

KSA.Line

Drawing.addDirection(direction, referenceFrame[, length[, visible]])#

Draw a line from the origin of a reference frame in a direction.

Arguments:

  • direction ([number, number, number]) – The direction of the line.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the direction.

  • length (number) – The length of the line, in meters. Defaults to 1e+01.

  • visible (boolean) – Whether the line is visible. Defaults to true.

Return type:

KSA.Line

Drawing.addPolyline(vertices, referenceFrame[, closed[, visible]])#

Draw a line through a list of positions.

Arguments:

  • vertices (Array of [number, number, number]) – The positions the line passes through, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the positions.

  • closed (boolean) – Whether the line joins the last position back to the first. Defaults to false.

  • visible (boolean) – Whether the line is visible. Defaults to true.

Return type:

KSA.Polyline

Drawing.addCircle(center, normal, radius, referenceFrame[, visible])#

Draw a circle.

Arguments:

  • center ([number, number, number]) – The position of the center of the circle, in meters.

  • normal ([number, number, number]) – The direction normal to the plane of the circle.

  • radius (number) – The radius of the circle, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position and direction.

  • visible (boolean) – Whether the circle is visible. Defaults to true.

Return type:

KSA.Circle

Drawing.addArc(center, normal, startDirection, angle, radius, referenceFrame[, visible])#

Draw an arc of a circle.

Arguments:

  • center ([number, number, number]) – The position of the center of the arc’s circle, in meters.

  • normal ([number, number, number]) – The direction normal to the plane of the arc.

  • startDirection ([number, number, number]) – The direction from the center to the start of the arc.

  • angle (number) – The angle the arc turns through, counterclockwise about the normal, in radians.

  • radius (number) – The radius of the arc, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position and directions.

  • visible (boolean) – Whether the arc is visible. Defaults to true.

Return type:

KSA.Arc

Drawing.addBox(center, size, rotation, referenceFrame[, visible])#

Draw the edges of a box.

Arguments:

  • center ([number, number, number]) – The position of the center of the box, in meters.

  • size ([number, number, number]) – The lengths of the box’s edges along its x, y and z axes, in meters.

  • rotation ([number, number, number, number]) – The rotation of the box’s axes, as a quaternion of the form (x, y, z, w).

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position and rotation.

  • visible (boolean) – Whether the box is visible. Defaults to true.

Return type:

KSA.Box

Drawing.addSphere(center, radius, referenceFrame[, visible])#

Draw a solid sphere.

Arguments:

  • center ([number, number, number]) – The position of the center of the sphere, in meters.

  • radius (number) – The radius of the sphere, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position.

  • visible (boolean) – Whether the sphere is visible. Defaults to true.

Return type:

KSA.Sphere

Drawing.addText(text, position, referenceFrame[, size[, visible]])#

Draw text over the scene, centered on a position.

Arguments:

  • text (string) – The text.

  • position ([number, number, number]) – The position of the center of the text, in meters.

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position.

  • size (number) – The height of the font, in pixels. Defaults to 16.0.

  • visible (boolean) – Whether the text is visible. Defaults to true.

Return type:

KSA.Text

Drawing.clear([clientOnly])#

Remove the drawing objects.

Arguments:

  • clientOnly (boolean) – Whether to remove only the objects added by the calling client. Defaults to false.
