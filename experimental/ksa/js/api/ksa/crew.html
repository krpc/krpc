Crew#

class KSA.Kitten()#

A kitten in the agency’s roster. Obtained from KSA.getKittens(), KSA.Vehicle.getCrew() or KSA.Seat.getKitten().

Kitten.getName()#

The kitten’s name, which is unique in the roster.

Property:

Read-only, cannot be set

Return type:

string

Kitten.getRosterIndex()#

The kitten’s position in the agency’s roster, from 0. See KSA.getKittens().

Property:

Read-only, cannot be set

Return type:

number

Kitten.getVehicle()#

The vehicle the kitten is in, or null if it is not in a seat.

Property:

Read-only, cannot be set

Return type:

KSA.Vehicle or null

Kitten.getSeat()#

The seat the kitten is in, or null if it is not in a seat.

Property:

Read-only, cannot be set

Return type:

KSA.Seat or null

Kitten.getKilledInAction()#

Whether the kitten has been killed in action.

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.getCauseOfDeath()#

What killed the kitten, or null if it is alive.

Property:

Read-only, cannot be set

Return type:

KSA.DeathCause or null

Kitten.getMissionCount()#

The number of missions the kitten has flown, including the current one.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getMissionTime()#

The time the kitten has spent on missions, including the current one, in seconds.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getDistanceTraveled()#

The distance the kitten has traveled on missions, in meters.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getFastestSpeed()#

The kitten’s highest speed on a mission, in meters per second.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getAcuteDose()#

The kitten’s acute radiation dose, in sieverts. It heals over time, and causes radiation sickness from 1 sievert and death from 4 sieverts.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getLifetimeDose()#

The kitten’s lifetime radiation dose, in sieverts. The kitten retires after a mission that takes it past 0.6 sieverts.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getDoseRate()#

The radiation dose rate the kitten receives, in sieverts per second. The vehicle’s shielding reduces it in a seat, and on EVA the kitten is unshielded. Zero when the kitten is not on a mission.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getRadiationSickness()#

Whether the kitten has radiation sickness, which keeps it from flying.

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.getTimeToRadiationSickness()#

The time until the kitten gets radiation sickness at its current dose rate, in seconds. Infinite if it never does, or the kitten already has it.

Property:

Read-only, cannot be set

Return type:

number

Note

The game forecasts it for a kitten on a mission while KSA.getRadiationEnabled() is true.

Kitten.getTimeToLethalDose()#

The time until the kitten takes a lethal radiation dose at its current dose rate, in seconds. Infinite if it never does.

Property:

Read-only, cannot be set

Return type:

number

Note

The game forecasts it for a kitten on a mission while KSA.getRadiationEnabled() is true, and only within a day of radiation sickness.

Kitten.getTimeUntilFitToFly()#

The time until the kitten has recovered from radiation sickness and can fly, resting at home, in seconds. Zero if the kitten does not have radiation sickness.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getRecoveryTime()#

The time until the kitten’s acute radiation dose has healed below 1 millisievert, resting at home, in seconds.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getRetired()#

Whether the kitten has retired, having reached its lifetime radiation dose limit.

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.getWorstCondition()#

The kitten’s worst condition across its supplies.

Property:

Read-only, cannot be set

Return type:

KSA.KittenCondition

Kitten.condition(supply)#

The effect on the kitten of going without a supply.

Arguments:

  • supply (KSA.LifeSupportSupply) – The supply.

Return type:

KSA.KittenCondition

Kitten.timeWithout(supply)#

The time the kitten has gone without a supply, in seconds. It counts down again once the supply returns.

Arguments:

  • supply (KSA.LifeSupportSupply) – The supply.

Return type:

number

Kitten.timeToNextCondition(supply)#

The further time the kitten can go without a supply before its condition from the supply worsens, in seconds. Infinite once the kitten is dead.

Arguments:

  • supply (KSA.LifeSupportSupply) – The supply.

Return type:

number

Kitten.getIncapacitated()#

Whether the kitten is incapacitated by going without a supply. An incapacitated kitten cannot fly the vehicle or move supplies.

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.getOnEva()#

Whether the kitten is on EVA.

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.goOnEva()#

Leave the kitten’s vehicle through its EVA hatch, and return once the kitten is on EVA. The kitten becomes the controlled kitten, see KSA.getActiveKitten().

Note

Throws an exception if the kitten is not in a seat, or the vehicle has no EVA hatch.

Kitten.getCanGoOnEva()#

Whether the kitten can go on EVA. See KSA.Kitten.goOnEva().

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.board()#

Board the nearest vehicle with a free seat, and return once the kitten is in the seat. The vehicle becomes the controlled vehicle.

Returns:

The vehicle the kitten boarded.

Return type:

KSA.Vehicle

Note

Throws an exception if the kitten is not on EVA, or no EVA hatch with a free seat is within one meter.

Kitten.getCanBoard()#

Whether the kitten is on EVA and an EVA hatch with a free seat is in range. See KSA.Kitten.board().

Property:

Read-only, cannot be set

Return type:

boolean

Kitten.getLocomotionMode()#

How the kitten on EVA is moving. Throws an exception if the kitten is not on EVA.

Property:

Read-only, cannot be set

Return type:

KSA.LocomotionMode

Kitten.position(referenceFrame)#

The position of the kitten, in meters. For a kitten in a seat, the position of the seat’s part. Throws an exception if the kitten is neither in a seat nor on EVA.

Arguments:

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the position.

Return type:

[number, number, number]

Kitten.velocity(referenceFrame)#

The velocity of the kitten, in meters per second. For a kitten in a seat, the velocity of the seat’s part. Throws an exception if the kitten is neither in a seat nor on EVA.

Arguments:

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the velocity.

Return type:

[number, number, number]

Kitten.getLifeSupport()#

How long the supplies in the kitten’s suit last, or null if the kitten is not on EVA.

Property:

Read-only, cannot be set

Return type:

KSA.LifeSupport or null

Note

The suit is filled from the kitten’s habitat zone when it goes on EVA, and what is left returns to the zone when it boards.

Kitten.getCarriedMeals()#

The number of meals the kitten on EVA carries. Throws an exception if the kitten is not on EVA.

Property:

Read-only, cannot be set

Return type:

number

Kitten.getCarriedCanisters()#

The number of carbon dioxide scrubber canisters the kitten on EVA carries. Throws an exception if the kitten is not on EVA.

Property:

Read-only, cannot be set

Return type:

number

Kitten.canCarry(habitat)#

Whether the kitten can take supplies from or stow them in a habitat. See KSA.Kitten.take() and KSA.Kitten.stow().

Arguments:

  • habitat (KSA.Habitat) – The habitat.

Return type:

boolean

Kitten.take(habitat[, meals[, canisters]])#

Take meals and canisters from a habitat within reach, and return once the kitten carries them. Takes fewer when the habitat holds fewer, or the kitten cannot carry more.

Arguments:

  • habitat (KSA.Habitat) – The habitat, which must store supplies.

  • meals (number) – The number of meals to take. Defaults to 0.

  • canisters (number) – The number of canisters to take. Defaults to 0.

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See KSA.Kitten.canCarry().

Kitten.stow(habitat[, meals[, canisters]])#

Stow the meals and canisters the kitten carries in a habitat within reach, and return once they are stowed. Stows fewer when the kitten carries fewer, or the habitat has less room.

Arguments:

  • habitat (KSA.Habitat) – The habitat, which must store supplies.

  • meals (number) – The number of meals to stow. Defaults to 0.

  • canisters (number) – The number of canisters to stow. Defaults to 0.

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See KSA.Kitten.canCarry().

class KSA.LocomotionMode()#

How a kitten on EVA is moving. See KSA.Kitten.getLocomotionMode().

LocomotionMode.mmu#

Flying with the maneuvering unit, away from any surface.

LocomotionMode.grounded#

Standing or walking on a surface.

LocomotionMode.airborne#

In the air above a surface, such as during a jump.

LocomotionMode.tumbling#

Tumbling after a fall or an impact.

LocomotionMode.righting#

Getting back up after tumbling.

LocomotionMode.ladder#

Holding a ladder or grab rail.

LocomotionMode.swimming#

Swimming in an ocean.

class KSA.KittenCondition()#

The effect on a kitten of going without a supply. See KSA.Kitten.condition().

KittenCondition.healthy#

Unaffected.

KittenCondition.warning#

Going without, with no effect yet.

KittenCondition.degraded#

Weakened, and unable to go on EVA.

KittenCondition.incapacitated#

Unable to fly the vehicle or move supplies.

KittenCondition.dead#

Dead.

class KSA.DeathCause()#

What killed a kitten. See KSA.Kitten.getCauseOfDeath().

DeathCause.unknown#

Not recorded.

DeathCause.noOxygen#

Lack of oxygen.

DeathCause.noScrubber#

Carbon dioxide, with no scrubber canisters left.

DeathCause.noWater#

Lack of water.

DeathCause.noFood#

Lack of food.

DeathCause.radiation#

A lethal radiation dose.

DeathCause.groundImpact#

Hitting the ground.

DeathCause.oceanImpact#

Hitting the ocean.

DeathCause.collision#

A collision.

DeathCause.excessiveGForce#

Excessive acceleration.

DeathCause.aerodynamicForces#

Aerodynamic forces breaking up the vehicle.

DeathCause.hydrodynamicForces#

Hydrodynamic forces breaking up the vehicle.

DeathCause.fall#

A fall on EVA.

DeathCause.abandoned#

Left in a vehicle that was abandoned.

class KSA.CrewEvent()#

A kitten’s most urgent coming event: its supplies running low, or its condition worsening. Obtained from KSA.Vehicle.getCrewEvents() or KSA.Vehicle.getNextCrewEvent().

Note

As the game’s crew clock, an event within a day is the worst stage the kitten reaches in that time, and a later event is the soonest. The event is the game’s forecast when it is read from the vehicle. Read it again for a new forecast.

CrewEvent.getKitten()#

The kitten.

Property:

Read-only, cannot be set

Return type:

KSA.Kitten

CrewEvent.getStage()#

What happens to the kitten.

Property:

Read-only, cannot be set

Return type:

KSA.CrewStage

CrewEvent.getHazard()#

The cause of the event.

Property:

Read-only, cannot be set

Return type:

KSA.CrewHazard

CrewEvent.getUT()#

The universal time of the event, in seconds.

Property:

Read-only, cannot be set

Return type:

number

CrewEvent.getTimeTo()#

The time until the event, in seconds. Zero once its time has passed.

Property:

Read-only, cannot be set

Return type:

number

class KSA.CrewStage()#

What happens to a kitten in a crew event. See KSA.CrewEvent.getStage().

CrewStage.low#

The supply runs low.

CrewStage.degraded#

The kitten is weakened, and unable to go on EVA. For radiation, the kitten gets radiation sickness.

CrewStage.incapacitated#

The kitten is unable to fly the vehicle or move supplies.

CrewStage.dead#

The kitten dies.

class KSA.CrewHazard()#

The cause of a crew event. See KSA.CrewEvent.getHazard().

CrewHazard.air#

Running out of air.

CrewHazard.scrubber#

Running out of carbon dioxide scrubber.

CrewHazard.water#

Running out of water.

CrewHazard.food#

Running out of food.

CrewHazard.radiation#

The radiation dose.

class KSA.Seat()#

A crew seat. Obtained from KSA.Part.getSeats().

Seat.getPart()#

The part the seat is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

Seat.getKitten()#
Seat.setKitten(value)#

Returns the kitten in the seat, or null if the seat is empty, and sets the kitten in the seat. Setting null empties the seat.

Property:

Can be read or written

Return type:

KSA.Kitten or null

Note

A kitten in another seat of the vehicle moves to this one, within its habitat zone. Throws an exception if the kitten is killed in action, retired, on EVA, in another vehicle, or incapacitated, or the seat is in another habitat zone.
