Vehicle#

class KSA.Vehicle()#

A vehicle in the current system. Obtained from KSA.getActiveVehicle() or KSA.getVehicles().

Note

Docking and undocking replace the vehicles involved, so an object for one of them throws an exception afterwards.

Vehicle.getName()#
Vehicle.setName(value)#

The name of the vehicle, which is unique in the system.

Property:

Can be read or written

Return type:

string

Vehicle.destroy()#

Destroy the vehicle, killing its crew, as abandoning the vehicle does. Returns once the vehicle is gone.

Note

If the vehicle is the active vehicle, the game hands control to a nearby vehicle.

Vehicle.getCanRecover()#

Whether the vehicle can be recovered: at rest on the surface of the home planet.

Property:

Read-only, cannot be set

Return type:

boolean

Vehicle.recover()#

Recover the vehicle, ending its crew’s missions, as the game’s recover button does. Returns once the vehicle is gone.

Note

Throws an exception if the vehicle cannot be recovered, see KSA.Vehicle.getCanRecover().

The situation of the vehicle.

KSA.Situation

Whether the game moves the vehicle without simulating the forces on it: along its orbit, or held on the surface. True in the freefall, landed, floating and bottomed situations.

boolean

number

Vehicle.getMomentOfInertia()#

The vehicle’s moments of inertia about the axes of KSA.Vehicle.getReferenceFrame() through its center of mass, in \(\mathrm{kg \cdot m^{2}}\).

Property:

Read-only, cannot be set

Return type:

[number, number, number]

Vehicle.getInertiaTensor()#

The vehicle’s inertia tensor about its center of mass, along the axes of KSA.Vehicle.getReferenceFrame(), in \(\mathrm{kg \cdot m^{2}}\), as its three rows.

Property:

Read-only, cannot be set

Return type:

Array of [number, number, number]

Vehicle.getAvailableRCSTorque()#

The torque the vehicle’s RCS thrusters can give about each axis of its control frame, in \(\mathrm{N \cdot m}\). Each is the smaller of the torques in the two directions about the axis.

Property:

Read-only, cannot be set

Return type:

[number, number, number]

Note

The control frame has the axes of KSA.Vehicle.getReferenceFrame(), unless the flight computer steers along the thrust. The thrusters give this torque while KSA.Control.getRCS() is on.

Vehicle.acceleration(referenceFrame)#

The vehicle’s acceleration from the forces on it other than gravity, in \(\mathrm{m/s^{2}}\).

Arguments:

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the acceleration.

Return type:

[number, number, number]

Note

The game measures it over the last physics step. Its length divided by standard gravity is KSA.Flight.getGForce().

Vehicle.angularAcceleration(referenceFrame)#

The vehicle’s angular acceleration, in \(\mathrm{rad/s^{2}}\). The vector points along the axis of rotation.

Arguments:

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the angular acceleration.

Return type:

[number, number, number]

Note

The game measures it over the last physics step.

Vehicle.getPeakGLoad()#

The highest smoothed g-load on the vehicle during the last physics step, as a multiple of standard gravity. Zero while the vehicle is KSA.Vehicle.getOnRails().

Property:

Read-only, cannot be set

Return type:

number

Vehicle.getMaxGLoad()#

Property:

Read-only, cannot be set

Return type:

number

Vehicle.getPeakDynamicPressure()#

The highest dynamic pressure on the vehicle during the last physics step, in pascals. In the sea, this is the dynamic pressure of the water. Zero while the vehicle is KSA.Vehicle.getOnRails().

Property:

Read-only, cannot be set

Return type:

number

Vehicle.getMaxDynamicPressure()#

The dynamic pressure the vehicle can take before it breaks up, in pascals. Zero while the vehicle is KSA.Vehicle.getOnRails().

Property:

Vehicle.addBurn(ut[, prograde[, normal[, radial]]])#

Plan a burn, and add it to the vehicle’s burn plan.

Arguments:

  • ut (number) – Universal time of the burn, in seconds.

  • prograde (number) – Change in velocity in the prograde direction, in meters per second. Defaults to 0.0.

  • normal (number) – Change in velocity along the orbit normal, in meters per second. Defaults to 0.0.

  • radial (number) – Change in velocity radially outward, in meters per second. Defaults to 0.0.

Returns:

The burn.

Return type:

KSA.Burn

Note

Returns once the flight computer has timed the burn, if it is the next one. Throws an exception if the time is in the past, or beyond the vehicle’s predicted trajectory.

class KSA.Situation()#

The situation of a vehicle: its contact with the surface, and whether the game is simulating it with physics or propagating it along its orbit. See KSA.Vehicle.getSituation().

Situation.maneuvering#

No surface contact, simulated with physics.

Situation.freefall#

No surface contact, on rails.

Situation.rolling#

On terrain, simulated with physics.

Situation.landed#

At rest on terrain.

Situation.sailing#

In the ocean, simulated with physics.

Situation.floating#

At rest in the ocean.

Situation.dragging#

On terrain and in the ocean, simulated with physics.

Situation.bottomed#

At rest on terrain and in the ocean.

class KSA.ControlState()#

Whether a vehicle can be flown, or why not. See KSA.Vehicle.getControlState().

ControlState.controllable#

The vehicle can be flown.

ControlState.noControlModule#

The vehicle has no control module, such as a capsule or a probe core.

ControlState.noCrew#

The capsules have no crew, and no probe core is on.

ControlState.crewIncapacitated#

Every kitten in the capsules is incapacitated, and no probe core is on.

ControlState.probeCoreUnpowered#

The probe core has no power.

ControlState.probeCoreOff#

The probe core is switched off.

ControlState.probeCoreFailed#

The probe core has failed from its radiation dose.

ControlState.probeCoreStormStandby#

The probe core is on standby for a radiation storm.

ControlState.probeCoreRebooting#

The probe core is rebooting after a radiation upset.
