Parts#

class KSA.Part()#

A part of a vehicle. Obtained from KSA.Vehicle.getParts().

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

Part.getName()#

The id of the part’s template.

Property:

Read-only, cannot be set

Return type:

string

Part.getTitle()#

The name of the part, as shown in the game.

Property:

Read-only, cannot be set

Return type:

string

Part.getVehicle()#

The vehicle the part belongs to.

Property:

Read-only, cannot be set

Return type:

KSA.Vehicle

Part.getParent()#

The part this part is attached to, or null for the root part.

Property:

Read-only, cannot be set

Return type:

KSA.Part or null

Part.getChildren()#

The parts attached to this part.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Part

Part.getSequence()#

The number of the sequence that activates the part, or -1 if no sequence does.

Property:

Read-only, cannot be set

Return type:

number

Part.getMass()#

The mass of the part, including its propellant, in kilograms.

Property:

Read-only, cannot be set

Return type:

number

Part.getDryMass()#

The mass of the part without its propellant, in kilograms.

Property:

Read-only, cannot be set

Return type:

number

Part.getResources()#

The resources the part holds, one for each substance.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Resource

Part.getShieldArealDensity()#

The areal density of the part’s radiation shielding, its hull included, in \(\mathrm{kg/m^{2}}\). Zero for an unshielded part.

Property:

Read-only, cannot be set

Return type:

number

Part.getShieldMass()#

The mass of the shielding material added to the part, in kilograms. Zero when the shielding is built into the hull.

Property:

Read-only, cannot be set

Return type:

number

Part.getTankCover()#

The fraction of the sky, seen from the part, that the contents of the vehicle’s tanks cover, between 0 and 1. The contents shield the part from radiation.

Property:

Read-only, cannot be set

Return type:

number

Part.getDoseRate()#

The radiation dose rate inside the part, behind its shielding and the vehicle’s tanks, in sieverts per second. Includes any solar particle event under way. A kitten in the part’s seats receives this dose rate.

Property:

Read-only, cannot be set

Return type:

number

Part.getHighlight()#
Part.setHighlight(value)#

The color the part is highlighted in.

Property:

Can be read or written

Return type:

KSA.HighlightColor

Note

The life support window uses this highlight to pick parts, and replaces it on the parts it picks from.

Part.getTanks()#

Property:

Read-only, cannot be set

Return type:

Array of KSA.Tank

Part.getHabitats()#

Property:

Read-only, cannot be set

Read-only, cannot be set

Part.getSolarPanels()#

Property:

Array of KSA.SolarPanel

The part’s generators.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Generator

Part.getPowerConsumers()#

The part’s power consumers.

Property:

Read-only, cannot be set

Return type:

Array of KSA.PowerConsumer

Part.getPowerForecast()#

The charge, draw and supply of the electrical circuit the part is on.

Property:

Read-only, cannot be set

Return type:

KSA.PowerForecast

Part.getAvionics()#

The part’s avionics, or null if it has none. A probe core has avionics.

Property:

Read-only, cannot be set

Return type:

KSA.Avionics or null

Part.getLights()#

The part’s lights.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Light

Part.getDeployables()#

Property:

Read-only, cannot be set

Return type:

Array of KSA.Deployable

Part.getMagneticScoops()#

The part’s magnetic scoops. Empty if it has none.

Property:

Read-only, cannot be set

Return type:

Array of KSA.MagneticScoop

Arguments:

[number, number, number]

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the rotation.

[number, number, number, number]

KSA.Parachute or null

The part’s docking port, or null if it has none.

Property:

Read-only, cannot be set

Return type:

KSA.DockingPort or null

Part.getSeats()#

The part’s crew seats.

Property:

Read-only, cannot be set

Array of KSA.Seat

The kittens in the part’s seats.

Property:

Array of KSA.Kitten

class KSA.Engine()#

An engine. Obtained from KSA.Part.getEngine().

Note

An active engine fires when the vehicle’s engines are on, at the vehicle’s throttle. See KSA.Control.getEngineOn() and KSA.Control.getThrottle().

Engine.getPart()#

The part the engine is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

Engine.getGimbals()#

The gimbals that steer the engine’s nozzles. Empty if the engine has none.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Gimbal

Engine.getActive()#
Engine.setActive(value)#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

Property:

Can be read or written

Return type:

boolean

Engine.getHasPropellant()#

Whether the engine has propellant to burn.

Property:

Read-only, cannot be set

Return type:

boolean

Engine.getMinimumThrottle()#

The lowest throttle the engine runs at, between 0 and 1.

Property:

Read-only, cannot be set

Return type:

number

Engine.getPropellants()#

The names of the substances the engine burns. See KSA.Resource.getName().

Property:

Read-only, cannot be set

Return type:

Array of string

Engine.getThrust()#

The thrust of the engine at its current throttle and the current atmospheric pressure, in Newtons. Zero when it is not firing.

Property:

Read-only, cannot be set

Return type:

number

Engine.getAvailableThrust()#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

Property:

Read-only, cannot be set

Return type:

number

Engine.getSpecificImpulse()#

The specific impulse of the engine at the current atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

Property:

Read-only, cannot be set

Return type:

number

Engine.availableThrustAt(pressure)#

The thrust of the engine at full throttle and the given atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

Arguments:

  • pressure (number) – The atmospheric pressure, in pascals.

Return type:

number

Engine.specificImpulseAt(pressure)#

The specific impulse of the engine at the given atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

Arguments:

  • pressure (number) – The atmospheric pressure, in pascals.

Return type:

number

Engine.getMaxThrust()#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons, whether or not it is active and has propellant.

Property:

Read-only, cannot be set

Return type:

number

Engine.getMaxVacuumThrust()#

The thrust of the engine at full throttle in a vacuum, in Newtons, whether or not it is active and has propellant.

Property:

Read-only, cannot be set

Return type:

number

Engine.getChamberPressure()#

The pressure in the engine’s combustion chamber, in pascals. Zero when it is not firing.

Property:

Read-only, cannot be set

Return type:

number

Engine.getSolid()#

Whether the engine is a solid rocket motor. Once ignited, a solid motor burns at full thrust until its grain runs out.

Property:

Read-only, cannot be set

Return type:

boolean

Engine.getGrainMass()#

The mass of the propellant grain of a solid rocket motor, in kilograms.

Property:

Read-only, cannot be set

Return type:

number

Note

Some of the grain is left unburned when the motor burns out. Throws an exception if the engine is not a solid rocket motor.

class KSA.Gimbal()#

A gimbal that steers an engine nozzle. Obtained from KSA.Part.getGimbals() or KSA.Engine.getGimbals().

Note

A gimbal turns about the y and z axes of its mount, which KSA.Gimbal.rotation() gives. The flight computer steers it while an engine it belongs to is KSA.Gimbal.getActive().

Gimbal.getPart()#

The part the gimbal is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

Gimbal.getAngleY()#

The angle of the gimbal about its y axis, in degrees.

Property:

Read-only, cannot be set

Return type:

number

Gimbal.getAngleZ()#

The angle of the gimbal about its z axis, in degrees.

Property:

Read-only, cannot be set

Return type:

number

Gimbal.getMaxAngleY()#

The largest angle of the gimbal about its y axis, in degrees. Zero if it does not turn about that axis.

Property:

Read-only, cannot be set

Return type:

number

Gimbal.getMaxAngleZ()#

The largest angle of the gimbal about its z axis, in degrees. Zero if it does not turn about that axis.

Property:

Read-only, cannot be set

Return type:

number

Gimbal.getActive()#

Whether an engine the gimbal steers is active.

Property:

Read-only, cannot be set

Return type:

boolean

Gimbal.rotation(referenceFrame)#

The rotation of the gimbal’s mount, whose y and z axes the gimbal turns about.

Arguments:

  • referenceFrame (KSA.ReferenceFrame) – The reference frame of the rotation.

Return type:

[number, number, number, number]

class KSA.Parachute()#

Parachute.getPart()#

The part the parachute is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

Parachute.getState()#

The state of the parachute.

Property:

Read-only, cannot be set

Return type:

KSA.ParachuteState

Parachute.getFill()#

How far the canopy is open, from 0 to 1.

Property:

Read-only, cannot be set

Return type:

Parachute.getDeployAltitude()#

The height above the terrain at which an armed parachute deploys, in meters.

Property:

Read-only, cannot be set

Return type:

number

Parachute.getCanCut()#

Whether the parachute can be cut away. Main parachutes cannot.

Property:

Read-only, cannot be set

Return type:

Parachute.deploy()#

Arm the parachute, so that it deploys at KSA.Parachute.getDeployAltitude(). Returns once it is armed. Throws an exception if it is not stowed.

Cut the parachute away. Returns once it is cut. Throws an exception if it cannot be cut. See KSA.Parachute.getCanCut().

class KSA.ParachuteState()#

The state of a parachute. See KSA.Parachute.getState().

ParachuteState.stowed#

Packed away.

ParachuteState.armed#

Waiting to deploy at KSA.Parachute.getDeployAltitude().

ParachuteState.lineStretch#

Leaving the pack.

ParachuteState.reefed#

Partly open, to limit the opening load.

ParachuteState.disreefing#

Opening from reefed to full.

ParachuteState.full#

Fully open.

ParachuteState.cut#

Cut away.

ParachuteState.ripped#

Torn by too much dynamic pressure.

ParachuteState.severedLines#

Lost after its lines broke under too much load.

class KSA.DockingPort()#

A docking port. Obtained from KSA.Part.getDockingPort().

DockingPort.getPart()#

The part the docking port is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

DockingPort.getDocked()#

Whether the port is docked.

Property:

Read-only, cannot be set

Return type:

boolean

DockingPort.getDockedPart()#

The part the port is docked to, or null if it is not docked.

Property:

Read-only, cannot be set

Return type:

DockingPort.getHatchOpen()#
DockingPort.setHatchOpen(value)#

Returns whether the hatch through the docked ports is open, and opens or closes it. An open hatch joins the habitat zones on either side.

Property:

Can be read or written

Return type:

boolean

Note

The hatch is closed while the port is not docked. Throws an exception when set on a port that is not docked.

DockingPort.undock()#

Undock the port, separating the vehicle into two. Returns once it has undocked. Throws an exception if the port is not docked.

Returns:

The new vehicles.

Return type:

Array of KSA.Vehicle

Note

Docking and undocking replace the vehicles involved. See KSA.Vehicle.

class KSA.Deployable()#

A part that deploys and retracts, such as a landing leg, a solar panel or a service module door. Obtained from KSA.Part.getDeployables().

Note

Deploying or retracting a part moves its symmetric copies with it, as the part’s menu in the game does.

Deployable.getPart()#

The part the deployable is in.

Property:

Read-only, cannot be set

Return type:

KSA.Part

Deployable.getState()#

The state of the part.

Property:

Read-only, cannot be set

Return type:

KSA.DeployableState

Deployable.deploy()#

Deploy the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

Deployable.retract()#

Retract the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

class KSA.DeployableState()#

The state of a deployable part. See KSA.Deployable.getState().

DeployableState.deployed#

Fully deployed.

DeployableState.retracted#

Fully retracted.

DeployableState.deploying#

Moving toward deployed.

DeployableState.retracting#

Moving toward retracted.

DeployableState.broken#

Broken, so it can no longer move.
