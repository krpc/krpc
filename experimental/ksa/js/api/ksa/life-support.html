Life Support#

class KSA.LifeSupport()#

How long the supplies of a vehicle, a habitat zone or a kitten’s suit last. Obtained from KSA.Vehicle.getLifeSupport(), KSA.HabitatZone.getLifeSupport() or KSA.Kitten.getLifeSupport().

Note

The times count down only while KSA.getLifeSupportEnabled() is true. Air lasts forever in breathable air outside the vehicle.

LifeSupport.getKittens()#

The number of kittens the supplies are shared between.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getAirMass()#

The mass of oxygen in the crew’s tanks, in kilograms.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getWaterMass()#

The mass of water in the crew’s tanks, in kilograms.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getMeals()#

The number of meals.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getAirTime()#

The time the air lasts, in seconds. Infinite with no crew, or in breathable air.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getScrubberTime()#

The time the carbon dioxide scrubbers last, in seconds. Infinite with no crew.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getWaterTime()#

The time the water lasts, in seconds. Infinite with no crew.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getFoodTime()#

The time the food lasts, in seconds. Infinite with no crew.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getTime()#

The time until the first supply runs out, in seconds. A suit counts its air and scrubber only. Infinite with no crew.

Property:

Read-only, cannot be set

Return type:

number

LifeSupport.getLimitingSupply()#

The supply that runs out first. Air when every time is infinite, as with no crew.

Property:

Read-only, cannot be set

Return type:

KSA.LifeSupportSupply

LifeSupport.getLevel()#

How long the supplies last, as the game’s life support gauge shows it.

Property:

Read-only, cannot be set

Return type:

KSA.LifeSupportLevel

LifeSupport.getTimeToNextLevel()#

The time until KSA.LifeSupport.getLevel() next changes, in seconds. Infinite with no crew.

Property:

Read-only, cannot be set

Return type:

number

class KSA.LifeSupportLevel()#

How long the crew’s supplies last. See KSA.LifeSupport.getLevel().

LifeSupportLevel.ok#

More than a day of supplies, or no crew.

LifeSupportLevel.low#

A day of supplies or less.

LifeSupportLevel.critical#

An hour of supplies or less.

LifeSupportLevel.out#

A supply has run out.

class KSA.LifeSupportSupply()#

A supply the crew needs. See KSA.LifeSupport.getLimitingSupply().

LifeSupportSupply.air#

Oxygen to breathe.

LifeSupportSupply.scrubber#

Lithium hydroxide canisters, which scrub carbon dioxide from the air.

LifeSupportSupply.water#

Drinking water.

LifeSupportSupply.food#

Meals.

class KSA.HabitatZone()#

The connected habitable parts of a vehicle, which share their crew’s supplies. Obtained from KSA.Vehicle.getHabitatZones() or KSA.Habitat.getZone().

Note

Parts join a zone through connections the crew can pass, such as an open docking port hatch.

HabitatZone.getVehicle()#

The vehicle the zone is in.

Property:

Read-only, cannot be set

Return type:

KSA.Vehicle

HabitatZone.getParts()#

The parts in the zone.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Part

HabitatZone.getHabitats()#

The habitats in the zone.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Habitat

HabitatZone.getSeats()#

The crew seats in the zone.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Seat

HabitatZone.getCrew()#

The kittens in the zone’s seats.

Property:

Read-only, cannot be set

Return type:

Array of KSA.Kitten

HabitatZone.getLinkedZones()#

The zones that join this one when closed docking port hatches between them open.

Property:

Read-only, cannot be set

Return type:

Array of KSA.HabitatZone

HabitatZone.hatchesTo(zone)#

The closed docking port hatches that join this zone to a linked zone when they open.

Arguments:

  • zone (KSA.HabitatZone) – A zone in KSA.HabitatZone.getLinkedZones().

Return type:

Array of KSA.DockingPort

Note

Throws an exception if the zone is not linked to this one.

number

Property:

Read-only, cannot be set

Property:

Read-only, cannot be set

HabitatZone.getMissionSupplies()#

Whether the zone’s supplies last its crew through the vehicle’s mission. null without a feasible mission with time left, or while KSA.getLifeSupportEnabled() is false.

Property:

Read-only, cannot be set

Return type:

KSA.MissionSupplies or null

HabitatZone.plannedKittens(leg)#

The number of kittens planned in the zone for a leg of the vehicle’s mission. The plan defaults to the kittens seated in the zone.

Arguments:

Return type:

number

class KSA.Mission()#

The mission planned for a vehicle in the editor’s life support window. Obtained from KSA.Vehicle.getMission().

Note

The game times the legs of the mission from the plan, and checks the supplies of each habitat zone against them. See KSA.HabitatZone.getMissionSupplies().

class KSA.MissionSupplies()#

Whether the supplies of a habitat zone last its crew through the vehicle’s mission, as the life support window shows it. Obtained from KSA.HabitatZone.getMissionSupplies().

Note

The check takes the legs left in the mission as planned, counted from the vehicle’s launch, and the kittens planned for each leg. The times are from now.

Property:

Read-only, cannot be set

Return type:

Read-only, cannot be set

number

Read-only, cannot be set

Return type:

The time until a supply runs out with the crew planned for each leg, in seconds. Infinite if it lasts the mission.

MissionSupplies.getEnd()#

class KSA.MissionSupplyVerdict()#

Whether a habitat zone has the supplies for a mission. See KSA.MissionSupplies.getVerdict().

The zone has no crew during the mission.

MissionSupplyVerdict.enough#

The supplies last the mission.

MissionSupplyVerdict.short#

A supply runs out before the end of the mission.

Habitat.transfer(to[, meals[, canisters]])#

Moves meals and canisters to another habitat in the same zone. Moves fewer when this habitat holds fewer, or the other has less room.

Arguments:

  • to (KSA.Habitat) – The habitat to move the supplies to.

  • meals (number) – The number of meals to move. Defaults to 0.

  • canisters (number) – The number of canisters to move. Defaults to 0.

Note

A kitten in the zone moves the supplies. Throws an exception if life support is disabled, the habitats are in different zones, or the zone has no crew able to move them.
