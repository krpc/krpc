UI#

class KSA.UI()#

Adds windows of buttons, text fields and other widgets to the game’s UI.

Note

The windows are removed when the client that added them disconnects. For messages on the screen, see KSA.showMessage().

UI.addWindow(title[, visible])#

Add a window, with no widgets.

Arguments:

  • title (string) – The text in the title bar.

  • visible (boolean) – Whether the window is visible. Defaults to true.

Return type:

KSA.Window

UI.clear([clientOnly])#

Remove the windows.

Arguments:

  • clientOnly (boolean) – Whether to remove only the windows added by the calling client. Defaults to false.

class KSA.Window()#

A window, holding widgets one per line. Created using KSA.UI.addWindow().

Note

The window fits its widgets until its size is set. Closing the window makes it invisible. The window is hidden with the game’s UI.

Return type:

Window.addSlider([label[, minimum[, maximum[, visible]]]])#

Add a slider, at its minimum value.

Arguments:

  • label (string) – The text shown next to the slider. Defaults to "".

  • minimum (number) – The minimum value. Defaults to 0.0.

  • maximum (number) – The maximum value. Defaults to 1.0.

  • visible (boolean) – Whether the slider is visible. Defaults to true.

Return type:

KSA.Slider

Note

Throws an exception if the minimum is not less than the maximum.
