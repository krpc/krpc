Computer#

class KFS.Computer()#

A vehicle’s flight computer, which runs a kFS program. Obtained from KFS.computer().

Note

A program is written in kC, a subset of C, or in kASM. The calls that change the computer, and KFS.Computer.writeGlobals(), take effect before the computer’s next tick, and return once they have. The computer ticks while the game is running and the vehicle is in the physics bubble, so until then they wait. The game does not save a program.

Computer.build(files)#

Build a program, without loading it.

Arguments:

  • files (Map from string to string) – The source files, by name. A program with a .c file is kC, and one with only .kasm files is kASM.

Returns:

The errors and warnings.

Return type:

Array of KFS.Diagnostic

Game Scenes:

Flight

Computer.load(files)#

Build a program and load it onto the computer. Throws an exception if the program has errors, or the computer rejects it.

Arguments:

  • files (Map from string to string) – The source files, by name, as for KFS.Computer.build().

Game Scenes:

Flight

Note

The program is in standby once loaded. See KFS.Computer.start().

Computer.start()#

Start the loaded program. Throws an exception if no program is loaded.

Computer.reset()#

Restart the loaded program, as the reset button does. Throws an exception if no program is loaded.

Computer.stop()#

Stop the program, and give the vehicle back to the pilot. The program stays loaded.

Computer.kill()#

Halt the program with the kill switch, and give the vehicle back to the pilot.

Computer.readGlobal(path)#

The value of one of the program’s global variables, as of its latest tick.

  • path (string) – The path of the variable, as in KFS.Computer.getGlobals().

Return type:

number

Game Scenes:

Flight

Computer.writeGlobals(values)#

Write the program’s global variables. The program sees all of them from the same tick.

Arguments:

  • values (Map from string to number) – The values, by the paths in KFS.Computer.getGlobals().

Game Scenes:

Flight

Note

A value is converted to the variable’s type. Throws an exception if a value does not fit, such as a fraction for an integer.

class KFS.ComputerState()#

The state of a flight computer. See KFS.Computer.getState().

ComputerState.noSoftware#

No program is loaded.

ComputerState.standby#

A program is loaded, and not running.

ComputerState.boot#

The program is running its initialization.

ComputerState.running#

The program is running.

ComputerState.idle#

The program is running, with no task to run.

ComputerState.halted#

The program has stopped, after a trap, a halt or the kill switch.

class KFS.ControlMode()#

The control a program has of a vehicle. See KFS.Computer.getMode().

ControlMode.pilot#

The game’s flight computer flies the vehicle, and the program steers it.

ControlMode.fullControl#

The program commands the thrusters, engines and gimbals itself. A program claims it with #pragma kfs claim ALLOCATION.

class KFS.Diagnostic(fields)#

An error or warning from building a program. See KFS.Computer.build().

Diagnostic.error#

Whether it is an error. An error stops the program from being built.

Type:

boolean

Diagnostic.code#

The diagnostic’s code, such as KC-E016.

Type:

string

Diagnostic.file#

The source file.

Type:

string

Diagnostic.line#

The line in the source file, from 1. Zero for the whole file.

Type:

number

Diagnostic.column#

The column in the line, from 1.

Type:

number

Diagnostic.message#

The message.

Type:

string

Diagnostic.hint#

A hint at the fix, or null if there is none.

Type:

string or null

The error that halted a program, and where it happened. See KFS.Computer.getTrap().

Trap.code#

The error.

Type:

Trap.function#

The function that was running.

Type:

string

Trap.file#

The source file, or null if it is not known.

Type:

string or null

Trap.line#

The line in the source file, or zero if it is not known.

Type:

number

class KFS.TrapCode()#

The error that halted a program. See KFS.Trap.code.

TrapCode.illegalOpcode#

An instruction the processor does not have.

TrapCode.operandOverflow#

The operand stack overflowed.

TrapCode.operandUnderflow#

The operand stack underflowed.

TrapCode.returnOverflow#

The return stack overflowed.

TrapCode.initOverrun#

The initialization ran past its budget.

TrapCode.stackOverflow#

The stack overflowed.

TrapCode.nullAccess#

A read or write through a null pointer.

TrapCode.badAddress#

A read or write outside memory.

TrapCode.readOnly#

A write to read-only memory.

TrapCode.misaligned#

A misaligned read or write.

TrapCode.divisionByZero#

A division by zero.

TrapCode.bounds#

An array index out of bounds.

TrapCode.user#

A trap raised by the program.

TrapCode.badJump#

A jump to an invalid address.

TrapCode.badSyscall#

A call to a service that does not exist.

TrapCode.badYield#

A task yielded where it may not.

TrapCode.memoryError#

A memory error, such as a radiation upset.
