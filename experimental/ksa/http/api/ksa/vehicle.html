Vehicle#

Vehicle

A vehicle in the current system. Obtained from GET /ksa/active-vehicle or GET /ksa/vehicles.

Note

Docking and undocking replace the vehicles involved, so an object for one of them throws an exception afterwards.

A Vehicle object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/vehicle/(id)/name#

The name of the vehicle, which is unique in the system.

Parameters:

  • id – The identifier of the Vehicle object.

Response JSON Object:

  • value (string)

PUT /ksa/vehicle/(id)/name#

The name of the vehicle, which is unique in the system.

Parameters:

  • id – The identifier of the Vehicle object.

Request JSON Object:

  • value (string) – The new value.

POST /ksa/vehicle/(id)/destroy#

Destroy the vehicle, killing its crew, as abandoning the vehicle does. Returns once the vehicle is gone.

Note

If the vehicle is the active vehicle, the game hands control to a nearby vehicle.

Parameters:

  • id – The identifier of the Vehicle object.

GET /ksa/vehicle/(id)/can-recover#

Whether the vehicle can be recovered: at rest on the surface of the home planet.

Parameters:

  • id – The identifier of the Vehicle object.

Response JSON Object:

  • value (bool)

POST /ksa/vehicle/(id)/recover#

Recover the vehicle, ending its crew’s missions, as the game’s recover button does. Returns once the vehicle is gone.

Note

Throws an exception if the vehicle cannot be recovered, see GET /ksa/vehicle/(id)/can-recover.

Parameters:

  • id – The identifier of the Vehicle object.

  • value (KSA.Situation)

POST /ksa/vehicle/(id)/add-burn#

Plan a burn, and add it to the vehicle’s burn plan.

Note

Returns once the flight computer has timed the burn, if it is the next one. Throws an exception if the time is in the past, or beyond the vehicle’s predicted trajectory.

Parameters:

  • id – The identifier of the Vehicle object.

Request JSON Object:

  • ut (double) – Universal time of the burn, in seconds.

  • prograde (float) – Change in velocity in the prograde direction, in meters per second. Optional, defaults to 0.0.

  • normal (float) – Change in velocity along the orbit normal, in meters per second. Optional, defaults to 0.0.

  • radial (float) – Change in velocity radially outward, in meters per second. Optional, defaults to 0.0.

Response JSON Object:

  • value (KSA.Burn) – The burn.

Situation

The situation of a vehicle: its contact with the surface, and whether the game is simulating it with physics or propagating it along its orbit. See GET /ksa/vehicle/(id)/situation.

Passed and returned as the name of one of its values:

"maneuvering"

No surface contact, simulated with physics.

"freefall"

No surface contact, on rails.

"rolling"

On terrain, simulated with physics.

"landed"

At rest on terrain.

"sailing"

In the ocean, simulated with physics.

"floating"

At rest in the ocean.

"dragging"

On terrain and in the ocean, simulated with physics.

"bottomed"

At rest on terrain and in the ocean.

ControlState

Whether a vehicle can be flown, or why not. See GET /ksa/vehicle/(id)/control-state.

Passed and returned as the name of one of its values:

"controllable"

The vehicle can be flown.

"no_control_module"

The vehicle has no control module, such as a capsule or a probe core.

"no_crew"

The capsules have no crew, and no probe core is on.

"crew_incapacitated"

VehicleDesign

A vehicle design that can be launched: one of the game’s default vehicles, or a vehicle saved by the player in the editor. Obtained from GET /ksa/vehicle-designs.

Note

The mass and delta-v are those the editor shows for the design.

A VehicleDesign object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/vehicle-design/(id)/name#

The name of the design, as passed to POST /ksa/launch-vehicle.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (string)

GET /ksa/vehicle-design/(id)/is-default#

Whether the design is one of the game’s default vehicles.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (bool)

GET /ksa/vehicle-design/(id)/part-count#

The number of parts in the design.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (int32)

GET /ksa/vehicle-design/(id)/mass#

The total mass of the design, including propellant, in kilograms.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (float)

GET /ksa/vehicle-design/(id)/dry-mass#

The mass of the design without propellant, in kilograms.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (float)

GET /ksa/vehicle-design/(id)/delta-v#

The change in velocity of all the design’s sequences, in meters per second.

Note

Each sequence is computed in the environment chosen for it in the editor, in vacuum or at sea level.

Parameters:

  • id – The identifier of the VehicleDesign object.

Response JSON Object:

  • value (float)
