Crew#

Kitten

A kitten in the agency’s roster. Obtained from GET /ksa/kittens, GET /ksa/vehicle/(id)/crew or GET /ksa/seat/(id)/kitten.

A Kitten object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/kitten/(id)/name#

The kitten’s name, which is unique in the roster.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (string)

GET /ksa/kitten/(id)/roster-index#

The kitten’s position in the agency’s roster, from 0. See GET /ksa/kittens.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (int32)

GET /ksa/kitten/(id)/vehicle#

The vehicle the kitten is in, or null if it is not in a seat.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.Vehicle?)

GET /ksa/kitten/(id)/seat#

The seat the kitten is in, or null if it is not in a seat.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.Seat?)

GET /ksa/kitten/(id)/killed-in-action#

Whether the kitten has been killed in action.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

GET /ksa/kitten/(id)/cause-of-death#

What killed the kitten, or null if it is alive.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.DeathCause?)

GET /ksa/kitten/(id)/mission-count#

The number of missions the kitten has flown, including the current one.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (int32)

GET /ksa/kitten/(id)/mission-time#

The time the kitten has spent on missions, including the current one, in seconds.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/distance-traveled#

The distance the kitten has traveled on missions, in meters.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/fastest-speed#

The kitten’s highest speed on a mission, in meters per second.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/acute-dose#

The kitten’s acute radiation dose, in sieverts. It heals over time, and causes radiation sickness from 1 sievert and death from 4 sieverts.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/lifetime-dose#

The kitten’s lifetime radiation dose, in sieverts. The kitten retires after a mission that takes it past 0.6 sieverts.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/dose-rate#

The radiation dose rate the kitten receives, in sieverts per second. The vehicle’s shielding reduces it in a seat, and on EVA the kitten is unshielded. Zero when the kitten is not on a mission.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/radiation-sickness#

Whether the kitten has radiation sickness, which keeps it from flying.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

GET /ksa/kitten/(id)/time-to-radiation-sickness#

The time until the kitten gets radiation sickness at its current dose rate, in seconds. Infinite if it never does, or the kitten already has it.

Note

The game forecasts it for a kitten on a mission while GET /ksa/radiation-enabled is true.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/time-to-lethal-dose#

The time until the kitten takes a lethal radiation dose at its current dose rate, in seconds. Infinite if it never does.

Note

The game forecasts it for a kitten on a mission while GET /ksa/radiation-enabled is true, and only within a day of radiation sickness.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/time-until-fit-to-fly#

The time until the kitten has recovered from radiation sickness and can fly, resting at home, in seconds. Zero if the kitten does not have radiation sickness.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/recovery-time#

The time until the kitten’s acute radiation dose has healed below 1 millisievert, resting at home, in seconds.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/retired#

Whether the kitten has retired, having reached its lifetime radiation dose limit.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

GET /ksa/kitten/(id)/worst-condition#

The kitten’s worst condition across its supplies.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.KittenCondition)

POST /ksa/kitten/(id)/condition#

The effect on the kitten of going without a supply.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • supply (KSA.LifeSupportSupply) – The supply.

Response JSON Object:

  • value (KSA.KittenCondition)

POST /ksa/kitten/(id)/time-without#

The time the kitten has gone without a supply, in seconds. It counts down again once the supply returns.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • supply (KSA.LifeSupportSupply) – The supply.

Response JSON Object:

  • value (float)

POST /ksa/kitten/(id)/time-to-next-condition#

The further time the kitten can go without a supply before its condition from the supply worsens, in seconds. Infinite once the kitten is dead.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • supply (KSA.LifeSupportSupply) – The supply.

Response JSON Object:

  • value (float)

GET /ksa/kitten/(id)/incapacitated#

Whether the kitten is incapacitated by going without a supply. An incapacitated kitten cannot fly the vehicle or move supplies.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

GET /ksa/kitten/(id)/on-eva#

Whether the kitten is on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

POST /ksa/kitten/(id)/go-on-eva#

Leave the kitten’s vehicle through its EVA hatch, and return once the kitten is on EVA. The kitten becomes the controlled kitten, see GET /ksa/active-kitten.

Note

Throws an exception if the kitten is not in a seat, or the vehicle has no EVA hatch.

Parameters:

  • id – The identifier of the Kitten object.

GET /ksa/kitten/(id)/can-go-on-eva#

Whether the kitten can go on EVA. See POST /ksa/kitten/(id)/go-on-eva.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

POST /ksa/kitten/(id)/board#

Board the nearest vehicle with a free seat, and return once the kitten is in the seat. The vehicle becomes the controlled vehicle.

Note

Throws an exception if the kitten is not on EVA, or no EVA hatch with a free seat is within one meter.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.Vehicle) – The vehicle the kitten boarded.

GET /ksa/kitten/(id)/can-board#

Whether the kitten is on EVA and an EVA hatch with a free seat is in range. See POST /ksa/kitten/(id)/board.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (bool)

GET /ksa/kitten/(id)/locomotion-mode#

How the kitten on EVA is moving. Throws an exception if the kitten is not on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.LocomotionMode)

POST /ksa/kitten/(id)/position#

The position of the kitten, in meters. For a kitten in a seat, the position of the seat’s part. Throws an exception if the kitten is neither in a seat nor on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

Response JSON Object:

  • value (tuple<double, double, double>)

POST /ksa/kitten/(id)/velocity#

The velocity of the kitten, in meters per second. For a kitten in a seat, the velocity of the seat’s part. Throws an exception if the kitten is neither in a seat nor on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the velocity.

Response JSON Object:

  • value (tuple<double, double, double>)

GET /ksa/kitten/(id)/life-support#

How long the supplies in the kitten’s suit last, or null if the kitten is not on EVA.

Note

The suit is filled from the kitten’s habitat zone when it goes on EVA, and what is left returns to the zone when it boards.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (KSA.LifeSupport?)

GET /ksa/kitten/(id)/carried-meals#

The number of meals the kitten on EVA carries. Throws an exception if the kitten is not on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (int32)

GET /ksa/kitten/(id)/carried-canisters#

The number of carbon dioxide scrubber canisters the kitten on EVA carries. Throws an exception if the kitten is not on EVA.

Parameters:

  • id – The identifier of the Kitten object.

Response JSON Object:

  • value (int32)

POST /ksa/kitten/(id)/can-carry#

Whether the kitten can take supplies from or stow them in a habitat. See POST /ksa/kitten/(id)/take and POST /ksa/kitten/(id)/stow.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • habitat (KSA.Habitat) – The habitat.

Response JSON Object:

  • value (bool)

POST /ksa/kitten/(id)/take#

Take meals and canisters from a habitat within reach, and return once the kitten carries them. Takes fewer when the habitat holds fewer, or the kitten cannot carry more.

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See POST /ksa/kitten/(id)/can-carry.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • habitat (KSA.Habitat) – The habitat, which must store supplies.

  • meals (int32) – The number of meals to take. Optional, defaults to 0.

  • canisters (int32) – The number of canisters to take. Optional, defaults to 0.

POST /ksa/kitten/(id)/stow#

Stow the meals and canisters the kitten carries in a habitat within reach, and return once they are stowed. Stows fewer when the kitten carries fewer, or the habitat has less room.

Note

Throws an exception if the kitten is not on EVA or is unwell, life support is disabled, or the habitat stores no supplies or is out of reach. See POST /ksa/kitten/(id)/can-carry.

Parameters:

  • id – The identifier of the Kitten object.

Request JSON Object:

  • habitat (KSA.Habitat) – The habitat, which must store supplies.

  • meals (int32) – The number of meals to stow. Optional, defaults to 0.

  • canisters (int32) – The number of canisters to stow. Optional, defaults to 0.

LocomotionMode

How a kitten on EVA is moving. See GET /ksa/kitten/(id)/locomotion-mode.

Passed and returned as the name of one of its values:

"mmu"

Flying with the maneuvering unit, away from any surface.

"grounded"

Standing or walking on a surface.

"airborne"

In the air above a surface, such as during a jump.

"tumbling"

Tumbling after a fall or an impact.

"righting"

Getting back up after tumbling.

"ladder"

Holding a ladder or grab rail.

"swimming"

Swimming in an ocean.

KittenCondition

The effect on a kitten of going without a supply. See POST /ksa/kitten/(id)/condition.

Passed and returned as the name of one of its values:

"healthy"

Unaffected.

"warning"

Going without, with no effect yet.

"degraded"

Weakened, and unable to go on EVA.

"incapacitated"

Unable to fly the vehicle or move supplies.

"dead"

Dead.

DeathCause

What killed a kitten. See GET /ksa/kitten/(id)/cause-of-death.

Passed and returned as the name of one of its values:

"unknown"

Not recorded.

"no_oxygen"

Lack of oxygen.

"no_scrubber"

Carbon dioxide, with no scrubber canisters left.

"no_water"

Lack of water.

"no_food"

Lack of food.

"radiation"

A lethal radiation dose.

"ground_impact"

Hitting the ground.

"ocean_impact"

Hitting the ocean.

"collision"

A collision.

"excessive_g_force"

Excessive acceleration.

"aerodynamic_forces"

Aerodynamic forces breaking up the vehicle.

"hydrodynamic_forces"

Hydrodynamic forces breaking up the vehicle.

"fall"

A fall on EVA.

"abandoned"

Left in a vehicle that was abandoned.

CrewEvent

A kitten’s most urgent coming event: its supplies running low, or its condition worsening. Obtained from GET /ksa/vehicle/(id)/crew-events or GET /ksa/vehicle/(id)/next-crew-event.

Note

As the game’s crew clock, an event within a day is the worst stage the kitten reaches in that time, and a later event is the soonest. The event is the game’s forecast when it is read from the vehicle. Read it again for a new forecast.

A CrewEvent object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/crew-event/(id)/kitten#

The kitten.

Parameters:

  • id – The identifier of the CrewEvent object.

Response JSON Object:

  • value (KSA.Kitten)

GET /ksa/crew-event/(id)/stage#

What happens to the kitten.

Parameters:

  • id – The identifier of the CrewEvent object.

Response JSON Object:

  • value (KSA.CrewStage)

GET /ksa/crew-event/(id)/hazard#

The cause of the event.

Parameters:

  • id – The identifier of the CrewEvent object.

Response JSON Object:

  • value (KSA.CrewHazard)

GET /ksa/crew-event/(id)/ut#

The universal time of the event, in seconds.

Parameters:

  • id – The identifier of the CrewEvent object.

Response JSON Object:

  • value (double)

GET /ksa/crew-event/(id)/time-to#

The time until the event, in seconds. Zero once its time has passed.

Parameters:

  • id – The identifier of the CrewEvent object.

Response JSON Object:

  • value (float)

CrewStage

What happens to a kitten in a crew event. See GET /ksa/crew-event/(id)/stage.

Passed and returned as the name of one of its values:

"low"

The supply runs low.

"degraded"

The kitten is weakened, and unable to go on EVA. For radiation, the kitten gets radiation sickness.

"incapacitated"

The kitten is unable to fly the vehicle or move supplies.

"dead"

The kitten dies.

CrewHazard

The cause of a crew event. See GET /ksa/crew-event/(id)/hazard.

Passed and returned as the name of one of its values:

"air"

Running out of air.

"scrubber"

Running out of carbon dioxide scrubber.

"water"

Running out of water.

"food"

Running out of food.

"radiation"

The radiation dose.

Seat

A crew seat. Obtained from GET /ksa/part/(id)/seats.

A Seat object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/seat/(id)/part#

The part the seat is in.

Parameters:

  • id – The identifier of the Seat object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/seat/(id)/kitten#

Returns the kitten in the seat, or null if the seat is empty, and sets the kitten in the seat. Setting null empties the seat.

Note

A kitten in another seat of the vehicle moves to this one, within its habitat zone. Throws an exception if the kitten is killed in action, retired, on EVA, in another vehicle, or incapacitated, or the seat is in another habitat zone.

Parameters:

  • id – The identifier of the Seat object.

Response JSON Object:

  • value (KSA.Kitten?)

PUT /ksa/seat/(id)/kitten#

Returns the kitten in the seat, or null if the seat is empty, and sets the kitten in the seat. Setting null empties the seat.

Note

A kitten in another seat of the vehicle moves to this one, within its habitat zone. Throws an exception if the kitten is killed in action, retired, on EVA, in another vehicle, or incapacitated, or the seat is in another habitat zone.

Parameters:

  • id – The identifier of the Seat object.

Request JSON Object:

  • value (KSA.Kitten?) – The new value.
