Drawing#

Drawing

Draws lines, shapes and text in the scene, each placed in a reference frame.

Note

The objects are drawn every frame until removed, and are removed when the client that added them disconnects. Lines are drawn at the game’s fixed gizmo width.

A Drawing object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

POST /ksa/drawing/add-line#

Draw a line between two positions.

Request JSON Object:

  • start (tuple<double, double, double>) – The position of the start of the line, in meters.

  • end (tuple<double, double, double>) – The position of the end of the line, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the positions.

  • visible (bool) – Whether the line is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Line)

POST /ksa/drawing/add-direction#

Draw a line from the origin of a reference frame in a direction.

Request JSON Object:

  • direction (tuple<double, double, double>) – The direction of the line.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the direction.

  • length (float) – The length of the line, in meters. Optional, defaults to 1e+01.

  • visible (bool) – Whether the line is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Line)

POST /ksa/drawing/add-polyline#

Draw a line through a list of positions.

Request JSON Object:

  • vertices (list<tuple<double, double, double>>) – The positions the line passes through, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the positions.

  • closed (bool) – Whether the line joins the last position back to the first. Optional, defaults to false.

  • visible (bool) – Whether the line is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Polyline)

POST /ksa/drawing/add-circle#

Draw a circle.

Request JSON Object:

  • center (tuple<double, double, double>) – The position of the center of the circle, in meters.

  • normal (tuple<double, double, double>) – The direction normal to the plane of the circle.

  • radius (float) – The radius of the circle, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position and direction.

  • visible (bool) – Whether the circle is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Circle)

POST /ksa/drawing/add-arc#

Draw an arc of a circle.

Request JSON Object:

  • center (tuple<double, double, double>) – The position of the center of the arc’s circle, in meters.

  • normal (tuple<double, double, double>) – The direction normal to the plane of the arc.

  • start_direction (tuple<double, double, double>) – The direction from the center to the start of the arc.

  • angle (float) – The angle the arc turns through, counterclockwise about the normal, in radians.

  • radius (float) – The radius of the arc, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position and directions.

  • visible (bool) – Whether the arc is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Arc)

POST /ksa/drawing/add-box#

Draw the edges of a box.

Request JSON Object:

  • center (tuple<double, double, double>) – The position of the center of the box, in meters.

  • size (tuple<double, double, double>) – The lengths of the box’s edges along its x, y and z axes, in meters.

  • rotation (tuple<double, double, double, double>) – The rotation of the box’s axes, as a quaternion of the form (x, y, z, w).

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position and rotation.

  • visible (bool) – Whether the box is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Box)

POST /ksa/drawing/add-sphere#

Draw a solid sphere.

Request JSON Object:

  • center (tuple<double, double, double>) – The position of the center of the sphere, in meters.

  • radius (float) – The radius of the sphere, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

  • visible (bool) – Whether the sphere is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Sphere)

POST /ksa/drawing/add-text#

Draw text over the scene, centered on a position.

Request JSON Object:

  • text (string) – The text.

  • position (tuple<double, double, double>) – The position of the center of the text, in meters.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position.

  • size (float) – The height of the font, in pixels. Optional, defaults to 16.0.

  • visible (bool) – Whether the text is visible. Optional, defaults to true.

Response JSON Object:

  • value (KSA.Text)

POST /ksa/drawing/clear#

Remove the drawing objects.

Request JSON Object:

  • client_only (bool) – Whether to remove only the objects added by the calling client. Optional, defaults to false.
