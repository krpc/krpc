Orbit#

Orbit

An orbit. Obtained from GET /ksa/vehicle/(id)/orbit, GET /ksa/body/(id)/orbit, GET /ksa/burn/(id)/orbit or GET /ksa/orbit/(id)/next-orbit.

Note

An orbit follows the game’s prediction as the trajectory changes. A predicted orbit, from GET /ksa/orbit/(id)/next-orbit or GET /ksa/burn/(id)/orbit, is a position in the vehicle’s or the burn’s predicted trajectory, and throws an exception while the trajectory is too short to reach it.

A Orbit object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/orbit/(id)/body#

The body being orbited.

Parameters:

  • id – The identifier of the Orbit object.

Response JSON Object:

  • value (KSA.Body)

GET /ksa/orbit/(id)/apoapsis#

The apoapsis of the orbit, in meters, from the center of the body being orbited. Not a number for a parabolic or hyperbolic orbit.

Parameters:

  • id – The identifier of the Orbit object.

Response JSON Object:

  • value (double)

POST /ksa/orbit/create-from-elements#

Create the orbit with the given elements around a body. The angles are those of Orbit.

Note

The orbit is a single conic around body, with no GET /ksa/orbit/(id)/next-orbit. It is held until POST /ksa/orbit/(id)/remove is called on it, or the client that created it disconnects.

Request JSON Object:

  • body (KSA.Body) – The body being orbited.

  • semi_major_axis (double) – The semi-major axis, in meters. Negative or positive for a hyperbolic orbit.

  • eccentricity (double) – The eccentricity. Below 1 for an elliptical orbit, and above 1 for a hyperbolic one.

  • inclination (double) – The inclination, in radians.

  • longitude_of_ascending_node (double) – The longitude of the ascending node, in radians.

  • argument_of_periapsis (double) – The argument of periapsis, in radians.

  • mean_anomaly_at_epoch (double) – The mean anomaly at the epoch, in radians.

  • epoch (double) – The universal time of the epoch, in seconds.

Response JSON Object:

  • value (KSA.Orbit)

POST /ksa/orbit/create-from-position-and-velocity#

Create the orbit around a body through the given position and velocity.

Note

The orbit is a single conic around body, with no GET /ksa/orbit/(id)/next-orbit. It is held until POST /ksa/orbit/(id)/remove is called on it, or the client that created it disconnects.

Request JSON Object:

  • body (KSA.Body) – The body being orbited.

  • position (tuple<double, double, double>) – The position, in meters, relative to where the body is now.

  • velocity (tuple<double, double, double>) – The velocity, in meters per second.

  • ut (double) – The universal time of the position and velocity, in seconds.

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the position and velocity.

Response JSON Object:

  • value (KSA.Orbit)

POST /ksa/orbit/(id)/remove#

Remove an orbit created by POST /ksa/orbit/create-from-elements or POST /ksa/orbit/create-from-position-and-velocity.

Note

Throws an exception if the orbit was not created by a client.

Parameters:

  • id – The identifier of the Orbit object.

OrbitTransition

How an orbit ends. See GET /ksa/orbit/(id)/end-transition.

Passed and returned as the name of one of its values:

"none"

The orbit does not end.

"encounter"

The orbit enters the sphere of influence of another body.

"escape"

The orbit leaves the sphere of influence of the body being orbited.

"impact"

The orbit hits the surface of the body being orbited.

"burn"

The orbit ends at a planned burn.
