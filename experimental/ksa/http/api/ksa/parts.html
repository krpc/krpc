Parts#

Part

A part of a vehicle. Obtained from GET /ksa/vehicle/(id)/parts.

Note

A part keeps its object when the vehicle it belongs to changes, for example when a decoupler separates it. Throws an exception once the part no longer exists.

A Part object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/part/(id)/name#

The id of the part’s template.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (string)

GET /ksa/part/(id)/title#

The name of the part, as shown in the game.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (string)

GET /ksa/part/(id)/vehicle#

The vehicle the part belongs to.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (KSA.Vehicle)

GET /ksa/part/(id)/parent#

The part this part is attached to, or null for the root part.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (KSA.Part?)

GET /ksa/part/(id)/children#

The parts attached to this part.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (list<KSA.Part>)

GET /ksa/part/(id)/sequence#

The number of the sequence that activates the part, or -1 if no sequence does.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (int32)

GET /ksa/part/(id)/mass#

The mass of the part, including its propellant, in kilograms.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/dry-mass#

The mass of the part without its propellant, in kilograms.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/resources#

The resources the part holds, one for each substance.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (list<KSA.Resource>)

GET /ksa/part/(id)/shield-areal-density#

The areal density of the part’s radiation shielding, its hull included, in \(\mathrm{kg/m^{2}}\). Zero for an unshielded part.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/shield-mass#

The mass of the shielding material added to the part, in kilograms. Zero when the shielding is built into the hull.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/tank-cover#

The fraction of the sky, seen from the part, that the contents of the vehicle’s tanks cover, between 0 and 1. The contents shield the part from radiation.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/dose-rate#

The radiation dose rate inside the part, behind its shielding and the vehicle’s tanks, in sieverts per second. Includes any solar particle event under way. A kitten in the part’s seats receives this dose rate.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (float)

GET /ksa/part/(id)/highlight#

The color the part is highlighted in.

Note

The life support window uses this highlight to pick parts, and replaces it on the parts it picks from.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (KSA.HighlightColor)

PUT /ksa/part/(id)/highlight#

The color the part is highlighted in.

Note

The life support window uses this highlight to pick parts, and replaces it on the parts it picks from.

Parameters:

  • id – The identifier of the Part object.

Request JSON Object:

  • value (KSA.HighlightColor) – The new value.

GET /ksa/part/(id)/tanks#

The part’s propellant tanks. Empty if it has none.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (list<KSA.Tank>)

GET /ksa/part/(id)/habitats#

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (list<KSA.Habitat>)

GET /ksa/part/(id)/batteries#

GET /ksa/part/(id)/solar-panels#

GET /ksa/part/(id)/power-consumers#

Parameters:

Response JSON Object:

  • value (list<KSA.Deployable>)

GET /ksa/part/(id)/magnetic-scoops#

The part’s magnetic scoops. Empty if it has none.

Parameters:

  • id – The identifier of the Part object.

Response JSON Object:

  • value (list<KSA.MagneticScoop>)

Response JSON Object:

  • value (tuple<double, double, double>)

Parameters:

  • id – The identifier of the Part object.

Request JSON Object:

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Response JSON Object:

  • value (tuple<double, double, double, double>)

GET /ksa/part/(id)/engine#

The part’s engine, or null if it has none.

Response JSON Object:

  • value (KSA.Engine?)

The part’s gimbals. An engine part can have several, each steering one nozzle.

HighlightColor

The color of a part’s highlight. See GET /ksa/part/(id)/highlight.

Passed and returned as the name of one of its values:

"none"

Not highlighted.

"green"

Green.

"yellow"

Yellow.

"red"

Red.

"purple"

Purple.

Engine

An engine. Obtained from GET /ksa/part/(id)/engine.

Note

An active engine fires when the vehicle’s engines are on, at the vehicle’s throttle. See GET /ksa/control/(id)/engine-on and GET /ksa/control/(id)/throttle.

A Engine object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/engine/(id)/part#

The part the engine is in.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/engine/(id)/gimbals#

The gimbals that steer the engine’s nozzles. Empty if the engine has none.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (list<KSA.Gimbal>)

GET /ksa/engine/(id)/active#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (bool)

PUT /ksa/engine/(id)/active#

Whether the engine is active, as when its sequence is activated. Setting it returns once the change has applied.

Parameters:

  • id – The identifier of the Engine object.

Request JSON Object:

  • value (bool) – The new value.

GET /ksa/engine/(id)/has-propellant#

Whether the engine has propellant to burn.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (bool)

GET /ksa/engine/(id)/minimum-throttle#

The lowest throttle the engine runs at, between 0 and 1.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/propellants#

The names of the substances the engine burns. See GET /ksa/resource/(id)/name.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (list<string>)

GET /ksa/engine/(id)/thrust#

The thrust of the engine at its current throttle and the current atmospheric pressure, in Newtons. Zero when it is not firing.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/available-thrust#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/specific-impulse#

The specific impulse of the engine at the current atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

POST /ksa/engine/(id)/available-thrust-at#

The thrust of the engine at full throttle and the given atmospheric pressure, in Newtons. Zero when it is inactive or has no propellant.

Parameters:

  • id – The identifier of the Engine object.

Request JSON Object:

  • pressure (float) – The atmospheric pressure, in pascals.

Response JSON Object:

  • value (float)

POST /ksa/engine/(id)/specific-impulse-at#

The specific impulse of the engine at the given atmospheric pressure, in seconds. Zero when it is inactive or has no propellant.

Parameters:

  • id – The identifier of the Engine object.

Request JSON Object:

  • pressure (float) – The atmospheric pressure, in pascals.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/max-thrust#

The thrust of the engine at full throttle and the current atmospheric pressure, in Newtons, whether or not it is active and has propellant.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/max-vacuum-thrust#

The thrust of the engine at full throttle in a vacuum, in Newtons, whether or not it is active and has propellant.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/chamber-pressure#

The pressure in the engine’s combustion chamber, in pascals. Zero when it is not firing.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

GET /ksa/engine/(id)/solid#

Whether the engine is a solid rocket motor. Once ignited, a solid motor burns at full thrust until its grain runs out.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (bool)

GET /ksa/engine/(id)/grain-mass#

The mass of the propellant grain of a solid rocket motor, in kilograms.

Note

Some of the grain is left unburned when the motor burns out. Throws an exception if the engine is not a solid rocket motor.

Parameters:

  • id – The identifier of the Engine object.

Response JSON Object:

  • value (float)

Gimbal

A gimbal that steers an engine nozzle. Obtained from GET /ksa/part/(id)/gimbals or GET /ksa/engine/(id)/gimbals.

Note

A gimbal turns about the y and z axes of its mount, which POST /ksa/gimbal/(id)/rotation gives. The flight computer steers it while an engine it belongs to is GET /ksa/gimbal/(id)/active.

A Gimbal object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/gimbal/(id)/part#

The part the gimbal is in.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/gimbal/(id)/angle-y#

The angle of the gimbal about its y axis, in degrees.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (float)

GET /ksa/gimbal/(id)/angle-z#

The angle of the gimbal about its z axis, in degrees.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (float)

GET /ksa/gimbal/(id)/max-angle-y#

The largest angle of the gimbal about its y axis, in degrees. Zero if it does not turn about that axis.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (float)

GET /ksa/gimbal/(id)/max-angle-z#

The largest angle of the gimbal about its z axis, in degrees. Zero if it does not turn about that axis.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (float)

GET /ksa/gimbal/(id)/active#

Whether an engine the gimbal steers is active.

Parameters:

  • id – The identifier of the Gimbal object.

Response JSON Object:

  • value (bool)

POST /ksa/gimbal/(id)/rotation#

The rotation of the gimbal’s mount, whose y and z axes the gimbal turns about.

Parameters:

  • id – The identifier of the Gimbal object.

Request JSON Object:

  • reference_frame (KSA.ReferenceFrame) – The reference frame of the rotation.

Response JSON Object:

  • value (tuple<double, double, double, double>)

Parameters:

  • id – The identifier of the RCS object.

Response JSON Object:

  • value (bool)

PUT /ksa/rcs/(id)/active#

Whether the thrusters are active. Setting it returns once the change has applied.

Parameters:

  • id – The identifier of the RCS object.

Request JSON Object:

  • value (bool) – The new value.

A Decoupler object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/decoupler/(id)/part#

The part the decoupler is in.

Parameters:

  • id – The identifier of the Decoupler object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/decoupler/(id)/enabled#

Whether the decoupler can fire.

Parameters:

  • id – The identifier of the Decoupler object.

Response JSON Object:

  • value (bool)

GET /ksa/decoupler/(id)/decoupled#

Whether the decoupler has fired, or is attached to nothing.

Parameters:

Response JSON Object:

  • value (bool)

Parachute

A parachute. Obtained from GET /ksa/part/(id)/parachute.

A Parachute object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/parachute/(id)/part#

The part the parachute is in.

Parameters:

  • id – The identifier of the Parachute object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/parachute/(id)/state#

The state of the parachute.

Parameters:

  • id – The identifier of the Parachute object.

Response JSON Object:

  • value (KSA.ParachuteState)

GET /ksa/parachute/(id)/fill#

How far the canopy is open, from 0 to 1.

Parameters:

  • id – The identifier of the Parachute object.

Response JSON Object:

  • value (float)

GET /ksa/parachute/(id)/deploy-altitude#

The height above the terrain at which an armed parachute deploys, in meters.

Parameters:

  • id – The identifier of the Parachute object.

Response JSON Object:

  • value (float)

GET /ksa/parachute/(id)/can-cut#

Whether the parachute can be cut away. Main parachutes cannot.

Parameters:

  • id – The identifier of the Parachute object.

Response JSON Object:

  • value (bool)

POST /ksa/parachute/(id)/deploy#

Arm the parachute, so that it deploys at GET /ksa/parachute/(id)/deploy-altitude. Returns once it is armed. Throws an exception if it is not stowed.

Parameters:

  • id – The identifier of the Parachute object.

POST /ksa/parachute/(id)/cut#

Cut the parachute away. Returns once it is cut. Throws an exception if it cannot be cut. See GET /ksa/parachute/(id)/can-cut.

Parameters:

  • id – The identifier of the Parachute object.

ParachuteState

The state of a parachute. See GET /ksa/parachute/(id)/state.

Passed and returned as the name of one of its values:

"stowed"

Packed away.

"armed"

Waiting to deploy at GET /ksa/parachute/(id)/deploy-altitude.

"line_stretch"

Leaving the pack.

"reefed"

Partly open, to limit the opening load.

"disreefing"

Opening from reefed to full.

"full"

Fully open.

"cut"

Cut away.

"ripped"

Torn by too much dynamic pressure.

"severed_lines"

Lost after its lines broke under too much load.

A docking port. Obtained from GET /ksa/part/(id)/docking-port.

A DockingPort object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/docking-port/(id)/part#

The part the docking port is in.

Parameters:

  • id – The identifier of the DockingPort object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/docking-port/(id)/docked#

Whether the port is docked.

Parameters:

  • id – The identifier of the DockingPort object.

Response JSON Object:

  • value (bool)

GET /ksa/docking-port/(id)/docked-part#

The part the port is docked to, or null if it is not docked.

Parameters:

  • id – The identifier of the DockingPort object.

Response JSON Object:

  • value (KSA.Part?)

GET /ksa/docking-port/(id)/hatch-open#

Returns whether the hatch through the docked ports is open, and opens or closes it. An open hatch joins the habitat zones on either side.

Note

The hatch is closed while the port is not docked. Throws an exception when set on a port that is not docked.

Parameters:

  • id – The identifier of the DockingPort object.

Response JSON Object:

  • value (bool)

PUT /ksa/docking-port/(id)/hatch-open#

Returns whether the hatch through the docked ports is open, and opens or closes it. An open hatch joins the habitat zones on either side.

Note

The hatch is closed while the port is not docked. Throws an exception when set on a port that is not docked.

Parameters:

  • id – The identifier of the DockingPort object.

Request JSON Object:

  • value (bool) – The new value.

POST /ksa/docking-port/(id)/undock#

Undock the port, separating the vehicle into two. Returns once it has undocked. Throws an exception if the port is not docked.

Note

Docking and undocking replace the vehicles involved. See Vehicle.

Parameters:

Deployable

A part that deploys and retracts, such as a landing leg, a solar panel or a service module door. Obtained from GET /ksa/part/(id)/deployables.

Note

Deploying or retracting a part moves its symmetric copies with it, as the part’s menu in the game does.

A Deployable object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/deployable/(id)/part#

The part the deployable is in.

Parameters:

  • id – The identifier of the Deployable object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/deployable/(id)/state#

The state of the part.

Parameters:

  • id – The identifier of the Deployable object.

Response JSON Object:

  • value (KSA.DeployableState)

POST /ksa/deployable/(id)/deploy#

Deploy the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

Parameters:

  • id – The identifier of the Deployable object.

POST /ksa/deployable/(id)/retract#

Retract the part. Returns once it has started to move.

Note

Throws an exception if the part is broken.

Parameters:

  • id – The identifier of the Deployable object.

DeployableState

The state of a deployable part. See GET /ksa/deployable/(id)/state.

Passed and returned as the name of one of its values:

"deployed"

Fully deployed.

"retracted"

Fully retracted.

"deploying"

Moving toward deployed.

"retracting"

Moving toward retracted.

"broken"

Broken, so it can no longer move.
