Power#

Battery

A battery, which stores electrical energy. Obtained from GET /ksa/part/(id)/batteries.

A Battery object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/battery/(id)/part#

The part the battery is in.

Parameters:

  • id – The identifier of the Battery object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/battery/(id)/stored-energy#

The energy stored in the battery, in joules.

Parameters:

  • id – The identifier of the Battery object.

Response JSON Object:

  • value (float)

GET /ksa/battery/(id)/energy-capacity#

The energy the battery can store, in joules.

Parameters:

  • id – The identifier of the Battery object.

Response JSON Object:

  • value (float)

SolarPanel

A solar panel, which turns sunlight into electrical power. Obtained from GET /ksa/part/(id)/solar-panels.

A SolarPanel object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/solar-panel/(id)/part#

The part the solar panel is in.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/solar-panel/(id)/active#

Whether the solar panel can produce power, because it is deployed or does not deploy.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (bool)

GET /ksa/solar-panel/(id)/power#

The power the solar panel produces, in watts.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (float)

GET /ksa/solar-panel/(id)/sun-angle#

The angle between the solar panel’s face and the direction to the sun, in degrees. Zero when the panel faces the sun.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (float)

GET /ksa/solar-panel/(id)/occluded#

Whether a body blocks the sunlight to the solar panel.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (bool)

GET /ksa/solar-panel/(id)/deployable#

The deployable section that opens the solar panel, or null for a panel that does not deploy.

Parameters:

  • id – The identifier of the SolarPanel object.

Response JSON Object:

  • value (KSA.Deployable?)

Generator

A generator, which produces electrical power. Obtained from GET /ksa/part/(id)/generators.

Note

A generator runs while its GET /ksa/generator/(id)/engine is active, and produces power in proportion to the engine’s throttle.

A Generator object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/generator/(id)/part#

The part the generator is in.

Parameters:

  • id – The identifier of the Generator object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/generator/(id)/engine#

The engine that drives the generator, or null if it has none.

Parameters:

  • id – The identifier of the Generator object.

Response JSON Object:

  • value (KSA.Engine?)

GET /ksa/generator/(id)/active#

Whether the generator is producing power.

Parameters:

  • id – The identifier of the Generator object.

Response JSON Object:

  • value (bool)

GET /ksa/generator/(id)/power#

The power the generator produces, in watts.

Parameters:

  • id – The identifier of the Generator object.

Response JSON Object:

  • value (float)

PowerConsumer

A power consumer, which uses electrical power, such as a light. Obtained from GET /ksa/part/(id)/power-consumers.

A PowerConsumer object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/power-consumer/(id)/part#

The part the power consumer is in.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/power-consumer/(id)/active#

Whether the part is using power.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (bool)

GET /ksa/power-consumer/(id)/power#

The power the part uses, in watts.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (float)

GET /ksa/power-consumer/(id)/has-power-switch#

Whether the part has a power switch, as a probe core does.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (bool)

GET /ksa/power-consumer/(id)/mode#

The setting of the power switch.

Note

Throws an exception if the part has no power switch.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (KSA.PowerMode)

PUT /ksa/power-consumer/(id)/mode#

The setting of the power switch.

Note

Throws an exception if the part has no power switch.

Parameters:

  • id – The identifier of the PowerConsumer object.

Request JSON Object:

  • value (KSA.PowerMode) – The new value.

GET /ksa/power-consumer/(id)/standby-in-storms#

Whether the part goes on standby, drawing no power, while a radiation storm is under way at the vehicle.

Note

The game takes a storm of level 1 or worse on the S scale, as GET /ksa/flight/(id)/radiation-storm-level gives. Throws an exception if the part has no power switch.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (bool)

PUT /ksa/power-consumer/(id)/standby-in-storms#

Whether the part goes on standby, drawing no power, while a radiation storm is under way at the vehicle.

Note

The game takes a storm of level 1 or worse on the S scale, as GET /ksa/flight/(id)/radiation-storm-level gives. Throws an exception if the part has no power switch.

Parameters:

  • id – The identifier of the PowerConsumer object.

Request JSON Object:

  • value (bool) – The new value.

GET /ksa/power-consumer/(id)/status#

The power status of the part.

Note

Throws an exception if the part has no power switch.

Parameters:

  • id – The identifier of the PowerConsumer object.

Response JSON Object:

  • value (KSA.PowerStatus)

PowerMode

The setting of a power switch. See GET /ksa/power-consumer/(id)/mode.

Passed and returned as the name of one of its values:

"off"

Switched off.

"auto"

On standby while another control module flies the vehicle, and on when none can.

"on"

Switched on.

PowerStatus

The power status of a part with a power switch. See GET /ksa/power-consumer/(id)/status.

Passed and returned as the name of one of its values:

"off"

Switched off.

"standby"

On standby, while another control module flies the vehicle or a radiation storm is under way.

"rebooting"

Rebooting after a radiation upset.

"on"

On, with power.

"low"

On, with power for less than five minutes.

"out"

Out of power.

"failed"

Failed from its radiation dose.

PowerForecast

The charge, draw and supply of the electrical circuit a part is on, and how long its batteries last. Obtained from GET /ksa/part/(id)/power-forecast.

Note

A circuit is the parts joined by connections that carry electricity. This is the forecast the game shows for a probe core.

A PowerForecast object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/power-forecast/(id)/has-battery#

Whether the circuit has a battery.

Parameters:

  • id – The identifier of the PowerForecast object.

Response JSON Object:

  • value (bool)

GET /ksa/power-forecast/(id)/charge#

The energy stored in the circuit’s batteries, in joules.

Parameters:

  • id – The identifier of the PowerForecast object.

Response JSON Object:

  • value (float)

GET /ksa/power-forecast/(id)/draw#

The power the parts on the circuit draw, in watts.

Parameters:

  • id – The identifier of the PowerForecast object.

Response JSON Object:

  • value (float)

GET /ksa/power-forecast/(id)/supply#

The power the solar panels and generators on the circuit supply, in watts.

Parameters:

  • id – The identifier of the PowerForecast object.

Response JSON Object:

  • value (float)

GET /ksa/power-forecast/(id)/time-left#

The time until the batteries run out, in seconds. Infinite while the supply meets the draw, and zero when the batteries are empty or there are none.

Parameters:

  • id – The identifier of the PowerForecast object.

Response JSON Object:

  • value (float)

Avionics

The avionics of a probe core, which radiation wears out and upsets. Obtained from GET /ksa/part/(id)/avionics or GET /ksa/vehicle/(id)/avionics.

Note

The avionics take a dose only while GET /ksa/radiation-enabled is true. Switched off or on standby, they take half the dose and no upsets.

A Avionics object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/avionics/(id)/part#

The part the avionics are in.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/avionics/(id)/health#

The health of the avionics.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (KSA.AvionicsHealth)

GET /ksa/avionics/(id)/dose#

The radiation dose the avionics have taken, in grays of silicon.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (float)

GET /ksa/avionics/(id)/tolerance#

The dose at which the avionics fail, in grays of silicon.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (float)

GET /ksa/avionics/(id)/dose-rate#

The rate at which the avionics take a dose, in grays of silicon per second, averaged over about an hour. Not a number until the avionics have taken a dose.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (float)

GET /ksa/avionics/(id)/time-left#

The time until the avionics fail at GET /ksa/avionics/(id)/dose-rate, in seconds. Infinite while they take no dose, and zero once they have failed.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (float)

GET /ksa/avionics/(id)/rebooting#

Whether the avionics are rebooting after a radiation upset.

Parameters:

  • id – The identifier of the Avionics object.

Response JSON Object:

  • value (bool)

AvionicsHealth

The health of avionics. See GET /ksa/avionics/(id)/health.

Passed and returned as the name of one of its values:

"ok"

Working.

"worn"

Working, with a dose of at least four fifths of the tolerance.

"failed"

Failed for good, at the tolerance.

Light

A light. Obtained from GET /ksa/part/(id)/lights.

Note

The vehicle’s lights switch on and off together, see GET /ksa/control/(id)/lights. Cabin lights are always on.

A Light object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /ksa/light/(id)/part#

The part the light is in.

Parameters:

  • id – The identifier of the Light object.

Response JSON Object:

  • value (KSA.Part)

GET /ksa/light/(id)/active#

Whether the light is on.

Parameters:

  • id – The identifier of the Light object.

Response JSON Object:

  • value (bool)
