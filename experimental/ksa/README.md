# kRPC for KSA

A kRPC server for Kitten Space Agency (KSA): a StarMap code mod that serves the `KSA` service
to the kRPC clients, and over gRPC.

The [documentation](https://krpc.github.io/krpc/experimental/ksa/) covers installing and using
it. Its [developer guide](https://krpc.github.io/krpc/experimental/ksa/developer-guide.html)
covers building, running and testing it from this folder.
