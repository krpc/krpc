## [v0.8.0]

- Connections
  - **Breaking:** Connect over one connection, removing the stream port and stream path
    parameters of `Connection.newInstance` and `Connection.newLocalInstance`. A server from
    before 0.8 refuses the connection (#1219)
  - **Breaking:** Give up after 5 seconds if the server does not accept the connection. Pass a
    handshake timeout of `Duration.ZERO` to wait for the player to approve it (#1219)
  - Add overloads of `Connection.newInstance` and `Connection.newLocalInstance` taking a
    handshake timeout and a stall timeout (#1219)
  - Send calls from several threads without waiting for each other's responses (#1219)
  - Tell the server when the connection closes (#1219)
  - Fix an interrupted call closing the connection (#1219)
  - Add `getStatus` and `getReason` to `ConnectionException` for a refused or ended
    connection (#1219)
  - Throw `ConnectionException` when the server cannot be reached or its host name does not
    resolve (#1219)

- Streams and events
  - **Breaking:** Throw `IllegalArgumentException` from `waitForUpdateWithTimeout` and
    `waitForWithTimeout` for a negative or NaN timeout, and wait with no deadline for an infinite
    one (#1219)
  - Keep a stream running when a value fails to decode, dropping the value (#1219)
  - Stream a procedure or server side function with no value as a `Stream<Void>` (#1198)
  - **Breaking:** Return the stream id from `KRPC.addStream` and `KRPC.addFunctionStream` (#1266)
  - Make `Stream` and `Event` `AutoCloseable`, to remove them at the end of a try-with-resources block (#1291)

- Fix the links to members in the javadoc of the services, which named no method (#1185)
- Fix the javadoc of the services that `javadoc` rejects, such as lists and setters with a
  `@return` tag (#1185)
- Exceptions
  - **Breaking:** Throw `InvalidOperationException` as `IllegalStateException`, and
    `ArgumentOutOfRangeException` as `IllegalArgumentException` (#1172)

- **Deprecated:** Passing the connection to `addStream` and `getCall` for a static method, which
  now take only its arguments (#1195)
- Add `bind` to classes with static methods, for calling them without passing the connection
  (#1195)
- Publish the client to Maven Central as `io.github.krpc:krpc-java` (#1231)
- **Breaking:** Return `KRPC.getStatus` as the struct `KRPC.ServerStatus`, with the settings
  and statistics under `getSettings` and `getStatistics` (#1244)
- **Breaking:** Leave internal procedures out of the services, such as `KRPC.addStream` (#1269)
- Add `Connection.compile` for a server side function built with the expression API (#1269)
- **Breaking:** Generate a flags enumeration, such as `SpaceCenter.MapFilterType`, as a class of
  constants with `or`, `and`, `xor`, `andNot` and `contains` (#1311)
- Mark a deprecated service's class with `@Deprecated` (#1322)
- Deprecate each member of a deprecated service, class, enumeration or structure (#1322)
- **Breaking:** Move `Encoder.decode` to `Decoder.decode`. Stubs generated by an earlier
  `krpc-clientgen` need regenerating (#1332)
- Throw `ConnectionException` when the connection request fails to be written, or the server
  closes the connection before answering it (#1332)

- Errors
  - **Breaking:** Make every exception unchecked, deriving the new `RemoteException` (#1333)
  - **Breaking:** Rename `RPCException` to `ServerException` (#1333)
  - **Breaking:** Remove `throws IOException` from `Connection.newInstance`, `newLocalInstance`
    and `close` (#1333)
  - **Breaking:** Remove the generated classes of mapped exceptions, which were never thrown, such
    as `KRPC.ArgumentException`, and of `KRPC.StreamRemovedException` (#1333)
  - **Breaking:** Throw `StreamException` when the server removes a stream or event (#1333)
  - **Breaking:** Throw `ConnectionException` for a call or stream the connection ends, in place
    of an `RPCException` or `StreamException` wrapping it (#1333)
  - **Breaking:** Throw `CancellationException` for an interrupted call or wait (#1333)
  - **Breaking:** Throw `IllegalArgumentException` for a null object, a null in a position that
    cannot hold one, a local socket path that is too long, and a method `addStream` or `getCall`
    cannot find (#1333)
  - Throw `EncodingException` for a tuple with too few items (#1333)
  - Give an `EncodingException` the message of its cause (#1333)

- **Breaking:** Name enumeration constants in upper snake case, e.g. `AltimeterMode.AGL`,
  `AlarmType.SOI_CHANGE` and `TypeCode.UINT32` in place of `A_GL`, `S_OI_CHANGE` and `U_INT32`
  (#1339)
- **Breaking:** Lower case a leading acronym in method and field names, e.g.
  `CelestialBody.mslPosition` and `Type.uint` in place of `mSLPosition` and `uInt` (#1339)
- Add `Connection.getCallTemplate`, which builds a call with no instance or arguments, for
  `Expression.callWithArguments` (#1352)
- Fix remote objects with an id past 63 bits ordering first (#1377)
- Throw `EncodingException` for an enumeration result the enumeration does not declare, in place
  of returning null (#1377)
- Throw `IllegalArgumentException` for a null passed for a parameter that cannot be null, before
  the call is sent (#1377)

## [v0.7.0]

- Streams and events
  - **Breaking:** Start a stream when it is added, removing `Stream.start`,
    `Stream.startAndWait` and `Event.start` (#1122)
  - **Breaking:** Return `true` from `Stream.waitForUpdateWithTimeout` and
    `Event.waitForWithTimeout` on an update, and `false` on a timeout (#1122)
  - Wait for a stream's first value in `Stream.get` (#1122)
  - End a stream on an error from the server, and every stream with a `StreamException` when
    the connection closes or fails (#1122)
  - Throw `StreamException` when reading or waiting on a removed stream or event (#1122)
  - Add `addEndCallback` to streams and events, called with the exception that ends the stream
    (#1122)
  - Call a callback added to a stream or event straight away for a value or firing already
    received (#1122)
  - Fix `Event.waitFor` missing an earlier firing, and waking only one of two waiting threads
    (#1122)
  - Fix the stream update thread stopping on a value it cannot decode (#1122)
  - Fix a second removal of a stream removing a newer stream for the same call, and an error
    ending a stream throwing `ClassCastException` in its callbacks (#1122)

- Server side functions
  - Add `Connection.run` and `Connection.addEvent`, and a `Connection.addStream` overload
    taking a server side function (#1129)
  - Add `RemoteObject.getObjectId`, which returns the id of a remote object for
    `Expression.constantObject` (#1160)

- Types and errors
  - **Breaking:** Throw the matching Java exception, such as `NullPointerException`,
    `NoSuchElementException` or `ArithmeticException`, for an error reported by any service, in
    place of `RPCException` (#1124)
  - **Breaking:** Support `null` for any nullable type, including a structure field, list
    element, tuple item and dictionary value. Primitives use the boxed type (`Integer`, ...)
    (#1017, #1091)
  - Support structure types, generated as a class with a constructor, getters, `equals`,
    `hashCode` and `Comparable` over its fields (#1066)

- Connections
  - **Breaking:** Send protocol version 1 when connecting, and fail to connect to a server from
    before 0.7 (#1162)
  - **Breaking:** Require Java 17 or later, for unix domain sockets (#1065)
  - Add `Connection.newLocalInstance`, which connects to a server on the same machine over a
    unix domain socket (#1065)
  - Add `Connection.newInstance` overloads taking a `timeout`, bounding how long a connection
    is waited for (#1065)
  - Update to protobuf-java 4.36.2 (#1139)
