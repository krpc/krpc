Installing the kRPC C++ client library
======================================

The C++ client documentation describes how to install the library with vcpkg
or CMake, and how to compile a program against it:

https://krpc.github.io/krpc/latest/cpp/client.html#installing-the-library

To build and install the library from this archive, with CMake 3.15 or later:

    cmake -B build -DCMAKE_INSTALL_PREFIX=/path/to/install
    cmake --build build
    cmake --install build
