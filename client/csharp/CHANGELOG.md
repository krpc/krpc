## [v0.8.0]

- Connections
  - **Breaking:** Connect over one connection, removing the `streamPort` and `streamPath`
    parameters of the `Connection` constructor and `Connection.ConnectLocal`. A server from
    before 0.8 refuses the connection (#1219)
  - **Breaking:** Rename the `rpcPort` and `rpcPath` parameters of the `Connection` constructor
    and `Connection.ConnectLocal` to `port` and `path` (#1219)
  - **Breaking:** Give up after 5 seconds if the server does not accept the connection. Pass
    a `handshakeTimeout` of `Timeout.InfiniteTimeSpan` to wait for the player to approve it
    (#1219)
  - Add `handshakeTimeout` and `stallTimeout` parameters to the `Connection` constructor and
    `Connection.ConnectLocal` (#1219)
  - Send calls from several threads without waiting for each other's responses (#1219)
  - Tell the server when the connection is disposed (#1219)
  - Add `Status` and `Reason` to `ConnectionException` for a refused or ended connection (#1219)
  - **Breaking:** Throw `ConnectionException` when the server cannot be reached, with the
    `SocketException` as its inner exception (#1219)
  - Keep a thread interrupt pending across `Dispose`, which closes the connection in full
    (#1219)

- Streams and events
  - **Breaking:** Throw `StreamRemovedException` when reading or waiting on a removed stream or
    event (#1219)
  - **Breaking:** Wait with no deadline in `Stream.Wait` and `Event.Wait` by default, or for
    an infinite timeout, and throw `ArgumentOutOfRangeException` for a negative or NaN one
    (#1219)
  - Keep a stream running when a value fails to decode, dropping the value (#1219)
  - Stream a lambda or server side function with no value as a `Stream` (#1198)
  - Add an overload of `Connection.GetCall` for a lambda with no value (#1198)
  - **Breaking:** Derive `Stream<T>` from a new class `Stream`, ambiguous with `System.IO.Stream`
    in a file that uses both namespaces (#1198)
  - **Breaking:** Return the stream id from `KRPC.AddStream` and `KRPC.AddFunctionStream` (#1266)
  - **Breaking:** Take the type code of the return value in `IConnection.Invoke` (#1266)
  - Make `Stream` and `Event` `IDisposable`, to remove them at the end of a `using` block (#1291)

- **Breaking:** Regenerate service stubs generated before 0.7.0, which can miss the first update
  of a stream or event they return (#1219)
- Fix the links in service documentation, which named no type or member (#1185)
- Fix a nullable enum return value, which threw `InvalidCastException` (#1194)
- Exceptions
  - **Breaking:** Remove the trailing space after `Server stack trace:` in an exception's
    message, and separate its lines with `\n` on every platform (#1172)

- Add `Bind` to classes with static methods, for calling them without passing the connection
  (#1195)
- **Breaking:** Return `KRPC.GetStatus` as the struct `ServerStatus`, with the settings and
  statistics under `Settings` and `Statistics` (#1244)
- **Breaking:** Leave internal procedures out of the services, such as `KRPC.AddStream` (#1269)
- Add `Connection.Compile` for a server side function built with the expression API (#1269)
- Add `EncodingException`, thrown when the server returns null for a value that cannot be null
  (#1269)
- Target .NET Standard 2.0 in place of .NET Framework 4.7.2, so a .NET 5 or later project uses the
  package without a compatibility warning (#1274)
- Fix .NET Framework programs failing to load `System.Memory` when decoding a nullable value in a
  collection or structure (#1274)
- Generate a flags enumeration with `[Flags]` (#1311)
- Compile `~` and `HasFlag` on flags enumeration values in server side functions (#1313)
- Mark a deprecated service's extension method and `Service` class with `[Obsolete]` (#1322)
- Deprecate each member of a deprecated service, class, enumeration or structure (#1322)
- **Breaking:** Move `Encoder.Decode` to `Decoder.Decode`. Stubs generated by an earlier
  `krpc-clientgen` need regenerating (#1332)
- Throw `ConnectionException` when the connection request fails to be written (#1332)

- Errors
  - **Breaking:** Derive every exception of the client from the new `RemoteException` (#1333)
  - **Breaking:** Rename `RPCException` to `ServerException`, and `FunctionCompilationException`
    to `CompilationException` (#1333)
  - **Breaking:** Remove the generated classes of mapped exceptions, which were never thrown, such
    as `KRPC.ArgumentException`, and of `KRPC.StreamRemovedException`. The .NET exception is
    thrown, as before (#1333)
  - **Breaking:** Throw the new `StreamException` when a stream or event is removed (#1333)
  - **Breaking:** Throw `ConnectionException` for a call after the connection is disposed (#1333)
  - **Breaking:** Throw `ArgumentException` for a function whose value does not match the type
    parameter (#1333)
  - **Breaking:** Throw `EncodingException` for every value that fails to decode, and for a null
    stream value of a type that cannot hold one (#1333)

- Add `Connection.GetCallTemplate` and `Connection.GetSetCallTemplate`, which build a call with
  no instance or arguments, for `Expression.CallWithArguments` (#1352)
- Order remote objects by id, with `CompareTo` and the comparison operators (#1377)
- Throw `EncodingException` for an enumeration result the enumeration does not declare (#1377)
- Throw `ArgumentNullException` for a null passed for a parameter that cannot be null, before the
  call is sent (#1377)

## [v0.7.0]

- Streams and events
  - **Breaking:** Start a stream when it is added, removing `Stream.Start` and `Event.Start`
    (#1122)
  - **Breaking:** Return `true` from `Stream.Wait` and `Event.Wait` on an update, and `false` on
    a timeout (#1122)
  - **Breaking:** Add an `IConnection.Invoke` overload taking the return type, which a class
    implementing `IConnection` must provide (#1122)
  - Wait for a stream's first value in `Stream.Get` (#1122)
  - End a stream on an error from the server, and every stream with `ConnectionException` when
    the connection closes or fails (#1122)
  - Throw `InvalidOperationException` when reading or waiting on a removed stream or event, and
    from `AddStream` on a connection with no stream server (#1122)
  - Add `AddEndCallback` to streams and events, called with the exception that ends the stream
    (#1122)
  - Call a callback added to a stream or event straight away for a value or firing already
    received (#1122)
  - Fix `Event.Wait` missing an earlier firing, and waking only one of two waiting threads
    (#1122)
  - Fix the stream update thread ending the process on a value it cannot decode or a message it
    cannot parse (#1122)
  - Fix a second removal of a stream removing a newer stream for the same call, and stream
    callbacks throwing `InvalidCastException` on an error from the server (#1122)

- Server side functions
  - Add `Connection.Compile`, which compiles a lambda into a server side function (#1128)
  - Compile operators, conditionals, casts, `System.Math`, string operations, collection, tuple
    and structure constructors, `Console.WriteLine` and the common LINQ operators (#1128)
  - Throw `FunctionCompilationException` naming a construct a lambda cannot contain, including
    a call that depends on the current culture (#1128)
  - Add `Connection.Run` and `Connection.AddEvent`, and a `Connection.AddStream<T>` overload
    taking a server side function (#1128)
  - **Breaking:** Compile a lambda given to `AddStream`, so the remote calls in its arguments
    are evaluated on every update (#1128)
  - **Breaking:** Replace `RemoteObject.id` with `RemoteObject.GetObjectId`, which returns the
    id of a remote object for `Expression.ConstantObject` (#1160)

- Types and errors
  - **Breaking:** Throw the matching .NET exception, such as `NullReferenceException`,
    `KeyNotFoundException` or `TimeoutException`, for an error reported by any service, in place
    of `RPCException` (#1124)
  - **Breaking:** Support `null` for any nullable type, including a structure field, list
    element, tuple item and dictionary value. Value types use the nullable form (`int?`)
    (#1017, #1091)
  - Throw `InvalidOperationException` from `Stream.Get` for a null value the stream's type
    cannot hold (#1128)
  - Support structure types, generated as a `struct` with a constructor, equality and ordering
    over its fields (#1066)
  - Fix an `ArgumentException` from the server carrying its message as the parameter name
    (#1111)

- Connections
  - **Breaking:** Send protocol version 1 when connecting, and fail to connect to a server from
    before 0.7 (#1162)
  - Add `Connection.ConnectLocal`, which connects to a server on the same machine over a unix
    domain socket (#1065)
  - Add a `timeout` parameter to the `Connection` constructor, bounding how long a connection is
    waited for (#1065)
  - Reduce the cost of a remote procedure call, most for one that returns a collection or an
    object (#1056)
  - Update to Google.Protobuf 3.36.2 (#1139)
