RoverAutopilot
==============


.. _http-MechJeb.RoverAutopilot:

.. rubric:: RoverAutopilot

The Rover Autopilot window, which drives a rover at a heading and speed, or along its
waypoints.

A ``RoverAutopilot`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

RoverWaypoint
-------------


.. _http-MechJeb.RoverWaypoint:

.. rubric:: RoverWaypoint

A waypoint of the :ref:`RoverAutopilot <http-MechJeb.RoverAutopilot>`, as the Waypoints window shows it.

.. note::

   The object is destroyed once the waypoints are cleared or replaced, as by
   :http:post:`/mech-jeb/rover-autopilot/(id)/clear-waypoints` and :http:post:`/mech-jeb/rover-autopilot/(id)/drive-to-target`.


A ``RoverWaypoint`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/rover-waypoint/(id)/latitude

   The latitude of the waypoint, in degrees. Throws an exception when set if the waypoint
   is at a vessel.


   :param id: The identifier of the :ref:`RoverWaypoint <http-MechJeb.RoverWaypoint>` object.

   :resjson double value:

.. http:put:: /mech-jeb/rover-waypoint/(id)/latitude

   The latitude of the waypoint, in degrees. Throws an exception when set if the waypoint
   is at a vessel.


   :param id: The identifier of the :ref:`RoverWaypoint <http-MechJeb.RoverWaypoint>` object.

   :reqjson double value: The new value.




.. http:get:: /mech-jeb/rover-waypoint/(id)/longitude
