AircraftApproach
================


.. _http-MechJeb.AircraftApproach:

.. rubric:: AircraftApproach

The Aircraft Approach and Autoland window, which lands a plane on a runway.

A ``AircraftApproach`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/aircraft-approach/(id)/runways

   The names of the runways on the body the vessel is at.


   :param id: The identifier of the :ref:`AircraftApproach <http-MechJeb.AircraftApproach>` object.

   :resjson list<string> value:




.. http:get:: /mech-jeb/aircraft-approach/(id)/runway

   The name of the runway to land on. Throws an exception if there is no runway on the
   body the vessel is at, or when set to the name of no such runway.


   :param id: The identifier of the :ref:`AircraftApproach <http-MechJeb.AircraftApproach>` object.

   :resjson string value:
