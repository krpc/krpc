Utilities
=========


.. _http-MechJeb.Utilities:

.. rubric:: Utilities

The Utilities window, which holds the autostaging and throttle settings, and deploys
the solar panels and antennas.

A ``Utilities`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/utilities/(id)/antennas

   The deployable antennas.


   :param id: The identifier of the :ref:`Utilities <http-MechJeb.Utilities>` object.

   :resjson MechJeb.DeployableController value:




.. http:get:: /mech-jeb/utilities/(id)/solar-panels

   The solar panels.


   :param id: The identifier of the :ref:`Utilities <http-MechJeb.Utilities>` object.

   :resjson MechJeb.DeployableController value:




.. http:get:: /mech-jeb/utilities/(id)/staging

   The autostaging settings. The same object as :http:get:`/mech-jeb/ascent-settings/(id)/staging`.


   :param id: The identifier of the :ref:`Utilities <http-MechJeb.Utilities>` object.

   :resjson MechJeb.Autostaging value:




.. http:get:: /mech-jeb/utilities/(id)/thrust

   The throttle limiters. The same object as :http:get:`/mech-jeb/ascent-settings/(id)/thrust`.


   :param id: The identifier of the :ref:`Utilities <http-MechJeb.Utilities>` object.

   :resjson MechJeb.ThrustLimiter value:

.. _http-MechJeb.DifferentialThrottleStatus:

.. rubric:: DifferentialThrottleStatus

The result of the differential throttle. See
:http:get:`/mech-jeb/thrust-limiter/(id)/differential-throttle-status`.

Passed and returned as the name of one of its values:


``"success"``
   The throttles balance the thrust.


``"all_engines_off"``
   All the engines are off.


``"more_engines_required"``
   The vessel needs more engines.


``"solver_failed"``
   The solver found no solution.
