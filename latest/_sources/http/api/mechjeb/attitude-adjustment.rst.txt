AttitudeAdjustment
==================


.. _http-MechJeb.AttitudeAdjustment:

.. rubric:: AttitudeAdjustment

The Attitude Adjustment window, which selects the attitude controller that the
autopilots steer with.

A ``AttitudeAdjustment`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/attitude-adjustment/(id)/rcs-auto

   Whether the attitude controller turns RCS on for a large attitude error, and off once
   the vessel settles.


   :param id: The identifier of the :ref:`AttitudeAdjustment <http-MechJeb.AttitudeAdjustment>` object.

   :resjson bool value:

.. http:put:: /mech-jeb/attitude-adjustment/(id)/rcs-auto

   Whether the attitude controller turns RCS on for a large attitude error, and off once
   the vessel settles.


   :param id: The identifier of the :ref:`AttitudeAdjustment <http-MechJeb.AttitudeAdjustment>` object.

   :reqjson bool value: The new value.




.. http:get:: /mech-jeb/attitude-adjustment/(id)/controller

   The attitude controller.


   :param id: The identifier of the :ref:`AttitudeAdjustment <http-MechJeb.AttitudeAdjustment>` object.

   :resjson MechJeb.AttitudeController value:

.. http:put:: /mech-jeb/attitude-adjustment/(id)/controller

   The attitude controller.


   :param id: The identifier of the :ref:`AttitudeAdjustment <http-MechJeb.AttitudeAdjustment>` object.

   :reqjson MechJeb.AttitudeController value: The new value.





.. _http-MechJeb.AttitudeController:

.. rubric:: AttitudeController

An attitude controller of MechJeb. See :http:get:`/mech-jeb/attitude-adjustment/(id)/controller`.

Passed and returned as the name of one of its values:


``"mj"``
   MechJeb's original attitude controller.


``"kos"``
   The attitude controller of kOS.


``"hybrid"``
   A hybrid of the MechJeb and kOS controllers.


``"better"``
   MechJeb's default controller.


``"lqr"``
   A linear-quadratic regulator.
