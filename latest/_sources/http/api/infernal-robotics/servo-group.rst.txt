ServoGroup
==========


.. _http-InfernalRobotics.ServoGroup:

.. rubric:: ServoGroup

A group of servos, obtained by calling :http:post:`/infernal-robotics/servo-groups`
or :http:post:`/infernal-robotics/servo-group-with-name`. Represents the "Servo Groups"
in the InfernalRobotics UI.

A ``ServoGroup`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /infernal-robotics/servo-group/(id)/name

   The name of the group.

   .. note::

      Renaming a group renames it for every servo in it. This object identifies the
      group by its name, so a rename destroys every object for the group, including the
      one the rename was made through. Obtain the group again under the new name.


   :param id: The identifier of the :ref:`ServoGroup <http-InfernalRobotics.ServoGroup>` object.

   :resjson string value:
