Node
====


.. _http-SpaceCenter.Node:

.. rubric:: Node

Represents a maneuver node. Can be created using :http:post:`/space-center/control/(id)/add-node`.

A ``Node`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/node/(id)/prograde

   The magnitude of the maneuver nodes delta-v in the prograde direction,
   in :math:`\mathrm{m/s}`.


   :param id: The identifier of the :ref:`Node <http-SpaceCenter.Node>` object.

   :resjson double value:

.. http:get:: /space-center/node/(id)/remaining-delta-v

   Gets the remaining delta-v of the maneuver node, in :math:`\mathrm{m/s}`. Changes as the

   :param id: The identifier of the :ref:`Node <http-SpaceCenter.Node>` object.

   :resjson double value:




.. http:post:: /space-center/node/(id)/burn-vector

   Returns the burn vector for the maneuver node.

   .. note::

      Does not change when executing the maneuver node. See :http:post:`/space-center/node/(id)/remaining-burn-vector`.


   :param id: The identifier of the :ref:`Node <http-SpaceCenter.Node>` object.

   :reqjson SpaceCenter.ReferenceFrame? reference_frame: The reference frame that the returned vector is in. Defaults to :http:get:`/space-center/vessel/(id)/orbital-reference-frame`. Optional, defaults to ``null``.
   :resjson tuple<double, double, double> value: A vector whose direction is the direction of the maneuver node burn, and magnitude is the delta-v of the burn in :math:`\mathrm{m/s}`.





.. http:post:: /space-center/node/(id)/remaining-burn-vector

   :reqjson SpaceCenter.ReferenceFrame? reference_frame: The reference frame that the returned vector is in. Defaults to :http:get:`/space-center/vessel/(id)/orbital-reference-frame`. Optional, defaults to ``null``.
   :resjson tuple<double, double, double> value: A vector whose direction is the direction of the maneuver node burn, and magnitude is the delta-v of the burn in :math:`\mathrm{m/s}`.

.. http:get:: /space-center/node/(id)/reference-frame

   The reference frame that is fixed relative to the maneuver node's burn.

   * The origin is at the position of the maneuver node.
   * The y-axis points in the direction of the burn.
   * The x-axis and z-axis point in arbitrary but fixed directions.


   :param id: The identifier of the :ref:`Node <http-SpaceCenter.Node>` object.

   :resjson SpaceCenter.ReferenceFrame value:




.. http:get:: /space-center/node/(id)/orbital-reference-frame

   The reference frame that is fixed relative to the maneuver node, and
   orientated with the orbital prograde/normal/radial directions of the
   original orbit at the maneuver node's position.

   * The origin is at the position of the maneuver node.
   * The x-axis points in the orbital anti-radial direction of the original
     orbit, at the position of the maneuver node.
   * The y-axis points in the orbital prograde direction of the original
     orbit, at the position of the maneuver node.
   * The z-axis points in the orbital normal direction of the original orbit,
     at the position of the maneuver node.


   :param id: The identifier of the :ref:`Node <http-SpaceCenter.Node>` object.

   :resjson SpaceCenter.ReferenceFrame value:
