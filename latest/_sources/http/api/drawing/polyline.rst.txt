Polyline
========


.. _http-Drawing.Polyline:

.. rubric:: Polyline

A line through a list of vertices, open at its ends. Created using
:http:post:`/drawing/add-polyline`.

A ``Polyline`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.
