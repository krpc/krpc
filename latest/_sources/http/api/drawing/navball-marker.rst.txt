NavballMarker
=============


.. _http-Drawing.NavballMarker:

.. rubric:: NavballMarker

A marker drawn on the navball. Created using :http:post:`/drawing/add-navball-marker`.

A ``NavballMarker`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /drawing/navball-marker/(id)/direction

   Direction that the marker is drawn at.


   :param id: The identifier of the :ref:`NavballMarker <http-Drawing.NavballMarker>` object.

   :resjson tuple<double, double, double> value:

   :reqjson tuple<double, double, double> value: The new value.

   Whether the marker is visible.
