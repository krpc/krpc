MapMarker
=========


.. _http-Drawing.MapMarker:

.. rubric:: MapMarker

A marker drawn in the map view, with one of the game's own map icons. Created using
:http:post:`/drawing/add-map-marker`.

A ``MapMarker`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

.. _http-Drawing.MapMarkerIcon:

.. rubric:: MapMarkerIcon

The icon a :ref:`MapMarker <http-Drawing.MapMarker>` is drawn with, from the game's own map icons.

Passed and returned as the name of one of its values:


``"generic"``
   A plain marker.


``"celestial_body"``
   A celestial body.


``"apoapsis"``
   An apoapsis.


``"periapsis"``
   A periapsis.


``"ascending_node"``
   An ascending node.


``"descending_node"``
   A descending node.


``"maneuver_node"``
   A maneuver node.


``"encounter"``
   An encounter with a sphere of influence.


``"escape"``
   An escape from a sphere of influence.


``"impact"``
   An impact with the surface.


``"close_approach"``
   A closest approach to a target.


``"intersect"``
   An intersection with the orbit of a target.


``"ship"``
   A ship.


``"probe"``
   A probe.


``"relay"``
   A relay.


``"station"``
   A station.


``"base"``
   A base.


``"lander"``
   A lander.


``"rover"``
   A rover.


``"plane"``
   A plane.


``"eva"``
   A kerbal on EVA.


``"flag"``
   A flag.


``"debris"``
   Debris.


``"space_object"``
   An asteroid or comet.


``"deployed_science"``
   Deployed science equipment.


``"launch_site"``
   A launch site.


``"runway"``
   A runway.


``"ksc"``
   The Kerbal Space Center.
