Service
=======


.. class:: MechJeb

   This service provides functionality to interact with MechJeb 2.

   .. note::

      The objects act on the MechJeb of the active vessel, and stay valid after the active
      vessel changes.

   .. property:: bool Available { get; }

      Whether MechJeb is installed.

      :Game Scenes: All

   .. property:: bool Ready { get; }

      Whether the active vessel has MechJeb.

      :Game Scenes: Flight

   .. property:: AircraftApproach AircraftApproach { get; }

      The Aircraft Approach and Autoland window.

      :Game Scenes: Flight

   .. property:: AircraftAutopilot AircraftAutopilot { get; }

      The Aircraft Autopilot window.

      :Game Scenes: Flight

   .. property:: AscentGuidance AscentGuidance { get; }

      The Ascent Guidance window.

      :Game Scenes: Flight

   .. property:: AttitudeAdjustment AttitudeAdjustment { get; }

      The Attitude Adjustment window.

      :Game Scenes: Flight

   .. property:: DockingAutopilot DockingAutopilot { get; }

      The Docking Autopilot window.

      :Game Scenes: Flight

   .. property:: LandingGuidance LandingGuidance { get; }

      The Landing Guidance window.

      :Game Scenes: Flight

   .. property:: ManeuverPlanner ManeuverPlanner { get; }

      The Maneuver Planner window.

      :Game Scenes: Flight

   .. property:: RendezvousAutopilot RendezvousAutopilot { get; }

      The Rendezvous Autopilot window.

      :Game Scenes: Flight

   .. property:: RoverAutopilot RoverAutopilot { get; }

      The Rover Autopilot window.

      :Game Scenes: Flight

   .. property:: SmartASS SmartASS { get; }

      The Smart A.S.S. window.

      :Game Scenes: Flight

   .. property:: SmartRCS SmartRCS { get; }

      The Smart RCS window.

      :Game Scenes: Flight

   .. property:: TargetController TargetController { get; }

      The target controller, which holds MechJeb's target.

      :Game Scenes: Flight

   .. property:: Translatron Translatron { get; }

      The Translatron window.

      :Game Scenes: Flight

   .. property:: Utilities Utilities { get; }

      The Utilities window.

      :Game Scenes: Flight

   A general error in the service.
