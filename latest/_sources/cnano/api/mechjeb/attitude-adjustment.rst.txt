AttitudeAdjustment
==================


.. type:: krpc_MechJeb_AttitudeAdjustment_t

   The Attitude Adjustment window, which selects the attitude controller that the
   autopilots steer with.

   .. macro:: KRPC_CLASS_MECHJEB_ATTITUDEADJUSTMENT

      The service and class ids of the class, for :func:`krpc_KRPC_Type_ClassTypeById`.

      the vessel settles.
