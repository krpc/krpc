AscentGuidance
==============


.. class:: AscentGuidance

   The Ascent Guidance window, which flies the vessel to orbit.

   .. note::

      See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
      for how to set up this autopilot.

   .. function:: bool enabled()
   .. function:: void set_enabled(bool value)

      Whether the module is enabled.

      :Game Scenes: Flight

   .. function:: std::string status()

      The autopilot status, which depends on the selected ascent path.

      :Game Scenes: Flight

   .. function:: AscentType ascent_type()
   .. function:: void set_ascent_type(AscentType value)

      The ascent path.

      :Game Scenes: Flight

   .. function:: AscentSettings settings()

      The Ascent Settings window.

      :Game Scenes: Flight

   .. function:: PVGSettings pvg_settings()

      The PVG Settings window, with the settings of the :enumerator:`AscentType::pvg` path.

      :Game Scenes: Flight

   .. function:: ClassicPath classic_path()

      The Ascent Path Editor window, with the settings of the
      :enumerator:`AscentType::classic` path.

      :Game Scenes: Flight

   .. function:: double desired_orbit_altitude()
   .. function:: void set_desired_orbit_altitude(double value)

      The altitude of the final circular orbit, in meters.

      :Game Scenes: Flight

   .. function:: double desired_apoapsis()
   .. function:: void set_desired_apoapsis(double value)

      The target apoapsis, in meters.

      :Game Scenes: Flight


      .. note::

         Applies on the :enumerator:`AscentType::pvg` path.

   .. function:: bool attach_alt_flag()
   .. function:: void set_attach_alt_flag(bool value)

      Whether the orbit is attached at :func:`AscentGuidance::desired_attach_alt`.

      :Game Scenes: Flight


      .. note::

         Applies on the :enumerator:`AscentType::pvg` path, with an early shutoff stage, set by
         :func:`PVGSettings::optimize_stage_flag` and :func:`PVGSettings::optimize_stage`.
         Without one, MechJeb always attaches the orbit.

   .. function:: double desired_attach_alt()
   .. function:: void set_desired_attach_alt(double value)

      The altitude at which the orbit is attached, in meters.

      :Game Scenes: Flight


      .. note::

         Applies on the :enumerator:`AscentType::pvg` path. Requires :func:`AscentGuidance::attach_alt_flag`,
         unless there is no early shutoff stage. See :func:`PVGSettings::optimize_stage`.

   .. function:: double desired_fpa()
   .. function:: void set_desired_fpa(double value)

      The flight path angle at orbit insertion, in degrees.

      :Game Scenes: Flight


      .. note::

         Applies on the :enumerator:`AscentType::pvg` path, when there is no early shutoff
         stage. See :func:`PVGSettings::optimize_stage`.

   .. function:: double desired_inclination()
   .. function:: void set_desired_inclination(double value)

      The inclination of the final circular orbit, in degrees.

      :Game Scenes: Flight

   .. function:: AscentLaunchMode launch_mode()

      The launch mode, which gives whether the autopilot is waiting for a timed launch.

      :Game Scenes: Flight

   .. function:: void launch_to_rendezvous()

      Launch to rendezvous with the target. Throws an exception if there is no target, or
      the ascent path is PVG.


      :Game Scenes: Flight

   .. function:: double launch_phase_angle()
   .. function:: void set_launch_phase_angle(double value)

      The phase angle to the target of a launch to rendezvous, in degrees.

      :Game Scenes: Flight

   .. function:: void launch_to_target_plane()

      Launch into the plane of the target. Throws an exception if there is no target.


      :Game Scenes: Flight

   .. function:: double launch_lan_difference()
   .. function:: void set_launch_lan_difference(double value)

      The difference from the target's longitude of the ascending node of a launch into the
      target's plane, in degrees.

      :Game Scenes: Flight

   .. function:: void launch_to_match_lan()

      Launch into the plane of the target, at the time the target's longitude of the
      ascending node, less :func:`AscentGuidance::launch_lan_difference`, passes overhead. Keeps
      :func:`AscentGuidance::desired_inclination`. Throws an exception if there is no target, or the
      ascent path is not :enumerator:`AscentType::pvg`.


      :Game Scenes: Flight

   .. function:: void launch_to_lan()

      Launch into the plane with longitude of the ascending node :func:`AscentGuidance::desired_lan`
      and inclination :func:`AscentGuidance::desired_inclination`. Throws an exception if the ascent
      path is not :enumerator:`AscentType::pvg`.


      :Game Scenes: Flight

   .. function:: double desired_lan()
   .. function:: void set_desired_lan(double value)

      The longitude of the ascending node of a launch to a LAN, in degrees.
      See :func:`AscentGuidance::launch_to_lan`.

      :Game Scenes: Flight

   .. function:: void abort_timed_launch()

      Abort a timed launch that has not started yet. Throws an exception if the launch mode
      is :enumerator:`AscentLaunchMode::unknown`.


      :Game Scenes: Flight

   .. function:: int32_t warp_count_down()
   .. function:: void set_warp_count_down(int32_t value)

      The time before a timed launch at which time warp stops, in seconds.

      :Game Scenes: Flight

   .. function:: bool override_warp_to_plane()
   .. function:: void set_override_warp_to_plane(bool value)

      Whether a timed launch launches at once, rather than at the time it computes.

      :Game Scenes: Flight



.. namespace:: krpc::services::MechJeb
.. enum-struct:: AscentType

   The ascent path. See :func:`AscentGuidance::ascent_type`.


   .. enumerator:: classic

      The classic ascent path. See :func:`AscentGuidance::classic_path`.


   .. enumerator:: pvg

      Primer Vector Guidance, for RSS/RO. See :func:`AscentGuidance::pvg_settings`.



.. namespace:: krpc::services::MechJeb
.. enum-struct:: AscentLaunchMode

   The launch mode of the ascent autopilot. See :func:`AscentGuidance::launch_mode`.


   .. enumerator:: normal

      The autopilot is not performing a timed launch.


   .. enumerator:: rendezvous

      A timed launch to rendezvous with the target vessel.


   .. enumerator:: target_plane

      A timed launch into the plane of the target.


   .. enumerator:: match_lan

      A timed launch to the target's longitude of the ascending node. See
      :func:`AscentGuidance::launch_to_match_lan`.


   .. enumerator:: lan

      A timed launch to a longitude of the ascending node. See
      :func:`AscentGuidance::launch_to_lan`.


   .. enumerator:: unknown

      A timed launch of another kind, started from MechJeb's window.
