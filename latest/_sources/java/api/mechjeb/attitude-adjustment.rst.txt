AttitudeAdjustment
==================


.. type:: public class AttitudeAdjustment

   The Attitude Adjustment window, which selects the attitude controller that the
   autopilots steer with.

   .. method:: boolean getRCSAuto()

   .. method:: void setRCSAuto(boolean value)

      Whether the attitude controller turns RCS on for a large attitude error, and off once
      the vessel settles.

      :Game Scenes: Flight

   .. method:: AttitudeController getController()

   .. method:: void setController(AttitudeController value)

      The attitude controller.

      :Game Scenes: Flight



.. type:: public enum AttitudeController

   An attitude controller of MechJeb. See :meth:`AttitudeAdjustment.getController()`.


   .. field:: public AttitudeController MJ

      MechJeb's original attitude controller.


   .. field:: public AttitudeController KOS

      The attitude controller of kOS.


   .. field:: public AttitudeController HYBRID

      A hybrid of the MechJeb and kOS controllers.


   .. field:: public AttitudeController BETTER

      MechJeb's default controller.


   .. field:: public AttitudeController LQR

      A linear-quadratic regulator.
