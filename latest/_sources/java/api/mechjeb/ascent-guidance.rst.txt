AscentGuidance
==============


.. type:: public class AscentGuidance

   The Ascent Guidance window, which flies the vessel to orbit.

   .. note::

      See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
      for how to set up this autopilot.

   .. method:: boolean getEnabled()

   .. method:: void setEnabled(boolean value)

      Whether the module is enabled.

      :Game Scenes: Flight

   .. method:: String getStatus()


      The autopilot status, which depends on the selected ascent path.

      :Game Scenes: Flight

   .. method:: AscentType getAscentType()

   .. method:: void setAscentType(AscentType value)

      The ascent path.

      :Game Scenes: Flight

   .. method:: AscentSettings getSettings()


      The Ascent Settings window.

      :Game Scenes: Flight

   .. method:: PVGSettings getPVGSettings()


      The PVG Settings window, with the settings of the :field:`AscentType.PVG` path.

      :Game Scenes: Flight

   .. method:: ClassicPath getClassicPath()


      The Ascent Path Editor window, with the settings of the
      :field:`AscentType.CLASSIC` path.

      :Game Scenes: Flight

   .. method:: double getDesiredOrbitAltitude()

   .. method:: void setDesiredOrbitAltitude(double value)

      The altitude of the final circular orbit, in meters.

      :Game Scenes: Flight

   .. method:: double getDesiredApoapsis()

   .. method:: void setDesiredApoapsis(double value)

      The target apoapsis, in meters.

      :Game Scenes: Flight


      .. note::

         Applies on the :field:`AscentType.PVG` path.

   .. method:: boolean getAttachAltFlag()

   .. method:: void setAttachAltFlag(boolean value)

      Whether the orbit is attached at :meth:`AscentGuidance.getDesiredAttachAlt()`.

      :Game Scenes: Flight


      .. note::

         Applies on the :field:`AscentType.PVG` path, with an early shutoff stage, set by
         :meth:`PVGSettings.getOptimizeStageFlag()` and :meth:`PVGSettings.getOptimizeStage()`.
         Without one, MechJeb always attaches the orbit.

   .. method:: double getDesiredAttachAlt()

   .. method:: void setDesiredAttachAlt(double value)

      The altitude at which the orbit is attached, in meters.

      :Game Scenes: Flight


      .. note::

         Applies on the :field:`AscentType.PVG` path. Requires :meth:`AscentGuidance.getAttachAltFlag()`,
         unless there is no early shutoff stage. See :meth:`PVGSettings.getOptimizeStage()`.

   .. method:: double getDesiredFPA()

   .. method:: void setDesiredFPA(double value)

      The flight path angle at orbit insertion, in degrees.

      :Game Scenes: Flight


      .. note::

         Applies on the :field:`AscentType.PVG` path, when there is no early shutoff
         stage. See :meth:`PVGSettings.getOptimizeStage()`.

   .. method:: double getDesiredInclination()

   .. method:: void setDesiredInclination(double value)

      The inclination of the final circular orbit, in degrees.

      :Game Scenes: Flight

   .. method:: AscentLaunchMode getLaunchMode()


      The launch mode, which gives whether the autopilot is waiting for a timed launch.

      :Game Scenes: Flight

   .. method:: void launchToRendezvous()

      Launch to rendezvous with the target. Throws an exception if there is no target, or
      the ascent path is PVG.

      :Game Scenes: Flight

   .. method:: double getLaunchPhaseAngle()

   .. method:: void setLaunchPhaseAngle(double value)

      The phase angle to the target of a launch to rendezvous, in degrees.

      :Game Scenes: Flight

   .. method:: void launchToTargetPlane()

      Launch into the plane of the target. Throws an exception if there is no target.

      :Game Scenes: Flight

   .. method:: double getLaunchLANDifference()

   .. method:: void setLaunchLANDifference(double value)

      The difference from the target's longitude of the ascending node of a launch into the
      target's plane, in degrees.

      :Game Scenes: Flight

   .. method:: void launchToMatchLan()

      Launch into the plane of the target, at the time the target's longitude of the
      ascending node, less :meth:`AscentGuidance.getLaunchLANDifference()`, passes overhead. Keeps
      :meth:`AscentGuidance.getDesiredInclination()`. Throws an exception if there is no target, or the
      ascent path is not :field:`AscentType.PVG`.

      :Game Scenes: Flight

   .. method:: void launchToLan()

      Launch into the plane with longitude of the ascending node :meth:`AscentGuidance.getDesiredLan()`
      and inclination :meth:`AscentGuidance.getDesiredInclination()`. Throws an exception if the ascent
      path is not :field:`AscentType.PVG`.

      :Game Scenes: Flight

   .. method:: double getDesiredLan()

   .. method:: void setDesiredLan(double value)

      The longitude of the ascending node of a launch to a LAN, in degrees.
      See :meth:`AscentGuidance.launchToLan()`.

      :Game Scenes: Flight

   .. method:: void abortTimedLaunch()

      Abort a timed launch that has not started yet. Throws an exception if the launch mode
      is :field:`AscentLaunchMode.UNKNOWN`.

      :Game Scenes: Flight

   .. method:: int getWarpCountDown()

   .. method:: void setWarpCountDown(int value)

      The time before a timed launch at which time warp stops, in seconds.

      :Game Scenes: Flight

   .. method:: boolean getOverrideWarpToPlane()

   .. method:: void setOverrideWarpToPlane(boolean value)

      Whether a timed launch launches at once, rather than at the time it computes.

      :Game Scenes: Flight



.. type:: public enum AscentType

   The ascent path. See :meth:`AscentGuidance.getAscentType()`.


   .. field:: public AscentType CLASSIC

      The classic ascent path. See :meth:`AscentGuidance.getClassicPath()`.


   .. field:: public AscentType PVG

      Primer Vector Guidance, for RSS/RO. See :meth:`AscentGuidance.getPVGSettings()`.



.. type:: public enum AscentLaunchMode

   The launch mode of the ascent autopilot. See :meth:`AscentGuidance.getLaunchMode()`.


   .. field:: public AscentLaunchMode NORMAL

      The autopilot is not performing a timed launch.


   .. field:: public AscentLaunchMode RENDEZVOUS

      A timed launch to rendezvous with the target vessel.


   .. field:: public AscentLaunchMode TARGET_PLANE

      A timed launch into the plane of the target.


   .. field:: public AscentLaunchMode MATCH_LAN

      A timed launch to the target's longitude of the ascending node. See
      :meth:`AscentGuidance.launchToMatchLan()`.


   .. field:: public AscentLaunchMode LAN

      A timed launch to a longitude of the ascending node. See
      :meth:`AscentGuidance.launchToLan()`.


   .. field:: public AscentLaunchMode UNKNOWN

      A timed launch of another kind, started from MechJeb's window.

   .. method:: void setTurnRoll(double value)

   .. method:: void setRollAltitude(double value)

   .. method:: void setLimitAngleOfAttack(boolean value)

         Applies on the :field:`AscentType.CLASSIC` path.

      The largest angle of attack, in degrees.

      :Game Scenes: Flight

         path.

      Whether the angle of attack limit is limiting the steering.

      The largest angle of attack the limit allows now, in degrees.

   .. method:: void setCorrectiveSteering(boolean value)

      Whether the autopilot steers by the velocity vector rather than the position vector.

      The gain of the corrective steering.
