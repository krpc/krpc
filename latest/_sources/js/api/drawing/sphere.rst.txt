Sphere
======


.. class:: Sphere

   A solid sphere. Created using :func:`Drawing.addSphere`.

   .. note::

      The sphere is drawn with an additive material, so a darker color draws it more
      transparent.

   .. method:: getCenter()
               setCenter(value)

      :Property: Can be read or written
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getRadius()
               setRadius(value)

      :rtype: ``number``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getReferenceFrame()
