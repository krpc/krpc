AscentGuidance#

AscentGuidance

The Ascent Guidance window, which flies the vessel to orbit.

Note

See the MechJeb wiki for how to set up this autopilot.

A AscentGuidance object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /mech-jeb/ascent-guidance/(id)/enabled#

Whether the module is enabled.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (bool)

PUT /mech-jeb/ascent-guidance/(id)/enabled#

Whether the module is enabled.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (bool) – The new value.

GET /mech-jeb/ascent-guidance/(id)/status#

The autopilot status, which depends on the selected ascent path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (string)

GET /mech-jeb/ascent-guidance/(id)/ascent-type#

The ascent path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (MechJeb.AscentType)

PUT /mech-jeb/ascent-guidance/(id)/ascent-type#

The ascent path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (MechJeb.AscentType) – The new value.

GET /mech-jeb/ascent-guidance/(id)/settings#

The Ascent Settings window.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (MechJeb.AscentSettings)

GET /mech-jeb/ascent-guidance/(id)/pvg-settings#

The PVG Settings window, with the settings of the "pvg" path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (MechJeb.PVGSettings)

GET /mech-jeb/ascent-guidance/(id)/classic-path#

The Ascent Path Editor window, with the settings of the "classic" path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (MechJeb.ClassicPath)

GET /mech-jeb/ascent-guidance/(id)/desired-orbit-altitude#

The altitude of the final circular orbit, in meters.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/ascent-guidance/(id)/desired-orbit-altitude#

The altitude of the final circular orbit, in meters.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (double) – The new value.

GET /mech-jeb/ascent-guidance/(id)/desired-apoapsis#

The target apoapsis, in meters.

Note

Applies on the "pvg" path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/ascent-guidance/(id)/desired-apoapsis#

The target apoapsis, in meters.

Note

Applies on the "pvg" path.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (double) – The new value.

GET /mech-jeb/ascent-guidance/(id)/attach-alt-flag#

Whether the orbit is attached at GET /mech-jeb/ascent-guidance/(id)/desired-attach-alt.

Note

Applies on the "pvg" path, with an early shutoff stage, set by GET /mech-jeb/pvg-settings/(id)/optimize-stage-flag and GET /mech-jeb/pvg-settings/(id)/optimize-stage. Without one, MechJeb always attaches the orbit.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (bool)

PUT /mech-jeb/ascent-guidance/(id)/attach-alt-flag#

Whether the orbit is attached at GET /mech-jeb/ascent-guidance/(id)/desired-attach-alt.

Note

Applies on the "pvg" path, with an early shutoff stage, set by GET /mech-jeb/pvg-settings/(id)/optimize-stage-flag and GET /mech-jeb/pvg-settings/(id)/optimize-stage. Without one, MechJeb always attaches the orbit.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (bool) – The new value.

GET /mech-jeb/ascent-guidance/(id)/desired-attach-alt#

The altitude at which the orbit is attached, in meters.

Note

Applies on the "pvg" path. Requires GET /mech-jeb/ascent-guidance/(id)/attach-alt-flag, unless there is no early shutoff stage. See GET /mech-jeb/pvg-settings/(id)/optimize-stage.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/ascent-guidance/(id)/desired-attach-alt#

The altitude at which the orbit is attached, in meters.

Note

Applies on the "pvg" path. Requires GET /mech-jeb/ascent-guidance/(id)/attach-alt-flag, unless there is no early shutoff stage. See GET /mech-jeb/pvg-settings/(id)/optimize-stage.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (double) – The new value.

GET /mech-jeb/ascent-guidance/(id)/desired-fpa#

The flight path angle at orbit insertion, in degrees.

Note

Applies on the "pvg" path, when there is no early shutoff stage. See GET /mech-jeb/pvg-settings/(id)/optimize-stage.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/ascent-guidance/(id)/desired-fpa#

The flight path angle at orbit insertion, in degrees.

Note

Applies on the "pvg" path, when there is no early shutoff stage. See GET /mech-jeb/pvg-settings/(id)/optimize-stage.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (double) – The new value.

GET /mech-jeb/ascent-guidance/(id)/desired-inclination#

The inclination of the final circular orbit, in degrees.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/ascent-guidance/(id)/desired-inclination#

The inclination of the final circular orbit, in degrees.

Parameters:

  • id – The identifier of the AscentGuidance object.

Request JSON Object:

  • value (double) – The new value.

GET /mech-jeb/ascent-guidance/(id)/launch-mode#

The launch mode, which gives whether the autopilot is waiting for a timed launch.

Parameters:

  • id – The identifier of the AscentGuidance object.

Response JSON Object:

  • value (MechJeb.AscentLaunchMode)

POST /mech-jeb/ascent-guidance/(id)/launch-to-rendezvous#

Launch to rendezvous with the target. Throws an exception if there is no target, or the ascent path is PVG.

Parameters:

  • id – The identifier of the AscentGuidance object.

GET /mech-jeb/ascent-guidance/(id)/launch-phase-angle#

The phase angle to the target of a launch to rendezvous, in degrees.
