LandingGuidance
===============


.. class:: LandingGuidance

   The Landing Guidance window, which lands at a target or wherever the vessel comes down.

   .. attribute:: enabled: boolean

      Whether the module is enabled.

      :Attribute: Can be read or written

   .. attribute:: status: string

      The status of the autopilot.

      :Attribute: Read-only, cannot be set

   .. attribute:: deploy_chutes: boolean

      Whether the autopilot deploys the parachutes.

      :Attribute: Can be read or written

   .. attribute:: deploy_gears: boolean

      Whether the autopilot deploys the landing gear.

      :Attribute: Can be read or written

   .. method:: land_at_target()

      Land at the target. See :meth:`MechJeb.LandingGuidance.set_target`.
      Throws an exception if there is no target, or the vessel is landed or splashed down.

   .. method:: land_somewhere()

      Land wherever the vessel comes down. Throws an exception if the vessel is landed or
      splashed down.

   .. attribute:: limit_chutes_stage: number

      The last stage in which the autopilot deploys the parachutes.

      :Attribute: Can be read or written

   .. attribute:: limit_gears_stage: number

      The last stage in which the autopilot deploys the landing gear.

      :Attribute: Can be read or written

   .. attribute:: rcs_adjustment: boolean

      Whether the autopilot corrects its course with RCS.

      :Attribute: Can be read or written

   .. method:: abort_autoland()

      Stop the landing.

   .. attribute:: touchdown_speed: number

      The speed at touchdown, in :math:`\mathrm{m/s}`.

      :Attribute: Can be read or written

   .. method:: get_target_position(): Tuple

      The world space position of the landing target. Throws an exception if there is no
      landing target.

   .. method:: get_target_string(): string

      The landing target as text.

   .. method:: pick_target_on_map()

      Let the player pick the landing target on the map.

   .. method:: set_target(body: SpaceCenter.CelestialBody, latitude: number, longitude: number)

      Set the landing target to a position on the surface of a body.

      :param body: The body.
      :param latitude: The latitude, in degrees.
      :param longitude: The longitude, in degrees.

   .. attribute:: autowarp: boolean

      Whether to warp time during the landing.

      :Attribute: Can be read or written

      .. note::

         The same setting as :attr:`MechJeb.ManeuverPlanner.autowarp`.
