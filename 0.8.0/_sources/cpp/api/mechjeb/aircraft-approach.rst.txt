AircraftApproach
================


.. class:: AircraftApproach

   The Aircraft Approach and Autoland window, which lands a plane on a runway.

   .. function:: std::vector<std::string> runways()

      The names of the runways on the body the vessel is at.

      :Game Scenes: Flight

   .. function:: std::string runway()
   .. function:: void set_runway(std::string value)

      The name of the runway to land on. Throws an exception if there is no runway on the
      body the vessel is at, or when set to the name of no such runway.

      :Game Scenes: Flight

   .. function:: double distance_to_runway()

      The distance to the start of the runway, in meters.

      :Game Scenes: Flight

   .. function:: void autoland()

      Land on the runway. Throws an exception if there is no runway on the body the vessel
      is at.


      :Game Scenes: Flight

   .. function:: void abort()

      Stop the autoland.


      :Game Scenes: Flight

   .. function:: bool enabled()

      Whether the autoland is running.

      :Game Scenes: Flight

   .. function:: std::string state()

      The stage of the approach, as MechJeb's window describes it.

      :Game Scenes: Flight

   .. function:: double glideslope()
   .. function:: void set_glideslope(double value)

      The glideslope of the approach, in degrees.

      :Game Scenes: Flight

   .. function:: double approach_speed()
   .. function:: void set_approach_speed(double value)

      The speed of the approach, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. function:: double touchdown_speed()
   .. function:: void set_touchdown_speed(double value)

      The speed at touchdown, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. function:: bool engage_reverse_if_available()
   .. function:: void set_engage_reverse_if_available(bool value)

      Whether to reverse the thrust at touchdown, on engines that can.

      :Game Scenes: Flight

   .. function:: bool brake_as_soon_as_landed()
   .. function:: void set_brake_as_soon_as_landed(bool value)

      Whether to brake as soon as the vessel is landed.

      :Game Scenes: Flight
