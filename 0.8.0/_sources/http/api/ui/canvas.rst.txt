Canvas
======


.. _http-UI.Canvas:

.. rubric:: Canvas

A canvas for user interface elements. See :http:get:`/ui/stock-canvas` and :http:post:`/ui/add-canvas`.

A ``Canvas`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /ui/canvas/(id)/rect-transform

   The rect transform for the UI object.


   :param id: The identifier of the :ref:`Canvas <http-UI.Canvas>` object.

   :resjson UI.RectTransform value:




.. http:get:: /ui/canvas/(id)/layout-element

   How much space the UI object asks a layout for.

   .. note::

      Only has an effect when the object is in a panel that has a layout. A canvas is
      not inside a layout and does not have one.


   :param id: The identifier of the :ref:`Canvas <http-UI.Canvas>` object.

   :resjson UI.LayoutElement value:




.. http:get:: /ui/canvas/(id)/visible

   Whether the UI object is visible.

   .. note::

      This is the object's own setting, which is what it was last set to. An object is
      only drawn when everything it is inside is visible as well, so an interface can
      be built with its parts visible, inside a panel that is not, and shown all at
      once by making that panel visible.


   :param id: The identifier of the :ref:`Canvas <http-UI.Canvas>` object.

   :resjson bool value:

.. http:put:: /ui/canvas/(id)/visible

   Whether the UI object is visible.

   .. note::

      This is the object's own setting, which is what it was last set to. An object is
      only drawn when everything it is inside is visible as well, so an interface can
      be built with its parts visible, inside a panel that is not, and shown all at
      once by making that panel visible.


   :param id: The identifier of the :ref:`Canvas <http-UI.Canvas>` object.

   :reqjson bool value: The new value.
