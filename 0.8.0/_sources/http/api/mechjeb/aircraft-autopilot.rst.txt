AircraftAutopilot
=================


.. _http-MechJeb.AircraftAutopilot:

.. rubric:: AircraftAutopilot

The Aircraft Autopilot window, which holds a heading, altitude, vertical speed, roll and speed.

A ``AircraftAutopilot`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/aircraft-autopilot/(id)/enabled

   Whether the module is enabled.


   :param id: The identifier of the :ref:`AircraftAutopilot <http-MechJeb.AircraftAutopilot>` object.

   :resjson bool value:
