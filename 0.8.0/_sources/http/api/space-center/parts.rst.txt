Parts
=====

The following classes allow interaction with a vessel's individual parts.

.. seealso:: The :std:ref:`parts guide <user-guide-parts>` walks the tree of parts, and explains
   fuel lines, stage numbers and part modules.

.. contents::
   :local:

Parts
-----


.. _http-SpaceCenter.Parts:

.. rubric:: Parts

Instances of this class are used to interact with the parts of a vessel.
An instance can be obtained by calling :http:get:`/space-center/vessel/(id)/parts`.

A ``Parts`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/parts/(id)/all

   A list of all of the vessels parts.


   :param id: The identifier of the :ref:`Parts <http-SpaceCenter.Parts>` object.

   :resjson list<SpaceCenter.Part> value:




.. http:get:: /space-center/parts/(id)/root

   The vessels root part.


   :param id: The identifier of the :ref:`Parts <http-SpaceCenter.Parts>` object.

   :resjson SpaceCenter.Part value:

.. note:: See the discussion on :rst:ref:`user-guide-parts-tree`.




.. http:get:: /space-center/parts/(id)/controlling

   The part from which the vessel is controlled.
   Returns ``null`` if the vessel has no control point, in which case it is
   oriented by its root part.

   .. note::

      A vessel gets no control point when it is created by a decoupler or an undocking
      and none of its parts is a command module with crew aboard. A probe core does not
      give it one either. Assign this property to choose the control point, which is
      equivalent to "Control From Here" in game.


   :param id: The identifier of the :ref:`Parts <http-SpaceCenter.Parts>` object.

   :resjson SpaceCenter.Part? value:

.. http:put:: /space-center/parts/(id)/controlling

      equivalent to "Control From Here" in game.


   :param id: The identifier of the :ref:`Parts <http-SpaceCenter.Parts>` object.

   :reqjson SpaceCenter.Part? value: The new value.

Part
----


.. _http-SpaceCenter.Part:

.. rubric:: Part

Represents an individual part. Vessels are made up of multiple parts.
Instances of this class can be obtained by several methods in :ref:`Parts <http-SpaceCenter.Parts>`.

A ``Part`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/part/(id)/name

   Internal name of the part, as used in
   `part cfg files <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation>`_.
   For example "Mark1-2Pod".


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson string value:




.. http:get:: /space-center/part/(id)/title

   Title of the part, as shown when the part is right clicked in-game. For example "Mk1-2 Command Pod".


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson string value:




.. http:get:: /space-center/part/(id)/config

   The static configuration of the part, as found in its
   `part cfg file <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation>`_.
   This provides access to data that is not exposed elsewhere, such as the
   configuration of the part's modules. Returns ``null`` if the part has no
   associated configuration node.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson SpaceCenter.ConfigNode value:




.. http:get:: /space-center/part/(id)/tag

   The name tag for the part. Can be set to a custom string using the
   in-game user interface. Throws an exception if no name tag part module is installed.

   .. note::

      Requires KSPCommunityPartModules 0.5 or later, or kOS, which share one name tag.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson string value:

.. http:put:: /space-center/part/(id)/tag

   The name tag for the part. Can be set to a custom string using the
   in-game user interface. Throws an exception if no name tag part module is installed.

   .. note::

      Requires KSPCommunityPartModules 0.5 or later, or kOS, which share one name tag.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :reqjson string value: The new value.




.. http:get:: /space-center/part/(id)/flag-url

   The asset URL for the part's flag.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson string value:

.. http:put:: /space-center/part/(id)/flag-url

   The asset URL for the part's flag.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :reqjson string value: The new value.




.. http:get:: /space-center/part/(id)/highlighted

   Whether the part is highlighted.

   .. note::

      The highlighting is removed when the client that enabled it disconnects.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson bool value:

.. http:put:: /space-center/part/(id)/highlighted

   Whether the part is highlighted.

   .. note::

   The color used to highlight the part.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

.. http:get:: /space-center/part/(id)/cost

.. http:get:: /space-center/part/(id)/children

   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson list<SpaceCenter.Part> value:

.. note:: See the discussion on :rst:ref:`user-guide-parts-tree`.

   :resjson bool value:

   .. note::

   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/buoyancy-multiplier

   The multiplier applied to the buoyant force on the part. One for most parts.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:post:: /space-center/part/(id)/buoyant-force-at

   The buoyant force on the part when fully submerged in a fluid of the given
   density, in Newtons.

   .. note::

      Applies :http:get:`/space-center/buoyancy-scalar` and
      :http:get:`/space-center/part/(id)/buoyancy-multiplier`, so the result is what the game would do to the
      part rather than what
      `Archimedes' principle <https://en.wikipedia.org/wiki/Archimedes%27_principle>`_ alone gives.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :reqjson double density: The density of the fluid, in :math:`\mathrm{kg/m^{3}}`.
   :reqjson double gravity: The acceleration due to gravity, in :math:`\mathrm{m/s^{2}}`.
   :resjson double value:





.. http:get:: /space-center/part/(id)/splashed

   Whether the part is in contact with water.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/max-depth

   The depth of the deepest point of the part below the waterline, in meters.
   Returns zero if the body the vessel is at has no ocean.

   .. note::

      depth.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/submerged-dynamic-pressure

   The dynamic pressure of the water acting on the part, in Pascals.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/submerged-drag-multiplier

   The multiplier applied to the drag on the part while it is submerged.

   .. note::

      The game sets this high on splashdown and eases it down as the part moves through
      the water. It climbs back once the part slows to a crawl, so a hull under way
      reads lower than one lying still.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/submerged-lift-multiplier

   The multiplier applied to the lift on the part while it is submerged.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/water-angular-drag-multiplier

   The multiplier applied to the angular drag on the part while it is submerged.

   .. note::

      Part of the part's configuration rather than a live readout, so it reads the same
      in the editor and at a body with no ocean.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/impact-tolerance

   The crash tolerance of the part, in :math:`\mathrm{m/s}`.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson double value:




.. http:get:: /space-center/part/(id)/breaking-force

   The breaking force of the part's attachments, in :math:`\mathrm{kN}`.

   .. note::

      The joint to the parent part takes the lower breaking force of the two parts,
      scaled by the size of the attachment node. See :http:get:`/space-center/part/(id)/joint-break-force`.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/breaking-torque

   The breaking torque of the part's attachments, in :math:`\mathrm{kN \cdot m}`.

   .. note::

      The joint to the parent part takes the lower breaking torque of the two parts,
      scaled by the size of the attachment node. See :http:get:`/space-center/part/(id)/joint-break-torque`.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/joint-break-force

   The force that breaks the joint to the parent part, in :math:`\mathrm{kN}`.
   Throws an exception if the part has no joint to its parent part.

   .. note::

      The sum over the joint's physics joints. It is infinite for a short time after
      the vessel loads, such as just after launch. The root part and a physicsless
      part have no joint to their parent.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/joint-break-torque

   The torque that breaks the joint to the parent part, in :math:`\mathrm{kN \cdot m}`.
   Throws an exception if the part has no joint to its parent part.

   .. note::

      The sum over the joint's physics joints. It is infinite for a short time after
      the vessel loads. On a stack node of size 2 or more, the physics joints sit apart
      around the node. A bending moment then breaks the joint when one physics joint's
      force exceeds its share of :http:get:`/space-center/part/(id)/joint-break-force`, usually at a much
      larger moment than this torque.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/joint-spring

   The spring constant of the joint to the parent part against translation, in
   :math:`\mathrm{kN/m}`.
   Throws an exception if the part has no joint to its parent part.

   .. note::

      The sum over the joint's physics joints. A rigid attachment locks the joint, and
      this spring then has no effect.


   :param id: The identifier of the :ref:`Part <http-SpaceCenter.Part>` object.

   :resjson float value:




.. http:get:: /space-center/part/(id)/joint-damper

   The damping constant of the joint to the parent part against translation, in
   :math:`\mathrm{kN \cdot s/m}`.
   Throws an exception if the part has no joint to its parent part.

   .. note::

Module
------


.. _http-SpaceCenter.Module:

.. rubric:: Module

This can be used to interact with a specific part module. This includes part modules in
stock KSP, and those added by mods.

In KSP, each part has zero or more
`PartModules <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation#MODULES>`_
associated with it. Each one contains some of the functionality of the part.
For example, an engine has a "ModuleEngines" part module that contains all the
functionality of an engine.

A ``Module`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/module/(id)/name

   Name of the PartModule. For example, "ModuleEngines".


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson string value:




.. http:get:: /space-center/module/(id)/part

   The part that contains this module.


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson SpaceCenter.Part value:




.. http:get:: /space-center/module/(id)/config

   The static configuration of the module, as found in the part's
   `cfg file <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation#MODULES>`_.
   This provides access to data that is not exposed as a field, such as the
   resources produced by a generator. Returns ``null`` if the module's
   configuration node cannot be found.


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson SpaceCenter.ConfigNode value:




.. http:get:: /space-center/module/(id)/field-list

   A list of all the fields of the module, including those not visible in the right-click
   menu of the part. Filter by :http:get:`/space-center/part-field/(id)/visible` to get just the visible ones.


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson list<SpaceCenter.PartField> value:




.. http:get:: /space-center/module/(id)/event-list

   A list of all the events of the module, including those not currently visible or active.
   Events are the clickable buttons visible in the right-click menu of the part. Filter by
   :http:get:`/space-center/part-event/(id)/visible` and :http:get:`/space-center/part-event/(id)/active` to get just the ones
   shown in the menu.


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson list<SpaceCenter.PartEvent> value:




.. http:get:: /space-center/module/(id)/action-list

   A list of all the actions of the module. These are the parts actions that can be assigned
   to action groups in the in-game editor.


   :param id: The identifier of the :ref:`Module <http-SpaceCenter.Module>` object.

   :resjson list<SpaceCenter.PartAction> value:

Config Node
-----------


.. _http-SpaceCenter.ConfigNode:

.. rubric:: ConfigNode

Represents a configuration node, as found in a part's configuration file. A node has a
name, a set of named values and a set of child nodes. This is used to access the
static configuration of a part or part module, for example via
:http:get:`/space-center/part/(id)/config` and :http:get:`/space-center/module/(id)/config`.

A ``ConfigNode`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/config-node/(id)/name

   The name of the configuration node. For example "MODULE".


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :resjson string value:




.. http:get:: /space-center/config-node/(id)/values

   The values stored in the node, as a dictionary mapping names to values.

   .. note::

      If a name appears more than once, only the first value is included. Use
      :http:post:`/space-center/config-node/(id)/find-values` to get all of the values with a given name.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :resjson dictionary<string, string> value:




.. http:post:: /space-center/config-node/(id)/has-value

   Returns ``true`` if the node has a value with the given name.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the value.
   :resjson bool value:





.. http:post:: /space-center/config-node/(id)/get-value

   Returns the value with the given name. If there is more than one value with
   the given name, the first is returned. Throws an exception if there is no
   value with the given name.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the value.
   :resjson string value:





.. http:post:: /space-center/config-node/(id)/find-values

   Returns all of the values with the given name, as a list.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the values.
   :resjson list<string> value:





.. http:get:: /space-center/config-node/(id)/nodes

   The child nodes contained in this node.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :resjson list<SpaceCenter.ConfigNode> value:




.. http:post:: /space-center/config-node/(id)/has-node

   Returns ``true`` if the node has a child node with the given name.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the child node.
   :resjson bool value:





.. http:post:: /space-center/config-node/(id)/get-node

   Returns the child node with the given name. If there is more than one child
   node with the given name, the first is returned. Throws an exception if there
   is no child node with the given name.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the child node.
   :resjson SpaceCenter.ConfigNode value:





.. http:post:: /space-center/config-node/(id)/find-nodes

   Returns all of the child nodes with the given name, as a list.


   :param id: The identifier of the :ref:`ConfigNode <http-SpaceCenter.ConfigNode>` object.

   :reqjson string name: Name of the child nodes.
   :resjson list<SpaceCenter.ConfigNode> value:

Deployable State
^^^^^^^^^^^^^^^^

The deployment state shared by antennas, cargo bays, landing legs, radiators,
resource harvesters, solar panels and wheels.


.. _http-SpaceCenter.DeployableState:

.. rubric:: DeployableState

The state of a deployable part.
:http:get:`/space-center/antenna/(id)/state`, :http:get:`/space-center/cargo-bay/(id)/state`,
:http:get:`/space-center/leg/(id)/state`, :http:get:`/space-center/radiator/(id)/state`,
:http:get:`/space-center/resource-harvester/(id)/state`, :http:get:`/space-center/solar-panel/(id)/state`,
:http:get:`/space-center/wheel/(id)/state`

Passed and returned as the name of one of its values:


``"deployed"``
   The part is fully deployed. A cargo bay in this state is fully open.
   Parts that cannot be retracted, such as fixed radiators, solar panels,
   antennas, landing legs and wheels, are always in this state.


``"retracted"``
   The part is fully retracted. A cargo bay in this state is closed and locked.


``"deploying"``
   The part is being deployed. A cargo bay in this state is opening.


``"retracting"``
   The part is being retracted. A cargo bay in this state is closing.


``"broken"``
   The part is broken. Cargo bays and resource harvesters never report
   this state, as the game does not track damage for them.

.. _http-SpaceCenter.DockingPortState:

.. rubric:: DockingPortState

The state of a docking port. See :http:get:`/space-center/docking-port/(id)/state`.

Passed and returned as the name of one of its values:


``"ready"``
   The docking port is ready to dock to another docking port.


``"docked"``
   The docking port is docked to another docking port, or docked to
   another part (from the VAB/SPH).


``"docking"``
   The docking port is very close to another docking port,
   but has not docked. It is using magnetic force to acquire a solid dock.


``"undocking"``
   The docking port has just been undocked from another docking port,
   and is disabled until it moves away by a sufficient distance
   (:http:get:`/space-center/docking-port/(id)/reengage-distance`).


``"shielded"``
   The docking port has a shield, and the shield is closed.


``"moving"``
   The docking ports shield is currently opening/closing.

   Data amount.


``science_value`` (float)

``transmit_value`` (float)
   Transmit value.



.. _http-SpaceCenter.ScienceSubject:

.. rubric:: ScienceSubject

Obtained by calling :http:get:`/space-center/experiment/(id)/science-subject`.

Passed and returned as an object with these fields:


``id`` (string)
   The identifier of the subject, e.g. ``crewReport@KerbinSrfLandedLaunchPad``.


``title`` (string)
   The title of the subject, as shown in the science archives.


``is_complete`` (bool)
   Whether the subject has been fully researched. This is true once the science banked for
   the subject reaches the science cap. As the banked science (see ``science``) is
   only updated after transmission/recovery, this reflects fully mining the subject over
   repeated experiments, not whether a single run has produced data. To check whether a run
   has produced data, and how valuable it is, use :http:get:`/space-center/experiment/(id)/has-data` and
   ``transmit_value``.


``science`` (float)
   Amount of science already earned from this subject, not updated until after
   transmission/recovery.


``science_cap`` (float)
   Total science allowable for this subject.


``data_scale`` (float)
   Multiply science value by this to determine data amount in mits.


``subject_value`` (float)
   Multiplier for specific Celestial Body/Experiment Situation combination.


``scientific_value`` (float)
   Diminishing value multiplier for decreasing the science value returned from repeated
   experiments.

.. _http-SpaceCenter.ParachuteState:

.. rubric:: ParachuteState

The state of a parachute. See :http:get:`/space-center/parachute/(id)/state`.

Passed and returned as the name of one of its values:


``"stowed"``
   The parachute is safely tucked away inside its housing.


``"armed"``
   The parachute is armed for deployment.


``"semi_deployed"``
   The parachute has been deployed and is providing some drag,
   but is not fully deployed yet. (Stock parachutes only)


``"deployed"``
   The parachute is fully deployed.


``"cut"``
   The parachute has been cut.



.. _http-SpaceCenter.ParachuteSafeState:

.. rubric:: ParachuteSafeState

The safety state of deploying a parachute. See :http:get:`/space-center/parachute/(id)/safe-state`.

Passed and returned as the name of one of its values:


``"safe"``
   The parachute is safe to deploy.


``"risky"``
   Deploying the parachute is risky, and it may break off.


``"unsafe"``
   The parachute is unsafe to deploy, and will break off.


``"none"``
   The safety state is not available, because the vessel is not in an
   atmosphere or the parachute has already been deployed or cut.

Thruster
^^^^^^^^


.. _http-SpaceCenter.Thruster:

.. rubric:: Thruster

The component of an :ref:`Engine <http-SpaceCenter.Engine>` or :ref:`RCS <http-SpaceCenter.RCS>` part that generates thrust.
Can obtained by calling :http:get:`/space-center/engine/(id)/thrusters` or :http:get:`/space-center/rcs/(id)/thrusters`.

.. note::

   Engines can consist of multiple thrusters.
   For example, the S3 KS-25x4 "Mammoth" has four rocket nozzels, and so consists of
   four thrusters.


A ``Thruster`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/thruster/(id)/part

   The :http:get:`/space-center/thruster/(id)/part` that contains this thruster.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :resjson SpaceCenter.Part value:




.. http:get:: /space-center/thruster/(id)/thrust

   The thrust being produced by the thruster, in Newtons.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :resjson float value:




.. http:post:: /space-center/thruster/(id)/thrust-position

   The position at which the thruster generates thrust, in the given reference frame.
   For gimballed engines, this takes into account the current rotation of the gimbal.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the returned position vector is in.
   :resjson tuple<double, double, double> value: The position as a vector.





.. http:post:: /space-center/thruster/(id)/thrust-direction

   The direction of the force generated by the thruster, in the given reference frame.
   This is opposite to the direction in which the thruster expels propellant.
   For gimballed engines, this takes into account the current rotation of the gimbal.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the returned direction is in.
   :resjson tuple<double, double, double> value: The direction as a unit vector.





.. http:get:: /space-center/thruster/(id)/thrust-reference-frame

   A reference frame that is fixed relative to the thruster and orientated with
   its thrust direction (:http:post:`/space-center/thruster/(id)/thrust-direction`).
   For gimballed engines, this takes into account the current rotation of the gimbal.

   * The origin is at the position of thrust for this thruster
     (:http:post:`/space-center/thruster/(id)/thrust-position`).
   * The axes rotate with the thrust direction.
     This is the direction in which the thruster expels propellant, including any gimballing.
   * The y-axis points along the thrust direction.
   * The x-axis and z-axis are perpendicular to the thrust direction.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :resjson SpaceCenter.ReferenceFrame value:




.. http:get:: /space-center/thruster/(id)/gimballed

   Whether the thruster is gimballed.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :resjson bool value:




.. http:post:: /space-center/thruster/(id)/gimbal-position

   Position around which the gimbal pivots.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the returned position vector is in.
   :resjson tuple<double, double, double> value: The position as a vector.





.. http:get:: /space-center/thruster/(id)/gimbal-angle

   The current gimbal angle in the pitch, roll and yaw axes, in degrees.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :resjson tuple<double, double, double> value:




.. http:post:: /space-center/thruster/(id)/initial-thrust-position

   The position at which the thruster generates thrust, when the engine is in its
   initial position (no gimballing), in the given reference frame.

   .. note::

      This position can move when the gimbal rotates. This is because the thrust position and
      gimbal position are not necessarily the same.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the returned position vector is in.
   :resjson tuple<double, double, double> value: The position as a vector.





.. http:post:: /space-center/thruster/(id)/initial-thrust-direction

   The direction of the force generated by the thruster, when the engine is in its
   initial position (no gimballing), in the given reference frame.
   This is opposite to the direction in which the thruster expels propellant.


   :param id: The identifier of the :ref:`Thruster <http-SpaceCenter.Thruster>` object.

   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the returned direction is in.
   :resjson tuple<double, double, double> value: The direction as a unit vector.

.. _http-SpaceCenter.MotorState:

.. rubric:: MotorState

The state of the motor on a powered wheel. See :http:get:`/space-center/wheel/(id)/motor-state`.

Passed and returned as the name of one of its values:


``"idle"``
   The motor is idle.


``"running"``
   The motor is running.


``"disabled"``
   The motor is disabled.


``"inoperable"``
   The motor is inoperable.


``"not_enough_resources"``
   The motor does not have enough resources to run.
