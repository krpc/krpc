Editor
======


.. _http-SpaceCenter.Editor:

.. rubric:: Editor

Provides access to the vehicle assembly building and space plane hangar.
Obtained by calling :http:get:`/space-center/editor`.

A ``Editor`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/editor/(id)/facility

   The editor that is currently open.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :resjson SpaceCenter.EditorFacility value:




.. http:get:: /space-center/editor/(id)/vessel

   The vessel that is being constructed.

   .. note::

      An editor that has not had a vessel loaded into it holds an empty vessel, with
      no parts, rather than nothing at all.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :resjson SpaceCenter.EditorVessel value:




.. http:post:: /space-center/editor/(id)/load-vessel

   Load a vessel from a craft file into the editor, replacing the vessel that
   is currently being constructed.

   .. note::

      The vessel is loaded into whichever editor is open, regardless of which
      directory it came from. Its delta-v figures are recalculated in the
      background afterwards; see :http:get:`/space-center/editor-vessel/(id)/delta-v-ready`.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :reqjson string craft_directory: Name of the directory in the current saves "Ships" directory, that contains the craft file. For example ``"VAB"`` or ``"SPH"``.
   :reqjson string name: Name of the vessel to load. This is the name of the ".craft" file in the save directory, without the ".craft" file extension.





.. http:post:: /space-center/editor/(id)/launch-vessel

   Launch the vessel that is being constructed, from the given launch site.

   .. note::

      The vessel being constructed is not a craft file, so it is written to the editor's
      auto-saved craft file and that is launched, as the game's own launch button does.
      The vessel's own craft file, if it was loaded from one, is left alone.
      The *crew* parameter works as it does for
      :http:post:`/space-center/launch-vessel`, and takes precedence over the crew assigned
      in the editor.
      Throws an exception if any of the games pre-flight checks fail.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :reqjson string launch_site: Name of the launch site. For example ``"LaunchPad"`` or ``"Runway"``.
   :reqjson list<string>? crew: The Kerbals to place in the vessel, by name. Controls how the vessel is crewed, as described in the remarks. Optional, defaults to ``null``.
   :reqjson bool recover: If true and there is a vessel on the launch site, recover it before launching. Optional, defaults to ``true``.
   :reqjson string flag_url: If not ``null``, the asset URL of the mission flag to use for the launch. Optional, defaults to ``""``.





.. http:get:: /space-center/editor/(id)/delta-v-body

   The body whose gravity and atmosphere the vessel's delta-v, thrust, TWR and
   specific impulse figures assume.

   .. note::

      This and :http:get:`/space-center/editor/(id)/delta-v-altitude` are what :http:get:`/space-center/editor-vessel/(id)/delta-v`,
      :http:get:`/space-center/stage/(id)/delta-v` and the other current-situation figures are
      computed for. The body sets the gravity the thrust-to-weight ratios are
      against, and, with the altitude, the atmospheric pressure and density the
      specific impulses and thrusts are against.
      This is global game state rather than editor state: the same setting backs
      the game's delta-v readout in flight, and it persists across scene changes.
      Setting it asks the game to re-run the simulation and returns straight away;
      the figures are out of date until :http:get:`/space-center/editor-vessel/(id)/delta-v-ready` is
      true again.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :resjson SpaceCenter.CelestialBody value:

.. http:get:: /space-center/editor/(id)/delta-v-altitude

   The altitude above :http:get:`/space-center/editor/(id)/delta-v-body`, in meters, that the vessel's
   delta-v, thrust, TWR and specific impulse figures assume. The atmospheric
   pressure and density at this altitude are what the figures are computed for,
   so raising it from zero to above the body's atmosphere moves them from the
   vessel's sea-level figures to its vacuum ones.
   Setting it asks the game to re-run the simulation and returns straight away;
   the figures are out of date until :http:get:`/space-center/editor-vessel/(id)/delta-v-ready` is
   true again.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :resjson double value:

.. http:get:: /space-center/editor/(id)/delta-v-situation

   Which situation the game's own delta-v readout shows figures for.

   .. note::

      This selects which column the game's own delta-v app displays, and nothing
      else. It does not affect anything kRPC reports: the current-situation
      figures follow :http:get:`/space-center/editor/(id)/delta-v-body` and :http:get:`/space-center/editor/(id)/delta-v-altitude`
      whatever this is set to, and the sea-level and vacuum figures are reported
      directly as :http:get:`/space-center/editor-vessel/(id)/sea-level-delta-v` and
      :http:get:`/space-center/editor-vessel/(id)/vacuum-delta-v`. It is here for completeness with the
      app.


   :param id: The identifier of the :ref:`Editor <http-SpaceCenter.Editor>` object.

   :resjson SpaceCenter.DeltaVSituation value:

.. _http-SpaceCenter.DeltaVSituation:

.. rubric:: DeltaVSituation

The situation the game's own delta-v readout shows figures for.
See :http:get:`/space-center/editor/(id)/delta-v-situation`.

Passed and returned as the name of one of its values:


``"sea_level"``
   At sea level on the selected body.


``"altitude"``
   At the selected altitude on the selected body.


``"vacuum"``
   In vacuum.

.. http:get:: /space-center/editor-vessel/(id)/reference-frame

   The reference frame that is fixed relative to the vessel,
   and orientated with the vessel.

   * The origin is at the center of mass of the vessel.
   * The axes rotate with the vessel.
   * The x-axis points out to the right of the vessel.
   * The y-axis points in the forward direction of the vessel.
   * The z-axis points out of the bottom off the vessel.

   .. note::

      The axes are those of the root part. This is the frame
      :http:get:`/space-center/vessel/(id)/reference-frame` gives at launch, with the root part as the
      control point.


   :param id: The identifier of the :ref:`EditorVessel <http-SpaceCenter.EditorVessel>` object.

   :resjson SpaceCenter.ReferenceFrame value:




.. http:get:: /space-center/editor-vessel/(id)/surface-reference-frame

   The reference frame that is fixed relative to the vessel,
   and orientated with the vertical of the editor.

   * The origin is at the center of mass of the vessel.
   * The axes are fixed in the editor.
   * The x-axis points upwards.
   * The y-axis and z-axis are horizontal.

   .. note::

      This is the vessel as it stands in the editor, and as it stands at launch. The
      editor has no north or east, so the horizontal axes are fixed in the editor.


   :param id: The identifier of the :ref:`EditorVessel <http-SpaceCenter.EditorVessel>` object.

   :resjson SpaceCenter.ReferenceFrame value:

.. _http-SpaceCenter.SimulatedFlight:

.. rubric:: SimulatedFlight

Used to simulate the vessel in the editor in flight. The counterpart of
:ref:`Flight <http-SpaceCenter.Flight>`. All of the information returned by this class is given in
the reference frame passed to :http:post:`/space-center/editor-vessel/(id)/flight`, or in
:http:get:`/space-center/simulated-flight/(id)/surface-reference-frame` if none was passed.
Obtained by calling :http:post:`/space-center/editor-vessel/(id)/flight`.

.. note::

   The simulated attitude is set by :http:get:`/space-center/simulated-flight/(id)/surface-reference-frame`, and belongs to
   this object. The vessel is read from the editor on each call, so the object follows
   every edit.


A ``SimulatedFlight`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /space-center/simulated-flight/(id)/surface-reference-frame

   The reference frame of the surface the vessel is simulated over. Its x-axis
   points upwards, and gravity acts along the negative x-axis. Defaults to
   :http:get:`/space-center/editor-vessel/(id)/surface-reference-frame`.

   .. note::

      Only the rotation of the frame is used. A frame created relative to
      :http:get:`/space-center/editor-vessel/(id)/reference-frame` follows the vessel as it is edited.


   :param id: The identifier of the :ref:`SimulatedFlight <http-SpaceCenter.SimulatedFlight>` object.

   :resjson SpaceCenter.ReferenceFrame value:

.. http:put:: /space-center/simulated-flight/(id)/surface-reference-frame

   The reference frame of the surface the vessel is simulated over. Its x-axis
   points upwards, and gravity acts along the negative x-axis. Defaults to
   :http:get:`/space-center/editor-vessel/(id)/surface-reference-frame`.

   .. note::

      Only the rotation of the frame is used. A frame created relative to
      :http:get:`/space-center/editor-vessel/(id)/reference-frame` follows the vessel as it is edited.


   :param id: The identifier of the :ref:`SimulatedFlight <http-SpaceCenter.SimulatedFlight>` object.

   :reqjson SpaceCenter.ReferenceFrame value: The new value.

   The torque the buoyant force exerts about the vessel's center of mass when fully
   submerged in a fluid of the given density, in reference frame
   :ref:`ReferenceFrame <http-SpaceCenter.ReferenceFrame>`. Gravity acts along the negative x-axis of
   :http:get:`/space-center/simulated-flight/(id)/surface-reference-frame`.


   :param id: The identifier of the :ref:`SimulatedFlight <http-SpaceCenter.SimulatedFlight>` object.

   :reqjson double density: The density of the fluid, in :math:`\mathrm{kg/m^{3}}`.
   :reqjson double gravity: The acceleration due to gravity, in :math:`\mathrm{m/s^{2}}`.
   :resjson tuple<double, double, double> value: A vector pointing along the axis of the torque, with its magnitude equal to the strength of the torque in :math:`\mathrm{N \cdot m}`.
