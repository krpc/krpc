OrbitPath
=========


.. _http-Drawing.OrbitPath:

.. rubric:: OrbitPath

The path of an orbit. Created using :http:post:`/drawing/add-orbit`.

A ``OrbitPath`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /drawing/orbit-path/(id)/orbit

   The orbit.


   :param id: The identifier of the :ref:`OrbitPath <http-Drawing.OrbitPath>` object.

   :resjson SpaceCenter.Orbit value:

.. http:put:: /drawing/orbit-path/(id)/orbit

   The orbit.


   :param id: The identifier of the :ref:`OrbitPath <http-Drawing.OrbitPath>` object.

   :reqjson SpaceCenter.Orbit value: The new value.

   :param id: The identifier of the :ref:`OrbitPath <http-Drawing.OrbitPath>` object.

   :resjson bool value:
