Box
===


.. _http-Drawing.Box:

.. rubric:: Box

The edges of a box. Created using :http:post:`/drawing/add-box`.

A ``Box`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /drawing/box/(id)/center

   Position of the center of the box.


   :param id: The identifier of the :ref:`Box <http-Drawing.Box>` object.

   :resjson tuple<double, double, double> value:

.. http:put:: /drawing/box/(id)/center

   :reqjson tuple<double, double, double> value: The new value.
