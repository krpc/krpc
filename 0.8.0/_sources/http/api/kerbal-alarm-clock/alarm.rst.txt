Alarm
=====


.. _http-KerbalAlarmClock.Alarm:

.. rubric:: Alarm

Represents an alarm. Obtained by calling
:http:get:`/kerbal-alarm-clock/alarms`,
:http:post:`/kerbal-alarm-clock/alarm-with-name` or
:http:post:`/kerbal-alarm-clock/alarms-with-type`.

A ``Alarm`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /kerbal-alarm-clock/alarm/(id)/action

   The action that the alarm triggers.

   .. note::

      An alarm that plays a sound has the action ``"custom"``.
      See :http:get:`/kerbal-alarm-clock/alarm/(id)/play-sound`.


   :param id: The identifier of the :ref:`Alarm <http-KerbalAlarmClock.Alarm>` object.

   :resjson KerbalAlarmClock.AlarmAction value:
