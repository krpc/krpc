AscentGuidance
==============


.. class:: AscentGuidance

   The Ascent Guidance window, which flies the vessel to orbit.

   .. note::

      See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
      for how to set up this autopilot.

   .. method:: getEnabled()
               setEnabled(value)

      Whether the module is enabled.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getStatus()

      The autopilot status, which depends on the selected ascent path.

      :Property: Read-only, cannot be set
      :rtype: ``string``
      :Game Scenes: Flight

   .. method:: getAscentType()
               setAscentType(value)

      The ascent path.

      :Property: Can be read or written
      :rtype: :class:`MechJeb.AscentType`
      :Game Scenes: Flight

   .. method:: getSettings()

      The Ascent Settings window.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.AscentSettings`
      :Game Scenes: Flight

   .. method:: getPVGSettings()

      The PVG Settings window, with the settings of the :attr:`MechJeb.AscentType.pvg` path.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.PVGSettings`
      :Game Scenes: Flight

   .. method:: getClassicPath()

      The Ascent Path Editor window, with the settings of the
      :attr:`MechJeb.AscentType.classic` path.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.ClassicPath`
      :Game Scenes: Flight

   .. method:: getDesiredOrbitAltitude()
               setDesiredOrbitAltitude(value)

      The altitude of the final circular orbit, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDesiredApoapsis()
               setDesiredApoapsis(value)

      The target apoapsis, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Applies on the :attr:`MechJeb.AscentType.pvg` path.

   .. method:: getAttachAltFlag()
               setAttachAltFlag(value)

      Whether the orbit is attached at :meth:`MechJeb.AscentGuidance.getDesiredAttachAlt`.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         Applies on the :attr:`MechJeb.AscentType.pvg` path, with an early shutoff stage, set by
         :meth:`MechJeb.PVGSettings.getOptimizeStageFlag` and :meth:`MechJeb.PVGSettings.getOptimizeStage`.
         Without one, MechJeb always attaches the orbit.

   .. method:: getDesiredAttachAlt()
               setDesiredAttachAlt(value)

      The altitude at which the orbit is attached, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Applies on the :attr:`MechJeb.AscentType.pvg` path. Requires :meth:`MechJeb.AscentGuidance.getAttachAltFlag`,
         unless there is no early shutoff stage. See :meth:`MechJeb.PVGSettings.getOptimizeStage`.

   .. method:: getDesiredFPA()
               setDesiredFPA(value)

      The flight path angle at orbit insertion, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Applies on the :attr:`MechJeb.AscentType.pvg` path, when there is no early shutoff
         stage. See :meth:`MechJeb.PVGSettings.getOptimizeStage`.

   .. method:: getDesiredInclination()
               setDesiredInclination(value)

      The inclination of the final circular orbit, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getLaunchMode()

      The launch mode, which gives whether the autopilot is waiting for a timed launch.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.AscentLaunchMode`
      :Game Scenes: Flight

   .. method:: launchToRendezvous()

      Launch to rendezvous with the target. Throws an exception if there is no target, or
      the ascent path is PVG.

      :Game Scenes: Flight

   .. method:: getLaunchPhaseAngle()
               setLaunchPhaseAngle(value)

      The phase angle to the target of a launch to rendezvous, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: launchToTargetPlane()

      Launch into the plane of the target. Throws an exception if there is no target.

      :Game Scenes: Flight

   .. method:: getLaunchLANDifference()
               setLaunchLANDifference(value)

      The difference from the target's longitude of the ascending node of a launch into the
      target's plane, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: launchToMatchLan()

      Launch into the plane of the target, at the time the target's longitude of the
      ascending node, less :meth:`MechJeb.AscentGuidance.getLaunchLANDifference`, passes overhead. Keeps
      :meth:`MechJeb.AscentGuidance.getDesiredInclination`. Throws an exception if there is no target, or the
      ascent path is not :attr:`MechJeb.AscentType.pvg`.

      :Game Scenes: Flight

   .. method:: launchToLan()

      Launch into the plane with longitude of the ascending node :meth:`MechJeb.AscentGuidance.getDesiredLan`
      and inclination :meth:`MechJeb.AscentGuidance.getDesiredInclination`. Throws an exception if the ascent
      path is not :attr:`MechJeb.AscentType.pvg`.

      :Game Scenes: Flight

   .. method:: getDesiredLan()
               setDesiredLan(value)

      The longitude of the ascending node of a launch to a LAN, in degrees.
      See :meth:`MechJeb.AscentGuidance.launchToLan`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: abortTimedLaunch()

      Abort a timed launch that has not started yet. Throws an exception if the launch mode
      is :attr:`MechJeb.AscentLaunchMode.unknown`.

      :Game Scenes: Flight

   .. method:: getWarpCountDown()
               setWarpCountDown(value)

      The time before a timed launch at which time warp stops, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getOverrideWarpToPlane()
               setOverrideWarpToPlane(value)

      Whether a timed launch launches at once, rather than at the time it computes.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight



.. class:: AscentType

   The ascent path. See :meth:`MechJeb.AscentGuidance.getAscentType`.


   .. attribute:: classic

      The classic ascent path. See :meth:`MechJeb.AscentGuidance.getClassicPath`.


   .. attribute:: pvg

      Primer Vector Guidance, for RSS/RO. See :meth:`MechJeb.AscentGuidance.getPVGSettings`.



.. class:: AscentLaunchMode

   The launch mode of the ascent autopilot. See :meth:`MechJeb.AscentGuidance.getLaunchMode`.


   .. attribute:: normal

      The autopilot is not performing a timed launch.


   .. attribute:: rendezvous

      A timed launch to rendezvous with the target vessel.


   .. attribute:: targetPlane

      A timed launch into the plane of the target.


   .. attribute:: matchLan

      A timed launch to the target's longitude of the ascending node. See
      :meth:`MechJeb.AscentGuidance.launchToMatchLan`.


   .. attribute:: lan

      A timed launch to a longitude of the ascending node. See
      :meth:`MechJeb.AscentGuidance.launchToLan`.


   .. attribute:: unknown

      A timed launch of another kind, started from MechJeb's window.
