AttitudeAdjustment
==================


.. class:: AttitudeAdjustment

   The Attitude Adjustment window, which selects the attitude controller that the
   autopilots steer with.

   .. method:: getRCSAuto()
               setRCSAuto(value)

      Whether the attitude controller turns RCS on for a large attitude error, and off once
      the vessel settles.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getController()
               setController(value)

      The attitude controller.

      :Property: Can be read or written
      :rtype: :class:`MechJeb.AttitudeController`
      :Game Scenes: Flight



.. class:: AttitudeController

   An attitude controller of MechJeb. See :meth:`MechJeb.AttitudeAdjustment.getController`.


   .. attribute:: mj

      MechJeb's original attitude controller.


   .. attribute:: kos

      The attitude controller of kOS.


   .. attribute:: hybrid

      A hybrid of the MechJeb and kOS controllers.


   .. attribute:: better

      MechJeb's default controller.


   .. attribute:: lqr

      A linear-quadratic regulator.
