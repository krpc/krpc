Utilities
=========


.. class:: Utilities

   The Utilities window, which holds the autostaging and throttle settings, and deploys
   the solar panels and antennas.

   .. method:: getAntennas()

      The deployable antennas.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.DeployableController`
      :Game Scenes: Flight

   .. method:: getSolarPanels()

      The solar panels.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.DeployableController`
      :Game Scenes: Flight

   .. method:: getStaging()

      The autostaging settings. The same object as :meth:`MechJeb.AscentSettings.getStaging`.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.Autostaging`
      :Game Scenes: Flight

   .. method:: getThrust()

      The throttle limiters. The same object as :meth:`MechJeb.AscentSettings.getThrust`.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.ThrustLimiter`
      :Game Scenes: Flight



Autostaging
-----------


.. class:: Autostaging

   The autostaging settings, which the Utilities and Ascent Settings windows show.

   .. method:: getEnabled()
               setEnabled(value)

      Whether the module is enabled.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getAutostagingOnce()

      Whether the controller disables itself after the next staging.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         See :meth:`MechJeb.Autostaging.autostageOnce`.

   .. method:: autostageOnce()

      Enable the controller until the next staging. Throws an exception if the controller is
      enabled.

      :Game Scenes: Flight

   .. method:: getAutostageLimit()
               setAutostageLimit(value)

      The last stage the controller activates.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getAutostagePostDelay()
               setAutostagePostDelay(value)

      The delay after each staging, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getAutostagePreDelay()
               setAutostagePreDelay(value)

      The delay before each staging, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getClampAutoStageThrustPct()
               setClampAutoStageThrustPct(value)

      The fraction of full thrust at which the controller releases the launch clamps.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getFairingMaxAerothermalFlux()
               setFairingMaxAerothermalFlux(value)

      The largest aerothermal flux at which the controller jettisons a fairing, in
      :math:`\mathrm{W/m^{2}}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getFairingMaxDynamicPressure()
               setFairingMaxDynamicPressure(value)

      The largest dynamic pressure at which the controller jettisons a fairing, in pascals.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getFairingMinAltitude()
               setFairingMinAltitude(value)

      The lowest altitude at which the controller jettisons a fairing, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getHotStaging()
               setHotStaging(value)

      Whether the controller ignites the next stage before the current one burns out.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getHotStagingLeadTime()
               setHotStagingLeadTime(value)

      The time before burnout at which a hot staging happens, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.Autostaging.getHotStaging`.



ThrustLimiter
-------------


.. class:: ThrustLimiter

   The throttle limiters, which the Utilities and Ascent Settings windows show.

   .. method:: getDifferentialThrottle()
               setDifferentialThrottle(value)

      Whether the controller throttles the engines differentially to steer.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getDifferentialThrottleStatus()

      The result of the differential throttle.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.DifferentialThrottleStatus`
      :Game Scenes: Flight

   .. method:: getElectricThrottle()
               setElectricThrottle(value)

      Whether to limit the throttle of electric engines to the available power.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getElectricThrottleHi()
               setElectricThrottleHi(value)

      The charge level at which electric engines run at full throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getElectricThrottle`.

   .. method:: getElectricThrottleLo()
               setElectricThrottleLo(value)

      The charge level at which electric engines stop, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getElectricThrottle`.

   .. method:: getFlameoutSafetyPct()
               setFlameoutSafetyPct(value)

      The safety margin of the jet engines' air intake, as a percentage.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimitToPreventFlameout`.

   .. method:: getLimitAcceleration()
               setLimitAcceleration(value)

      Whether to limit the acceleration.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitDynamicPressure()
               setLimitDynamicPressure(value)

      Whether to limit the dynamic pressure.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitThrottle()
               setLimitThrottle(value)

      Whether to limit the throttle.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitToPreventFlameout()
               setLimitToPreventFlameout(value)

      Whether to limit the throttle to keep jet engines from flaming out.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitToPreventOverheats()
               setLimitToPreventOverheats(value)

      Whether to limit the throttle to keep parts from overheating.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimiterMinThrottle()
               setLimiterMinThrottle(value)

      Whether to keep the throttle above :meth:`MechJeb.ThrustLimiter.getMinThrottle`.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getManageIntakes()
               setManageIntakes(value)

      Whether the controller opens and closes the air intakes.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimitToPreventFlameout`.

   .. method:: getMaxAcceleration()
               setMaxAcceleration(value)

      The largest acceleration, in :math:`\mathrm{m/s^{2}}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimitAcceleration`.

   .. method:: getMaxDynamicPressure()
               setMaxDynamicPressure(value)

      The largest dynamic pressure, in pascals.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimitDynamicPressure`.

   .. method:: getMaxThrottle()
               setMaxThrottle(value)

      The largest throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimitThrottle`.

   .. method:: getMinThrottle()
               setMinThrottle(value)

      The smallest throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustLimiter.getLimiterMinThrottle`.

   .. method:: getLimitToPreventUnstableIgnition()
               setLimitToPreventUnstableIgnition(value)

      Whether to hold the throttle at zero while the engines' fuel is unstable.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         MechJeb shows this setting only with Real Fuels, as stock engines have
         stable fuel.

   .. method:: getAutoRCSUllaging()
               setAutoRCSUllaging(value)

      Whether to fire the RCS forward to settle the fuel before the engines ignite.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         MechJeb shows this setting only with Real Fuels, as stock engines have
         stable fuel.

   .. method:: getLimiter()

      The limiter that limits the throttle now.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.LimitMode`
      :Game Scenes: Flight



.. class:: LimitMode

   A throttle limiter. See :meth:`MechJeb.ThrustLimiter.getLimiter`.


   .. attribute:: none

      No limiter limits the throttle.


   .. attribute:: terminalVelocity

      The terminal velocity limit.


   .. attribute:: temperature

      :meth:`MechJeb.ThrustLimiter.getLimitToPreventOverheats`.


   .. attribute:: flameout

      :meth:`MechJeb.ThrustLimiter.getLimitToPreventFlameout`.


   .. attribute:: acceleration

      :meth:`MechJeb.ThrustLimiter.getLimitAcceleration`.


   .. attribute:: throttle

      :meth:`MechJeb.ThrustLimiter.getLimitThrottle`.


   .. attribute:: dynamicPressure

      :meth:`MechJeb.ThrustLimiter.getLimitDynamicPressure`.


   .. attribute:: minThrottle

      :meth:`MechJeb.ThrustLimiter.getLimiterMinThrottle`.


   .. attribute:: electric

      :meth:`MechJeb.ThrustLimiter.getElectricThrottle`.


   .. attribute:: unstableIgnition

      :meth:`MechJeb.ThrustLimiter.getLimitToPreventUnstableIgnition`.


   .. attribute:: autoRCSUllage

      :meth:`MechJeb.ThrustLimiter.getAutoRCSUllaging`.



.. class:: DifferentialThrottleStatus

   The result of the differential throttle. See
   :meth:`MechJeb.ThrustLimiter.getDifferentialThrottleStatus`.


   .. attribute:: success

      The throttles balance the thrust.


   .. attribute:: allEnginesOff

      All the engines are off.


   .. attribute:: moreEnginesRequired

      The vessel needs more engines.


   .. attribute:: solverFailed

      The solver found no solution.



DeployableController
--------------------


.. class:: DeployableController

   The controller of one kind of deployable part, such as antennas or solar panels.

   .. method:: allRetracted()

      Whether all the parts are retracted.

      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getAutoDeploy()
               setAutoDeploy(value)

      Whether a MechJeb autopilot deploys the parts.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: extendAll()

      Extend all the parts.

      :Game Scenes: Flight

   .. method:: retractAll()

      Retract all the parts.

      :Game Scenes: Flight
