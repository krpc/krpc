Burn Time
=========


.. class:: BurnTime(fields)

   The time to burn a delta-v at full thrust, staging as each stage runs dry.


   .. attribute:: duration

      The duration of the burn, in seconds.

      :Type: ``number``

   .. attribute:: halfDuration

      The time to burn half the delta-v, in seconds.

      :Type: ``number``
