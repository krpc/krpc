OrbitPath
=========


.. class:: OrbitPath

   The path of an orbit. Created using :func:`Drawing.addOrbit`.

   .. method:: getOrbit()
               setOrbit(value)

      The orbit.

      :Property: Can be read or written
      :rtype: :class:`SpaceCenter.Orbit`
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getWholeOrbit()
               setWholeOrbit(value)

      Whether the whole orbit is drawn, up to where it leaves the sphere of influence of
      its body. When false, the orbit is drawn from :meth:`Drawing.OrbitPath.getStartTrueAnomaly`
      to :meth:`Drawing.OrbitPath.getEndTrueAnomaly`.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getStartTrueAnomaly()
               setStartTrueAnomaly(value)

      The true anomaly at which the path starts, in radians.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph


      .. note::

         Setting this sets :meth:`Drawing.OrbitPath.getWholeOrbit` to false.

   .. method:: getEndTrueAnomaly()
               setEndTrueAnomaly(value)

      The true anomaly at which the path ends, in radians.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph


      .. note::

         Setting this sets :meth:`Drawing.OrbitPath.getWholeOrbit` to false.

   .. method:: getVisible()
               setVisible(value)

      Whether the object is visible.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getColor()
               setColor(value)

      The color of the path.

      :Property: Can be read or written
      :rtype: :class:`StdLib.ColorRGB`
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph


      .. note::

         For a path drawn with more than one color, this is the color at its start.

   .. method:: getColors()
               setColors(value)

      The colors of the path, blended evenly from its start to its end.

      :Property: Can be read or written
      :rtype: ``Array`` of :class:`StdLib.ColorRGB`
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph


      .. note::

         Throws an exception if the list is empty or holds more than 8 colors.

   .. method:: getThickness()
               setThickness(value)

      :rtype: ``boolean``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getArrowSize()

      The size of the arrow heads, relative to the thickness.

      :rtype: ``number``
      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph

   .. method:: getDashed()
               setDashed(value)

      Whether the path is drawn as a dashed line.

      :Game Scenes: Flight, Tracking Station, Editor Vab, Editor Sph
