AscentGuidance#

public class AscentGuidance#

The Ascent Guidance window, which flies the vessel to orbit.

Note

See the MechJeb wiki for how to set up this autopilot.

void setEnabled(boolean value)#

Whether the module is enabled.

Flight

The autopilot status, which depends on the selected ascent path.

Flight

The ascent path.

Game Scenes:

Flight

The Ascent Settings window.

Game Scenes:

Flight

The PVG Settings window, with the settings of the AscentType.PVG path.

Game Scenes:

Flight

The Ascent Path Editor window, with the settings of the AscentType.CLASSIC path.

Game Scenes:

Flight

double getDesiredOrbitAltitude()#
void setDesiredOrbitAltitude(double value)#

The altitude of the final circular orbit, in meters.

Game Scenes:

Flight

double getDesiredApoapsis()#
void setDesiredApoapsis(double value)#

The target apoapsis, in meters.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path.

boolean getAttachAltFlag()#
void setAttachAltFlag(boolean value)#

Whether the orbit is attached at AscentGuidance.getDesiredAttachAlt().

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path, with an early shutoff stage, set by PVGSettings.getOptimizeStageFlag() and PVGSettings.getOptimizeStage(). Without one, MechJeb always attaches the orbit.

double getDesiredAttachAlt()#
void setDesiredAttachAlt(double value)#

The altitude at which the orbit is attached, in meters.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path. Requires AscentGuidance.getAttachAltFlag(), unless there is no early shutoff stage. See PVGSettings.getOptimizeStage().

double getDesiredFPA()#
void setDesiredFPA(double value)#

The flight path angle at orbit insertion, in degrees.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path, when there is no early shutoff stage. See PVGSettings.getOptimizeStage().

double getDesiredInclination()#
void setDesiredInclination(double value)#

The inclination of the final circular orbit, in degrees.

Game Scenes:

Flight

AscentLaunchMode getLaunchMode()#

The launch mode, which gives whether the autopilot is waiting for a timed launch.

Game Scenes:

Flight

void launchToRendezvous()#

Launch to rendezvous with the target. Throws an exception if there is no target, or the ascent path is PVG.

Game Scenes:

Flight

double getLaunchPhaseAngle()#
void setLaunchPhaseAngle(double value)#

The phase angle to the target of a launch to rendezvous, in degrees.

Game Scenes:

Flight

void launchToTargetPlane()#

Launch into the plane of the target. Throws an exception if there is no target.

Game Scenes:

Flight

double getLaunchLANDifference()#
void setLaunchLANDifference(double value)#

The difference from the target’s longitude of the ascending node of a launch into the target’s plane, in degrees.

Game Scenes:

Flight

void launchToMatchLan()#

Launch into the plane of the target, at the time the target’s longitude of the ascending node, less AscentGuidance.getLaunchLANDifference(), passes overhead. Keeps AscentGuidance.getDesiredInclination(). Throws an exception if there is no target, or the ascent path is not AscentType.PVG.

Game Scenes:

Flight

void launchToLan()#

Launch into the plane with longitude of the ascending node AscentGuidance.getDesiredLan() and inclination AscentGuidance.getDesiredInclination(). Throws an exception if the ascent path is not AscentType.PVG.

Game Scenes:

Flight

double getDesiredLan()#
void setDesiredLan(double value)#

The longitude of the ascending node of a launch to a LAN, in degrees. See AscentGuidance.launchToLan().

Game Scenes:

Flight

void abortTimedLaunch()#

Abort a timed launch that has not started yet. Throws an exception if the launch mode is AscentLaunchMode.UNKNOWN.

Game Scenes:

Flight

int getWarpCountDown()#
void setWarpCountDown(int value)#

The time before a timed launch at which time warp stops, in seconds.

Game Scenes:

Flight

boolean getOverrideWarpToPlane()#
void setOverrideWarpToPlane(boolean value)#

Whether a timed launch launches at once, rather than at the time it computes.

Game Scenes:

Flight

public enum AscentType#

The ascent path. See AscentGuidance.getAscentType().

public AscentType CLASSIC#

The classic ascent path. See AscentGuidance.getClassicPath().

public AscentType PVG#

Primer Vector Guidance, for RSS/RO. See AscentGuidance.getPVGSettings().

public enum AscentLaunchMode#

The launch mode of the ascent autopilot. See AscentGuidance.getLaunchMode().

public AscentLaunchMode NORMAL#

The autopilot is not performing a timed launch.

public AscentLaunchMode RENDEZVOUS#

A timed launch to rendezvous with the target vessel.

public AscentLaunchMode TARGET_PLANE#

A timed launch into the plane of the target.

public AscentLaunchMode MATCH_LAN#

A timed launch to the target’s longitude of the ascending node. See AscentGuidance.launchToMatchLan().

public AscentLaunchMode LAN#

A timed launch to a longitude of the ascending node. See AscentGuidance.launchToLan().

public AscentLaunchMode UNKNOWN#

A timed launch of another kind, started from MechJeb’s window.
