Debug#

Provides functionality to modify the state of the simulation directly, in ways the game normally does not allow: teleporting a vessel, setting its attitude, refilling its tanks and enabling the game’s cheat options.

Note

Everything in this service is cheating. It has the same effect on a save as the game’s own debug menu (Alt+F12), and the same consequences: contracts, records and career progress made with it are not earned. It is intended for setting up a scenario to fly or a script to test, without flying there first.

Move the active vessel onto a circular orbit around a body.

Parameters:

  • altitude (float) – Altitude of the orbit, in meters above sea level.

static set_orbit(body, semi_major_axis, eccentricity, inclination, longitude_of_ascending_node, argument_of_periapsis, mean_anomaly_at_epoch, epoch)#

Move the active vessel onto the orbit with the given orbital elements. The angles use the same units and conventions as SpaceCenter.Orbit.

Parameters:

  • body (SpaceCenter.CelestialBody) – Body to orbit.

  • semi_major_axis (float) – Semi-major axis of the orbit, in meters.

  • eccentricity (float) – Eccentricity of the orbit.

  • inclination (float) – Inclination of the orbit, in radians.

  • longitude_of_ascending_node (float) – Longitude of the ascending node, in radians.

  • argument_of_periapsis (float) – Argument of periapsis, in radians.

  • mean_anomaly_at_epoch (float) – Mean anomaly at epoch, in radians.

  • epoch (float) – Universal time of the epoch, in seconds.

static set_landed(body, latitude, longitude[, altitude=0.0])#

Place the active vessel on the surface of a body at the given latitude and longitude, and wait for it to come to rest.

Parameters:

  • body (SpaceCenter.CelestialBody) – Body to land on.

  • latitude (float) – Latitude in degrees.

  • longitude (float) – Longitude in degrees.

  • altitude (float) – Height above the terrain to settle at, in meters. Defaults to 0, resting on the surface.

Game Scenes:

Flight

static set_flight(body, latitude, longitude, altitude, speed, heading[, pitch=0.0][, roll=0.0][, angle_of_attack=0.0])#

Place the active vessel in atmospheric flight over the given point: at the given altitude and airspeed, pointing along the given heading at the given pitch and roll, and let physics resume so that it is flying. Use this to set up an in-air scenario without flying the craft up from the runway.

Parameters:

  • body (SpaceCenter.CelestialBody) – Body to fly over.

  • latitude (float) – Latitude in degrees.

  • longitude (float) – Longitude in degrees.

  • altitude (float) – Altitude in meters above sea level.

  • speed (float) – Airspeed in meters per second, relative to the surface.

  • heading (float) – Compass heading to point along, in degrees (90 is east).

  • pitch (float) – Pitch above the horizon, in degrees. Defaults to 0 (level).

  • roll (float) – Roll, in degrees. Defaults to 0 (wings level).

  • angle_of_attack (float) – Angle of attack in degrees: how far the airspeed vector sits below the nose, in the pitch plane. 0 (the default) puts the airspeed along the nose; a positive value gives a nose-up attitude relative to the flight path, so the flight-path angle is pitch minus this.

Game Scenes:

Flight

Note

The pitch, heading and roll match those reported by the vessel’s SpaceCenter.Flight.

static set_position(position, reference_frame)#

Move the active vessel to the given position, leaving its velocity as it is. To put it alongside another vessel, pass a position in that vessel’s reference frame.

Parameters:

  • position (tuple) – Position of the vessel’s center of mass, in meters.

  • reference_frame (SpaceCenter.ReferenceFrame) – Reference frame the position is in. Defaults to the reference frame of the body being orbited.

Game Scenes:

Flight

Note

This is the inverse of SpaceCenter.Vessel.position() in the same reference frame.

static set_velocity(velocity, reference_frame)#

Set the velocity of the active vessel, leaving it where it is. The vessel is moved onto the orbit that passes through its current position at the new velocity, so this works in orbit and in the atmosphere alike.

Parameters:

  • velocity (tuple) – Velocity in meters per second.

  • reference_frame (SpaceCenter.ReferenceFrame) – Reference frame the velocity is in. Defaults to the reference frame of the body being orbited, which rotates with it, so a zero velocity leaves the vessel at rest relative to the ground.

Game Scenes:

Flight

Note

This is the inverse of SpaceCenter.Vessel.velocity() in the same reference frame.

static set_pitch_heading_roll(pitch, heading, roll, reference_frame, vessel)#

Set the attitude of a vessel to the given pitch, heading and roll in the given reference frame, and stop it rotating. Lets a script start from a fixed, still pose without first flying the autopilot there.

Parameters:

  • pitch (float) – Target pitch, in degrees.

  • heading (float) – Target heading, in degrees.

  • roll (float) – Target roll, in degrees.

  • reference_frame (SpaceCenter.ReferenceFrame) – Reference frame the angles are in. Defaults to the vessel’s surface reference frame.

  • vessel (SpaceCenter.Vessel) – Vessel to rotate. Defaults to the active vessel.

Game Scenes:

Flight

Note

The angles match those reported by the vessel’s SpaceCenter.Flight.

static set_direction(direction, roll, reference_frame, vessel)#

Point a vessel along the given direction in the given reference frame, and stop it rotating. This is set_pitch_heading_roll() with a pointing vector instead of a pitch and heading, matching the attitude the autopilot holds for the same target direction and roll.

Parameters:

  • direction (tuple) – Direction to point the nose of the vessel in.

  • roll (float) – Target roll, in degrees, or NaN to leave the roll uncontrolled.

  • reference_frame (SpaceCenter.ReferenceFrame) – Reference frame the direction and roll are in. Defaults to the vessel’s surface reference frame.

  • vessel (SpaceCenter.Vessel) – Vessel to rotate. Defaults to the active vessel.

Game Scenes:

Flight

  • axis (tuple) – Axis to rotate about.

  • vessel (SpaceCenter.Vessel) – Vessel to rotate. Defaults to the active vessel.

Game Scenes:

static set_angular_velocity(angular_velocity, reference_frame, vessel)#

Set the angular velocity of a vessel, expressed in the given reference frame. Pass a zero vector to stop the vessel rotating.

Parameters:

  • angular_velocity (tuple) – Angular velocity, in radians per second. The direction is the axis of rotation and the magnitude is the rate.

  • reference_frame (SpaceCenter.ReferenceFrame) – Reference frame the angular velocity is in. Defaults to the vessel’s surface reference frame.

  • vessel (SpaceCenter.Vessel) – Vessel to rotate. Defaults to the active vessel.

Game Scenes:

Flight

Note

The whole vessel is put into a rigid rotation about its center of mass, so it spins in place rather than shearing apart or translating.
