AscentGuidance#

class AscentGuidance#

The Ascent Guidance window, which flies the vessel to orbit.

Note

See the MechJeb wiki for how to set up this autopilot.

enabled#

Whether the module is enabled.

Attribute:

Can be read or written

Return type:

bool

Game Scenes:

Flight

status#

The autopilot status, which depends on the selected ascent path.

Attribute:

Read-only, cannot be set

Return type:

str

Game Scenes:

Flight

ascent_type#

The ascent path.

Attribute:

Can be read or written

Return type:

AscentType

Game Scenes:

Flight

settings#

The Ascent Settings window.

Attribute:

Read-only, cannot be set

Return type:

AscentSettings

Game Scenes:

Flight

pvg_settings#

The PVG Settings window, with the settings of the AscentType.pvg path.

Attribute:

Read-only, cannot be set

Return type:

PVGSettings

Game Scenes:

Flight

classic_path#

The Ascent Path Editor window, with the settings of the AscentType.classic path.

Attribute:

Read-only, cannot be set

Return type:

ClassicPath

Game Scenes:

Flight

desired_orbit_altitude#

The altitude of the final circular orbit, in meters.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

desired_apoapsis#

The target apoapsis, in meters.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Applies on the AscentType.pvg path.

attach_alt_flag#

Whether the orbit is attached at AscentGuidance.desired_attach_alt.

Attribute:

Can be read or written

Return type:

bool

Game Scenes:

Flight

Note

Applies on the AscentType.pvg path, with an early shutoff stage, set by PVGSettings.optimize_stage_flag and PVGSettings.optimize_stage. Without one, MechJeb always attaches the orbit.

desired_attach_alt#

The altitude at which the orbit is attached, in meters.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Applies on the AscentType.pvg path. Requires AscentGuidance.attach_alt_flag, unless there is no early shutoff stage. See PVGSettings.optimize_stage.

desired_fpa#

The flight path angle at orbit insertion, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Applies on the AscentType.pvg path, when there is no early shutoff stage. See PVGSettings.optimize_stage.

desired_inclination#

The inclination of the final circular orbit, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

launch_mode#

The launch mode, which gives whether the autopilot is waiting for a timed launch.

Attribute:

Read-only, cannot be set

Return type:

AscentLaunchMode

Game Scenes:

Flight

launch_to_rendezvous()#

Launch to rendezvous with the target. Throws an exception if there is no target, or the ascent path is PVG.

Game Scenes:

Flight

launch_phase_angle#

The phase angle to the target of a launch to rendezvous, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

launch_to_target_plane()#

Launch into the plane of the target. Throws an exception if there is no target.

Game Scenes:

Flight

launch_lan_difference#

The difference from the target’s longitude of the ascending node of a launch into the target’s plane, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

launch_to_match_lan()#

Launch into the plane of the target, at the time the target’s longitude of the ascending node, less AscentGuidance.launch_lan_difference, passes overhead. Keeps AscentGuidance.desired_inclination. Throws an exception if there is no target, or the ascent path is not AscentType.pvg.

Game Scenes:

Flight

launch_to_lan()#

Launch into the plane with longitude of the ascending node AscentGuidance.desired_lan and inclination AscentGuidance.desired_inclination. Throws an exception if the ascent path is not AscentType.pvg.

Game Scenes:

Flight

desired_lan#

The longitude of the ascending node of a launch to a LAN, in degrees. See AscentGuidance.launch_to_lan().

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

abort_timed_launch()#

Abort a timed launch that has not started yet. Throws an exception if the launch mode is AscentLaunchMode.unknown.

Game Scenes:

Flight

warp_count_down#

The time before a timed launch at which time warp stops, in seconds.

Attribute:

Can be read or written

Return type:

int

Game Scenes:

Flight

override_warp_to_plane#

Whether a timed launch launches at once, rather than at the time it computes.

Attribute:

Can be read or written

Return type:

bool

Game Scenes:

Flight

class AscentType#

The ascent path. See AscentGuidance.ascent_type.

classic#

The classic ascent path. See AscentGuidance.classic_path.

pvg#

Primer Vector Guidance, for RSS/RO. See AscentGuidance.pvg_settings.

class AscentLaunchMode#

The launch mode of the ascent autopilot. See AscentGuidance.launch_mode.

normal#

The autopilot is not performing a timed launch.

rendezvous#

A timed launch to rendezvous with the target vessel.

target_plane#

A timed launch into the plane of the target.

match_lan#

A timed launch to the target’s longitude of the ascending node. See AscentGuidance.launch_to_match_lan().

lan#

A timed launch to a longitude of the ascending node. See AscentGuidance.launch_to_lan().

unknown#

A timed launch of another kind, started from MechJeb’s window.

AscentSettings#

class AscentSettings#

The Ascent Settings window, which holds the settings shared by the ascent paths.

force_roll#

Whether the autopilot controls the roll.

Attribute:

Can be read or written

Return type:

bool

Game Scenes:

Flight

vertical_roll#

The roll during the vertical climb, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Requires AscentSettings.force_roll.

turn_roll#

The roll during the turn, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Requires AscentSettings.force_roll.

roll_altitude#

The altitude above which the autopilot controls the roll, in meters.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Requires AscentSettings.force_roll.

limit_angle_of_attack#

Whether to limit the angle of attack.

Attribute:

Can be read or written

Return type:

bool

Game Scenes:

Flight

Note

Applies on the AscentType.classic path.

max_angle_of_attack#

The largest angle of attack, in degrees.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Requires AscentSettings.limit_angle_of_attack, and applies on the AscentType.classic path.

angle_of_attack_limit_fadeout_pressure#

The dynamic pressure below which the angle of attack limit fades out, in pascals.

Attribute:

Can be read or written

Return type:

float

Game Scenes:
