ManeuverPlanner#

class ManeuverPlanner#

The maneuver planner, which makes maneuver nodes for its operations.

Note

MechJeb shares the operations, and most of their settings, between vessels.

class OperationException#

Thrown when an operation cannot make its nodes, such as when it needs a target and there is none.

TimeSelector#

class TimeSelector#

The time of a maneuver.

circularize_altitude#

The altitude, in meters.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Applies to TimeReference.altitude.

lead_time#

The time from now, in seconds.

Attribute:

Can be read or written

Return type:

float

Game Scenes:

Flight

Note

Applies to TimeReference.x_from_now.

time_reference#

The time reference. Throws an exception if set to a reference the operation does not allow.

Attribute:

Can be read or written

Return type:

TimeReference

Game Scenes:

Flight

class TimeReference#

The time reference of a maneuver. See TimeSelector.time_reference.

altitude#

At TimeSelector.circularize_altitude.

apoapsis#

At the next apoapsis.

closest_approach#

At the closest approach to the target.

computed#

At the optimum time.

eq_ascending#

At the equatorial ascending node.

eq_descending#

At the equatorial descending node.

eq_highest_ad#

At the cheaper of the equatorial ascending and descending nodes.

eq_nearest_ad#

At the nearer of the equatorial ascending and descending nodes.

periapsis#

At the next periapsis.

rel_ascending#

At the next ascending node with the target.

rel_descending#

At the next descending node with the target.

rel_highest_ad#

At the cheaper of the ascending and descending nodes with the target.

rel_nearest_ad#

At the nearer of the ascending and descending nodes with the target.

x_from_now#

After TimeSelector.lead_time.

OperationCircularize#

class OperationCircularize#

Circularize the orbit.

Note

To raise the periapsis to the apoapsis, set the time to TimeReference.apoapsis, and to lower the apoapsis to the periapsis, set it to TimeReference.periapsis. These are the cheapest.

OperationResonantOrbit#

class OperationResonantOrbit#

Change to a resonant orbit, to place satellites in a constellation.

Note

Start from an orbit in the plane of the constellation. To deploy satellites, set the denominator to their number. A numerator one less than the denominator is the cheapest, though not the fastest. The two numbers must have no common factor.

class OperationTransfer#

A bi-impulsive (Hohmann) transfer to the target, within one sphere of influence. It suits a rendezvous with a vessel or a transfer to a moon.

Note

Despite the name, the transfer is often uni-impulsive. It happens at the selected time, or at the optimum time.
