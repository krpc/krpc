Drawing#

class Drawing : public krpc::Service#

Provides functionality for drawing objects in the flight scene, the map view, the editor and the tracking station.

Note

For drawing and interacting with the user interface, see the UI service. Objects drawn by a client are removed when that client disconnects.

Drawing(krpc::Client *client)#

Construct an instance of this service.

Line add_line(std::tuple<double, double, double> start, std::tuple<double, double, double> end, SpaceCenter::ReferenceFrame reference_frame, bool visible = true)#

Draw a line in the scene.

Parameters:

  • start – Position of the start of the line.

  • end – Position of the end of the line.

  • reference_frame – Reference frame that the positions are in.

  • visible – Whether the line is visible.

Game Scenes:

Flight, Tracking Station, Editor Vab, Editor Sph

Line add_direction(std::tuple<double, double, double> direction, SpaceCenter::ReferenceFrame reference_frame, float length = 1e+01f, bool visible = true)#

Draw a direction vector in the scene, starting from the origin of the given reference frame.

Parameters:

  • direction – Direction to draw the line in.

  • reference_frame – Reference frame that the direction is in and defines the start position.

  • length – The length of the line.

  • visible – Whether the line is visible.

Game Scenes:

Flight, Tracking Station, Editor Vab, Editor Sph

Circle add_circle(std::tuple<double, double, double> center, std::tuple<double, double, double> normal, double radius, SpaceCenter::ReferenceFrame reference_frame, bool visible = true)#

Draw a circle in the scene.

Parameters:

  • center – Position of the center of the circle.

  • normal – Normal of the plane of the circle.

  • radius – Radius of the circle, in meters.

  • reference_frame – Reference frame that the position and normal are in.

  • visible – Whether the circle is visible.

Game Scenes:

Flight, Tracking Station, Editor Vab, Editor Sph

Note

Throws an exception if the normal is zero.

Arc add_arc(std::tuple<double, double, double> center, std::tuple<double, double, double> normal, std::tuple<double, double, double> start_direction, double angle, double radius, SpaceCenter::ReferenceFrame reference_frame, bool visible = true)#

Draw an arc of a circle in the scene.

Parameters:

  • center – Position of the center of the arc.

  • normal – Normal of the plane of the arc.

  • start_direction – Direction from the center to the start of the arc.

  • angle – Angle of the arc, in radians.

  • radius – Radius of the arc, in meters.

  • reference_frame – Reference frame that the position and directions are in.

  • visible – Whether the arc is visible.

Game Scenes:

Flight, Tracking Station, Editor Vab, Editor Sph

Note

The arc turns counterclockwise about the normal, seen from the side it points to. Throws an exception if the normal is zero, or the start direction is parallel to it.

OrbitPath add_orbit(SpaceCenter::Orbit orbit, bool visible = true)#
