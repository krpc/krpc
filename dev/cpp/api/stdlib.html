Standard Library#

class StdLib : public krpc::Service#

A standard library of scalar mathematics, vector and quaternion operations, and printing, for use within server side functions.

Note

Vectors are position and direction tuples, and rotations are unit quaternion tuples in the order x, y, z, w the SpaceCenter service uses. Angles are in radians unless stated otherwise.
