Expressions#

The nodes a server side function is built from, and the types they work with. See the server side functions guide for how a function is assembled and run.

class Expression#

A server side expression.

Note

Numeric operands of differing types are converted to a common type.

Type return_type()#

The type of the value the expression evaluates to. Throws an exception if the value cannot be sent to a client.

Note

A function created with Expression::lambda() evaluates to the value it returns. A lazily evaluated collection, such as from Expression::select(), is sent once converted by Expression::to_list() or Expression::to_set().

bool has_return_type()#

Whether the expression evaluates to a value.

Note

An expression with no value has no Expression::return_type(). An empty collection and no value both encode to an empty sequence of bytes.

std::vector<Type> parameter_types()#

The types of the function’s parameters.

Note

Empty for a function that is not created with Expression::lambda().

static Expression call(Client &connection, krpc::schema::ProcedureCall call)#

An RPC call.

Parameters:

  • call – The procedure call.

Note

The instance the call is made on, and the values of its arguments, are fixed when the expression is created. A call to a procedure with no return value is evaluated for its effects, as a statement in a Expression::block(). A collection the procedure returns is copied, as a client would receive it.

static Expression call_with_arguments(Client &connection, krpc::schema::ProcedureCall call, std::map<int32_t, Expression> args)#

An RPC call, where some or all of the arguments are computed by expressions.

Parameters:

  • call – The RPC to call.

  • args – Expressions computing the call’s arguments, by position.

Note

Position 0 is the instance of a class method or property. A position with no expression takes the argument encoded in the call, or the parameter’s default. A collection the procedure returns is copied, as a client would receive it.

static Expression equal(Client &connection, Expression arg0, Expression arg1)#

Equality comparison.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Note

Collections, tuples, bytes and structures compare by their contents. Throws an exception if the operands are of unrelated types.

static Expression not_equal(Client &connection, Expression arg0, Expression arg1)#

Inequality comparison.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Note

Collections, tuples, bytes and structures compare by their contents. Throws an exception if the operands are of unrelated types.

Less than numerical comparison.

Parameters:

  • arg0 – The first operand.

static Expression less_than_or_equal(Client &connection, Expression arg0, Expression arg1)#

Less than or equal numerical comparison.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Whether a value is null. Throws an exception if the type of the value cannot be null.

  • value – The value.

Logical or bitwise or, which evaluates both operands.

Logical and, which evaluates the second operand only when the first is true.

  • arg0 – The first operand.

Logical or, which evaluates the second operand only when the first is false.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

static Expression exclusive_or(Client &connection, Expression arg0, Expression arg1)#

Logical or bitwise exclusive or.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

static Expression not_(Client &connection, Expression arg)#

Logical or bitwise negation.

Parameters:

  • arg – The operand.

static Expression negate(Client &connection, Expression arg)#

Numerical negation, which negates a uint as a long.

Parameters:

  • arg – The operand.

static Expression conditional(Client &connection, Expression condition, Expression if_true, Expression if_false)#

The second argument if the condition is true, and the third argument otherwise.

Parameters:

  • condition – The boolean condition.

  • if_true – The value when the condition is true.

  • if_false – The value when the condition is false.

Note

Throws an exception if the two values have no common type.

Numerical addition.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Numerical subtraction.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Numerical multiplication.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Numerical division.

  • arg0 – The first operand.

  • arg1 – The second operand.

Numerical modulo operator.

  • arg0 – The first operand.

  • arg1 – The second operand.

Numerical power operator.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Returns:

arg0 raised to the power of arg1, at the common type of the operands

static Expression left_shift(Client &connection, Expression arg0, Expression arg1)#

Bitwise left shift.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Note

Only the low 5 bits of the count are used for a 32-bit value, and the low 6 bits for a 64-bit value.

static Expression right_shift(Client &connection, Expression arg0, Expression arg1)#

Bitwise right shift.

Parameters:

  • arg0 – The first operand.

  • arg1 – The second operand.

Note

Only the low 5 bits of the count are used for a 32-bit value, and the low 6 bits for a 64-bit value.

static Expression cast(Client &connection, Expression arg, Type type)#

A value cast to the given type.

Parameters:

  • arg – The value to cast.

  • type – Type to cast the argument to.

Note

A tuple or collection is cast element by element.

static Expression parameter(Client &connection, std::string name, Type type)#

A named parameter of a function.

Parameters:

  • name – The name of the parameter.

  • type – The type of the parameter.

Returns:

A named parameter.

Note

A value is bound to it by name with Expression::invoke(), or by its position in the parameters of a Expression::lambda().

static Expression lambda(Client &connection, std::vector<Expression> parameters, Expression body)#

A function with the given parameters and body.

Parameters:

  • parameters – The parameters of the function.

  • body – The body of the function.

Returns:

A function.

Note

The body is an expression or a block of statements, and a body with no value is evaluated for its effects. A Expression::return_() or Expression::return_nothing() statement ends the evaluation.

static Expression invoke(Client &connection, Expression function, std::map<std::string, Expression> args)#

A function call.

Parameters:

  • function – The function to call.

  • args – The arguments to call the function with.

Returns:

A function call.

static Expression block(Client &connection, std::vector<Expression> statements)#

A block of statements, whose value is that of its last statement.

Parameters:

  • statements – The statements.

static Expression block_with_variables(Client &connection, std::vector<Expression> variables, std::vector<Expression> statements)#

A block of statements with local variables.

Parameters:

  • variables – The local variables of the block.

  • statements – The statements.

Note

The value of the block is that of its last statement. The variables are in scope for the statements of the block, including within nested functions.

static Expression variable(Client &connection, std::string name, Type type)#

A local variable, declared by Expression::block_with_variables().

Parameters:

  • name – The name of the variable.

  • type – The type of the variable.

Returns:

A local variable.

static Expression state_variable(Client &connection, std::string name, Expression initial_value)#

A variable that keeps its value between evaluations of a function.

Parameters:

  • name – The name of the variable.

  • initial_value – The initial value of the variable.

Returns:

A state variable.

Note

The initial value is evaluated once, when the variable is created, and gives the variable its type. The value belongs to the variable, so every function that contains it shares it.

static Expression assign(Client &connection, Expression variable, Expression value)#

An assignment to a local variable, state variable or function parameter.

Parameters:

  • variable – The variable to assign to.

  • value – The value to assign.

Note

The value’s type must be assignable to the variable’s type. A numeric value of a different type is widened, and narrowing it requires a cast.

static Expression if_then(Client &connection, Expression condition, Expression body)#

An if statement, with no value.

Parameters:

  • condition – The boolean condition.

  • body – The statement evaluated when the condition is true.

Note

Use Expression::conditional() for an if-then-else that produces a value.

static Expression if_then_else(Client &connection, Expression condition, Expression body, Expression else_body)#

An if-else statement, with no value.

Parameters:

  • condition – The boolean condition.

  • body – The statement evaluated when the condition is true.

  • else_body – The statement evaluated when the condition is false.

Note

Use Expression::conditional() for an if-then-else that produces a value.

static Expression while_(Client &connection, Expression condition, Expression body)#

A while loop, which evaluates the body while the condition is true.

Parameters:

  • condition – The boolean condition.

  • body – The statement evaluated on each iteration.

Note

A Expression::break_() or Expression::continue_() in the body applies to this loop.

static Expression for_each(Client &connection, Expression variable, Expression collection, Expression body)#

A loop that evaluates the body once for each value of a collection.

Parameters:

  • variable – The loop variable.

  • collection – The collection to iterate over.

  • body – The statement evaluated on each iteration.

Note

The loop variable is a local variable declared by an enclosing Expression::block_with_variables(), or a parameter of an enclosing Expression::lambda(). A Expression::break_() or Expression::continue_() in the body applies to this loop.

static Expression break_(Client &connection)#

A break statement, which ends the enclosing loop.

static Expression continue_(Client &connection)#

A continue statement, which skips to the next iteration of the enclosing loop.

static Expression return_(Client &connection, Expression value)#

A return statement, which ends the enclosing function with a value.

Parameters:

  • value – The value to return.

static Expression return_nothing(Client &connection)#

A return statement, which ends the enclosing function with no value.

static Expression throw_(Client &connection, std::string service, std::string name, Expression message)#

A throw statement, which raises the named exception.

Parameters:

  • service – The name of the service the exception is defined in.

  • name – The name of the exception.

  • message – The message of the exception.

Note

The client receives the exception as an error from the function, or from the stream or event evaluating it. For example, the service KRPC and the name Error raise Error. Throws an exception if the service does not declare it.

static Expression try_catch(Client &connection, Expression body, std::string service, std::string name, std::optional<Expression> message, Expression handler)#

A try-catch statement that handles the named exception.

Parameters:

  • body – The statement to evaluate.

  • service – The name of the service the exception is defined in.

  • name – The name of the exception.

  • message – A string variable assigned the exception’s message, or null.

  • handler – The statement evaluated when the exception is caught.

Note

Only an exception a service declares can be named, and Expression::try_catch_all() handles any exception. Throws an exception if the service does not declare it.

static Expression try_catch_all(Client &connection, Expression body, std::optional<Expression> message, Expression handler)#

A try-catch statement that handles any exception.

Parameters:

  • body – The statement to evaluate.

  • message – A string variable assigned the exception’s message, or null.

  • handler – The statement evaluated when an exception is caught.

static Expression try_finally(Client &connection, Expression body, Expression finalizer)#

A try-finally statement.

Parameters:

  • body – The statement to evaluate.

  • finalizer – The statement evaluated after the body.

Note

The finalizer is evaluated after the body, whether or not the body raises an exception. A break, continue or return cannot leave the finalizer.

static Expression create_tuple(Client &connection, std::vector<Expression> elements)#

A tuple of the given elements. Throws an exception if there are no elements or more than seven.

Parameters:

  • elements – The elements.

Returns:

The tuple.

static Expression create_struct(Client &connection, Type type, std::vector<Expression> field_values)#

A structure with the given field values. Throws an exception if the field values do not match its fields.

Parameters:

  • type – The type of the structure.

  • field_values – The values of the structure’s fields, in the order the structure declares them.

Returns:

The structure.

static Expression create_list(Client &connection, std::vector<Expression> values)#

A list of the given values, with numbers widened to their common type. Throws an exception if there are no values.

Parameters:

  • values – The values.

Returns:

The list.

static Expression create_set(Client &connection, std::set<Expression> values)#

A set of the given values, with numbers widened to their common type. Throws an exception if there are no values, or a value is null.

Parameters:

  • values – The values.

Returns:

The set.

Note

The values are evaluated in an unspecified order.

static Expression create_dictionary(Client &connection, std::vector<Expression> keys, std::vector<Expression> values)#

A dictionary of the given keys and corresponding values, with numbers widened to their common type. Throws an exception if there are no keys, the counts differ, the keys are not of a valid key type, or a key is null.

Parameters:

  • keys – The keys.

  • values – The values.

Returns:

The dictionary.

Note

A repeated key takes the last of its values.

static Expression create_empty_list(Client &connection, Type value_type)#

An empty list of the given value type.

Parameters:

  • value_type – The type of the values the list holds.

Returns:

The empty list.

static Expression create_empty_set(Client &connection, Type value_type)#

An empty set of the given value type. Throws an exception if the value type is nullable.

Parameters:

  • value_type – The type of the values the set holds.

Returns:

The empty set.

static Expression create_empty_dictionary(Client &connection, Type key_type, Type value_type)#

An empty dictionary of the given key and value types. Throws an exception if the key type is nullable or not a valid key type.
