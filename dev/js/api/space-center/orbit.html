Orbit#

class SpaceCenter.Orbit()#

Describes an orbit. For example, the orbit of a vessel, obtained by calling SpaceCenter.Vessel.getOrbit(), or a celestial body, obtained by calling SpaceCenter.CelestialBody.getOrbit().

Orbit.createFromPositionAndVelocity(body, position, velocity, ut[, referenceFrame])#

Create the orbit that passes through a given position at a given velocity. The orbit coasts freely under the gravity of the body being orbited, so it describes where an object left to fall from that position and velocity would be at any later time.

Arguments:

  • body (SpaceCenter.CelestialBody) – The celestial body being orbited.

  • position ([number, number, number]) – The position, as a position vector.

  • velocity ([number, number, number]) – The velocity, as a vector pointing in the direction of travel, whose magnitude is the speed in \(\mathrm{m/s}\).

  • ut (number) – The universal time, in seconds, at which the object is at position traveling at velocity.

  • referenceFrame (SpaceCenter.ReferenceFrame or null) – The reference frame that position and velocity are in. Defaults to SpaceCenter.CelestialBody.getNonRotatingReferenceFrame() of body.

Return type:

SpaceCenter.Orbit

Note

The orbit is a single conic around body. It never changes sphere of influence, so SpaceCenter.Orbit.getNextOrbit() is null, and no atmosphere slows it. A vessel held on rails follows its own orbit exactly, while one inside the physics bubble is simulated and drifts from it a little.

SpaceCenter.Orbit.getRadius(), SpaceCenter.Orbit.getSpeed(), SpaceCenter.Orbit.position(), SpaceCenter.Orbit.velocity() and the like describe the orbit at ut and stay there. Use SpaceCenter.Orbit.radiusAt(), SpaceCenter.Orbit.speedAt(), SpaceCenter.Orbit.positionAt(), SpaceCenter.Orbit.velocityAt() and SpaceCenter.Orbit.trueAnomalyAtUT() for another time, and SpaceCenter.Orbit.getReferenceFrame() and SpaceCenter.Orbit.getOrbitalReferenceFrame() to follow the orbit as time passes.

The orbit is held until SpaceCenter.Orbit.remove() is called on it or the client that created it disconnects. Remove each one created by a script that creates them repeatedly, for example once per update.

Orbit.createFromOrbitalElements(body, semiMajorAxis, eccentricity, inclination, longitudeOfAscendingNode, argumentOfPeriapsis, meanAnomalyAtEpoch, epoch)#

Create the orbit with the given orbital elements around a given body. The orbit coasts freely under the gravity of that body, so it describes where an object on it would be at any time.

Arguments:

  • body (SpaceCenter.CelestialBody) – The celestial body being orbited.

  • semiMajorAxis (number) – The semi-major axis of the orbit, in meters. Positive for an ellipse and negative for a hyperbola.

  • eccentricity (number) – The eccentricity of the orbit. Below one for an ellipse and above one for a hyperbola.

  • inclination (number) – The inclination of the orbit, in radians.

  • longitudeOfAscendingNode (number) – The longitude of the ascending node, in radians.

  • argumentOfPeriapsis (number) – The argument of periapsis, in radians.

  • meanAnomalyAtEpoch (number) – The mean anomaly at epoch, in radians.

  • epoch (number) – The universal time, in seconds, that meanAnomalyAtEpoch is measured at.

Return type:

SpaceCenter.Orbit

Note

The orbit is a single conic around body. It never changes sphere of influence, so SpaceCenter.Orbit.getNextOrbit() is null, and no atmosphere slows it.

The angles are measured against the reference plane and direction that SpaceCenter.Orbit.getInclination(), SpaceCenter.Orbit.getLongitudeOfAscendingNode() and SpaceCenter.Orbit.getArgumentOfPeriapsis() report them against. SpaceCenter.Orbit.referencePlaneNormal() and SpaceCenter.Orbit.referencePlaneDirection() give these as vectors in a reference frame.

SpaceCenter.Orbit.getRadius(), SpaceCenter.Orbit.getSpeed(), SpaceCenter.Orbit.position(), SpaceCenter.Orbit.velocity() and the like describe the orbit at epoch and stay there. Use SpaceCenter.Orbit.radiusAt(), SpaceCenter.Orbit.speedAt(), SpaceCenter.Orbit.positionAt(), SpaceCenter.Orbit.velocityAt() and SpaceCenter.Orbit.trueAnomalyAtUT() for another time, and SpaceCenter.Orbit.getReferenceFrame() and SpaceCenter.Orbit.getOrbitalReferenceFrame() to follow the orbit as time passes.

The orbit is held until SpaceCenter.Orbit.remove() is called on it or the client that created it disconnects. Remove each one created by a script that creates them repeatedly, for example once per update.

Orbit.remove()#

Remove the orbit, releasing the memory the server holds for it.

Note

Only an orbit created by SpaceCenter.Orbit.createFromPositionAndVelocity() or SpaceCenter.Orbit.createFromOrbitalElements() can be removed. Every other orbit belongs to something in the game, and the server holds one of each.

Any further use of this object throws an exception, as does use of a reference frame defined against it. An orbit belongs to the client that created it, and is removed when that client disconnects.

Orbit.getBody()#

The celestial body (e.g. planet or moon) around which the object is orbiting.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.CelestialBody

Orbit.getReferenceFrame()#

The reference frame that moves along the orbit, and is orientated in a fixed direction.

  • The origin is at the point the orbit has reached at the current time.

  • The axes do not rotate. They point in the same fixed directions as those of SpaceCenter.CelestialBody.getNonRotatingReferenceFrame() of SpaceCenter.Orbit.getBody().

Property:

Read-only, cannot be set

Return type:

SpaceCenter.ReferenceFrame

Note

For the orbit of a vessel, the origin is the point the vessel’s orbit has reached rather than the vessel’s own center of mass. The two are a few meters apart, as a vessel inside the physics bubble is simulated rather than being held on its orbit.

Orbit.getOrbitalReferenceFrame()#

The reference frame that moves along the orbit, and is orientated with its prograde/normal/radial directions.

  • The origin is at the point the orbit has reached at the current time.

  • The axes rotate with the orbital prograde/normal/radial directions.

  • The x-axis points in the orbital anti-radial direction.

  • The y-axis points in the orbital prograde direction.

  • The z-axis points in the orbital normal direction.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.ReferenceFrame

Note

For the orbit of a vessel, the origin is the point the vessel’s orbit has reached rather than the vessel’s own center of mass, which is what SpaceCenter.Vessel.getOrbitalReferenceFrame() is centered on.

Orbit.getApoapsis()#

Gets the apoapsis of the orbit, in meters, from the center of mass of the body being orbited.

Property:

Read-only, cannot be set

Return type:

number

Note

For the apoapsis altitude reported on the in-game map view, use SpaceCenter.Orbit.getApoapsisAltitude().

Orbit.getPeriapsis()#

The periapsis of the orbit, in meters, from the center of mass of the body being orbited.

Property:

Read-only, cannot be set

Return type:

number

Note

For the periapsis altitude reported on the in-game map view, use SpaceCenter.Orbit.getPeriapsisAltitude().

Orbit.getApoapsisAltitude()#

The apoapsis of the orbit, in meters, above the sea level of the body being orbited.

Property:

Read-only, cannot be set

Return type:

number

Note

This is equal to SpaceCenter.Orbit.getApoapsis() minus the equatorial radius of the body.

Orbit.getPeriapsisAltitude()#

The periapsis of the orbit, in meters, above the sea level of the body being orbited.

Property:

Read-only, cannot be set

Return type:

number

Note

This is equal to SpaceCenter.Orbit.getPeriapsis() minus the equatorial radius of the body.

Orbit.getSemiMajorAxis()#

The semi-major axis of the orbit, in meters.

Property:

Read-only, cannot be set

Return type:

number

Orbit.getSemiMinorAxis()#

The semi-minor axis of the orbit, in meters.

Property:

Read-only, cannot be set
