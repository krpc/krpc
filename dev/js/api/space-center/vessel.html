Vessel#

class SpaceCenter.Vessel()#

These objects are used to interact with vessels in KSP. This includes getting orbital and flight data, manipulating control inputs and managing resources. Created using SpaceCenter.getActiveVessel() or SpaceCenter.getVessels().

Vessel.getName()#
Vessel.setName(value)#

The name of the vessel.

Property:

Can be read or written

Return type:

string

Vessel.getType()#
Vessel.setType(value)#

The type of the vessel.

Property:

Can be read or written

Return type:

SpaceCenter.VesselType

Vessel.getSituation()#

The situation the vessel is in.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.VesselSituation

Vessel.getLoaded()#

Whether the vessel is loaded, i.e. its parts are instantiated in the scene because it is within loading range of the active vessel. A vessel that is not loaded exists only as orbital data and is always on-rails (see SpaceCenter.Vessel.getPacked()).

Property:

Read-only, cannot be set

Return type:

boolean

Vessel.getPacked()#

Whether the vessel is packed (on-rails). A packed vessel has its physics simulation suspended and follows its orbit analytically. A vessel that is not loaded (see SpaceCenter.Vessel.getLoaded()) is always packed.

Property:

Read-only, cannot be set

Return type:

boolean

Vessel.getPhysicsRange()#
Vessel.setPhysicsRange(value)#

The distance from the active vessel, in meters, out to which this vessel keeps running its physics simulation, and so stays controllable, able to burn its engines and respond to its autopilot. Setting this raises the vessel out of the stock physics bubble, so that it keeps flying while the active vessel is far away. Set to zero to restore the game’s default range.

Property:

Can be read or written

Return type:

number

Game Scenes:

Flight

Note

This always reports the vessel’s live range, so reading it when no range has been set gives the game’s default for the vessel’s current SpaceCenter.Vessel.getSituation(), which is much shorter than the distance at which the vessel unloads. In orbit a vessel is put on rails just 350m away, long before it unloads at 2.5km, and a vessel on rails produces no thrust and ignores control input even though it is still loaded.

There is a 10% margin below the range, so that a vessel hovering at the threshold does not repeatedly drop out of the simulation and rejoin it. The vessel leaves the simulation at the distance set here, and rejoins it at 90% of that distance; in between it keeps whichever state it is already in.

The requested range applies in every situation. The game’s own defaults are not uniform, and a vessel flying in atmosphere stays loaded out to 22.5km, so setting a small range can shorten the range such a vessel would otherwise have had.

A range lasts until it is set back to zero or the game is exited. Unlike most state a client sets, it is not released when that client disconnects, because dropping a distant vessel back to the default range would put it on-rails part way through a maneuver.

Holding a vessel off-rails a long way from the active vessel costs performance, and accumulates positional error that can destroy it. Raise the range on the vessels that need it, by as little as they need.

Vessel.getRecoverable()#

Whether the vessel is recoverable.

Property:

Read-only, cannot be set

Return type:

boolean

Vessel.recover()#

Recover the vessel. The crew return to the astronaut complex, and the funds and science the vessel is worth are awarded.

Note

Recovering the active vessel ends the flight and returns to the space center, as pressing recover in game does. When a non-active vessel is recovered the current scene is unaffected, and the mission completion dialog is not shown, so a script flying several vessels keeps control of the rest of them.

Returns immediately, does not wait for the vessel to be recovered.

Vessel.terminate()#

Terminate the vessel. The vessel and its parts are removed from the game, and its crew are lost, as when the vessel is terminated from the tracking station. Nothing is recovered: no funds, no science and no crew.

Note

The crew are reported missing, and return to the astronaut complex once their respawn timer expires, or never if the game is set up so that missing crews do not respawn.

The active vessel cannot be terminated, because the vessel being flown cannot be taken out of the scene it is being flown in. Switch to another vessel first, or use SpaceCenter.Vessel.recover(), which ends the flight and returns to the space center.

Returns immediately, does not wait for the vessel to be terminated.

Vessel.getMET()#

The mission elapsed time in seconds.

Property:

Read-only, cannot be set

Return type:

number

Vessel.getLaunchSite()#

The launch site the vessel was launched from, or null if the vessel was not launched from a known launch site, such as a vessel spawned by a contract.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.LaunchSite or null

Vessel.getBiome()#

The name of the biome the vessel is currently in.

Property:

Read-only, cannot be set

Return type:

string

Vessel.flight([referenceFrame])#

Returns a SpaceCenter.Flight object that can be used to get flight telemetry for the vessel, in the specified reference frame.

Arguments:

  • referenceFrame (SpaceCenter.ReferenceFrame or null) – Reference frame. Defaults to the vessel’s surface reference frame (SpaceCenter.Vessel.getSurfaceReferenceFrame()).

Return type:

SpaceCenter.Flight

Game Scenes:

Flight

Note

When this is called with no arguments, the vessel’s surface reference frame is used. This reference frame moves with the vessel, therefore velocities and speeds returned by the flight object will be zero. See the reference frames guide for examples of getting the orbital and surface speeds of a vessel.

Vessel.getOrbit()#

The current orbit of the vessel.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.Orbit

Vessel.getControl()#

Returns a SpaceCenter.Vessel.getControl() object that can be used to manipulate the vessel’s control inputs. For example, its pitch/yaw/roll controls, RCS and thrust.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.Control

Game Scenes:

Flight

Vessel.getComms()#

Returns a SpaceCenter.Vessel.getComms() object that can be used to interact with CommNet for this vessel.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.Comms

Game Scenes:

Flight

Vessel.getAutoPilot()#

An SpaceCenter.Vessel.getAutoPilot() object, that can be used to perform simple auto-piloting of the vessel.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.AutoPilot

Game Scenes:

Flight

Vessel.getCrewCapacity()#

The number of crew that can occupy the vessel.

Property:

Read-only, cannot be set

Return type:

number

Vessel.getCrewCount()#

The number of crew that are occupying the vessel.

Property:

Read-only, cannot be set

Return type:

number

Vessel.getCrew()#

The crew in the vessel.

Property:

Read-only, cannot be set

Return type:

Array of SpaceCenter.CrewMember

Vessel.getResources()#

A SpaceCenter.Vessel.getResources() object, that can used to get information about resources stored in the vessel.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.Resources

Game Scenes:

Flight

Vessel.getStages()#

Activation (burn) stages for this vessel, in ascending stage order. This does not include the -1 stage (parts with no staging icon), as it carries no delta-v; use SpaceCenter.Vessel.stageAt() with -1 to get those parts.

Property:

Read-only, cannot be set

Return type:

Array of SpaceCenter.Stage

Game Scenes:

Flight

Note

Lists activation stages only (decouple is false). See also Staging.

Vessel.stageAt(stage)#

The activation stage with the given number. Pass -1 to get the parts that are never activated (those with no staging icon).

Arguments:

  • stage (number) – Get activation stage at this index.

Return type:

SpaceCenter.Stage

Game Scenes:

Vessel.getSurfaceReferenceFrame()#

The reference frame that is fixed relative to the vessel, and orientated with the surface of the body being orbited.

  • The origin is at the center of mass of the vessel.

  • The axes rotate with the north and up directions on the surface of the body.

  • The x-axis points in the zenith direction (upwards, normal to the body being orbited, from the center of the body towards the center of mass of the vessel).

  • The y-axis points northwards towards the astronomical horizon (north, and tangential to the surface of the body – the direction in which a compass would point when on the surface).

  • The z-axis points eastwards towards the astronomical horizon (east, and tangential to the surface of the body – east on a compass when on the surface).

Vessel.getSurfaceSpeedReferenceFrame()#

The reference frame that the navball measures speed against in ‘surface’ mode.

  • The origin is at the center of mass of the vessel.

  • The axes are the directions the navball marks in this mode, in the same arrangement as SpaceCenter.Vessel.getOrbitalReferenceFrame(): the y-axis points in the direction the vessel is moving relative to the surface, which is where the prograde marker points; the z-axis is normal to the plane of that motion; and the x-axis is anti-radial, pointing towards the body and perpendicular to the other two.

  • The frame moves with the surface of the body being orbited, so it rotates with the body.

Property:

Read-only, cannot be set

Return type:

SpaceCenter.ReferenceFrame

Game Scenes:

The velocity gives the frame its orientation, so, as with SpaceCenter.Vessel.getSurfaceVelocityReferenceFrame(), the frame is singular and raises an error when the vessel is stationary relative to the surface.

CrewMember.eva()#

Send the crew member outside on EVA, through the hatch of the part it is in, and return the vessel it becomes. The game switches to that vessel, which can then be walked around and flown using its SpaceCenter.Vessel.getControl(), and brought back in with SpaceCenter.Control.board(). The kerbal climbs out onto the ladder by the hatch, if there is one.

Return type:

SpaceCenter.Vessel

Game Scenes:

Flight

Note

Throws an exception if EVA is disabled for the game, if the crew member is not in a loaded vessel, if it is already on EVA, or if every hatch out of the part it is in is obstructed.
