ManeuverPlanner#

class MechJeb.ManeuverPlanner()#

The Maneuver Planner window, which makes maneuver nodes for its operations, and executes them.

Note

MechJeb shares the operations, and most of their settings, between vessels.

ManeuverPlanner.getOperationAdvancedTransfer()#

The operation that transfers to another planet, at the departure that needs the least delta-v.

Property:

Read-only, cannot be set

Return type:

MechJeb.OperationAdvancedTransfer

Game Scenes:

Flight

The operation that changes the apoapsis.

Property:

Read-only, cannot be set

Return type:

class MechJeb.TimeReference()#

The time reference of a maneuver. See MechJeb.TimeSelector.getTimeReference().

TimeReference.computed#

At the optimum time.

TimeReference.xFromNow#

After MechJeb.TimeSelector.getLeadTime().

TimeReference.apoapsis#

class MechJeb.OperationResonantOrbit()#

Change to a resonant orbit, to place satellites in a constellation.
