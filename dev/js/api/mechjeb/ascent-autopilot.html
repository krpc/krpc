AscentAutopilot#

class MechJeb.AscentAutopilot()#

The ascent autopilot.

Note

See the MechJeb wiki for how to set up this autopilot.

AscentAutopilot.getEnabled()#
AscentAutopilot.setEnabled(value)#

Whether the autopilot is enabled. Enabling it engages the autopilot of the selected ascent path, and disabling it disengages the autopilots of both paths.

Property:

Can be read or written

Return type:

boolean

Game Scenes:

Flight

AscentAutopilot.getStatus()#

The autopilot status, which depends on the selected ascent path.

Property:

Read-only, cannot be set

Return type:

string

Game Scenes:

Flight

AscentAutopilot.getAscentPathIndex()#
AscentAutopilot.setAscentPathIndex(value)#

The selected ascent path: 0 for MechJeb.AscentClassic or 2 for MechJeb.AscentPVG.

Property:

Can be read or written

Return type:

number

Game Scenes:

Flight

Note

MechJeb 2.15 removed the stock-style gravity turn path, which was 1. Setting any other value throws an exception.

Game Scenes:

Game Scenes:

Flight

class MechJeb.AscentLaunchMode()#

The launch mode of the ascent autopilot. See MechJeb.AscentAutopilot.getLaunchMode().

AscentLaunchMode.normal#

The autopilot is not performing a timed launch.

AscentLaunchMode.rendezvous#

A timed launch to rendezvous with the target vessel.

AscentLaunchMode.targetPlane#

A timed launch into the plane of the target.

AscentLaunchMode.unknown#

A timed launch of another kind, started from MechJeb’s window.
