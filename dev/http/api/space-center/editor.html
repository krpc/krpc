Editor#

Editor

Provides access to the vehicle assembly building and space plane hangar. Obtained by calling GET /space-center/editor.

A Editor object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /space-center/editor/(id)/facility#

The editor that is currently open.

Parameters:

  • id – The identifier of the Editor object.

Response JSON Object:

  • value (SpaceCenter.EditorFacility)

GET /space-center/editor/(id)/vessel#

The vessel that is being constructed.

Note

An editor that has not had a vessel loaded into it holds an empty vessel, with no parts, rather than nothing at all.

Parameters:

  • id – The identifier of the Editor object.

Response JSON Object:

  • value (SpaceCenter.EditorVessel)

POST /space-center/editor/(id)/load-vessel#

Load a vessel from a craft file into the editor, replacing the vessel that is currently being constructed.

Note

The vessel is loaded into whichever editor is open, regardless of which directory it came from. Its delta-v figures are recalculated in the background afterwards; see GET /space-center/editor-vessel/(id)/delta-v-ready.

Parameters:

  • id – The identifier of the Editor object.

Request JSON Object:

  • craft_directory (string) – Name of the directory in the current saves “Ships” directory, that contains the craft file. For example "VAB" or "SPH".

  • name (string) – Name of the vessel to load. This is the name of the “.craft” file in the save directory, without the “.craft” file extension.

POST /space-center/editor/(id)/launch-vessel#

Launch the vessel that is being constructed, from the given launch site.

Note

The vessel being constructed is not a craft file, so it is written to the editor’s auto-saved craft file and that is launched, as the game’s own launch button does. The vessel’s own craft file, if it was loaded from one, is left alone. The crew parameter works as it does for POST /space-center/launch-vessel, and takes precedence over the crew assigned in the editor. Throws an exception if any of the games pre-flight checks fail.

Parameters:

  • id – The identifier of the Editor object.

Request JSON Object:

  • launch_site (string) – Name of the launch site. For example "LaunchPad" or "Runway".

  • crew (list<string>?) – The Kerbals to place in the vessel, by name. Controls how the vessel is crewed, as described in the remarks. Optional, defaults to null.

  • recover (bool) – If true and there is a vessel on the launch site, recover it before launching. Optional, defaults to true.

  • flag_url (string) – If not null, the asset URL of the mission flag to use for the launch. Optional, defaults to "".

GET /space-center/editor/(id)/delta-v-body#

The body whose gravity and atmosphere the vessel’s delta-v, thrust, TWR and specific impulse figures assume.

Note

This and GET /space-center/editor/(id)/delta-v-altitude are what GET /space-center/editor-vessel/(id)/delta-v, GET /space-center/stage/(id)/delta-v and the other current-situation figures are computed for. The body sets the gravity the thrust-to-weight ratios are against, and, with the altitude, the atmospheric pressure and density the specific impulses and thrusts are against. This is global game state rather than editor state: the same setting backs the game’s delta-v readout in flight, and it persists across scene changes. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until GET /space-center/editor-vessel/(id)/delta-v-ready is true again.

Parameters:

  • id – The identifier of the Editor object.

Response JSON Object:

  • value (SpaceCenter.CelestialBody)

PUT /space-center/editor/(id)/delta-v-body#

The body whose gravity and atmosphere the vessel’s delta-v, thrust, TWR and specific impulse figures assume.

Note

This and GET /space-center/editor/(id)/delta-v-altitude are what GET /space-center/editor-vessel/(id)/delta-v, GET /space-center/stage/(id)/delta-v and the other current-situation figures are computed for. The body sets the gravity the thrust-to-weight ratios are against, and, with the altitude, the atmospheric pressure and density the specific impulses and thrusts are against. Parameters:

  • id – The identifier of the Editor object.

Request JSON Object:

  • value (SpaceCenter.CelestialBody) – The new value.

GET /space-center/editor/(id)/delta-v-altitude#

The altitude above GET /space-center/editor/(id)/delta-v-body, in meters, that the vessel’s delta-v, thrust, TWR and specific impulse figures assume. The atmospheric pressure and density at this altitude are what the figures are computed for, so raising it from zero to above the body’s atmosphere moves them from the vessel’s sea-level figures to its vacuum ones. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until GET /space-center/editor-vessel/(id)/delta-v-ready is true again.

Parameters:

  • id – The identifier of the Editor object.

Response JSON Object:

  • value (double)

PUT /space-center/editor/(id)/delta-v-altitude#

The altitude above GET /space-center/editor/(id)/delta-v-body, in meters, that the vessel’s delta-v, thrust, TWR and specific impulse figures assume. Request JSON Object:

  • value (double) – The new value.

GET /space-center/editor/(id)/delta-v-situation#

Which situation the game’s own delta-v readout shows figures for.

Note

This selects which column the game’s own delta-v app displays, and nothing else. It does not affect anything kRPC reports: the current-situation figures follow GET /space-center/editor/(id)/delta-v-body and GET /space-center/editor/(id)/delta-v-altitude whatever this is set to, and the sea-level and vacuum figures are reported directly as GET /space-center/editor-vessel/(id)/sea-level-delta-v and GET /space-center/editor-vessel/(id)/vacuum-delta-v. It is here for completeness with the app.

Parameters:

  • id – The identifier of the Editor object.

Response JSON Object:

  • value (SpaceCenter.DeltaVSituation)

Request JSON Object:

  • value (SpaceCenter.DeltaVSituation) – The new value.

DeltaVSituation

The situation the game’s own delta-v readout shows figures for. See GET /space-center/editor/(id)/delta-v-situation.

Passed and returned as the name of one of its values:

"sea_level"

At sea level on the selected body.

"altitude"

At the selected altitude on the selected body.

"vacuum"

In vacuum.

EditorVessel

The vessel that is being constructed in the editor. Obtained by calling GET /space-center/editor/(id)/vessel.

A EditorVessel object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /space-center/editor-vessel/(id)/reference-frame#

The reference frame that is fixed relative to the vessel, and orientated with the vessel.

  • The origin is at the center of mass of the vessel.

  • The axes rotate with the vessel.

  • The x-axis points out to the right of the vessel.

  • The y-axis points in the forward direction of the vessel.

  • The z-axis points out of the bottom off the vessel.

Note

The axes are those of the root part. This is the frame GET /space-center/vessel/(id)/reference-frame gives at launch, with the root part as the control point.

Parameters:

  • id – The identifier of the EditorVessel object.

Response JSON Object:

  • value (SpaceCenter.ReferenceFrame)

GET /space-center/editor-vessel/(id)/surface-reference-frame#

The reference frame that is fixed relative to the vessel, and orientated with the vertical of the editor.

  • The origin is at the center of mass of the vessel.

  • The axes are fixed in the editor.

  • The x-axis points upwards.

  • The y-axis and z-axis are horizontal.

Note

This is the vessel as it stands in the editor, and as it stands at launch. The editor has no north or east, so the horizontal axes are fixed in the editor.

Parameters:

  • id – The identifier of the EditorVessel object.

Response JSON Object:

  • value (SpaceCenter.ReferenceFrame)

GET /space-center/editor-vessel/(id)/delta-v-ready#

Whether the stock delta-v figures for the vessel have been calculated.

Note

The game recalculates them in the background whenever the vessel changes, and whenever GET /space-center/editor/(id)/delta-v-body or GET /space-center/editor/(id)/delta-v-altitude is set, and they are out of date until it has finished. Reading GET /space-center/editor-vessel/(id)/delta-v, or any delta-v member of a Stage, before then raises an error rather than returning a stale figure. Poll this after changing anything the figures depend on.

Parameters:

  • id – The identifier of the EditorVessel object.

SimulatedFlight

Used to simulate the vessel in the editor in flight. The counterpart of Flight. All of the information returned by this class is given in the reference frame passed to POST /space-center/editor-vessel/(id)/flight, or in GET /space-center/simulated-flight/(id)/surface-reference-frame if none was passed. Obtained by calling POST /space-center/editor-vessel/(id)/flight.

Note

The simulated attitude is set by GET /space-center/simulated-flight/(id)/surface-reference-frame, and belongs to this object. The vessel is read from the editor on each call, so the object follows every edit.

A SimulatedFlight object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /space-center/simulated-flight/(id)/surface-reference-frame#

The reference frame of the surface the vessel is simulated over. Its x-axis points upwards, and gravity acts along the negative x-axis. Defaults to GET /space-center/editor-vessel/(id)/surface-reference-frame.

Note

Only the rotation of the frame is used. A frame created relative to GET /space-center/editor-vessel/(id)/reference-frame follows the vessel as it is edited.

Parameters:

  • id – The identifier of the SimulatedFlight object.

Response JSON Object:

  • value (SpaceCenter.ReferenceFrame)
