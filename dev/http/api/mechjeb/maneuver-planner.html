ManeuverPlanner#

ManeuverPlanner

The Maneuver Planner window, which makes maneuver nodes for its operations, and executes them.

Note

MechJeb shares the operations, and most of their settings, between vessels.

A ManeuverPlanner object is passed and returned as its identifier, a number. A path that acts on an object takes it as (id).

GET /mech-jeb/maneuver-planner/(id)/operation-advanced-transfer#

The operation that transfers to another planet, at the departure that needs the least delta-v.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationAdvancedTransfer)

GET /mech-jeb/maneuver-planner/(id)/operation-apoapsis#

The operation that changes the apoapsis.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationApoapsis)

GET /mech-jeb/maneuver-planner/(id)/operation-circularize#

The operation that circularizes the orbit.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationCircularize)

GET /mech-jeb/maneuver-planner/(id)/operation-course-correction#

The operation that fine tunes the closest approach to the target.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationCourseCorrection)

GET /mech-jeb/maneuver-planner/(id)/operation-eccentricity#

The operation that changes the eccentricity.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationEccentricity)

GET /mech-jeb/maneuver-planner/(id)/operation-ellipticize#

The operation that changes both the periapsis and the apoapsis.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (MechJeb.OperationEllipticize)

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

Response JSON Object:

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

POST /mech-jeb/maneuver-planner/(id)/abort-node-execution#

Stop executing the maneuver nodes.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

POST /mech-jeb/maneuver-planner/(id)/execute-all-nodes#

Execute all the maneuver nodes. Throws an exception if the vessel has no maneuver node.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

POST /mech-jeb/maneuver-planner/(id)/execute-next-node#

Execute the next maneuver node. Throws an exception if the vessel has no maneuver node.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

GET /mech-jeb/maneuver-planner/(id)/autowarp#

Whether to warp time to the burn.

Note

The same setting as GET /mech-jeb/ascent-settings/(id)/autowarp, GET /mech-jeb/landing-guidance/(id)/autowarp and GET /mech-jeb/rendezvous-autopilot/(id)/autowarp.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (bool)

PUT /mech-jeb/maneuver-planner/(id)/autowarp#

Whether to warp time to the burn.

Note

The same setting as GET /mech-jeb/ascent-settings/(id)/autowarp, GET /mech-jeb/landing-guidance/(id)/autowarp and GET /mech-jeb/rendezvous-autopilot/(id)/autowarp.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Request JSON Object:

  • value (bool) – The new value.

GET /mech-jeb/maneuver-planner/(id)/executing-node#

Whether a maneuver node is being executed.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (bool)

GET /mech-jeb/maneuver-planner/(id)/lead-time#

The time before the burn at which time warp stops, in seconds.

Parameters:

  • id – The identifier of the ManeuverPlanner object.

Response JSON Object:

  • value (double)

PUT /mech-jeb/maneuver-planner/(id)/lead-time#

OperationResonantOrbit
