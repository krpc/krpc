Expressions#

The nodes a server side function is built from, and the types they work with. See the server side functions guide for how a function is assembled and run.

public class Expression#

A server side expression.

Note

Numeric operands of differing types are converted to a common type.

Type getReturnType()#

The type of the value the expression evaluates to. Throws an exception if the value cannot be sent to a client.

Note

A function created with Expression.lambda(java.util.List<Expression>, Expression) evaluates to the value it returns. A lazily evaluated collection, such as from Expression.select(Expression, Expression), is sent once converted by Expression.toList(Expression) or Expression.toSet(Expression).

boolean getHasReturnType()#

Whether the expression evaluates to a value.

Note

An expression with no value has no Expression.getReturnType(). An empty collection and no value both encode to an empty sequence of bytes.

java.util.List<Type> getParameterTypes()#

The types of the function’s parameters.

Note

Empty for a function that is not created with Expression.lambda(java.util.List<Expression>, Expression).

static Expression call(Connection connection, krpc.schema.KRPC.ProcedureCall call)#

An RPC call.

Parameters:

  • call (krpc.schema.KRPC.ProcedureCall) – The procedure call.

Note

The instance the call is made on, and the values of its arguments, are fixed when the expression is created. A call to a procedure with no return value is evaluated for its effects, as a statement in a Expression.block(java.util.List<Expression>). A collection the procedure returns is copied, as a client would receive it.

static Expression callWithArguments(Connection connection, krpc.schema.KRPC.ProcedureCall call, java.util.Map<Integer, Expression> args)#

An RPC call, where some or all of the arguments are computed by expressions.

Parameters:

  • call (krpc.schema.KRPC.ProcedureCall) – The RPC to call.

  • args (java.util.Map) – Expressions computing the call’s arguments, by position.

Note

Position 0 is the instance of a class method or property. A position with no expression takes the argument encoded in the call, or the parameter’s default. A collection the procedure returns is copied, as a client would receive it.

static Expression equal(Connection connection, Expression arg0, Expression arg1)#

Equality comparison.

Parameters:

  • arg0 (Expression) – The first operand.

  • arg1 (Expression) – The second operand.

Note

Collections, tuples, bytes and structures compare by their contents. Throws an exception if the operands are of unrelated types.

Bitwise left shift.

Parameters:

  • arg1 (Expression) – The second operand.

Note

  • type (Type) – Type to cast the argument to.

static Expression parameter(Connection connection, String name, Type type)#

A named parameter of a function.

Parameters:

  • name (String) – The name of the parameter.

  • type (Type) – The type of the parameter.

Returns:

A named parameter.

Note

A value is bound to it by name with Expression.invoke(Expression, java.util.Map<String,Expression>), or by its position in the parameters of a Expression.lambda(java.util.List<Expression>, Expression).

static Expression lambda(Connection connection, java.util.List<Expression> parameters, Expression body)#

A function with the given parameters and body.

Parameters:

  • parameters (java.util.List) – The parameters of the function.

  • body (Expression) – The body of the function.

Returns:

A function.

Note

The body is an expression or a block of statements, and a body with no value is evaluated for its effects. A Expression.return_(Expression) or Expression.returnNothing() statement ends the evaluation.

static Expression block(Connection connection, java.util.List<Expression> statements)#

A block of statements, whose value is that of its last statement.

  • statements (java.util.List) – The statements.

static Expression blockWithVariables(Connection connection, java.util.List<Expression> variables, java.util.List<Expression> statements)#

A block of statements with local variables.

Parameters:

  • variables (java.util.List) – The local variables of the block.

  • statements (java.util.List) – The statements.

Note

The value of the block is that of its last statement. The variables are in scope for the statements of the block, including within nested functions.

static Expression variable(Connection connection, String name, Type type)#

A local variable, declared by Expression.blockWithVariables(java.util.List<Expression>, java.util.List<Expression>).

Parameters:

  • type (Type) – The type of the variable.

Returns:

A local variable.

static Expression stateVariable(Connection connection, String name, Expression initialValue)#

A variable that keeps its value between evaluations of a function.

Parameters:

  • name (String) – The name of the variable.

  • initialValue (Expression) – The initial value of the variable.

Returns:

A state variable.

Note

The initial value is evaluated once, when the variable is created, and gives the variable its type. The value belongs to the variable, so every function that contains it shares it.

static Expression assign(Connection connection, Expression variable, Expression value)#

An assignment to a local variable, state variable or function parameter.

Parameters:

  • variable (Expression) – The variable to assign to.

  • value (Expression) – The value to assign.

Note

The value’s type must be assignable to the variable’s type. A numeric value of a different type is widened, and narrowing it requires a cast.

static Expression ifThen(Connection connection, Expression condition, Expression body)#

An if statement, with no value.

Parameters:

  • condition (Expression) – The boolean condition.

  • body (Expression) – The statement evaluated when the condition is true.

Note

Use Expression.conditional(Expression, Expression, Expression) for an if-then-else that produces a value.

static Expression ifThenElse(Connection connection, Expression condition, Expression body, Expression elseBody)#

An if-else statement, with no value.

Parameters:

  • condition (Expression) – The boolean condition.

  • body (Expression) – The statement evaluated when the condition is true.

  • elseBody (Expression) – The statement evaluated when the condition is false.

Note

Use Expression.conditional(Expression, Expression, Expression) for an if-then-else that produces a value.

static Expression while_(Connection connection, Expression condition, Expression body)#

A while loop, which evaluates the body while the condition is true.

Parameters:

  • condition (Expression) – The boolean condition.

  • body (Expression) – The statement evaluated on each iteration.

Note

A Expression.break_() or Expression.continue_() in the body applies to this loop.

static Expression forEach(Connection connection, Expression variable, Expression collection, Expression body)#

A loop that evaluates the body once for each value of a collection.

Parameters:

  • variable (Expression) – The loop variable.

  • collection (Expression) – The collection to iterate over.

  • body (Expression) – The statement evaluated on each iteration.

Note

The loop variable is a local variable declared by an enclosing Expression.blockWithVariables(java.util.List<Expression>, java.util.List<Expression>), or a parameter of an enclosing Expression.lambda(java.util.List<Expression>, Expression). A Expression.break_() or Expression.continue_() in the body applies to this loop.

static Expression break_(Connection connection)#

A break statement, which ends the enclosing loop.

static Expression continue_(Connection connection)#

A continue statement, which skips to the next iteration of the enclosing loop.

static Expression return_(Connection connection, Expression value)#

A return statement, which ends the enclosing function with a value.

Parameters:

  • value (Expression) – The value to return.

static Expression returnNothing(Connection connection)#

A return statement, which ends the enclosing function with no value.

static Expression throw_(Connection connection, String service, String name, Expression message)#

A throw statement, which raises the named exception.

Parameters:

  • service (String) – The name of the service the exception is defined in.

  • name (String) – The name of the exception.

  • message (Expression) – The message of the exception.

Note

The client receives the exception as an error from the function, or from the stream or event evaluating it. For example, the service KRPC and the name Error raise Error. Throws an exception if the service does not declare it.

static Expression tryCatch(Connection connection, Expression body, String service, String name, Expression message, Expression handler)#

A try-catch statement that handles the named exception.

Parameters:

  • body (Expression) – The statement to evaluate.

  • service (String) – The name of the service the exception is defined in.

  • name (String) – The name of the exception.

  • message (Expression) – A string variable assigned the exception’s message, or null.

  • handler (Expression) – The statement evaluated when the exception is caught.

Note

Only an exception a service declares can be named, and Expression.tryCatchAll(Expression, Expression, Expression) handles any exception. Throws an exception if the service does not declare it.

static Expression tryCatchAll(Connection connection, Expression body, Expression message, Expression handler)#

A try-catch statement that handles any exception.

Parameters:

  • body (Expression) – The statement to evaluate.

  • message (Expression) – A string variable assigned the exception’s message, or null.

  • handler (Expression) – The statement evaluated when an exception is caught.

static Expression tryFinally(Connection connection, Expression body, Expression finalizer)#

A try-finally statement.

Parameters:

  • body (Expression) – The statement to evaluate.

  • finalizer (Expression) – The statement evaluated after the body.

Note

The finalizer is evaluated after the body, whether or not the body raises an exception. A break, continue or return cannot leave the finalizer.

static Expression createTuple(Connection connection, java.util.List<Expression> elements)#

A tuple of the given elements. Throws an exception if there are no elements or more than seven.

Parameters:

  • elements (java.util.List) – The elements.

Returns:

The tuple.

static Expression createStruct(Connection connection, Type type, java.util.List<Expression> fieldValues)#

A structure with the given field values. Throws an exception if the field values do not match its fields.

Parameters:

  • type (Type) – The type of the structure.

  • fieldValues (java.util.List) – The values of the structure’s fields, in the order the structure declares them.

Returns:

The structure.

static Expression createList(Connection connection, java.util.List<Expression> values)#

A list of the given values, with numbers widened to their common type. Throws an exception if there are no values.

Parameters:

  • values (java.util.List) – The values.

Returns:

The list.

static Expression createSet(Connection connection, java.util.Set<Expression> values)#

A set of the given values, with numbers widened to their common type. Throws an exception if there are no values, or a value is null.

Parameters:

  • values (java.util.Set) – The values.

Returns:

The set.
