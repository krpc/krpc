Standard Library#

public class StdLib#

A standard library of mathematics and printing for server side functions, and of the colors other services use.

Note

Vectors are position and direction tuples, and rotations are unit quaternion tuples in the order x, y, z, w the SpaceCenter service uses. Angles are in radians unless stated otherwise.

void print(String message)#

Writes a message to the game’s log, for debugging.

Parameters:

  • message (String) – The message.

Note

A function evaluated by a stream or an event prints on every update. The message is written at the Info level, so a server log level of Warning or Error hides it.
