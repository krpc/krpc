AscentAutopilot#

public class AscentAutopilot#

The ascent autopilot.

Note

See the MechJeb wiki for how to set up this autopilot.

boolean getEnabled()#
void setEnabled(boolean value)#

Whether the autopilot is enabled. Enabling it engages the autopilot of the selected ascent path, and disabling it disengages the autopilots of both paths.

Game Scenes:

Flight

String getStatus()#

The autopilot status, which depends on the selected ascent path.

Game Scenes:

Flight

int getAscentPathIndex()#
void setAscentPathIndex(int value)#

The selected ascent path: 0 for AscentClassic or 2 for AscentPVG.

Game Scenes:

Flight

Note

MechJeb 2.15 removed the stock-style gravity turn path, which was 1. Setting any other value throws an exception.

AscentClassic getAscentPathClassic()#

The settings of the classic ascent profile.

Flight

The settings of the Primer Vector Guidance (RSS/RO) profile.

Flight

Flight

Flight

Note

Whether the autopilot steers by the velocity vector rather than the position vector.

public enum AscentLaunchMode#

The launch mode of the ascent autopilot. See AscentAutopilot.getLaunchMode().

public AscentLaunchMode NORMAL#

The autopilot is not performing a timed launch.

public AscentLaunchMode RENDEZVOUS#

A timed launch to rendezvous with the target vessel.

public AscentLaunchMode TARGET_PLANE#

A timed launch into the plane of the target.

public AscentLaunchMode UNKNOWN#

A timed launch of another kind, started from MechJeb’s window.
