Client Coverage#

The conformance tests run against each client in this repository. Each table below gives the result of a client on each requirement of a page:

  • ✓ The client passes the test.

  • ✗ The client fails the test, and the failure is recorded as a known defect.

  • ! The client fails some of the test’s cases, or fails it over some protocols.

  • ? The requirement has no test.

  • A blank cell means the requirement does not apply to the client. It belongs to a profile the client does not implement, or the client lists its test as unsupported.
