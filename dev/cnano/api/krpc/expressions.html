Expressions#

The nodes a server side function is built from, and the types they work with. See the server side functions tutorial for how a function is assembled and run.

type krpc_KRPC_Expression_t#

A server side expression.

Note

Numeric operands of differing types are converted to a common type.

krpc_error_t krpc_KRPC_Expression_ReturnType(krpc_connection_t connection, krpc_KRPC_Type_t *returnValue, krpc_KRPC_Expression_t instance)#

The type of the value the expression evaluates to. Throws an exception if the value cannot be sent to a client.

Note

A function created with krpc_KRPC_Expression_Lambda() evaluates to the value it returns. A lazily evaluated collection, such as from krpc_KRPC_Expression_Select(), is sent once converted by krpc_KRPC_Expression_ToList() or krpc_KRPC_Expression_ToSet().

krpc_error_t krpc_KRPC_Expression_HasReturnType(krpc_connection_t connection, bool *returnValue, krpc_KRPC_Expression_t instance)#

Whether the expression evaluates to a value.

Note

An expression with no value has no krpc_KRPC_Expression_ReturnType(). An empty collection and no value both encode to an empty sequence of bytes.

krpc_error_t krpc_KRPC_Expression_ParameterTypes(krpc_connection_t connection, krpc_list_object_t *returnValue, krpc_KRPC_Expression_t instance)#

The types of the function’s parameters.

krpc_error_t krpc_KRPC_Expression_Call(krpc_connection_t connection, krpc_KRPC_Expression_t *returnValue, const krpc_schema_ProcedureCall *call)#

An RPC call.

Parameters:

  • call – The procedure call.

Note

The instance the call is made on, and the values of its arguments, are fixed when the expression is created. A call to a procedure with no return value is evaluated for its effects, as a statement in a krpc_KRPC_Expression_Block(). A collection the procedure returns is copied, as a client would receive it.

krpc_error_t krpc_KRPC_Expression_CallWithArguments(krpc_connection_t connection, krpc_KRPC_Expression_t *returnValue, const krpc_schema_ProcedureCall *call, const krpc_dictionary_int32_object_t *args)#

Parameters:

  • call – The RPC to call.

  • args – Expressions computing the call’s arguments, by position.

Note

Position 0 is the instance of a class method or property. A position with no expression takes the argument encoded in the call, or the parameter’s default. A collection the procedure returns is copied, as a client would receive it.
