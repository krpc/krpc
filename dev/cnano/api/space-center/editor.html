krpc_error_t krpc_SpaceCenter_Editor_LoadVessel(krpc_connection_t connection, const char *craftDirectory, const char *name)#

Load a vessel from a craft file into the editor, replacing the vessel that is currently being constructed.

Parameters:

  • craftDirectory – Name of the directory in the current saves “Ships” directory, that contains the craft file. For example "VAB" or "SPH".

  • name – Name of the vessel to load. This is the name of the “.craft” file in the save directory, without the “.craft” file extension.

Game Scenes:

Editor Vab, Editor Sph

Note

The vessel is loaded into whichever editor is open, regardless of which directory it came from. Its delta-v figures are recalculated in the background afterwards; see krpc_SpaceCenter_EditorVessel_DeltaVReady().

krpc_error_t krpc_SpaceCenter_Editor_LaunchVessel(krpc_connection_t connection, const char *launchSite, const krpc_list_string_t *crew, bool recover, const char *flagUrl)#

Launch the vessel that is being constructed, from the given launch site.

Parameters:

  • launchSite – Name of the launch site. For example "LaunchPad" or "Runway".

  • crew – The Kerbals to place in the vessel, by name. Controls how the vessel is crewed, as described in the remarks.

  • recover – If true and there is a vessel on the launch site, recover it before launching.

  • flagUrl – If not nullptr, the asset URL of the mission flag to use for the launch.

Game Scenes:

Editor Vab, Editor Sph

Note

The vessel being constructed is not a craft file, so it is written to the editor’s auto-saved craft file and that is launched, as the game’s own launch button does. The vessel’s own craft file, if it was loaded from one, is left alone. The crew parameter works as it does for krpc_SpaceCenter_LaunchVessel(), and takes precedence over the crew assigned in the editor. Throws an exception if any of the games pre-flight checks fail.

krpc_error_t krpc_SpaceCenter_Editor_DeltaVBody(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t *result)#
void krpc_SpaceCenter_Editor_set_DeltaVBody(krpc_SpaceCenter_CelestialBody_t value)#

The body whose gravity and atmosphere the vessel’s delta-v, thrust, TWR and specific impulse figures assume.

Game Scenes:

Editor Vab, Editor Sph

Note

This and krpc_SpaceCenter_Editor_DeltaVAltitude() are what krpc_SpaceCenter_EditorVessel_DeltaV(), krpc_SpaceCenter_Stage_DeltaV() and the other current-situation figures are computed for. The body sets the gravity the thrust-to-weight ratios are against, and, with the altitude, the atmospheric pressure and density the specific impulses and thrusts are against. This is global game state rather than editor state: the same setting backs the game’s delta-v readout in flight, and it persists across scene changes. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until krpc_SpaceCenter_EditorVessel_DeltaVReady() is true again.

krpc_error_t krpc_SpaceCenter_Editor_DeltaVAltitude(krpc_connection_t connection, double *result)#
void krpc_SpaceCenter_Editor_set_DeltaVAltitude(double value)#

The altitude above krpc_SpaceCenter_Editor_DeltaVBody(), in meters, that the vessel’s delta-v, thrust, TWR and specific impulse figures assume. The atmospheric pressure and density at this altitude are what the figures are computed for, so raising it from zero to above the body’s atmosphere moves them from the vessel’s sea-level figures to its vacuum ones. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until krpc_SpaceCenter_EditorVessel_DeltaVReady() is true again.

Game Scenes:

Editor Vab, Editor Sph

krpc_error_t krpc_SpaceCenter_Editor_DeltaVSituation(krpc_connection_t connection, krpc_SpaceCenter_DeltaVSituation_t *result)#
void krpc_SpaceCenter_Editor_set_DeltaVSituation(krpc_SpaceCenter_DeltaVSituation_t value)#

Which situation the game’s own delta-v readout shows figures for.

Game Scenes:

Editor Vab, Editor Sph

Note

This selects which column the game’s own delta-v app displays, and nothing else. It does not affect anything kRPC reports: the current-situation figures follow krpc_SpaceCenter_Editor_DeltaVBody() and krpc_SpaceCenter_Editor_DeltaVAltitude() whatever this is set to, and the sea-level and vacuum figures are reported directly as krpc_SpaceCenter_EditorVessel_SeaLevelDeltaV() and krpc_SpaceCenter_EditorVessel_VacuumDeltaV(). It is here for completeness with the app.

type krpc_SpaceCenter_DeltaVSituation_t#

The situation the game’s own delta-v readout shows figures for. See krpc_SpaceCenter_Editor_DeltaVSituation().

KRPC_SPACECENTER_DELTAVSITUATION_SEALEVEL#

At sea level on the selected body.

KRPC_SPACECENTER_DELTAVSITUATION_ALTITUDE#

At the selected altitude on the selected body.

KRPC_SPACECENTER_DELTAVSITUATION_VACUUM#

In vacuum.

Only the parts of krpc_SpaceCenter_Part_t that describe the design are available in the editor. krpc_error_t krpc_SpaceCenter_EditorVessel_DeltaVReady(krpc_connection_t connection, bool *result)#

Whether the stock delta-v figures for the vessel have been calculated.

Game Scenes:

Editor Vab, Editor Sph

Note

The game recalculates them in the background whenever the vessel changes, and whenever krpc_SpaceCenter_Editor_DeltaVBody() or krpc_SpaceCenter_Editor_DeltaVAltitude() is set, and they are out of date until it has finished. Reading krpc_SpaceCenter_EditorVessel_DeltaV(), or any delta-v member of a krpc_SpaceCenter_Stage_t, before then raises an error rather than returning a stale figure. Poll this after changing anything the figures depend on.
