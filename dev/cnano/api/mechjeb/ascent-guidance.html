AscentGuidance#

type krpc_MechJeb_AscentGuidance_t#

The Ascent Guidance window, which flies the vessel to orbit.

Note

See the MechJeb wiki for how to set up this autopilot.

KRPC_CLASS_MECHJEB_ASCENTGUIDANCE#

The service and class ids of the class, for krpc_KRPC_Type_ClassTypeById().

krpc_error_t krpc_MechJeb_AscentGuidance_Enabled(krpc_connection_t connection, bool *returnValue, krpc_MechJeb_AscentGuidance_t instance)#
krpc_error_t krpc_MechJeb_AscentGuidance_set_Enabled(krpc_connection_t connection, krpc_MechJeb_AscentGuidance_t instance, bool value)#

Whether the module is enabled.
