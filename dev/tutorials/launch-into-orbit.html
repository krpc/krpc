Launch into Orbit#

This tutorial launches the AeroEquus, one of the game’s stock craft, into a 150km circular orbit. Load it in the Vehicle Assembly Building and launch it to the pad before you run the program.

The program is available in a variety of languages:

Python, C#, C++, C, Java, Lua, JavaScript

Preparing for Launch#

The following code connects to the server, gets the active vessel, sets up a bunch of streams to get flight telemetry then prepares the rocket for launch. The C and Lua clients do not support streams, so their scripts read the telemetry with a call each time.

Ascent#

The next part of the program launches the rocket on its four solid boosters. It then adds an event for each of the two lower stages, which fires when the stage runs out of fuel, and a callback that the event calls. The callback activates two stages: one drops the empty stage, and the next lights the engine above it. It also removes its event, as the stage it watched is gone.

The callbacks run alongside the main loop. On every pass between 250 m and 45 km, the loop sets the auto-pilot’s target pitch, which gradually turns the rocket towards the horizon. It pauses for 50 ms between passes, so it does not flood the server with calls. The JavaScript program waits for the next altitude update in place of the pause. The loop exits when the rocket’s apoapsis is close to the target apoapsis.

The C and Lua clients have no events, so their loops also watch the fuel in the current stage, and activate the stages the same way.

Leaving the Atmosphere#

Next, the program fine tunes the apoapsis using 25% thrust, then waits until the rocket has left Kerbin’s atmosphere. Each wait is an event, which the server checks every physics tick. See Server Side Functions for how events work.

The Python, C# and JavaScript clients compile the event’s condition from a lambda, and the C++ and Java clients build it with the expression API. The C and Lua programs poll in a loop with a short pause, as those clients have no events.

# Fine tune the apoapsis at 25% thrust
vessel.control.throttle = 0.25
event = conn.add_event(
    lambda: vessel.orbit.apoapsis_altitude >= target_altitude
)
with event.condition:
    event.wait()
print("Target apoapsis reached")
vessel.control.throttle = 0.0

Planning the Circularization Burn#

It is now time to plan the circularization burn. First, we calculate the delta-v required to circularize the orbit using the vis-viva equation. We then calculate the burn time needed to achieve this delta-v, using the Tsiolkovsky rocket equation.

Note

The per-stage values that feed this calculation are also available directly from the staging API: Vessel.stage_at() returns a Stage object with properties such as Stage.delta_v, Stage.specific_impulse and Stage.burn_time. The derivation is shown here because we need the burn time for a specific delta-v, rather than for burning the whole stage.

Executing the Burn#

Finally, the program waits until half the burn time before apoapsis, then starts the burn. A loop steers along the remaining burn vector, which turns as the vessel moves around its orbit. It burns at full throttle, then at 5% for the last 5 m/s.

The burn ends when less than 0.1 m/s remains. It also ends if the remaining delta-v starts to grow, which means the burn has overshot:
