Sub-Orbital Flight#

This introductory tutorial uses kRPC to send some Kerbals on a sub-orbital flight, and return them safely to Kerbin. It covers the following topics:

  • Controlling a rocket, by activating stages and setting the throttle

  • Using the autopilot to point the vessel in a direction

  • Using events to wait for things to happen in the game

  • Tracking the amount of resources in the vessel

  • Tracking flight data, such as altitude and vertical speed

  • Setting a part’s properties, such as a parachute’s deploy altitude

Note

For details on how to write scripts and connect to kRPC, see the Getting Started guide.

The tutorial flies the Kerbal 2, one of the game’s stock craft. Load it in the Vehicle Assembly Building and launch it to the pad before you run the script.

The tutorial includes source code for the main client languages kRPC supports. Download the whole program in your chosen language:

Python, C#, C++, C, Java, Lua, JavaScript

Preparing for Launch#

First we open a connection to the server, passing a name for the script. The name appears in the server window in the game. The C program also defines sleep_ms, which its polling loops pause with:

conn = krpc.connect(name="Sub-orbital flight")

        var conn = new Connection ("Sub-orbital flight");

  krpc::Connection conn = krpc::connect("Sub-orbital flight");
  krpc::services::SpaceCenter space_center(conn);

#ifdef _WIN32
#define WIN32_LEAN_AND_MEAN
#include <windows.h>
#define sleep_ms(ms) Sleep(ms)
#else
#define _POSIX_C_SOURCE 200809L
#include <time.h>
static void sleep_ms(long ms) {
  struct timespec duration = {ms / 1000, (ms % 1000) * 1000000};
  nanosleep(&duration, NULL);
}
#endif

Pitching Over#

Once the rocket has cleared the launch pad, it starts to turn. We wait for an event that fires at an altitude of 500 m:

flight = vessel.flight()
event = conn.add_event(lambda: flight.mean_altitude > 500)
with event.condition:
    event.wait()

        var flight = vessel.Flight ();
        {
            var evnt = conn.AddEvent (() => flight.MeanAltitude > 500);
            lock (evnt.Condition) {
                evnt.Wait ();
            }
        }

  auto e = krpc::services::KRPC::Expression::bind(conn);

  auto flight = vessel.flight();
  {
    auto expr = e.greater_than(e.call(flight.mean_altitude_call()),
                               e.constant_double(500));
    auto event = krpc::add_event(expr);
    event.acquire();
    event.wait();
    event.release();
  }

  krpc_SpaceCenter_Flight_t flight;
  krpc_SpaceCenter_Vessel_Flight(conn, &flight, vessel, KRPC_NULL);
  while (true) {
    double mean_altitude;
    krpc_SpaceCenter_Flight_MeanAltitude(conn, &mean_altitude, flight);
    if (mean_altitude > 500) break;
    sleep_ms(100);
  }

    Expression.Bound e = Expression.bind(connection);

    Flight flight = vessel.flight(null);
    {
      ProcedureCall meanAltitude =
        connection.getCall(flight, "getMeanAltitude");
      Expression expr = e.greaterThan(
        e.call(meanAltitude), e.constantDouble(500));
      Event event = connection.addEvent(expr);
      synchronized (event.getCondition()) {
        event.waitFor();
      }
    }

while vessel:flight().mean_altitude < 500 do
    socket.sleep(0.1)
end

const flight = await vessel.flight();
const altitudeEvent = await conn.addEvent(
  ({ flight }) => flight.meanAltitude > 500,
  { flight },
);
await altitudeEvent.wait();

vessel.flight() returns a Flight object, which gives information about the rocket in flight, such as its altitude, direction and velocity.

The event is a server side function that compares the altitude with 500. The server checks it every physics tick, and the script sleeps until it fires.

The Python, C# and JavaScript clients compile the lambda into the function. The C++ and Java clients build it from expression objects: an embedded call to mean_altitude, a constant and a comparison. The C and Lua clients do not support events, so their scripts poll in a loop, with a short pause on each pass.

Now we tilt the rocket 20° from vertical, to a pitch of 70°, and hold a heading of 90°, due east. A target smoothing time of 10 seconds turns the rocket over gradually, rather than all at once:

vessel.resources returns a Resources object, which gives the amounts of the resources in the rocket.

At flame out we cut the throttle, and the rocket coasts up to its apoapsis. The autopilot now points the rocket prograde, so it follows its arc:

print("Flame out")
vessel.control.throttle = 0

vessel.auto_pilot.target_direction = (0, 1, 0)

            vessel.SurfaceVelocityReferenceFrame;

vessel.surface_velocity_reference_frame has its y-axis along the rocket’s velocity relative to the surface. So the direction (0, 1, 0) in this frame points prograde. The frame turns with the velocity, and the rocket turns with it.

Returning Safely to Kerbin#

We separate the capsule at apoapsis, where the rocket stops climbing. This waits for an event that fires when the vertical speed falls below zero:

body_flight = vessel.flight(vessel.orbit.body.reference_frame)
event = conn.add_event(lambda: body_flight.vertical_speed < 0)
with event.condition:
    event.wait()

        var bodyFlight = vessel.Flight (vessel.Orbit.Body.ReferenceFrame);
        {
            var evnt = conn.AddEvent (() => bodyFlight.VerticalSpeed < 0);
            lock (evnt.Condition) {
                evnt.Wait ();
            }
        }

  auto body_flight = vessel.flight(vessel.orbit().body().reference_frame());
  {
    auto expr = e.less_than(e.call(body_flight.vertical_speed_call()),
                            e.constant_double(0));
    auto event = krpc::add_event(expr);
    event.acquire();
    event.wait();
    event.release();
  }

  krpc_SpaceCenter_Orbit_t orbit;
  krpc_SpaceCenter_Vessel_Orbit(conn, &orbit, vessel);
  krpc_SpaceCenter_CelestialBody_t body;
  krpc_SpaceCenter_Orbit_Body(conn, &body, orbit);
  krpc_SpaceCenter_ReferenceFrame_t body_frame;
  krpc_SpaceCenter_CelestialBody_ReferenceFrame(conn, &body_frame, body);
  krpc_SpaceCenter_Flight_t body_flight;
  krpc_SpaceCenter_Vessel_Flight(conn, &body_flight, vessel, body_frame);
  while (true) {
    double vertical_speed;
    krpc_SpaceCenter_Flight_VerticalSpeed(conn, &vertical_speed,
                                          body_flight);
    if (vertical_speed < 0) break;
    sleep_ms(100);
  }

    Flight bodyFlight =
      vessel.flight(vessel.getOrbit().getBody().getReferenceFrame());
    {
      ProcedureCall verticalSpeed =
        connection.getCall(bodyFlight, "getVerticalSpeed");
      Expression expr = e.lessThan(
        e.call(verticalSpeed), e.constantDouble(0));
      Event event = connection.addEvent(expr);
      synchronized (event.getCondition()) {
        event.waitFor();
      }
    }

local body_frame = vessel.orbit.body.reference_frame
while vessel:flight(body_frame).vertical_speed > 0 do
    socket.sleep(0.1)
end

const orbit = await vessel.getOrbit();
const bodyFrame = await (await orbit.getBody()).getReferenceFrame();
const bodyFlight = await vessel.flight(bodyFrame);
const apoapsisEvent = await conn.addEvent(
  ({ bodyFlight }) => bodyFlight.verticalSpeed < 0,
  { bodyFlight },
);
await apoapsisEvent.wait();

This calls vessel.flight() again, now with a ReferenceFrame. We want the vertical speed relative to the surface of Kerbin, so the flight object has to give values in a frame fixed to Kerbin. vessel.orbit.body.reference_frame has its origin at the center of Kerbin, and rotates with the planet. See the Reference Frames guide for more.

Then we separate the capsule, and have the autopilot turn it retrograde. wait blocks until the capsule points there. We then disengage the autopilot, and the capsule’s drag keeps it pointing retrograde as it falls:

        vessel.AutoPilot.Wait ();
        vessel.AutoPilot.Engaged = false;

The Kerbals are now on a collision course with the surface. We wait until they fall to 2 km above the surface, then deploy the parachute. You can use time warp to skip ahead to just before this happens, and the script carries on working:

The parachute semi-deploys as soon as it is safe, which slows the capsule a little. It opens fully at its deploy altitude, 1000 m by default. We lower it to 550 m, so the capsule spends less time hanging under its parachute.
