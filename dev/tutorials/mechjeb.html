MechJeb#

MechJeb is an autopilot. The MechJeb service follows MechJeb’s windows: a script sets what a player would set in a window, then engages the autopilot. This tutorial walks through a script that flies the stock PT Series Munsplorer from the launch pad to the surface of Minmus. MechJeb adds itself to every command pod, so the craft needs no extra part.

The tutorial includes the script in each of the client languages kRPC supports. Download the whole program in your chosen language:

Python, C#, C++, C, Java, Lua, JavaScript

The script starts with its helpers. wait_for waits until a condition is true, with an event. print_steps prints each step of an autopilot, from a stream of its status. print_orbit prints the vessel’s orbit. The C and Lua clients have no events or streams, so their scripts poll. Each waits for an autopilot in a loop that prints its steps, and the C program defines sleep_ms to pause between calls:

// Print the step of an autopilot's status, if it differs from the last
static void print_step(const char* status, char* last, size_t size) {
  // The step, without the figures that change on each update
  size_t length = strcspn(status, "\n0123456789");
  const char* infinity = strstr(status, "∞");
  if (infinity && (size_t)(infinity - status) < length)
    length = infinity - status;
  while (length > 0 && strchr(" :=", status[length - 1])) length--;
  if (length == 0 || length >= size) return;
  if (strncmp(status, last, length) == 0 && last[length] == '\0') return;
  memcpy(last, status, length);
  last[length] = '\0';
  printf("%s\n", last);
}

The script sets the target orbit on AscentGuidance, and the settings of MechJeb’s Ascent Settings window on AscentGuidance.settings. With AscentSettings.autostage on, MechJeb stages the vessel once the first stage is activated. The autopilot disengages once it has circularized the orbit.

AscentGuidance.ascent_type picks the ascent path. The classic path flies a turn whose shape AscentGuidance.classic_path sets. The PVG path, Primer Vector Guidance, computes its own path, and is the one for Realism Overhaul. Its settings are on AscentGuidance.pvg_settings.

MechJeb keeps the throttle at 5% or more. At full thrust, the lander’s engine is too strong for Minmus’ weak gravity, and the lander climbs even at 5% throttle. A thrust limit of 30% lets the lowest throttle leave the lander falling. ThrustLimiter.min_throttle sets that lowest throttle.

LandingGuidance.set_target() sets the landing target, as a latitude and longitude. The autopilot burns to deorbit over the target, then brakes to a hover 200 m above it. Once it has stopped drifting, it descends at LandingGuidance.touchdown_speed, and disengages once the vessel has landed.
