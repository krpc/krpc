Scanner
=======


.. class:: Scanner

   A SCANsat scanner on a part. Obtained by calling :meth:`ScanSat.Scanner <ScanSat.ScanSat.Scanner>` or
   :meth:`ScanSat.Scanners <ScanSat.ScanSat.Scanners>`.

   .. property:: SpaceCenter.Part Part { get; }

      The part containing this scanner.

      :Game Scenes: Flight

   .. property:: ScanType ScanTypes { get; }

      The scan types of the scanner.

      :Game Scenes: Flight

   .. property:: bool Active { get; set; }

      Returns whether the scanner is switched on, and switches it on or off, as the buttons
      of the part do.

      :Game Scenes: Flight


      .. note::

         A resource scanner only switches on when :prop:`ScanSat.InstantResourceScan <ScanSat.ScanSat.InstantResourceScan>`
         is off, or :prop:`ScanSat.StockResourceScan <ScanSat.ScanSat.StockResourceScan>` is off.

   .. property:: float FieldOfView { get; }

      The field of view of the scanner at its best altitude, in degrees.

      :Game Scenes: Flight

   .. property:: float MinAltitude { get; }

      The lowest altitude the scanner scans at, in meters.

      :Game Scenes: Flight

   .. property:: float BestAltitude { get; }

      The lowest altitude for the full field of view, in meters.

      :Game Scenes: Flight

   .. property:: float MaxAltitude { get; }

      The highest altitude the scanner scans at, in meters.

      :Game Scenes: Flight

   .. property:: bool RequiresLight { get; }

      Whether the scanner only scans in daylight, when :prop:`ScanSat.DaylightCheck <ScanSat.ScanSat.DaylightCheck>`
      is on.

      :Game Scenes: Flight

   .. property:: ScannerState State { get; }

      The state of the scanner.

      :Game Scenes: Flight




.. enum:: ScannerState

   The state of a scanner. See :prop:`Scanner.State`.


   .. enumerator:: Off

      Switched off.


   .. enumerator:: OutOfRange

      Switched on, and outside its minimum and maximum altitudes.


   .. enumerator:: InDarkness

      Switched on, and paused as it needs light and the ground below it is in darkness.


   .. enumerator:: InRange

      Scanning between its minimum and best altitudes, with a reduced field of view.


   .. enumerator:: InBestRange

      Scanning between its best and maximum altitudes, with its full field of view.
