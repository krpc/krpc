Example
-------

kRPC adds a page named ``krpc`` to every Raster Prop Monitor screen. The page shows the screen's
:type:`Display`, which a script draws on.
The following example draws a page on the first screen in the active vessel's IVA, showing
whether SAS is on. The screen's ENTER button toggles SAS, and its NAV button shows the page:

.. literalinclude:: /scripts/api/raster-prop-monitor/RasterPropMonitorExample.cs

The page text names Raster Prop Monitor's ``SAS`` variable, and the format gives ``ON`` for 1 and
``OFF`` for 0. Raster Prop Monitor updates the page as SAS changes, however it is switched. On the
screens of the Mk1 Lander Can, NAV is ``buttonR1``.
