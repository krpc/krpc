LiDAR Replacement
-----------------

A LiDAR casts a fan of rays from its part. :meth:`SpaceCenter.RaycastDistance <SpaceCenter.SpaceCenter.RaycastDistance>` casts one
ray. This example casts 8 rays below the root part of the active vessel:

.. literalinclude:: /scripts/api/lidar/RaycastExample.cs

The function stream casts every ray in the same physics tick, as a LiDAR does.
