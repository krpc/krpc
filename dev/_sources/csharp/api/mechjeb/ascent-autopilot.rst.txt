AscentAutopilot
===============


.. class:: AscentAutopilot

   The ascent autopilot.

   .. note::

      See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
      for how to set up this autopilot.

   .. property:: bool Enabled { get; set; }

      Whether the autopilot is enabled. Enabling it engages the autopilot of the selected
      ascent path, and disabling it disengages the autopilots of both paths.

      :Game Scenes: Flight

   .. property:: string Status { get; }

      The autopilot status, which depends on the selected ascent path.

      :Game Scenes: Flight

   .. property:: int AscentPathIndex { get; set; }

      The selected ascent path: 0 for :type:`AscentClassic` or 2 for
      :type:`AscentPVG`.

      :Game Scenes: Flight


      .. note::

         MechJeb 2.15 removed the stock-style gravity turn path, which was 1. Setting any other
         value throws an exception.

   .. property:: AscentClassic AscentPathClassic { get; }

      The settings of the classic ascent profile.

      :Game Scenes: Flight

   .. property:: AscentPVG AscentPathPVG { get; }

      The settings of the Primer Vector Guidance (RSS/RO) profile.

      :Game Scenes: Flight

   .. property:: double DesiredInclination { get; set; }

      The inclination of the final circular orbit, in degrees.

      :Game Scenes: Flight

   .. property:: double DesiredOrbitAltitude { get; set; }

      The altitude of the final circular orbit, in meters.

      :Game Scenes: Flight

   .. property:: ThrustController ThrustController { get; }

      The thrust controller. The same as :prop:`MechJeb.ThrustController <MechJeb.MechJeb.ThrustController>`.

      :Game Scenes: Flight

   .. property:: bool ForceRoll { get; set; }

      Whether the autopilot controls the roll.

      :Game Scenes: Flight

   .. property:: double TurnRoll { get; set; }

      The roll during the turn, in degrees.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentAutopilot.ForceRoll`.

   .. property:: double VerticalRoll { get; set; }

      The roll during the vertical climb, in degrees.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentAutopilot.ForceRoll`.

   .. property:: bool LimitAoA { get; set; }

      Whether to limit the angle of attack.

      :Game Scenes: Flight

   .. property:: double MaxAoA { get; set; }

      The largest angle of attack, in degrees.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentAutopilot.LimitAoA`.

   .. property:: double AoALimitFadeoutPressure { get; set; }

      The dynamic pressure below which the angle of attack limit fades out, in pascals.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentAutopilot.LimitAoA`.

   .. property:: bool CorrectiveSteering { get; set; }

      Whether the autopilot steers by the velocity vector rather than the position vector.

      :Game Scenes: Flight


      .. note::

         It is more accurate, though large craft may do better without it.

   .. property:: double CorrectiveSteeringGain { get; set; }

      The gain of the corrective steering.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentAutopilot.CorrectiveSteering`.

   .. property:: bool Autostage { get; set; }

      Whether the autopilot stages when the current stage runs out of fuel.

      :Game Scenes: Flight

   .. property:: StagingController StagingController { get; }

      The staging controller. The same as :prop:`MechJeb.StagingController <MechJeb.MechJeb.StagingController>`.

      :Game Scenes: Flight

   .. property:: bool AutodeploySolarPanels { get; set; }

      Whether to deploy the solar panels when the ascent finishes.

      :Game Scenes: Flight

   .. property:: bool AutoDeployAntennas { get; set; }

      Whether to deploy the antennas when the ascent finishes.

      :Game Scenes: Flight

   .. property:: bool SkipCircularization { get; set; }

      Whether to skip the circularization burn.

      :Game Scenes: Flight

   .. property:: int WarpCountDown { get; set; }

      The time before a timed launch at which time warp stops, in seconds.

      :Game Scenes: Flight

   .. property:: double LaunchLANDifference { get; set; }

      The difference from the target's longitude of the ascending node of a launch into the
      target's plane, in degrees.

      :Game Scenes: Flight

   .. property:: double LaunchPhaseAngle { get; set; }

      The phase angle to the target of a launch to rendezvous, in degrees.

      :Game Scenes: Flight

   .. property:: AscentLaunchMode LaunchMode { get; }

      The launch mode, which gives whether the autopilot is waiting for a timed launch.

      :Game Scenes: Flight

   .. function:: void AbortTimedLaunch()

      Abort a timed launch that has not started yet. Throws an exception if the launch mode
      is :value:`AscentLaunchMode.Unknown`.


      :Game Scenes: Flight

   .. function:: void LaunchToRendezvous()

      Launch to rendezvous with the target. Throws an exception if there is no target, or
      the ascent path is PVG.


      :Game Scenes: Flight

   .. function:: void LaunchToTargetPlane()

      Launch into the plane of the target. Throws an exception if there is no target.


      :Game Scenes: Flight



.. enum:: AscentLaunchMode

   The launch mode of the ascent autopilot. See :prop:`AscentAutopilot.LaunchMode`.


   .. enumerator:: Normal

      The autopilot is not performing a timed launch.


   .. enumerator:: Rendezvous

      A timed launch to rendezvous with the target vessel.


   .. enumerator:: TargetPlane

      A timed launch into the plane of the target.


   .. enumerator:: Unknown

      A timed launch of another kind, started from MechJeb's window.



AscentClassic
-------------


.. class:: AscentClassic

   The classic ascent profile.

   .. property:: bool AutoPath { get; set; }

      Whether the autopilot chooses the turn altitudes and speed.

      :Game Scenes: Flight

   .. property:: float AutoTurnPercent { get; set; }

      The altitude at which an automatic turn starts, as a fraction of the height of the
      atmosphere.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentClassic.AutoPath`.

   .. property:: float AutoTurnSpeedFactor { get; set; }

      The factor that sets the speed at which an automatic turn starts.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentClassic.AutoPath`.

   .. property:: double AutoTurnStartAltitude { get; }

      The altitude at which an automatic turn starts, in meters.

      :Game Scenes: Flight

   .. property:: double AutoTurnStartVelocity { get; }

      The speed at which an automatic turn starts, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. property:: double AutoTurnEndAltitude { get; }

      The altitude at which an automatic turn ends, in meters.

      :Game Scenes: Flight

   .. property:: double TurnStartAltitude { get; set; }

      The altitude at which the turn starts, in meters.

      :Game Scenes: Flight

   .. property:: double TurnStartVelocity { get; set; }

      The speed at which the turn starts, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. property:: double TurnEndAltitude { get; set; }

      The altitude at which the turn ends, in meters.

      :Game Scenes: Flight

   .. property:: double TurnEndAngle { get; set; }

      The final flight path angle, in degrees.

      :Game Scenes: Flight

   .. property:: double TurnShapeExponent { get; set; }

      The steepness of the turn, between 0 and 1.

      :Game Scenes: Flight



AscentPVG
---------


.. class:: AscentPVG

   The Primer Vector Guidance (RSS/RO) profile.

   .. property:: bool AttachAltFlag { get; set; }

      Whether the orbit is attached at :prop:`AscentPVG.DesiredAttachAlt`.

      :Game Scenes: Flight


      .. note::

         MechJeb reads this setting only when its PVG settings window has an early shutoff
         stage. Without one, MechJeb always attaches the orbit.

   .. property:: double DesiredApoapsis { get; set; }

      The target apoapsis, in meters.

      :Game Scenes: Flight

   .. property:: double DesiredAttachAlt { get; set; }

      The altitude at which the orbit is attached, in meters.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentPVG.AttachAltFlag`, unless MechJeb's PVG settings window has no early
         shutoff stage.

   .. property:: double DynamicPressureTrigger { get; set; }

      The dynamic pressure below which guidance starts, in pascals.

      :Game Scenes: Flight

   .. property:: bool FixedCoast { get; set; }

      Whether the coast has a fixed length.

      :Game Scenes: Flight

   .. property:: double FixedCoastLength { get; set; }

      The length of the coast, in seconds.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentPVG.FixedCoast`.

   .. property:: double PitchRate { get; set; }

      The pitch rate of the booster, in :math:`\mathrm{deg/s}`.

      :Game Scenes: Flight

   .. property:: double PitchStartVelocity { get; set; }

      The speed at which the booster starts to pitch over, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. property:: int StagingTrigger { get; set; }

      The stage after which guidance starts.

      :Game Scenes: Flight


      .. note::

         Requires :prop:`AscentPVG.StagingTriggerFlag`.

   .. property:: bool StagingTriggerFlag { get; set; }

      Whether guidance starts after :prop:`AscentPVG.StagingTrigger`.

      :Game Scenes: Flight
