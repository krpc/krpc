LandingAutopilot
================


.. class:: LandingAutopilot

   The landing autopilot, which lands at a target or wherever the vessel comes down.

   .. property:: bool Enabled { get; set; }

      Whether the module is enabled.

      :Game Scenes: Flight

   .. property:: string Status { get; }

      The status of the autopilot.

      :Game Scenes: Flight

   .. property:: bool DeployChutes { get; set; }

      Whether the autopilot deploys the parachutes.

      :Game Scenes: Flight

   .. property:: bool DeployGears { get; set; }

      Whether the autopilot deploys the landing gear.

      :Game Scenes: Flight

   .. function:: void LandAtPositionTarget()

      Land at the position target. See :meth:`TargetController.SetPositionTarget`.


      :Game Scenes: Flight

   .. function:: void LandUntargeted()

      Land wherever the vessel comes down.


      :Game Scenes: Flight

   .. property:: int LimitChutesStage { get; set; }

      The last stage in which the autopilot deploys the parachutes.

      :Game Scenes: Flight

   .. property:: int LimitGearsStage { get; set; }

      The last stage in which the autopilot deploys the landing gear.

      :Game Scenes: Flight

   .. property:: bool RcsAdjustment { get; set; }

      Whether the autopilot corrects its course with RCS.

      :Game Scenes: Flight

   .. function:: void StopLanding()

      Stop the landing.


      :Game Scenes: Flight

   .. property:: double TouchdownSpeed { get; set; }

      The speed at touchdown, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight
