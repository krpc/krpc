MapMarker
=========


.. class:: MapMarker

   A marker drawn in the map view, with one of the game's own map icons. Created using
   :meth:`Drawing.AddMapMarker <Drawing.Drawing.AddMapMarker>`.

   .. property:: System.Tuple<double,double,double> Position { get; set; }

      Position of the marker.

      :Game Scenes: Flight, Tracking Station

   .. property:: SpaceCenter.ReferenceFrame ReferenceFrame { get; set; }

      Reference frame that the position of the marker is in.

      :Game Scenes: Flight, Tracking Station

   .. property:: bool Visible { get; set; }

      Whether the marker is visible.

      :Game Scenes: Flight, Tracking Station

   .. property:: MapMarkerIcon Icon { get; set; }

      The icon that the marker is drawn with.

      :Game Scenes: Flight, Tracking Station

   .. property:: Image Image { get; set; }

      The image that the marker is drawn with in place of its icon, or null to draw the
      icon.

      :Game Scenes: Flight, Tracking Station

   .. property:: string Caption { get; set; }

      The caption shown when the mouse is over the marker.

      :Game Scenes: Flight, Tracking Station

   .. property:: System.Tuple<double,double,double> Color { get; set; }

      The color of the marker.

      :Game Scenes: Flight, Tracking Station

   .. function:: void Remove()

      Remove the marker.


      :Game Scenes: Flight, Tracking Station
