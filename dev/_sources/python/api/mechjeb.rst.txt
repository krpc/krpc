MechJeb API
===========

Provides functionality to interact with the `MechJeb <https://github.com/MuMech/MechJeb2>`_ mod.
Originally written by `Genhis <https://github.com/Genhis/KRPC.MechJeb>`_.
The service acts on the MechJeb of the active vessel, which needs a part with MechJeb.
