Orbit
=====


.. class:: Orbit

   Describes an orbit. For example, the orbit of a vessel, obtained by calling
   :attr:`Vessel.orbit`, or a celestial body, obtained by calling
   :attr:`CelestialBody.orbit`.

   .. staticmethod:: create_from_position_and_velocity(body, position, velocity, ut, reference_frame)

      Create the orbit that passes through a given position at a given velocity.
      The orbit coasts freely under the gravity of the body being orbited, so it
      describes where an object left to fall from that position and velocity would
      be at any later time.

      :param CelestialBody body: The celestial body being orbited.
      :param tuple position: The position, as a position vector.
      :param tuple velocity: The velocity, as a vector pointing in the direction of travel, whose magnitude is the speed in meters per second.
      :param float ut: The universal time, in seconds, at which the object is at *position* traveling at *velocity*.
      :param ReferenceFrame reference_frame: The reference frame that *position* and *velocity* are in. Defaults to :attr:`CelestialBody.non_rotating_reference_frame` of *body*.
      :rtype: :class:`Orbit`
   

      .. note::

         The orbit is a single conic around *body*. It never changes
         sphere of influence, so :attr:`Orbit.next_orbit` is ``None``, and no
         atmosphere slows it. A vessel held on rails follows its own orbit exactly,
         while one inside the physics bubble is simulated and drifts from it a little.

         :attr:`Orbit.radius`, :attr:`Orbit.speed`, :meth:`Orbit.position`,
         :meth:`Orbit.velocity` and the like describe the orbit at
         *ut* and stay there. Use :meth:`Orbit.radius_at`,
         :meth:`Orbit.speed_at`, :meth:`Orbit.position_at`, :meth:`Orbit.velocity_at` and
         :meth:`Orbit.true_anomaly_at_ut` for another time, and
         :attr:`Orbit.reference_frame` and :attr:`Orbit.orbital_reference_frame` to follow
         the orbit as time passes.

         The orbit is held until :meth:`Orbit.remove` is called on it or the client
         that created it disconnects. Remove each one created by a script that creates
         them repeatedly, for example once per update.

   .. staticmethod:: create_from_orbital_elements(body, semi_major_axis, eccentricity, inclination, longitude_of_ascending_node, argument_of_periapsis, mean_anomaly_at_epoch, epoch)

      Create the orbit with the given
      `orbital elements <https://en.wikipedia.org/wiki/Orbital_elements>`_
      around a given body. The orbit coasts freely under the gravity of that body,
      so it describes where an object on it would be at any time.

      :param CelestialBody body: The celestial body being orbited.
      :param float semi_major_axis: The semi-major axis of the orbit, in meters. Positive for an ellipse and negative for a hyperbola.
      :param float eccentricity: The eccentricity of the orbit. Below one for an ellipse and above one for a hyperbola.
      :param float inclination: The inclination of the orbit, in radians.
      :param float longitude_of_ascending_node: The longitude of the ascending node, in radians.
      :param float argument_of_periapsis: The argument of periapsis, in radians.
      :param float mean_anomaly_at_epoch: The mean anomaly at *epoch*, in radians.
      :param float epoch: The universal time, in seconds, that *mean_anomaly_at_epoch* is measured at.
      :rtype: :class:`Orbit`
   

      .. note::

         The orbit is a single conic around *body*. It never changes
         sphere of influence, so :attr:`Orbit.next_orbit` is ``None``, and no
         atmosphere slows it.

         The angles are measured against the reference plane and direction that
         :attr:`Orbit.inclination`, :attr:`Orbit.longitude_of_ascending_node` and
         :attr:`Orbit.argument_of_periapsis` report them against.
         :meth:`Orbit.reference_plane_normal` and :meth:`Orbit.reference_plane_direction`
         give these as vectors in a reference frame.

         :attr:`Orbit.radius`, :attr:`Orbit.speed`, :meth:`Orbit.position`,
         :meth:`Orbit.velocity` and the like describe the orbit at
         *epoch* and stay there. Use :meth:`Orbit.radius_at`,
         :meth:`Orbit.speed_at`, :meth:`Orbit.position_at`, :meth:`Orbit.velocity_at` and
         :meth:`Orbit.true_anomaly_at_ut` for another time, and
         :attr:`Orbit.reference_frame` and :attr:`Orbit.orbital_reference_frame` to follow
         the orbit as time passes.

         The orbit is held until :meth:`Orbit.remove` is called on it or the client
         that created it disconnects. Remove each one created by a script that creates
         them repeatedly, for example once per update.

   .. method:: remove()

      Remove the orbit, releasing the memory the server holds for it.

   

      .. note::

         Only an orbit created by :meth:`Orbit.create_from_position_and_velocity` or
         :meth:`Orbit.create_from_orbital_elements` can be removed. Every other orbit
         belongs to something in the game, and the server holds one of each.

         Any further use of this object throws an exception, as does use of a
         reference frame defined against it. An orbit belongs to the client that
         created it, and is removed when that client disconnects.

   .. attribute:: body

      The celestial body (e.g. planet or moon) around which the object is orbiting.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`CelestialBody`
   

   .. attribute:: reference_frame

      The reference frame that moves along the orbit, and is orientated in a fixed
      direction.

      * The origin is at the point the orbit has reached at the
        current time.
      * The axes do not rotate. They point in the same fixed
        directions as those of
        :attr:`CelestialBody.non_rotating_reference_frame` of
        :attr:`Orbit.body`.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`ReferenceFrame`
   

      .. note::

         For the orbit of a vessel, the origin is the point the vessel's orbit has
         reached rather than the vessel's own center of mass. The two are a few meters
         apart, as a vessel inside the physics bubble is simulated rather than being
         held on its orbit.

   .. attribute:: orbital_reference_frame

      The reference frame that moves along the orbit, and is orientated with its
      prograde/normal/radial directions.

      * The origin is at the point the orbit has reached at the
        current time.
      * The axes rotate with the orbital prograde/normal/radial
        directions.
      * The x-axis points in the orbital anti-radial direction.
      * The y-axis points in the orbital prograde direction.
      * The z-axis points in the orbital normal direction.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`ReferenceFrame`
   

      .. note::

         For the orbit of a vessel, the origin is the point the vessel's orbit has
         reached rather than the vessel's own center of mass, which is what
         :attr:`Vessel.orbital_reference_frame` is centered on.
