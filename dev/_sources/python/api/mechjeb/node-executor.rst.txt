NodeExecutor
============


.. class:: NodeExecutor

   The maneuver node executor.

   .. attribute:: enabled

      Whether the executor is running.

      :Attribute: Read-only, cannot be set
      :rtype: bool
      :Game Scenes: Flight

   .. method:: abort()

      Stop executing the maneuver nodes.

      :Game Scenes: Flight

   .. attribute:: autowarp

      Whether the executor warps to the burn.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. method:: execute_all_nodes()

      Execute all the maneuver nodes.

      :Game Scenes: Flight

   .. method:: execute_one_node()

      Execute the next maneuver node.

      :Game Scenes: Flight

   .. attribute:: lead_time

      The time before the burn at which time warp stops, in seconds.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight
