ManeuverPlanner
===============


.. class:: ManeuverPlanner

   The maneuver planner, which makes maneuver nodes for its operations.

   .. note::

      MechJeb shares the operations, and most of their settings, between vessels.

   .. attribute:: operation_apoapsis

      The operation that changes the apoapsis.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`OperationApoapsis`
      :Game Scenes: Flight

      :rtype: :class:`OperationCircularize`

.. class:: OperationException

   Thrown when an operation cannot make its nodes, such as when it needs a target and
   there is none.

   A subclass of :class:`krpc.error.ServerError`.



TimeSelector
------------


.. class:: TimeSelector

   The time of a maneuver.

   .. attribute:: circularize_altitude

      The altitude, in meters.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies to :attr:`TimeReference.altitude`.

   .. attribute:: lead_time

      The time from now, in seconds.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies to :attr:`TimeReference.x_from_now`.

   .. attribute:: time_reference

      The time reference. Throws an exception if set to a reference the operation does
      not allow.

      :Attribute: Can be read or written
      :rtype: :class:`TimeReference`
      :Game Scenes: Flight



.. class:: TimeReference

   The time reference of a maneuver. See :attr:`TimeSelector.time_reference`.


   .. data:: altitude

      At :attr:`TimeSelector.circularize_altitude`.


   .. data:: apoapsis

      At the next apoapsis.


   .. data:: closest_approach

      At the closest approach to the target.


   .. data:: computed

      At the optimum time.


   .. data:: eq_ascending

      At the equatorial ascending node.


   .. data:: eq_descending

      At the equatorial descending node.


   .. data:: eq_highest_ad

      At the cheaper of the equatorial ascending and descending nodes.


   .. data:: eq_nearest_ad

      At the nearer of the equatorial ascending and descending nodes.


   .. data:: periapsis

      At the next periapsis.


   .. data:: rel_ascending

      At the next ascending node with the target.


   .. data:: rel_descending

      At the next descending node with the target.


   .. data:: rel_highest_ad

      At the cheaper of the ascending and descending nodes with the target.


   .. data:: rel_nearest_ad

      At the nearer of the ascending and descending nodes with the target.


   .. data:: x_from_now

      After :attr:`TimeSelector.lead_time`.

OperationResonantOrbit
^^^^^^^^^^^^^^^^^^^^^^


.. class:: OperationResonantOrbit

   Change to a resonant orbit, to place satellites in a constellation.

   .. note::

      Start from an orbit in the plane of the constellation. To deploy satellites, set the
      denominator to their number. A numerator one less than the denominator is the cheapest,
      though not the fastest. The two numbers must have no common factor.

   .. attribute:: error_message

      The warning from the last call to ``MakeNodes``, or an empty string.

      :Attribute: Read-only, cannot be set
      :rtype: str
      :Game Scenes: Flight

   .. method:: make_node()

      .. warning:: Deprecated. Use ``MakeNodes`` instead.

      Make the maneuver nodes of the operation, and return the first one.

      :returns: The first maneuver node.
      :rtype: :class:`SpaceCenter.Node`
      :Game Scenes: Flight

   .. method:: make_nodes()

      Make the maneuver nodes of the operation. Throws an :class:`OperationException`
      if the operation cannot make them.

      :returns: The maneuver nodes.
      :rtype: list(:class:`SpaceCenter.Node`)
      :Game Scenes: Flight


      .. note::

         A warning may be left in ``ErrorMessage``.

   .. attribute:: resonance_denominator

      The denominator of the ratio of the new orbital period to the current one.

      :Attribute: Can be read or written
      :rtype: int
      :Game Scenes: Flight

   .. attribute:: resonance_numerator

      The numerator of the ratio of the new orbital period to the current one.

      :Attribute: Can be read or written
      :rtype: int
      :Game Scenes: Flight

   .. attribute:: time_selector

      The time of the maneuver.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`TimeSelector`
      :Game Scenes: Flight

OperationTransfer
^^^^^^^^^^^^^^^^^


.. class:: OperationTransfer

   A bi-impulsive (Hohmann) transfer to the target, within one sphere of influence. It
   suits a rendezvous with a vessel or a transfer to a moon.

   .. note::

      Despite the name, the transfer is often uni-impulsive. It happens at the selected time,
      or at the optimum time.

   .. attribute:: error_message

      The warning from the last call to ``MakeNodes``, or an empty string.

      :Attribute: Read-only, cannot be set
      :rtype: str
      :Game Scenes: Flight

   .. method:: make_node()

      .. warning:: Deprecated. Use ``MakeNodes`` instead.

      Make the maneuver nodes of the operation, and return the first one.

      :returns: The first maneuver node.
      :rtype: :class:`SpaceCenter.Node`
      :Game Scenes: Flight

   .. method:: make_nodes()

      Make the maneuver nodes of the operation. Throws an :class:`OperationException`
      if the operation cannot make them.

      :returns: The maneuver nodes.
      :rtype: list(:class:`SpaceCenter.Node`)
      :Game Scenes: Flight


      .. note::

         A warning may be left in ``ErrorMessage``.

   .. attribute:: intercept_only

      Whether to plan only the intercept, with no capture burn, for an impact or a flyby.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. attribute:: simple_transfer

      Whether the transfer is coplanar.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. attribute:: time_selector

      The time of the maneuver.

      :Attribute: Read-only, cannot be set
      :rtype: :class:`TimeSelector`
      :Game Scenes: Flight
