SmartASS
========


.. class:: SmartASS

   The Smart A.S.S. window, which points the vessel in a chosen direction.

   .. attribute:: interface_mode

      The mode of the window, which selects its buttons and nothing else.
      Throws an exception if set to :attr:`SmartASSInterfaceMode.automatic`.

      :Attribute: Can be read or written
      :rtype: :class:`SmartASSInterfaceMode`
      :Game Scenes: Flight

   .. attribute:: autopilot_mode

      The autopilot mode. Throws an exception if set to
      :attr:`SmartASSAutopilotMode.automatic`.

      :Attribute: Can be read or written
      :rtype: :class:`SmartASSAutopilotMode`
      :Game Scenes: Flight


      .. note::

         Call :meth:`SmartASS.update` to apply a change.

   .. method:: update(reset_pid)

      Apply the settings.

      :param bool reset_pid: Whether to reset the attitude controller. Use it only if the vessel does not follow the new settings.
      :Game Scenes: Flight

   .. attribute:: force_yaw

      Whether the autopilot controls the yaw in the :attr:`SmartASSAutopilotMode.surface`,
      :attr:`SmartASSAutopilotMode.surface_prograde` and
      :attr:`SmartASSAutopilotMode.surface_retrograde` modes.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. attribute:: force_pitch

      Whether the autopilot controls the pitch in the :attr:`SmartASSAutopilotMode.surface`,
      :attr:`SmartASSAutopilotMode.surface_prograde` and
      :attr:`SmartASSAutopilotMode.surface_retrograde` modes.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. attribute:: force_roll

      Whether the autopilot controls the roll.

      :Attribute: Can be read or written
      :rtype: bool
      :Game Scenes: Flight

   .. attribute:: surface_heading

      The heading, in degrees.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface` mode.

   .. attribute:: surface_pitch

      The pitch above the horizon, in degrees. 90 is straight up.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface` mode.

   .. attribute:: surface_roll

      The roll, in degrees. 0 is top side up.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface` mode.

   .. attribute:: surface_vel_yaw

      The yaw from the surface velocity, in degrees.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface_prograde` and
         :attr:`SmartASSAutopilotMode.surface_retrograde` modes.

   .. attribute:: surface_vel_pitch

      The pitch from the surface velocity, in degrees.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface_prograde` and
         :attr:`SmartASSAutopilotMode.surface_retrograde` modes.

   .. attribute:: surface_vel_roll

      The roll, in degrees. 0 is top side up.

      :Attribute: Can be read or written
      :rtype: float
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.surface_prograde` and
         :attr:`SmartASSAutopilotMode.surface_retrograde` modes.

   .. attribute:: advanced_reference

      The reference frame of :attr:`SmartASS.advanced_direction`. Throws an exception if
      MechJeb uses a reference this enumeration lacks.

      :Attribute: Can be read or written
      :rtype: :class:`AttitudeReference`
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.advanced` mode.

   .. attribute:: advanced_direction

      The direction in :attr:`SmartASS.advanced_reference`.

      :Attribute: Can be read or written
      :rtype: :class:`Direction`
      :Game Scenes: Flight


      .. note::

         Applies in the :attr:`SmartASSAutopilotMode.advanced` mode.



.. class:: SmartASSInterfaceMode

   The mode of the Smart A.S.S. window. See :attr:`SmartASS.interface_mode`.


   .. data:: orbital

      The orbital modes.


   .. data:: surface

      The surface modes.


   .. data:: target

      The target modes.


   .. data:: advanced

      The advanced mode.


   .. data:: automatic

      Set by MechJeb's autopilots. Cannot be set.



.. class:: SmartASSAutopilotMode

   The autopilot mode of Smart A.S.S. See :attr:`SmartASS.autopilot_mode`.


   .. data:: off

      Off.


   .. data:: kill_rot

      Stop the vessel's rotation.


   .. data:: node

      Point at the next maneuver node.


   .. data:: advanced

      Point in the direction set by :attr:`SmartASS.advanced_reference` and
      :attr:`SmartASS.advanced_direction`.


   .. data:: automatic

      Set by MechJeb's autopilots. Cannot be set.


   .. data:: prograde

      Point orbital prograde.


   .. data:: retrograde

      Point orbital retrograde.


   .. data:: normal_plus

      Point orbit normal.


   .. data:: normal_minus

      Point orbit anti-normal.


   .. data:: radial_plus

      Point radially outward.


   .. data:: radial_minus

      Point radially inward.


   .. data:: surface_prograde

      Point along the surface velocity.


   .. data:: surface_retrograde

      Point against the surface velocity.


   .. data:: horizontal_plus

      Point along the horizontal surface velocity.


   .. data:: horizontal_minus

      Point against the horizontal surface velocity.


   .. data:: surface

      Point in the direction set by :attr:`SmartASS.surface_heading`,
      :attr:`SmartASS.surface_pitch` and :attr:`SmartASS.surface_roll`.


   .. data:: vertical_plus

      Point up, normal to the surface.


   .. data:: target_plus

      Point at the target.


   .. data:: target_minus

      Point away from the target.


   .. data:: relative_plus

      Point along the velocity relative to the target.


   .. data:: relative_minus

      Point against the velocity relative to the target.


   .. data:: parallel_plus

      Point parallel to the target's orientation. For a docking port, along its axis
      and away from it.


   .. data:: parallel_minus

      Point antiparallel to the target's orientation. For a docking port, along its axis
      and toward it.



.. class:: AttitudeReference

   A reference frame of Smart A.S.S. See :attr:`SmartASS.advanced_reference`.


   .. data:: inertial

      The world coordinate system.


   .. data:: orbit

      Forward is prograde, left is normal and up is radial out.


   .. data:: orbit_horizontal

      Forward is the orbital velocity projected onto the surface, and up is the surface normal.


   .. data:: surface_north

      Forward is north, left is west and up is the surface normal.


   .. data:: surface_velocity

      Forward is the surface velocity, and up is the surface normal perpendicular to it.


   .. data:: target

      Forward is toward the target, and up is the vessel's heading perpendicular to it.


   .. data:: relative_velocity

      Forward is the velocity relative to the target.


   .. data:: target_orientation

      Forward is the direction the target faces, and up is the target's up.


   .. data:: maneuver_node

      Forward is the burn direction of the next maneuver node.


   .. data:: sun

      Forward is the orbital velocity of the body that orbits the sun, and up is radial
      out of that orbit.


   .. data:: surface_horizontal

      Forward is the horizontal surface velocity, and up is the surface normal.



.. class:: Direction

   A direction of Smart A.S.S. See :attr:`SmartASS.advanced_direction`.


   .. data:: forward

      Forward.


   .. data:: back

      Back.


   .. data:: up

      Up.


   .. data:: down

      Down.


   .. data:: right

      Right.


   .. data:: left

      Left.
