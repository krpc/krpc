Laser
=====


.. class:: Laser

   .. warning:: Deprecated. Use :meth:`SpaceCenter.raycast_distance` instead.

   A LiDAR. Obtained by calling :meth:`LIDAR.laser`.

   .. attribute:: part: SpaceCenter.Part

      Get the part containing this LiDAR.

      :Attribute: Read-only, cannot be set

   .. attribute:: cloud: List

      Get the point cloud from the LiDAR.
      Returns an empty list on failure.

      :Attribute: Read-only, cannot be set
