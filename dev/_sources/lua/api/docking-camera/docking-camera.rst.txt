DockingCamera
=============


.. module:: DockingCamera

This service provides functionality to interact with
`Docking Camera (KURS) <https://spacedock.info/mod/1542>`_.


.. attribute:: available: boolean

   Whether Docking Camera (KURS) is available.

   :Attribute: Read-only, cannot be set




.. staticmethod:: camera(part: SpaceCenter.Part): DockingCamera.Camera

   Get the camera on a part.
   Throws an exception if the part is not an onboard camera or a docking port.

   :param part: The part.
