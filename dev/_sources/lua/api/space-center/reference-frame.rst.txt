ReferenceFrame
==============


.. class:: ReferenceFrame

   Represents a reference frame for positions, rotations and
   velocities. Contains:

   * The position of the origin.
   * The directions of the x, y and z axes.
   * The linear velocity of the frame.
   * The angular velocity of the frame.

   .. note::

      Apart from being created and removed, a reference frame is only used as a
      parameter to other functions.

   .. staticmethod:: create_relative(reference_frame: SpaceCenter.ReferenceFrame, position?: Tuple, rotation?: Tuple, velocity?: Tuple, angular_velocity?: Tuple): SpaceCenter.ReferenceFrame

      Create a relative reference frame. This is a custom reference frame
      whose components offset the components of a parent reference frame.

      :param reference_frame: The parent reference frame on which to base this reference frame.
      :param position: The offset of the position of the origin, as a position vector. Defaults to ``(0, 0, 0)`` Defaults to ``{0.0, 0.0, 0.0}``.
      :param rotation: The rotation to apply to the parent frames rotation, as a quaternion of the form ``(x, y, z, w)``. Defaults to ``(0, 0, 0, 1)`` (i.e. no rotation) Defaults to ``{0.0, 0.0, 0.0, 1.0}``.
      :param velocity: The linear velocity to offset the parent frame by, as a vector pointing in the direction of travel, whose magnitude is the speed in :math:`\mathrm{m/s}`. Defaults to ``(0, 0, 0)``. Defaults to ``{0.0, 0.0, 0.0}``.
      :param angular_velocity: The angular velocity to offset the parent frame by, as a vector. This vector points in the direction of the axis of rotation, and its magnitude is the speed of the rotation in :math:`\mathrm{rad/s}`. Defaults to ``(0, 0, 0)``. Defaults to ``{0.0, 0.0, 0.0}``.

      .. note::

         Each call returns a new frame, which is kept until :meth:`SpaceCenter.ReferenceFrame.remove` is
         called on it or the client that created it disconnects, so a script that
         creates one repeatedly, for example once per update, should remove each one
         when it is finished with it.

   .. staticmethod:: create_hybrid(position: SpaceCenter.ReferenceFrame, rotation?: SpaceCenter.ReferenceFrame | Types.none, velocity?: SpaceCenter.ReferenceFrame | Types.none, angular_velocity?: SpaceCenter.ReferenceFrame | Types.none): SpaceCenter.ReferenceFrame

      Create a hybrid reference frame. This is a custom reference frame
      whose components inherited from other reference frames.

      :param position: The reference frame providing the position of the origin.
      :param rotation: The reference frame providing the rotation of the frame.
      :param velocity: The reference frame providing the linear velocity of the frame.
      :param angular_velocity: The reference frame providing the angular velocity of the frame.

      .. note::

         The *position* reference frame is required but all other
         reference frames are optional. If omitted, they are set to the
         *position* reference frame.

         Each call returns a new frame, which is kept until :meth:`SpaceCenter.ReferenceFrame.remove` is
         called on it or the client that created it disconnects, so a script that
         creates one repeatedly, for example once per update, should remove each one
         when it is finished with it.

   .. method:: remove()

      Remove the reference frame, releasing the memory the server holds for it.


      .. note::

         Only a frame created by :meth:`SpaceCenter.ReferenceFrame.create_relative` or
         :meth:`SpaceCenter.ReferenceFrame.create_hybrid` can be removed. Every other frame belongs to
         something in the game, and the server holds one of each.

         Any further use of this object throws an exception, as does use of a frame
         built on it, which cannot be evaluated without it. A frame belongs to the
         client that created it, and is removed when that client disconnects.
