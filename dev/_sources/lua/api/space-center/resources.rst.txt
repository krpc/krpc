Resources
=========


.. class:: Resources

   Represents the collection of resources stored in a vessel, stage or part.
   Created by calling :attr:`SpaceCenter.Vessel.resources`,
   :meth:`SpaceCenter.Stage.resources`, :attr:`SpaceCenter.EditorVessel.resources`
   or :attr:`SpaceCenter.Part.resources`.

   .. attribute:: all: List

      All the individual resources that can be stored.

      :Attribute: Read-only, cannot be set

   .. method:: with_resource(name: string): List

      All the individual resources with the given name that can be stored.

   .. attribute:: names: List

      A list of resource names that can be stored.

      :Attribute: Read-only, cannot be set

   .. method:: has_resource(name: string): boolean

      Check whether the named resource can be stored.

      :param name: The name of the resource.

   .. method:: amount(name: string): number

      Returns the amount of a resource that is currently stored.

      :param name: The name of the resource.

   .. method:: max(name: string): number

      Returns the amount of a resource that can be stored.

      :param name: The name of the resource.

   .. staticmethod:: density(name: string): number

      Returns the density of a resource, in :math:`\mathrm{kg/l}`.

      :param name: The name of the resource.

   .. staticmethod:: flow_mode(name: string): SpaceCenter.ResourceFlowMode

      Returns the flow mode of a resource.

      :param name: The name of the resource.

   .. attribute:: enabled: boolean

      Whether use of all the resources are enabled.

      :Attribute: Can be read or written

      .. note::

         This is ``True`` if all of the resources are enabled.
         If any of the resources are not enabled, this is ``False``.



.. class:: Resource

   An individual resource stored within a part.
   Created using methods in the :class:`SpaceCenter.Resources` class.

   .. attribute:: name: string

      The name of the resource.

      :Attribute: Read-only, cannot be set

   .. attribute:: part: SpaceCenter.Part

      The part containing the resource.

      :Attribute: Read-only, cannot be set

   .. attribute:: amount: number

      The amount of the resource that is currently stored in the part.

      :Attribute: Read-only, cannot be set

   .. attribute:: max: number

      The total amount of the resource that can be stored in the part.

      :Attribute: Read-only, cannot be set

   .. attribute:: density: number

      The density of the resource, in :math:`\mathrm{kg/l}`.

      :Attribute: Read-only, cannot be set

   .. attribute:: flow_mode: SpaceCenter.ResourceFlowMode

      The flow mode of the resource.

      :Attribute: Read-only, cannot be set

   .. attribute:: enabled: boolean

      Whether use of this resource is enabled.

      :Attribute: Can be read or written



.. class:: ResourceTransfer

   Transfer resources between parts.

   .. staticmethod:: start(from_part: SpaceCenter.Part, to_part: SpaceCenter.Part, resource: string, max_amount: number): SpaceCenter.ResourceTransfer

      Start transferring a resource transfer between a pair of parts. The transfer will move
      at most *max_amount* units of the resource, depending on how much of
      the resource is available in the source part and how much storage is available in the
      destination part.
      Use :attr:`SpaceCenter.ResourceTransfer.complete` to check if the transfer is complete.
      Use :attr:`SpaceCenter.ResourceTransfer.amount` to see how much of the resource has been transferred.

      :param from_part: The part to transfer to.
      :param to_part: The part to transfer from.
      :param resource: The name of the resource to transfer.
      :param max_amount: The maximum amount of resource to transfer.

      .. note::

         Use :meth:`SpaceCenter.ResourceTransfer.cancel` to stop the transfer before it finishes; a canceled
         transfer is marked as complete. Use :meth:`SpaceCenter.ResourceTransfer.remove` to release the memory
         the server holds for a transfer that is done with. A transfer is stopped and
         removed if the client that started it disconnects, or if the flight it runs in
         is left.

   .. method:: cancel()

      Cancel the transfer. No more of the resource is moved and
      :attr:`SpaceCenter.ResourceTransfer.complete` becomes true.

   .. method:: remove()

      Remove the transfer, releasing the memory the server holds for it. The
      transfer is canceled if it has not finished.


      .. note::

         Any further use of this object throws an exception. A transfer that is left is
         held until the parts it runs between are gone, the flight it runs in is left,
         or the client that started it disconnects, whichever comes first; the first of
         those may be the rest of the flight away.

   .. attribute:: amount: number

      The amount of the resource that has been transferred.

      :Attribute: Read-only, cannot be set

   .. attribute:: complete: boolean

      Whether the transfer has completed. Also becomes true if the transfer is
      canceled by calling :meth:`SpaceCenter.ResourceTransfer.cancel`.

      :Attribute: Read-only, cannot be set



.. class:: ResourceFlowMode

   The way in which a resource flows between parts. See :meth:`SpaceCenter.Resources.flow_mode`.


   .. data:: vessel

      The resource flows to any part in the vessel. For example, electric charge.


   .. data:: stage

      The resource flows from parts in the first stage, followed by the second,
      and so on. For example, mono-propellant.


   .. data:: adjacent

      The resource flows between adjacent parts within the vessel. For example,
      liquid fuel or oxidizer.


   .. data:: none

      The resource does not flow. For example, solid fuel.
