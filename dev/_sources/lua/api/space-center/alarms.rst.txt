Alarms
======


.. class:: AlarmManager

   Alarm manager.
   Obtained by calling :attr:`SpaceCenter.alarm_manager`.

   .. attribute:: alarms: List

      A list of all alarms.

      :Attribute: Read-only, cannot be set

   .. method:: alarms_with_type(type: SpaceCenter.AlarmType): List

      A list of all alarms of the given type.

      :param type: The type of alarm to return.

   .. method:: alarm_with_name(name: string): SpaceCenter.Alarm | nil

      Returns the first alarm with the given title, or ``nil`` if no such
      alarm exists. Alarm titles are not guaranteed to be unique; if more than
      one alarm shares the given title, the first one found is returned.

      :param name: The title of the alarm to return.

   .. staticmethod:: add_alarm(time: number, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm.

      :param time: Number of seconds from now that the alarm should trigger.
      :param title: Title for the alarm. Defaults to ``'Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_vessel_alarm(time: number, vessel: SpaceCenter.Vessel, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm linked to a vessel.

      :param time: Number of seconds from now that the alarm should trigger.
      :param vessel: Vessel to link the alarm to.
      :param title: Title for the alarm. Defaults to ``'Vessel Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_apoapsis_alarm(vessel: SpaceCenter.Vessel, offset?: number, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm for the given vessel's next apoapsis.

      :param vessel: The vessel.
      :param offset: Time in seconds to offset the alarm by. Defaults to ``60.0``.
      :param title: Title for the alarm. Defaults to ``'Apoapsis Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_periapsis_alarm(vessel: SpaceCenter.Vessel, offset?: number, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm for the given vessel's next periapsis.

      :param vessel: The vessel.
      :param offset: Time in seconds to offset the alarm by. Defaults to ``60.0``.
      :param title: Title for the alarm. Defaults to ``'Periapsis Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_maneuver_node_alarm(vessel: SpaceCenter.Vessel, node: SpaceCenter.Node, offset?: number, add_burn_time?: boolean, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm for the given vessel and maneuver node.

      :param vessel: The vessel.
      :param node: The maneuver node.
      :param offset: Time in seconds to offset the alarm by. Defaults to ``60.0``.
      :param add_burn_time: Whether the node's burn time should be included in the alarm. Defaults to ``true``.
      :param title: Title for the alarm. Defaults to ``'Maneuver Node Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_soi_alarm(vessel: SpaceCenter.Vessel, offset?: number, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm for the given vessel's next sphere of influence change.

      :param vessel: The vessel.
      :param offset: Time in seconds to offset the alarm by. Defaults to ``60.0``.
      :param title: Title for the alarm. Defaults to ``'SOI Change Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

   .. staticmethod:: add_transfer_window_alarm(vessel: SpaceCenter.Vessel, target: SpaceCenter.CelestialBody, title?: string, description?: string): SpaceCenter.Alarm

      Create an alarm for the next planetary transfer window from the vessel's
      current parent body to the target body.

      :param vessel: The vessel.
      :param target: The target body.
      :param title: Title for the alarm. Defaults to ``'Transfer Window Alarm'``.
      :param description: Description for the alarm. Defaults to ``''``.

      .. note::

         This relies on KSP's stock transfer-window alarm logic. If KSP cannot
         compute a transfer from the vessel's current parent body to the target,
         the resulting alarm may not fire at a useful time; in that case the
         properties on the returned alarm can still be used to inspect or adjust it.



.. class:: Alarm

   An alarm. Can be accessed using :attr:`SpaceCenter.alarm_manager`.

   .. attribute:: id: number

      Unique identifier of the alarm.
      KSP destroys and recreates an alarm when it is edited.
      This id will remain constant between the old and new alarms.

      :Attribute: Read-only, cannot be set

   .. attribute:: type: SpaceCenter.AlarmType

      Type of alarm.

      :Attribute: Read-only, cannot be set

   .. attribute:: title: string

      Title of the alarm.

      :Attribute: Can be read or written

   .. attribute:: description: string

      Description of the alarm.

      :Attribute: Can be read or written

   .. attribute:: time: number

      Time the alarm will trigger, in seconds since epoch.

      :Attribute: Can be read or written

   .. attribute:: time_until: number

      Time until the alarm triggers, in seconds.

      :Attribute: Read-only, cannot be set

   .. attribute:: event_offset: number

      Seconds between the alarm going off and the event it references.

      :Attribute: Can be read or written

      .. note::

         For a maneuver alarm that includes the burn time, setting this sets the margin
         before the start of the burn, and the value read back includes half the burn time.

   .. attribute:: vessel: SpaceCenter.Vessel | nil

      Vessel the alarm references. ``nil`` if it does not reference a vessel.

      :Attribute: Read-only, cannot be set

   .. attribute:: node: SpaceCenter.Node

      Maneuver node the alarm references. Only valid for alarms of type
      :data:`SpaceCenter.AlarmType.maneuver`.

      :Attribute: Can be read or written

      .. note::

         Throws an exception if the alarm is not of
         type :data:`SpaceCenter.AlarmType.maneuver`.

   .. attribute:: origin_body: SpaceCenter.CelestialBody

      Origin body for the transfer window. Only valid for alarms of type
      :data:`SpaceCenter.AlarmType.transfer_window`.

      :Attribute: Can be read or written

      .. note::

         Throws an exception if the alarm is not of
         type :data:`SpaceCenter.AlarmType.transfer_window`.

   .. attribute:: destination_body: SpaceCenter.CelestialBody

      Destination body for the transfer window. Only valid for alarms of type
      :data:`SpaceCenter.AlarmType.transfer_window`.

      :Attribute: Can be read or written

      .. note::

         Throws an exception if the alarm is not of
         type :data:`SpaceCenter.AlarmType.transfer_window`.

   .. attribute:: warp_action: SpaceCenter.AlarmWarpAction

      The action taken on time warp when the alarm fires.

      :Attribute: Can be read or written

   .. attribute:: message_action: SpaceCenter.AlarmMessageAction

      The on-screen message behavior when the alarm fires.

      :Attribute: Can be read or written

   .. attribute:: play_sound: boolean

      Whether the alarm plays a sound when it fires.

      :Attribute: Can be read or written

   .. attribute:: delete_on_dismiss: boolean

      Whether the alarm is deleted automatically once the player has dismissed
      the triggered message.

      :Attribute: Can be read or written

   .. attribute:: triggered: boolean

      Whether the time of the alarm has passed and its actions have been triggered.

      :Attribute: Read-only, cannot be set

   .. attribute:: actioned: boolean

      Whether the alarm's actions were triggered and then completed or closed.

      :Attribute: Read-only, cannot be set

   .. method:: remove()

      Removes the alarm.


      .. note::

         Any further use of this object throws an exception.



.. class:: AlarmType

   The type of an alarm. See :attr:`SpaceCenter.Alarm.type`.


   .. data:: raw

      An alarm for a specific date/time or a specific period in the future.


   .. data:: apoapsis

      An alarm for the next apoapsis of a vessel.


   .. data:: periapsis

      An alarm for the next periapsis of a vessel.


   .. data:: maneuver

      An alarm based on a maneuver node on the vessel's flight path.


   .. data:: soi_change

      An alarm for the next sphere of influence change on the vessel's flight path.


   .. data:: transfer_window

      An alarm for the next planetary transfer window from the vessel's current
      orbit to a target body.


   .. data:: unknown

      The alarm is of a type not recognized by kRPC. Typically this is a type
      introduced by a mod.



.. class:: AlarmWarpAction

   The warp action taken when an alarm fires.
   See :attr:`SpaceCenter.Alarm.warp_action`.


   .. data:: no_change

      Do not change time warp when the alarm fires.


   .. data:: stop_warp

      Drop out of time warp when the alarm fires.


   .. data:: pause_game

      Pause the game when the alarm fires.



.. class:: AlarmMessageAction

   The on-screen message action taken when an alarm fires.
   See :attr:`SpaceCenter.Alarm.message_action`.


   .. data:: no_message

      Do not display a message when the alarm fires.


   .. data:: message

      Display a message when the alarm fires.


   .. data:: message_if_not_active_vessel

      Display a message only if the alarm's vessel is not the currently active vessel.
