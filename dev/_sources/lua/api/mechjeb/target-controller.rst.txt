TargetController
================


.. class:: TargetController

   The target controller, which holds MechJeb's target.

   .. note::

      Positions and directions are in world space, the coordinate system of the game's
      physics.

   .. attribute:: can_align: boolean

      Whether the vessel can align with the target, which it can with a docking port.

      :Attribute: Read-only, cannot be set

   .. attribute:: distance: number

      The distance to the target, in meters.

      :Attribute: Read-only, cannot be set

   .. attribute:: docking_axis: Tuple

      The world space docking axis of the target.

      :Attribute: Read-only, cannot be set

   .. method:: get_position_target_position(): Tuple

      The world space position of the position target.

   .. method:: get_position_target_string(): string

      The position target as text.

   .. attribute:: normal_target_exists: boolean

      Whether there is a target that is a vessel, a body or a direction target.

      :Attribute: Read-only, cannot be set

   .. method:: pick_position_target_on_map()

      Let the player pick the position target on the map.

   .. attribute:: position: Tuple

      The world space position of the target.

      :Attribute: Read-only, cannot be set

   .. attribute:: position_target_exists: boolean

      Whether there is a target that is a position or a vessel.

      :Attribute: Read-only, cannot be set

   .. attribute:: relative_position: Tuple

      The world space position of the vessel relative to the target.

      :Attribute: Read-only, cannot be set

   .. attribute:: relative_velocity: Tuple

      The world space velocity of the vessel relative to the target, in :math:`\mathrm{m/s}`.

      :Attribute: Read-only, cannot be set

   .. method:: set_direction_target(name: string)

      Set the target to a direction.

      :param name: The name of the target.

      .. note::

         Set the direction with :meth:`MechJeb.TargetController.update_direction_target`.

   .. method:: set_position_target(body: SpaceCenter.CelestialBody, latitude: number, longitude: number)

      Set the target to a position on the surface of a body.

      :param body: The body.
      :param latitude: The latitude, in degrees.
      :param longitude: The longitude, in degrees.

   .. attribute:: target_orbit: SpaceCenter.Orbit

      The orbit of the target.

      :Attribute: Read-only, cannot be set

   .. method:: update_direction_target(direction: Tuple)

      Set the direction of the direction target.

      :param direction: The world space direction.
