Debug
=====


.. module:: Debug

Provides functionality to modify the state of the simulation directly, in ways
the game normally does not allow: teleporting a vessel, setting its attitude,
refilling its tanks and enabling the game's cheat options.

.. note::

   Everything in this service is cheating. It has the same effect on a save as the
   game's own debug menu (Alt+F12), and the same consequences: contracts, records and
   career progress made with it are not earned. It is intended for setting up a
   scenario to fly or a script to test, without flying there first.



.. staticmethod:: set_circular_orbit(body, altitude)

   Move the active vessel onto a circular orbit around a body.

   :param SpaceCenter.CelestialBody body: Body to orbit.
   :param number altitude: Altitude of the orbit, in meters above sea level.




.. staticmethod:: set_orbit(body, semi_major_axis, eccentricity, inclination, longitude_of_ascending_node, argument_of_periapsis, mean_anomaly_at_epoch, epoch)

   Move the active vessel onto the orbit with the given orbital elements. The angles use
   the same units and conventions as :class:`SpaceCenter.Orbit`.

   :param SpaceCenter.CelestialBody body: Body to orbit.
   :param number semi_major_axis: Semi-major axis of the orbit, in meters.
   :param number eccentricity: Eccentricity of the orbit.
   :param number inclination: Inclination of the orbit, in radians.
   :param number longitude_of_ascending_node: Longitude of the ascending node, in radians.
   :param number argument_of_periapsis: Argument of periapsis, in radians.
   :param number mean_anomaly_at_epoch: Mean anomaly at epoch, in radians.
   :param number epoch: Universal time of the epoch, in seconds.




.. staticmethod:: set_landed(body, latitude, longitude, [altitude = 0.0])

   Place the active vessel on the surface of a body at the given latitude and longitude,
   and wait for it to come to rest.

   :param SpaceCenter.CelestialBody body: Body to land on.
   :param number latitude: Latitude in degrees.
   :param number longitude: Longitude in degrees.
   :param number altitude: Height above the terrain to settle at, in meters. Defaults to 0, resting on the surface.




.. staticmethod:: set_flight(body, latitude, longitude, altitude, speed, heading, [pitch = 0.0], [roll = 0.0], [angle_of_attack = 0.0])

   Place the active vessel in atmospheric flight over the given point: at the given altitude
   and airspeed, pointing along the given heading at the given pitch and roll, and
   let physics resume so that it is flying. Use this to set up an in-air scenario
   without flying the craft up from the runway.

   :param SpaceCenter.CelestialBody body: Body to fly over.
   :param number latitude: Latitude in degrees.
   :param number longitude: Longitude in degrees.
   :param number altitude: Altitude in meters above sea level.
   :param number speed: Airspeed in meters per second, relative to the surface.
   :param number heading: Compass heading to point along, in degrees (90 is east).
   :param number pitch: Pitch above the horizon, in degrees. Defaults to 0 (level).
   :param number roll: Roll, in degrees. Defaults to 0 (wings level).
   :param number angle_of_attack: Angle of attack in degrees: how far the airspeed vector sits below the nose, in the pitch plane. 0 (the default) puts the airspeed along the nose; a positive value gives a nose-up attitude relative to the flight path, so the flight-path angle is *pitch* minus this.

   .. note::

      The pitch, heading and roll match those reported by the vessel's
      :class:`SpaceCenter.Flight`.




.. staticmethod:: set_position(position, reference_frame)

   Move the active vessel to the given position, leaving its velocity as it is. To put it
   alongside another vessel, pass a position in that vessel's reference frame.

   :param Tuple position: Position of the vessel's center of mass, in meters.
   :param SpaceCenter.ReferenceFrame reference_frame: Reference frame the position is in. Defaults to the reference frame of the body being orbited.

   .. note::

      This is the inverse of :meth:`SpaceCenter.Vessel.position` in the same
      reference frame.




.. staticmethod:: set_velocity(velocity, reference_frame)

   Set the velocity of the active vessel, leaving it where it is. The vessel is moved onto the
   orbit that passes through its current position at the new velocity, so this works
   in orbit and in the atmosphere alike.

   :param Tuple velocity: Velocity in meters per second.
   :param SpaceCenter.ReferenceFrame reference_frame: Reference frame the velocity is in. Defaults to the reference frame of the body being orbited, which rotates with it, so a zero velocity leaves the vessel at rest relative to the ground.

   .. note::

      This is the inverse of :meth:`SpaceCenter.Vessel.velocity` in the same
      reference frame.




.. staticmethod:: set_pitch_heading_roll(pitch, heading, roll, reference_frame, vessel)

   Set the attitude of a vessel to the given pitch, heading and roll in the given
   reference frame, and stop it rotating. Lets a script start from a fixed, still
   pose without first flying the autopilot there.

   :param number pitch: Target pitch, in degrees.
   :param number heading: Target heading, in degrees.
   :param number roll: Target roll, in degrees.
   :param SpaceCenter.ReferenceFrame reference_frame: Reference frame the angles are in. Defaults to the vessel's surface reference frame.
   :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.

   .. note::

      The angles match those reported by the vessel's
      :class:`SpaceCenter.Flight`.




.. staticmethod:: set_direction(direction, roll, reference_frame, vessel)

   Point a vessel along the given direction in the given reference frame, and stop it
   rotating. This is :meth:`Debug.set_pitch_heading_roll` with a pointing vector instead
   of a pitch and heading, matching the attitude the autopilot holds for the same
   target direction and roll.

   :param Tuple direction: Direction to point the nose of the vessel in.
   :param number roll: Target roll, in degrees, or ``NaN`` to leave the roll uncontrolled.
   :param SpaceCenter.ReferenceFrame reference_frame: Reference frame the direction and roll are in. Defaults to the vessel's surface reference frame.
   :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.




.. staticmethod:: apply_rotation(angle, axis, vessel)

   Rotate a vessel about the given axis, in its own reference frame, by the given angle.

   :param number angle: Angle to rotate by, in degrees.
   :param Tuple axis: Axis to rotate about.
   :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.




.. staticmethod:: set_angular_velocity(angular_velocity, reference_frame, vessel)

   Set the angular velocity of a vessel, expressed in the given reference frame. Pass a
   zero vector to stop the vessel rotating.

   :param Tuple angular_velocity: Angular velocity, in radians per second. The direction is the axis of rotation and the magnitude is the rate.
   :param SpaceCenter.ReferenceFrame reference_frame: Reference frame the angular velocity is in. Defaults to the vessel's surface reference frame.
   :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.

   .. note::

      The whole vessel is put into a rigid rotation about its center of mass, so it spins in
      place rather than shearing apart or translating.




.. staticmethod:: fill_all_resources(vessel)

   Fill every resource tank on a vessel to its maximum capacity.

   :param SpaceCenter.Vessel vessel: Vessel to fill. Defaults to the active vessel.




.. staticmethod:: fill_resources(resource_name, vessel)

   Fill the tanks of a single resource on a vessel to their maximum capacity.

   :param string resource_name: Name of the resource to fill, for example ``"LiquidFuel"``.
   :param SpaceCenter.Vessel vessel: Vessel to fill. Defaults to the active vessel.

.. staticmethod:: unlock_technology_tree()

   Research every node in the technology tree and purchase every part in it.
   Only available in career and science mode.





.. staticmethod:: upgrade_facilities()

   Upgrade every building at the space center to its highest level.
   Only available in career mode.

   Raise every kerbal in the roster to the highest experience level.
