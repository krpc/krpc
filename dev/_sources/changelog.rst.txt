Changelog
=========


v0.8.0 - unreleased
-------------------


SpaceCenter service
^^^^^^^^^^^^^^^^^^^

* Allow the rails warp rates the game allows the player, which ignore the altitude limits when the periapsis is clear of the atmosphere and terrain (:issue:`1167`)


v0.7.0
------


Core
^^^^

* Server side functions

  * Extend ``KRPC.Expression`` to build server side functions, which the server evaluates (:issue:`503`, :issue:`517`, :issue:`521`, :issue:`1124`)
  * Allow a function to declare local variables, loop, branch, assign, return early, raise and handle exceptions, and call a procedure that returns no value (:issue:`1124`)
  * Allow a function to work on strings, nullable values, and lists, sets and dictionaries, including changing them (:issue:`1124`)
  * Add ``KRPC.RunFunction``, which runs a function once within a single physics tick, and ``KRPC.CompileFunction`` and ``KRPC.AddFunctionStream`` (:issue:`1124`)
  * Add ``KRPC.Expression.StateVariable``, a variable that keeps its value between evaluations of a function (:issue:`1124`)
  * Add ``KRPC.Expression.CallWithArguments``, ``CreateStruct``, ``GetField``, ``IsNull``, ``Negate``, ``Conditional``, ``ConditionalAnd``, ``ConditionalOr``, the empty collections and a constant for every type (:issue:`1124`)
  * Add ``KRPC.Expression.ReturnType`` and ``HasReturnType`` (:issue:`1124`)
  * Add ``KRPC.TypeCode`` and the ``Code``, ``Service``, ``Name``, ``Types`` and ``Nullable`` properties of ``KRPC.Type``, which names every type a procedure takes or returns (:issue:`1124`)
  * Add the ``StdLib`` service, of scalar mathematics and vector and quaternion operations, with ``StdLib.Print`` for debugging a function (:issue:`1125`)
  * Widen numbers, tuples and collections to a common type in ``KRPC.Expression.Invoke``, ``Cast``, ``CreateList``, ``CreateSet``, ``CreateDictionary`` and ``Concat`` (:issue:`1124`)
  * Fix ``KRPC.Expression.Count`` on a returned collection, and ``OrderBy`` ordering strings by the system locale (:issue:`1124`)
  * Fix ``KRPC.Expression.Equal``, ``NotEqual``, ``Contains``, ``ToSet`` and ``CreateSet`` comparing objects, tuples, bytes and collections by reference (:issue:`1124`)
  * Fix the integer arithmetic of ``KRPC.Expression`` for mixed operand types, on overflow and for the smallest integer divided by -1 (:issue:`1124`)
  * :breaking:`Breaking` Rename ``KRPC.Expression.Function`` to ``Lambda``, and the parameter of ``KRPC.AddEvent`` from ``expression`` to ``function`` (:issue:`1124`)
  * :breaking:`Breaking` Renumber the procedures of the ``KRPC`` service, so a client that calls them by id must use stubs generated for this version (:issue:`1124`)
  * :breaking:`Breaking` Type ``KRPC.Expression.Power`` by both operands, require a constant index in ``Get``, limit ``CreateTuple`` to seven elements, and reject calls to ``KRPC`` procedures (:issue:`1124`)

* Errors

  * Add ``KRPC.NullReferenceException``, ``KeyNotFoundException``, ``IndexOutOfRangeException``, ``DivideByZeroException``, ``NotSupportedException``, ``TimeoutException`` and ``OverflowException``, raised by any service and by a function (:issue:`1124`)
  * Add ``KRPC.Error``, a general error a function can raise (:issue:`1124`)
  * Add ``KRPC.ObjectDestroyedException``, for an object whose game object is gone, and ``KRPC.ObjectNotLoadedException``, for one that is not loaded (:issue:`1051`, :issue:`1120`)
  * :breaking:`Breaking` Throw ``KRPC.UnsupportedSceneException`` for a procedure called outside its game scenes (:issue:`1119`)

* Streams and events

  * :breaking:`Breaking` Start a stream when it is added, removing ``KRPC.StartStream`` and the ``start`` argument of ``KRPC.AddStream`` (:issue:`1122`)
  * :breaking:`Breaking` Create a new stream for every ``KRPC.AddStream``, so removing one leaves the others for the same call (:issue:`1122`, :issue:`902`)
  * Hold a stream or event over an unloaded object, or a procedure unavailable in the game scene, until it is available (:issue:`1122`, :issue:`877`)
  * Add ``KRPC.StreamRemovedException``, the final result of a stream the server ends (:issue:`1122`)
  * Throw an exception when streaming a procedure that returns a stream or event, and from ``KRPC.RemoveStream`` for an unknown stream id (:issue:`1122`)
  * Fix a failing stream or event stopping the others, and the server keeping memory for every stream sent on a connection (:issue:`1122`)

* Types and protocol

  * :breaking:`Breaking` Support null for any nullable type, signaled by an ``is_null`` field. Class-typed arguments are not implicitly nullable (:issue:`1017`)
  * :breaking:`Breaking` Carry nullability in ``Type.nullable`` at every position, replacing ``Parameter.nullable`` and ``Procedure.return_is_nullable`` (:issue:`1091`)
  * :breaking:`Breaking` Return ``KRPC.Clients`` as a list of ``KRPC.ClientInfo`` structures (:issue:`1148`)
  * Allow a structure field, list element, tuple item and dictionary value to be nullable, declared with ``Nullable<T>`` or ``KRPCNullable`` (:issue:`1091`)
  * Add structure types, a compound value with named fields, declared with ``KRPCStruct`` on a C# ``struct`` (:issue:`1066`)
  * Add ``StdLib.ColorRGB`` and ``StdLib.ColorRGBA``, the colors of the SpaceCenter, Drawing and UI services (:issue:`1148`)
  * Add extension members, which a service declares on another service's class as C# extension methods (:issue:`1077`)
  * Add a communication protocol over a unix domain socket, for clients on the same machine as the game (:issue:`1065`)
  * Fix a serial connection freezing the game while it carries an RPC (:issue:`1035`)
  * Add a protocol version to the connection handshake, sent over WebSockets as the subprotocol ``krpc.N`` and reported by ``KRPC.GetStatus`` (:issue:`1162`)
  * Fix an exception on a serial connection request that carries no ``ConnectionRequest`` (:issue:`1162`)
  * Encode and decode values without reflection, cutting the server cost of a call that passes or returns an object by about three quarters (:issue:`1091`)

* Game state

  * :breaking:`Breaking` Remove ``KRPC.CurrentGameScene``, replaced by ``KRPC.GameScene`` (:issue:`1140`)
  * Add ``KRPC.HoldTick``, ``KRPC.ReleaseTick`` and ``KRPC.NextTick``, which hold the game on one physics tick so a control loop can read, compute and write within it (:issue:`1070`)
  * Add ``KRPC.GameStateLoads``, the number of game states that have finished loading (:issue:`1121`)
  * Remove objects whose game objects are gone from the object store when a game state loads (:issue:`1051`)
  * Fix one server stopping emptying the object store that every server shares (:issue:`1020`)
  * Fix a request naming an object the server no longer has leaving the connection stuck (:issue:`1019`)



Server
^^^^^^

* :breaking:`Breaking` KSP 1.12.5 is the minimum supported version, matching the maximum (:issue:`1048`)
* Add the local socket protocol to the server window. It opens no network port (:issue:`1065`)
* Add the ``TickHoldTimeout`` setting, which bounds how long a client may hold the game on one physics tick (:issue:`1070`)
* Update the server before the game collects control inputs, so a control input takes effect on the tick of its call (:issue:`1070`)
* Stop the server whenever no game is loaded, disconnecting clients when the player quits to the main menu (:issue:`1041`)
* Save the game when setting ``KRPC.GameScene`` leaves flight, unless the game cannot be saved (:issue:`1117`)
* Remove objects whose game objects are gone from the object store when the game loads, changes scene or destroys a part or vessel (:issue:`1051`)
* Fix setting ``KRPC.GameScene`` from one editor to the other, or back to flight, breaking the flight camera or failing with a null reference (:issue:`1038`, :issue:`1117`)
* Fix the error from a call that waits on the game being reported as ``Exception has been thrown by the target of an invocation`` (:issue:`1083`)
* Fix the end of a long serial port name being hidden in the server window (:issue:`1065`)

  * Fix decoupler, maneuver node and force objects accumulating for the rest of the session (:issue:`1051`, :issue:`771`)
  * Add ``Orbit.Remove``, ``ReferenceFrame.Remove`` and ``ResourceTransfer.Remove``, which free the memory the server holds for an object (:issue:`1072`)
  * :breaking:`Breaking` Return a new frame from each call to ``ReferenceFrame.CreateRelative`` and ``CreateHybrid``, owned by the calling client (:issue:`1072`)
  * Throw an exception from ``ReferenceFrame.CreateRelative`` and ``CreateHybrid`` when given no frame (:issue:`1072`)

  * :breaking:`Breaking` Make ``LaunchSite``, ``ScienceSubject``, ``ScienceData``, ``ActionGroupAction`` and ``CommNode`` structures (:issue:`1148`, :issue:`1132`)

  * Add ``ScienceSubject.Id`` (:issue:`1148`)

* Space center

  * :breaking:`Breaking` Remove ``SpaceCenter.LoadSpaceCenter``, replaced by setting ``KRPC.GameScene`` (:issue:`1140`)
  * Add ``SpaceCenter.CanSave``, whether the game can be saved (:issue:`1117`)

  * Throw an exception from ``SpaceCenter.WarpTo`` if the game scene changes during the warp (:issue:`1145`)

  * Fix setting ``SpaceCenter.ActiveVessel`` from the space center or tracking station clearing the game's contracts (:issue:`1102`)
  * Fix the offset of an apoapsis, periapsis, SOI or maneuver node alarm, and ``Alarm.EventOffset``, leaving the alarm time unchanged (:issue:`1114`)
  * Fix many stages, vessel resources, communication links, resource converters or hybrid reference frames slowing the server down (:issue:`1071`)

* Editor

  * Add ``SpaceCenter.Editor``, for the vessel under construction in the vehicle assembly building and space plane hangar, with ``Editor.LoadVessel`` and ``Editor.LaunchVessel`` (:issue:`1038`)
  * Add ``EditorVessel.Parts``, ``Resources``, ``Stages``, ``StageAt``, ``DecoupleStages`` and ``DecoupleStageAt``, with the figures they give in flight (:issue:`1038`)

  * Add ``EditorVessel.Position``, ``MomentOfInertia``, ``InertiaTensor``, ``ReferenceFrame``, ``SurfaceReferenceFrame``, ``BoundingBox``, ``Rotation`` and ``Direction``, as on ``Vessel`` (:issue:`1059`, :issue:`1153`)
  * Make the position, orientation, mass and inertia members of ``Part`` available in the editor (:issue:`1059`, :issue:`1064`, :issue:`1153`)
  * Add ``EditorVessel.Flight``, a ``SimulatedFlight`` for the vessel in a simulated attitude (:issue:`1153`)

* Vessels and crew

  * Add ``Vessel.Terminate``, which removes a vessel without recovering it (:issue:`1034`)
  * Recover a vessel other than the active one with ``Vessel.Recover`` without switching to the space center, and close the mission completion dialog (:issue:`1021`)
  * Add ``Vessel.OrbitSpeedReferenceFrame``, ``SurfaceSpeedReferenceFrame`` and ``TargetSpeedReferenceFrame``, one per navball speed mode (:issue:`1029`)
  * Restrict ``Vessel.InertiaTensor`` to flight, as ``Vessel.MomentOfInertia`` is (:issue:`1059`)

* EVA

  * Add ``CrewMember.EVA``, which sends a Kerbal out through the hatch and returns its vessel (:issue:`319`)
  * Drive a Kerbal on EVA with ``Vessel.Control``. The translation inputs walk and fly the jetpack, ``Control.RCS`` deploys it, and ``Control.Lights`` switches the helmet lamp (:issue:`319`)
  * Add ``Control.Board``, ``Airlock``, ``GrabLadder``, ``ReleaseLadder`` and ``Ladder``, for a Kerbal on EVA (:issue:`319`)

  * Add ``Part.Drag`` and ``Part.Lift`` returning the aerodynamic drag and lift forces acting on an individual part (:issue:`459`)
  * Fix ``Flight.SimulateAerodynamicForceAt`` ignoring the current deflection of aerodynamic control surfaces, including deployed airbrakes (:issue:`622`)
  * Fix ``Flight.SimulateAerodynamicForceAt`` overestimating drag at low altitude and subsonic speed by applying KSP's pseudo-Reynolds drag multiplier to cube drag (:issue:`912`)
  * Fix ``Flight.SimulateAerodynamicForceAt`` returning force in kilonewtons instead of newtons when FAR is installed (:issue:`915`)
  * Fix ``Flight.SimulateAerodynamicForceAt`` computing incorrect lift for command pods and other parts with a perpendicular-only lifting-surface module: cube body lift was applied even where the game disables it (a pod with a heatshield occupying its bottom node has none), and lifting-surface modules were evaluated against stale internal airflow state, so results depended on the game context the call was made from (landed, in vacuum, or in atmospheric flight) (:issue:`914`)
  * Fix ``Part.Lift``, ``Flight.Lift`` and ``Flight.AerodynamicForce`` including stale body lift for parts whose body lift the game suppresses, e.g. a pod with a heatshield attached (:issue:`971`)
  * A ``Flight`` is freed once the reference frame it is measured in is gone, rather than being kept for as long as its vessel exists (:issue:`1072`)
