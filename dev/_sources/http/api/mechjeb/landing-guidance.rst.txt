LandingGuidance
===============


.. _http-MechJeb.LandingGuidance:

.. rubric:: LandingGuidance

The Landing Guidance window, which lands at a target or wherever the vessel comes down.

A ``LandingGuidance`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/landing-guidance/(id)/enabled

   :param id: The identifier of the :ref:`LandingGuidance <http-MechJeb.LandingGuidance>` object.

   :resjson bool value:

   Set the landing target to a position on the surface of a body.


   :param id: The identifier of the :ref:`LandingGuidance <http-MechJeb.LandingGuidance>` object.
