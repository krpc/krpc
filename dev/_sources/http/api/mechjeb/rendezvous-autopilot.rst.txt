RendezvousAutopilot
===================


.. _http-MechJeb.RendezvousAutopilot:

.. rubric:: RendezvousAutopilot

The rendezvous autopilot, which brings the vessel close to the target vessel.

A ``RendezvousAutopilot`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/rendezvous-autopilot/(id)/enabled

   Whether the module is enabled.


   :param id: The identifier of the :ref:`RendezvousAutopilot <http-MechJeb.RendezvousAutopilot>` object.

   :resjson bool value:

.. http:put:: /mech-jeb/rendezvous-autopilot/(id)/enabled

   :param id: The identifier of the :ref:`RendezvousAutopilot <http-MechJeb.RendezvousAutopilot>` object.

   :reqjson bool value: The new value.
