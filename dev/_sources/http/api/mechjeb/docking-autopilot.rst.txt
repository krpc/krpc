DockingAutopilot
================


.. _http-MechJeb.DockingAutopilot:

.. rubric:: DockingAutopilot

The docking autopilot, which docks with the target docking port.

A ``DockingAutopilot`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /mech-jeb/docking-autopilot/(id)/enabled

   Whether the module is enabled.


   :param id: The identifier of the :ref:`DockingAutopilot <http-MechJeb.DockingAutopilot>` object.

   :resjson bool value:
