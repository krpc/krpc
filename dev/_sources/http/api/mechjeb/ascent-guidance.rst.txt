AscentGuidance
==============


.. _http-MechJeb.AscentGuidance:

.. rubric:: AscentGuidance

The Ascent Guidance window, which flies the vessel to orbit.

.. note::

   See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
   for how to set up this autopilot.


A ``AscentGuidance`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

.. _http-MechJeb.AscentType:

.. rubric:: AscentType

The ascent path. See :http:get:`/mech-jeb/ascent-guidance/(id)/ascent-type`.

Passed and returned as the name of one of its values:


``"classic"``
   The classic ascent path. See :http:get:`/mech-jeb/ascent-guidance/(id)/classic-path`.


``"pvg"``
   Primer Vector Guidance, for RSS/RO. See :http:get:`/mech-jeb/ascent-guidance/(id)/pvg-settings`.



.. _http-MechJeb.AscentLaunchMode:

.. rubric:: AscentLaunchMode

The launch mode of the ascent autopilot. See :http:get:`/mech-jeb/ascent-guidance/(id)/launch-mode`.

Passed and returned as the name of one of its values:


``"normal"``
   The autopilot is not performing a timed launch.


``"rendezvous"``
   A timed launch to rendezvous with the target vessel.


``"target_plane"``
   A timed launch into the plane of the target.


``"match_lan"``
   A timed launch to the target's longitude of the ascending node. See
   :http:post:`/mech-jeb/ascent-guidance/(id)/launch-to-match-lan`.


``"lan"``
   A timed launch to a longitude of the ascending node. See
   :http:post:`/mech-jeb/ascent-guidance/(id)/launch-to-lan`.


``"unknown"``
   A timed launch of another kind, started from MechJeb's window.

ClassicPath
-----------


.. _http-MechJeb.ClassicPath:

.. rubric:: ClassicPath

The Ascent Path Editor window, which holds the settings of the classic ascent path.

A ``ClassicPath`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.
