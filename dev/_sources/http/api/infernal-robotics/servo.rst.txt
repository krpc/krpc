Servo
=====


.. _http-InfernalRobotics.Servo:

.. rubric:: Servo

Represents a servo. Obtained using
:http:get:`/infernal-robotics/servo-group/(id)/servos`,
:http:post:`/infernal-robotics/servo-group/(id)/servo-with-name`
or :http:post:`/infernal-robotics/servo-with-name`.

A ``Servo`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

.. _http-InfernalRobotics.ServoMode:

.. rubric:: ServoMode

The mode a servo is operating in. See :http:get:`/infernal-robotics/servo/(id)/mode`.

Passed and returned as the name of one of its values:


``"servo"``
   The part acts as a servo, driving towards a target position.


``"rotor"``
   The part acts as a rotor, spinning continuously.
