Service
=======


.. _http-SpaceCenter:

Provides functionality to interact with Kerbal Space Program. This includes controlling
the active vessel, managing its resources, planning maneuver nodes and auto-piloting.

.. http:post:: /space-center/launch-vessel

   Launch a vessel.

   .. note::

      The *crew* parameter controls how the craft is crewed:

      * If ``null``, the craft's default crew assignments are used.
      * If an empty list, the craft is launched with no crew.
      * Otherwise, the named Kerbals are placed in the craft in the order
        given: the first name takes the first seat, the second name the next seat, and so on,
        scanning the craft's parts in order. No other Kerbals are hired to fill remaining seats.
        Throws an exception, without launching, if a name does not match an available Kerbal
        or the craft has too few seats for the requested crew.

      Throws an exception if any of the games pre-flight checks fail.


   :reqjson string craft_directory: Name of the directory in the current saves "Ships" directory, that contains the craft file. For example ``"VAB"`` or ``"SPH"``.
   :reqjson string name: Name of the vessel to launch. This is the name of the ".craft" file in the save directory, without the ".craft" file extension.
   :reqjson string launch_site: Name of the launch site. For example ``"LaunchPad"`` or ``"Runway"``.
   :reqjson list<string>? crew: The Kerbals to place in the craft, by name. Controls how the craft is crewed, as described in the remarks. Optional, defaults to ``null``.
   :reqjson bool recover: If true and there is a vessel on the launch site, recover it before launching. Optional, defaults to ``true``.
   :reqjson string flag_url: If not ``null``, the asset URL of the mission flag to use for the launch. Optional, defaults to ``""``.





.. http:post:: /space-center/launch-vessel-from-vab

   Launch a new vessel from the VAB onto the launchpad.

   .. note::

      This is equivalent to calling :http:post:`/space-center/launch-vessel` with the craft directory

      Throws an exception if any of the games pre-flight checks fail.


   :reqjson string name: Name of the vessel to launch.
   :reqjson bool recover: If true and there is a vessel on the launch pad, recover it before launching. Optional, defaults to ``true``.

.. http:get:: /space-center/warp-rate

   The current warp rate. This is the rate at which time is passing for
   either on-rails or physical time warp. For example, a value of 10 means
   time is passing 10x faster than normal. Returns 1 if time warp is not
   active.


   :resjson float value:




.. http:get:: /space-center/warp-factor

   The current warp factor. This is the index of the rate at which time
   is passing for either regular "on-rails" or physical time warp. Returns 0
   if time warp is not active. When in on-rails time warp, this is equal to
   :http:get:`/space-center/rails-warp-factor`, and in physics time warp, this is equal to
   :http:get:`/space-center/physics-warp-factor`.


   :resjson float value:




.. http:get:: /space-center/rails-warp-factor

   The time warp rate, using regular "on-rails" time warp. A value between
   0 and 7 inclusive. 0 means no time warp. Returns 0 if physical time warp
   is active.

   If requested time warp factor cannot be set, it will be set to the next
   lowest possible value. For example, if the vessel is too close to a
   planet. See `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_ for details.

   .. note::

      Outside the flight scene, every factor can be set.


   :resjson int32 value:

.. http:put:: /space-center/rails-warp-factor

   The time warp rate, using regular "on-rails" time warp. A value between
   0 and 7 inclusive. 0 means no time warp. Returns 0 if physical time warp
   is active.

   If requested time warp factor cannot be set, it will be set to the next
   lowest possible value. For example, if the vessel is too close to a
   planet. See `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_ for details.

   .. note::

      Outside the flight scene, every factor can be set.


   :reqjson int32 value: The new value.

.. http:post:: /space-center/can-rails-warp-at

   Returns ``true`` if regular "on-rails" time warp can be used, at the specified warp
   *factor*. The maximum time warp rate is limited by various things,
   including how close the active vessel is to a planet. See
   `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_
   for details.

   .. note::

      Outside the flight scene, every valid factor can be used.


   :reqjson int32 factor: The warp factor to check. Optional, defaults to ``1``.
   :resjson bool value:





.. http:get:: /space-center/maximum-rails-warp-factor

   The current maximum regular "on-rails" warp factor that can be set.
   A value between 0 and 7 inclusive. See
   `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_
   for details.

   .. note::

      Outside the flight scene, this is the highest factor.


   :resjson int32 value:




.. http:post:: /space-center/warp-to

   Uses time acceleration to warp forward to a time in the future, specified
   by universal time *ut*. This call blocks until the desired
   time is reached. Uses regular "on-rails" or physical time warp as appropriate.
   For example, physical time warp is used when the active vessel is traveling
   through an atmosphere. When using regular "on-rails" time warp, the warp
   rate is limited by *max_rails_rate*, and when using physical
   time warp, the warp rate is limited by *max_physics_rate*.

   .. note::

      Outside the flight scene, only regular "on-rails" time warp is used.
      Throws an exception if the game scene changes during the time warp.


   :reqjson double ut: The universal time to warp to, in seconds.
   :reqjson float max_rails_rate: The maximum warp rate in regular "on-rails" time warp. Optional, defaults to ``1e+05``.
   :reqjson float max_physics_rate: The maximum warp rate in physical time warp. Optional, defaults to ``2.0``.





.. http:post:: /space-center/transform-position

   Converts a position from one reference frame to another.


   :reqjson tuple<double, double, double> position: Position, as a vector, in reference frame *from*.
   :reqjson SpaceCenter.ReferenceFrame from: The reference frame that the position is in.
   :reqjson SpaceCenter.ReferenceFrame to: The reference frame to covert the position to.
   :resjson tuple<double, double, double> value: The corresponding position, as a vector, in reference frame *to*.





.. http:post:: /space-center/transform-direction

   Converts a direction from one reference frame to another.


   :reqjson tuple<double, double, double> direction: Direction, as a vector, in reference frame *from*.
   :reqjson SpaceCenter.ReferenceFrame from: The reference frame that the direction is in.
   :reqjson SpaceCenter.ReferenceFrame to: The reference frame to covert the direction to.
   :resjson tuple<double, double, double> value: The corresponding direction, as a vector, in reference frame *to*.





.. http:post:: /space-center/transform-rotation

   Converts a rotation from one reference frame to another.


   :reqjson tuple<double, double, double, double> rotation: Rotation, as a quaternion of the form ``(x, y, z, w)``, in reference frame *from*.
   :reqjson SpaceCenter.ReferenceFrame from: The reference frame that the rotation is in.
   :reqjson SpaceCenter.ReferenceFrame to: The reference frame to covert the rotation to.
   :resjson tuple<double, double, double, double> value: The corresponding rotation, as a quaternion of the form ``(x, y, z, w)``, in reference frame *to*.





.. http:post:: /space-center/transform-velocity

   Converts a velocity (acting at the specified position) from one reference frame
   to another. The position is required to take the relative angular velocity of the
   reference frames into account.


   :reqjson tuple<double, double, double> position: Position, as a vector, in reference frame *from*.
   :reqjson tuple<double, double, double> velocity: Velocity, as a vector that points in the direction of travel and whose magnitude is the speed in :math:`\mathrm{m/s}`, in reference frame *from*.
   :reqjson SpaceCenter.ReferenceFrame from: The reference frame that the position and velocity are in.
   :reqjson SpaceCenter.ReferenceFrame to: The reference frame to covert the velocity to.
   :resjson tuple<double, double, double> value: The corresponding velocity, as a vector, in reference frame *to*.





.. http:post:: /space-center/raycast-distance

   Cast a ray from a given position in a given direction, and return the distance to the hit point.
   If no hit occurs, returns infinity.


   :reqjson tuple<double, double, double> position: Position, as a vector, of the origin of the ray.
   :reqjson tuple<double, double, double> direction: Direction of the ray, as a unit vector.
   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the position and direction are in.
   :resjson double value: The distance to the hit, in meters, or infinity if there was no hit.





.. http:post:: /space-center/raycast-part

   Cast a ray from a given position in a given direction, and return the part that it hits.
   If no hit occurs, returns ``null``.


   :reqjson tuple<double, double, double> position: Position, as a vector, of the origin of the ray.
   :reqjson tuple<double, double, double> direction: Direction of the ray, as a unit vector.
   :reqjson SpaceCenter.ReferenceFrame reference_frame: The reference frame that the position and direction are in.
   :resjson SpaceCenter.Part? value: The part that was hit or ``null`` if there was no hit.

.. _http-SpaceCenter.LaunchSite:

.. rubric:: LaunchSite

A place where craft can be launched from.
More of these can be added with mods like Kerbal Konstructs.

Passed and returned as an object with these fields:


``name`` (string)
   The name of the launch site.


``body`` (SpaceCenter.CelestialBody)
   The celestial body the launch site is on.


``editor_facility`` (SpaceCenter.EditorFacility)
   Which editor is normally used for this launch site.


``latitude`` (double)
   The latitude of the point vessels launch from, in degrees, or ``NaN`` if the
   site has no spawn point.


``longitude`` (double)
   The longitude of the point vessels launch from, in degrees, or ``NaN`` if the
   site has no spawn point.


``altitude`` (double)
   The altitude above sea level of the point vessels launch from, in meters, or
   ``NaN`` if the site has no spawn point.
