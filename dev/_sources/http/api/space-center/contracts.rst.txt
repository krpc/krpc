.. _http-SpaceCenter.ContractManager:

.. rubric:: ContractManager

Contracts manager.
Obtained by calling :http:get:`/space-center/contract-manager`.

A ``ContractManager`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

   A list of all contract types.


   :param id: The identifier of the :ref:`ContractManager <http-SpaceCenter.ContractManager>` object.

   :resjson set<string> value:

   :param id: The identifier of the :ref:`ContractManager <http-SpaceCenter.ContractManager>` object.

   :resjson list<SpaceCenter.Contract> value:

   A list of all active contracts.


   :param id: The identifier of the :ref:`ContractManager <http-SpaceCenter.ContractManager>` object.

   :resjson list<SpaceCenter.Contract> value:




.. http:get:: /space-center/contract-manager/(id)/offered-contracts

   A list of all offered, but unaccepted, contracts.


   :param id: The identifier of the :ref:`ContractManager <http-SpaceCenter.ContractManager>` object.

   :resjson list<SpaceCenter.Contract> value:




.. http:get:: /space-center/contract-manager/(id)/completed-contracts

.. _http-SpaceCenter.ContractState:

.. rubric:: ContractState

The state of a contract. See :http:get:`/space-center/contract/(id)/state`.

Passed and returned as the name of one of its values:


``"active"``
   The contract is active.


``"canceled"``
   The contract has been canceled.


``"completed"``
   The contract has been completed.


``"deadline_expired"``
   The deadline for the contract has expired.


``"declined"``
   The contract has been declined.


``"failed"``
   The contract has been failed.


``"generated"``
   The contract has been generated.


``"offered"``
   The contract has been offered to the player.


``"offer_expired"``
   The contract was offered to the player, but the offer expired.


``"withdrawn"``
   The contract has been withdrawn.
