Rect Transform
==============


.. _http-UI.RectTransform:

.. rubric:: RectTransform

A Unity engine Rect Transform for a UI object.
See the `Unity manual <https://docs.unity3d.com/Manual/class-RectTransform.html>`_ for more details.

A ``RectTransform`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.


.. http:get:: /ui/rect-transform/(id)/position

   Position of the rectangles pivot point relative to the anchors.


   :param id: The identifier of the :ref:`RectTransform <http-UI.RectTransform>` object.

   :resjson tuple<double, double> value:
