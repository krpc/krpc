Sphere
======


.. _http-Drawing.Sphere:

.. rubric:: Sphere

A solid sphere. Created using :http:post:`/drawing/add-sphere`.

.. note::

   The sphere is drawn with an additive material, so a darker color draws it more
   transparent.


A ``Sphere`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.
