Point
=====


.. _http-Drawing.Point:

.. rubric:: Point

A point, drawn as a dot that keeps its size on screen. Created using
:http:post:`/drawing/add-point`.

A ``Point`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.

   Position of the point.


   :param id: The identifier of the :ref:`Point <http-Drawing.Point>` object.

   :resjson tuple<double, double, double> value:

   Position of the point.


   :param id: The identifier of the :ref:`Point <http-Drawing.Point>` object.

   :reqjson tuple<double, double, double> value: The new value.
