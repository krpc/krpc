Arc
===


.. _http-Drawing.Arc:

.. rubric:: Arc

An arc of a circle. Created using :http:post:`/drawing/add-arc`.

A ``Arc`` object is passed and returned as its identifier, a number. A path that acts on
an object takes it as ``(id)``.
