LandingGuidance
===============


.. class:: LandingGuidance

   The Landing Guidance window, which lands at a target or wherever the vessel comes down.

   .. function:: bool enabled()
   .. function:: void set_enabled(bool value)

      Whether the module is enabled.

      :Game Scenes: Flight

   .. function:: std::string status()

      The status of the autopilot.

      :Game Scenes: Flight

   .. function:: bool deploy_chutes()
   .. function:: void set_deploy_chutes(bool value)

      Whether the autopilot deploys the parachutes.

      :Game Scenes: Flight

   .. function:: bool deploy_gears()
   .. function:: void set_deploy_gears(bool value)

      Whether the autopilot deploys the landing gear.

      :Game Scenes: Flight

   .. function:: void land_at_target()

      Land at the target. See :func:`LandingGuidance::set_target`.
      Throws an exception if there is no target, or the vessel is landed or splashed down.


      :Game Scenes: Flight

   .. function:: void land_somewhere()

      Land wherever the vessel comes down. Throws an exception if the vessel is landed or
      splashed down.


      :Game Scenes: Flight

   .. function:: int32_t limit_chutes_stage()
   .. function:: void set_limit_chutes_stage(int32_t value)

      The last stage in which the autopilot deploys the parachutes.

      :Game Scenes: Flight

   .. function:: int32_t limit_gears_stage()
   .. function:: void set_limit_gears_stage(int32_t value)

      The last stage in which the autopilot deploys the landing gear.

      :Game Scenes: Flight

   .. function:: bool rcs_adjustment()
   .. function:: void set_rcs_adjustment(bool value)

      Whether the autopilot corrects its course with RCS.

      :Game Scenes: Flight

   .. function:: void abort_autoland()

      Stop the landing.


      :Game Scenes: Flight

   .. function:: double touchdown_speed()
   .. function:: void set_touchdown_speed(double value)

      The speed at touchdown, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> get_target_position()

      The world space position of the landing target. Throws an exception if there is no
      landing target.


      :Game Scenes: Flight

   .. function:: std::string get_target_string()

      The landing target as text.


      :Game Scenes: Flight

   .. function:: void pick_target_on_map()

      Let the player pick the landing target on the map.


      :Game Scenes: Flight

   .. function:: void set_target(SpaceCenter::CelestialBody body, double latitude, double longitude)

      Set the landing target to a position on the surface of a body.

      :Parameters:

       * **body** -- The body.
       * **latitude** -- The latitude, in degrees.
       * **longitude** -- The longitude, in degrees.

      :Game Scenes: Flight

   .. function:: bool autowarp()
   .. function:: void set_autowarp(bool value)

      Whether to warp time during the landing.

      :Game Scenes: Flight


      .. note::

         The same setting as :func:`ManeuverPlanner::autowarp`.
