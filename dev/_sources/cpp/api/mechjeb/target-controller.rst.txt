TargetController
================


.. class:: TargetController

   The target controller, which holds MechJeb's target.

   .. note::

      Positions and directions are in world space, the coordinate system of the game's
      physics.

   .. function:: bool can_align()

      Whether the vessel can align with the target, which it can with a docking port.

      :Game Scenes: Flight

   .. function:: float distance()

      The distance to the target, in meters.

      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> docking_axis()

      The world space docking axis of the target.

      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> get_position_target_position()

      The world space position of the position target.


      :Game Scenes: Flight

   .. function:: std::string get_position_target_string()

      The position target as text.


      :Game Scenes: Flight

   .. function:: bool normal_target_exists()

      Whether there is a target that is a vessel, a body or a direction target.

      :Game Scenes: Flight

   .. function:: void pick_position_target_on_map()

      Let the player pick the position target on the map.


      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> position()

      The world space position of the target.

      :Game Scenes: Flight

   .. function:: bool position_target_exists()

      Whether there is a target that is a position or a vessel.

      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> relative_position()

      The world space position of the vessel relative to the target.

      :Game Scenes: Flight

   .. function:: std::tuple<double, double, double> relative_velocity()

      The world space velocity of the vessel relative to the target, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. function:: void set_direction_target(std::string name)

      Set the target to a direction.

      :Parameters:

       * **name** -- The name of the target.

      :Game Scenes: Flight


      .. note::

         Set the direction with :func:`TargetController::update_direction_target`.

   .. function:: void set_position_target(SpaceCenter::CelestialBody body, double latitude, double longitude)

      Set the target to a position on the surface of a body.

      :Parameters:

       * **body** -- The body.
       * **latitude** -- The latitude, in degrees.
       * **longitude** -- The longitude, in degrees.

      :Game Scenes: Flight

   .. function:: SpaceCenter::Orbit target_orbit()

      The orbit of the target.

      :Game Scenes: Flight

   .. function:: void update_direction_target(std::tuple<double, double, double> direction)

      Set the direction of the direction target.

      :Parameters:

       * **direction** -- The world space direction.

      :Game Scenes: Flight
