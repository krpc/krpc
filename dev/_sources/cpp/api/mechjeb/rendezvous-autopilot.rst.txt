RendezvousAutopilot
===================


.. class:: RendezvousAutopilot

   The rendezvous autopilot, which brings the vessel close to the target vessel.

   .. function:: bool enabled()
   .. function:: void set_enabled(bool value)

      Whether the module is enabled.

      :Game Scenes: Flight

   .. function:: std::string status()

      The status of the autopilot.

      :Game Scenes: Flight

   .. function:: double desired_distance()
   .. function:: void set_desired_distance(double value)

      The final distance from the target, in meters.

      :Game Scenes: Flight

   .. function:: double max_phasing_orbits()
   .. function:: void set_max_phasing_orbits(double value)

      The largest number of orbits to wait for the phase angle.

      :Game Scenes: Flight

   .. function:: double max_closing_speed()
   .. function:: void set_max_closing_speed(double value)

      The largest speed at which to approach the target, in :math:`\mathrm{m/s}`.

      :Game Scenes: Flight

   .. function:: bool autowarp()
   .. function:: void set_autowarp(bool value)

      Whether to warp time during the rendezvous.

      :Game Scenes: Flight


      .. note::

         The same setting as :func:`ManeuverPlanner::autowarp`.
