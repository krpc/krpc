DockingCamera
=============


.. namespace:: krpc::services
.. class:: DockingCamera : public krpc::Service

   This service provides functionality to interact with
   `Docking Camera (KURS) <https://spacedock.info/mod/1542>`_.

   .. function:: DockingCamera(krpc::Client* client)

      Construct an instance of this service.

   .. function:: bool available()

      Whether Docking Camera (KURS) is available.

   

   .. function:: Camera camera(SpaceCenter::Part part)

      Get the camera on a part.
      Throws an exception if the part is not an onboard camera or a docking port.

      :Parameters:

       * **part** -- The part.
