MapMarker
=========


.. class:: MapMarker

   A marker drawn in the map view, with one of the game's own map icons. Created using
   :func:`add_map_marker`.

   .. function:: std::tuple<double, double, double> position()
   .. function:: void set_position(std::tuple<double, double, double> value)

      Position of the marker.

      :Game Scenes: Flight, Tracking Station

   .. function:: SpaceCenter::ReferenceFrame reference_frame()
   .. function:: void set_reference_frame(SpaceCenter::ReferenceFrame value)

      Reference frame that the position of the marker is in.

      :Game Scenes: Flight, Tracking Station

   .. function:: bool visible()
   .. function:: void set_visible(bool value)

      Whether the marker is visible.

      :Game Scenes: Flight, Tracking Station

   .. function:: MapMarkerIcon icon()
   .. function:: void set_icon(MapMarkerIcon value)

      The icon that the marker is drawn with.

      :Game Scenes: Flight, Tracking Station

   .. function:: std::optional<Image> image()
   .. function:: void set_image(std::optional<Image> value)

      The image that the marker is drawn with in place of its icon, or null to draw the
      icon.

      :Game Scenes: Flight, Tracking Station

   .. function:: std::string caption()
   .. function:: void set_caption(std::string value)

      The caption shown when the mouse is over the marker.

      :Game Scenes: Flight, Tracking Station

   .. function:: std::tuple<double, double, double> color()
   .. function:: void set_color(std::tuple<double, double, double> value)

      The color of the marker.

      :Game Scenes: Flight, Tracking Station

   .. function:: void remove()

      Remove the marker.


      :Game Scenes: Flight, Tracking Station
