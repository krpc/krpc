Alarm
=====


.. class:: Alarm

   Represents an alarm. Obtained by calling
   :func:`KerbalAlarmClock.getAlarms`,
   :func:`KerbalAlarmClock.alarmWithName` or
   :func:`KerbalAlarmClock.alarmsWithType`.

      .. note::

         An alarm that plays a sound has the action :attr:`KerbalAlarmClock.AlarmAction.custom`.
         See :meth:`KerbalAlarmClock.Alarm.getPlaySound`.
