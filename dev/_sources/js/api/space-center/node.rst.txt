Node
====


.. class:: Node

   Represents a maneuver node. Can be created using :meth:`SpaceCenter.Control.addNode`.

   .. method:: getPrograde()
               setPrograde(value)

      The magnitude of the maneuver nodes delta-v in the prograde direction,
      in :math:`\mathrm{m/s}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getNormal()
               setNormal(value)

      The magnitude of the maneuver nodes delta-v in the normal direction,
      in :math:`\mathrm{m/s}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getRadial()
               setRadial(value)

      The magnitude of the maneuver nodes delta-v in the radial direction,
      in :math:`\mathrm{m/s}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDeltaV()
               setDeltaV(value)

      The delta-v of the maneuver node, in :math:`\mathrm{m/s}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Does not change when executing the maneuver node. See :meth:`SpaceCenter.Node.getRemainingDeltaV`.

   .. method:: getRemainingDeltaV()

      Gets the remaining delta-v of the maneuver node, in :math:`\mathrm{m/s}`. Changes as the
      node is executed. This is equivalent to the delta-v reported in-game.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: burnVector([referenceFrame])

      Returns the burn vector for the maneuver node.

      :param referenceFrame: The reference frame that the returned vector is in. Defaults to :meth:`SpaceCenter.Vessel.getOrbitalReferenceFrame`.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame` or ``null``
      :returns: A vector whose direction is the direction of the maneuver node burn, and magnitude is the delta-v of the burn in :math:`\mathrm{m/s}`.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight


      .. note::

         Does not change when executing the maneuver node. See :meth:`SpaceCenter.Node.remainingBurnVector`.

   .. method:: remainingBurnVector([referenceFrame])

      Returns the remaining burn vector for the maneuver node.

      :param referenceFrame: The reference frame that the returned vector is in. Defaults to :meth:`SpaceCenter.Vessel.getOrbitalReferenceFrame`.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame` or ``null``
      :returns: A vector whose direction is the direction of the maneuver node burn, and magnitude is the delta-v of the burn in :math:`\mathrm{m/s}`.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight


      .. note::

         Changes as the maneuver node is executed. See :meth:`SpaceCenter.Node.burnVector`.

   .. method:: getUT()
               setUT(value)

      The universal time at which the maneuver will occur, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getTimeTo()

      The time until the maneuver node will be encountered, in seconds.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getOrbit()

      The orbit that results from executing the maneuver node.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.Orbit`
      :Game Scenes: Flight

   .. method:: remove()

      Removes the maneuver node.

      :Game Scenes: Flight

   .. method:: getReferenceFrame()

      The reference frame that is fixed relative to the maneuver node's burn.

      * The origin is at the position of the maneuver node.
      * The y-axis points in the direction of the burn.
      * The x-axis and z-axis point in arbitrary but fixed directions.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.ReferenceFrame`
      :Game Scenes: Flight

   .. method:: getOrbitalReferenceFrame()

      The reference frame that is fixed relative to the maneuver node, and
      orientated with the orbital prograde/normal/radial directions of the
      original orbit at the maneuver node's position.

      * The origin is at the position of the maneuver node.
      * The x-axis points in the orbital anti-radial direction of the original
        orbit, at the position of the maneuver node.
      * The y-axis points in the orbital prograde direction of the original
        orbit, at the position of the maneuver node.
      * The z-axis points in the orbital normal direction of the original orbit,
        at the position of the maneuver node.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.ReferenceFrame`
      :Game Scenes: Flight

   .. method:: position(referenceFrame)

      The position vector of the maneuver node in the given reference frame.

      :param referenceFrame: The reference frame that the returned position vector is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The position as a vector.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight

   .. method:: rotation(referenceFrame)

      The rotation of the maneuver nodes burn.

      :param referenceFrame: The reference frame that the returned rotation is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The rotation as a quaternion of the form ``(x, y, z, w)``.
      :rtype: ``[number, number, number, number]``
      :Game Scenes: Flight

   .. method:: direction(referenceFrame)

      The direction of the maneuver nodes burn.

      :param referenceFrame: The reference frame that the returned direction is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The direction as a unit vector.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight
