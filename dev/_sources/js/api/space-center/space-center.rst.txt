Service
=======


.. module:: SpaceCenter

Provides functionality to interact with Kerbal Space Program. This includes controlling
the active vessel, managing its resources, planning maneuver nodes and auto-piloting.

.. function:: launchVessel(craftDirectory, name, launchSite[, crew[, recover[, flagUrl]]])

   Launch a vessel.

   :param craftDirectory: Name of the directory in the current saves "Ships" directory, that contains the craft file. For example ``"VAB"`` or ``"SPH"``.
   :type craftDirectory: ``string``
   :param name: Name of the vessel to launch. This is the name of the ".craft" file in the save directory, without the ".craft" file extension.
   :type name: ``string``
   :param launchSite: Name of the launch site. For example ``"LaunchPad"`` or ``"Runway"``.
   :type launchSite: ``string``
   :param crew: The Kerbals to place in the craft, by name. Controls how the craft is crewed, as described in the remarks.
   :type crew: ``Array`` of ``string`` or ``null``
   :param recover: If true and there is a vessel on the launch site, recover it before launching. Defaults to ``true``.
   :type recover: ``boolean``
   :param flagUrl: If not ``null``, the asset URL of the mission flag to use for the launch. Defaults to ``""``.
   :type flagUrl: ``string``
   

   .. note::

      The *crew* parameter controls how the craft is crewed:

      * If ``null``, the craft's default crew assignments are used.
      * If an empty list, the craft is launched with no crew.
      * Otherwise, the named Kerbals are placed in the craft in the order
        given: the first name takes the first seat, the second name the next seat, and so on,
        scanning the craft's parts in order. No other Kerbals are hired to fill remaining seats.
        Throws an exception, without launching, if a name does not match an available Kerbal
        or the craft has too few seats for the requested crew.

      Throws an exception if any of the games pre-flight checks fail.




.. function:: launchVesselFromVAB(name[, recover])

   Launch a new vessel from the VAB onto the launchpad.

   :param name: Name of the vessel to launch.
   :type name: ``string``
   :param recover: If true and there is a vessel on the launch pad, recover it before launching. Defaults to ``true``.
   :type recover: ``boolean``
   

   .. note::

      This is equivalent to calling :func:`SpaceCenter.launchVessel` with the craft directory
      set to "VAB" and the launch site set to "LaunchPad".
      Throws an exception if any of the games pre-flight checks fail.

.. function:: getWarpRate()

   The current warp rate. This is the rate at which time is passing for
   either on-rails or physical time warp. For example, a value of 10 means
   time is passing 10x faster than normal. Returns 1 if time warp is not
   active.

   :Property: Read-only, cannot be set
   :rtype: ``number``
   :Game Scenes: Space Center, Flight, Tracking Station





.. function:: getWarpFactor()

   The current warp factor. This is the index of the rate at which time
   is passing for either regular "on-rails" or physical time warp. Returns 0
   if time warp is not active. When in on-rails time warp, this is equal to
   :func:`SpaceCenter.getRailsWarpFactor`, and in physics time warp, this is equal to
   :func:`SpaceCenter.getPhysicsWarpFactor`.

   :Property: Read-only, cannot be set
   :rtype: ``number``
   :Game Scenes: Space Center, Flight, Tracking Station





.. function:: getRailsWarpFactor()
              setRailsWarpFactor(value)

   The time warp rate, using regular "on-rails" time warp. A value between
   0 and 7 inclusive. 0 means no time warp. Returns 0 if physical time warp
   is active.

   If requested time warp factor cannot be set, it will be set to the next
   lowest possible value. For example, if the vessel is too close to a
   planet. See `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_ for details.

   :Property: Can be read or written
   :rtype: ``number``
   :Game Scenes: Space Center, Flight, Tracking Station


   .. note::

      Outside the flight scene, every factor can be set.




.. function:: getPhysicsWarpFactor()
              setPhysicsWarpFactor(value)

   The physical time warp rate. A value between 0 and 3 inclusive. 0 means
   no time warp. Returns 0 if regular "on-rails" time warp is active.

   :Property: Can be read or written
   :rtype: ``number``
   :Game Scenes: Flight





.. function:: canRailsWarpAt([factor])

   Returns ``true`` if regular "on-rails" time warp can be used, at the specified warp
   *factor*. The maximum time warp rate is limited by various things,
   including how close the active vessel is to a planet. See
   `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_
   for details.

   :param factor: The warp factor to check. Defaults to ``1``.
   :type factor: ``number``
   :rtype: ``boolean``
   :Game Scenes: Space Center, Flight, Tracking Station


   .. note::

      Outside the flight scene, every valid factor can be used.




.. function:: getMaximumRailsWarpFactor()

   The current maximum regular "on-rails" warp factor that can be set.
   A value between 0 and 7 inclusive. See
   `the KSP wiki <https://wiki.kerbalspaceprogram.com/wiki/Time_warp>`_
   for details.

   :Property: Read-only, cannot be set
   :rtype: ``number``
   :Game Scenes: Space Center, Flight, Tracking Station


   .. note::

      Outside the flight scene, this is the highest factor.




.. function:: warpTo(ut[, maxRailsRate[, maxPhysicsRate]])

   Uses time acceleration to warp forward to a time in the future, specified
   by universal time *ut*. This call blocks until the desired
   time is reached. Uses regular "on-rails" or physical time warp as appropriate.
   For example, physical time warp is used when the active vessel is traveling
   through an atmosphere. When using regular "on-rails" time warp, the warp
   rate is limited by *maxRailsRate*, and when using physical
   time warp, the warp rate is limited by *maxPhysicsRate*.

   :param ut: The universal time to warp to, in seconds.
   :type ut: ``number``
   :param maxRailsRate: The maximum warp rate in regular "on-rails" time warp. Defaults to ``1e+05``.
   :type maxRailsRate: ``number``
   :param maxPhysicsRate: The maximum warp rate in physical time warp. Defaults to ``2.0``.
   :type maxPhysicsRate: ``number``
   :Game Scenes: Space Center, Flight, Tracking Station


   .. note::

      Outside the flight scene, only regular "on-rails" time warp is used.
      Throws an exception if the game scene changes during the time warp.

.. function:: transformVelocity(position, velocity, from, to)

   Converts a velocity (acting at the specified position) from one reference frame
   to another. The position is required to take the relative angular velocity of the
   reference frames into account.

   :param position: Position, as a vector, in reference frame *from*.
   :type position: ``[number, number, number]``
   :param velocity: Velocity, as a vector that points in the direction of travel and whose magnitude is the speed in :math:`\mathrm{m/s}`, in reference frame *from*.
   :type velocity: ``[number, number, number]``
   :param from: The reference frame that the position and velocity are in.
   :type from: :class:`SpaceCenter.ReferenceFrame`
   :param to: The reference frame to covert the velocity to.
   :type to: :class:`SpaceCenter.ReferenceFrame`
   :returns: The corresponding velocity, as a vector, in reference frame *to*.
   :rtype: ``[number, number, number]``
   




.. function:: raycastDistance(position, direction, referenceFrame)

   Cast a ray from a given position in a given direction, and return the distance to the hit point.
   If no hit occurs, returns infinity.

   :param position: Position, as a vector, of the origin of the ray.
   :type position: ``[number, number, number]``
   :param direction: Direction of the ray, as a unit vector.
   :type direction: ``[number, number, number]``
   :param referenceFrame: The reference frame that the position and direction are in.
   :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
   :returns: The distance to the hit, in meters, or infinity if there was no hit.
   :rtype: ``number``
   




.. function:: raycastPart(position, direction, referenceFrame)

   Cast a ray from a given position in a given direction, and return the part that it hits.
   If no hit occurs, returns ``null``.

   :param position: Position, as a vector, of the origin of the ray.
   :type position: ``[number, number, number]``
   :param direction: Direction of the ray, as a unit vector.
   :type direction: ``[number, number, number]``
   :param referenceFrame: The reference frame that the position and direction are in.
   :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
   :returns: The part that was hit or ``null`` if there was no hit.
   :rtype: :class:`SpaceCenter.Part` or ``null``
   :Game Scenes: Flight
