Parts
=====

The following classes allow interaction with a vessel's individual parts.

.. seealso:: The :std:ref:`parts guide <user-guide-parts>` walks the tree of parts, and explains
   fuel lines, stage numbers and part modules.

.. contents::
   :local:

Parts
-----


.. class:: Parts

   Instances of this class are used to interact with the parts of a vessel.
   An instance can be obtained by calling :meth:`SpaceCenter.Vessel.getParts`.

   .. method:: getAll()

      A list of all of the vessels parts.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

   .. method:: getRoot()

      The vessels root part.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.Part`
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-tree`.

   .. method:: getControlling()
               setControlling(value)

      The part from which the vessel is controlled.
      Returns ``null`` if the vessel has no control point, in which case it is
      oriented by its root part.

      :Property: Can be read or written
      :rtype: :class:`SpaceCenter.Part` or ``null``
      :Game Scenes: Flight


      .. note::

         A vessel gets no control point when it is created by a decoupler or an undocking
         and none of its parts is a command module with crew aboard. A probe core does not
         give it one either. Assign this property to choose the control point, which is
         equivalent to "Control From Here" in game.

   .. method:: withName(name)

      A list of parts whose :meth:`SpaceCenter.Part.getName` is *name*.

      :param name: The name of the part.
      :type name: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

   .. method:: withTitle(title)

      A list of all parts whose :meth:`SpaceCenter.Part.getTitle` is *title*.

      :param title: The title of the part.
      :type title: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

   .. method:: withTag(tag)

      A list of all parts whose :meth:`SpaceCenter.Part.getTag` is *tag*.

      :param tag: The name tag of the part.
      :type tag: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

   .. method:: withModule(moduleName)

      A list of all parts that contain a :class:`SpaceCenter.Module` whose
      :meth:`SpaceCenter.Module.getName` is *moduleName*.

      :param moduleName: The name of the module.
      :type moduleName: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

   .. method:: modulesWithName(moduleName)

      A list of modules (combined across all parts in the vessel) whose
      :meth:`SpaceCenter.Module.getName` is *moduleName*.

      :param moduleName: The name of the module.
      :type moduleName: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.Module`
   

   .. method:: getAntennas()

      A list of all antennas in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Antenna`
   

      .. note::

         A part with several antennas has an entry for each.
         If RemoteTech is installed, this will always return an empty list.
         To interact with RemoteTech antennas, use the RemoteTech service APIs.

   .. method:: getCargoBays()

      A list of all cargo bays in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.CargoBay`
   

   .. method:: getControlSurfaces()

      A list of all control surfaces in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.ControlSurface`
   

   .. method:: getDecouplers()

      A list of all decouplers in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Decoupler`
   

   .. method:: getDockingPorts()

      A list of all docking ports in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.DockingPort`
   

   .. method:: getEngines()

      A list of all engines in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Engine`
   

      .. note::

         This includes any part that generates thrust. This covers many different types
         of engine, including liquid fuel rockets, solid rocket boosters, jet engines and
         RCS thrusters.

   .. method:: getExperiments()

      A list of all science experiments in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Experiment`
   

   .. method:: getFairings()

      A list of all fairings in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Fairing`
   

   .. method:: getIntakes()

      A list of all intakes in the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Intake`
   

   .. method:: getLegs()

   .. method:: getRadiators()

      :rtype: ``Array`` of :class:`SpaceCenter.Radiator`
   

   .. method:: getResourceDrains()

   .. method:: getRCS()

      :rtype: ``Array`` of :class:`SpaceCenter.RCS`
   

   .. method:: getReactionWheels()

      :Property: Read-only, cannot be set

Part
----


.. class:: Part

   Represents an individual part. Vessels are made up of multiple parts.
   Instances of this class can be obtained by several methods in :class:`SpaceCenter.Parts`.

   .. method:: getName()

      Internal name of the part, as used in
      `part cfg files <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation>`_.
      For example "Mark1-2Pod".

      :Property: Read-only, cannot be set
      :rtype: ``string``
   

   .. method:: getTitle()

      Title of the part, as shown when the part is right clicked in-game. For example "Mk1-2 Command Pod".

      :Property: Read-only, cannot be set
      :rtype: ``string``
   

   .. method:: getConfig()

      The static configuration of the part, as found in its
      `part cfg file <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation>`_.
      This provides access to data that is not exposed elsewhere, such as the
      configuration of the part's modules. Returns ``null`` if the part has no
      associated configuration node.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.ConfigNode`
   

   .. method:: getTag()
               setTag(value)

      The name tag for the part. Can be set to a custom string using the
      in-game user interface. Throws an exception if no name tag part module is installed.

      :Property: Can be read or written
      :rtype: ``string``
   

      .. note::

         Requires KSPCommunityPartModules 0.5 or later, or kOS, which share one name tag.

   .. method:: getFlagURL()
               setFlagURL(value)

      The asset URL for the part's flag.

      :Property: Can be read or written
      :rtype: ``string``
   

   .. method:: getHighlighted()
               setHighlighted(value)

      Whether the part is highlighted.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         The highlighting is removed when the client that enabled it disconnects.

   .. method:: getHighlightColor()
               setHighlightColor(value)

      The color used to highlight the part.

      :Property: Can be read or written
      :rtype: :class:`StdLib.ColorRGB`
      :Game Scenes: Flight

   .. method:: getCost()

      The cost of the part with its resources full, in units of funds.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getVessel()

      The vessel that contains this part.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.Vessel`
      :Game Scenes: Flight

   .. method:: getParent()

      The parts parent. Returns ``null`` if the part does not have a parent.
      This, in combination with :meth:`SpaceCenter.Part.getChildren`, can be used to traverse the vessels
      parts tree.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.Part` or ``null``
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-tree`.

   .. method:: getChildren()

      The parts children. Returns an empty list if the part has no children.
      This, in combination with :meth:`SpaceCenter.Part.getParent`, can be used to traverse the vessels
      parts tree.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.Part`
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-tree`.

   .. method:: getAxiallyAttached()

      Whether the part is axially attached to its parent, i.e. on the top
      or bottom of its parent. If the part has no parent, returns ``false``.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-attachment-modes`.

   .. method:: getRadiallyAttached()

      Whether the part is radially attached to its parent, i.e. on the side of its parent.
      If the part has no parent, returns ``false``.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-attachment-modes`.

   .. method:: getStage()

      The stage in which this part will be activated. Returns -1 if the part is not
      activated by staging.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-staging`.

   .. method:: getDecoupleStage()

      The stage in which this part will be decoupled. Returns -1 if the part is never
      decoupled from the vessel.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

      .. note:: See the discussion on :rst:ref:`user-guide-parts-staging`.

   .. method:: getMassless()

      Whether the part is
      `massless <https://wiki.kerbalspaceprogram.com/wiki/Massless_part>`_.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
   

   .. method:: getMass()

      The current mass of the part, including resources it contains, in kilograms.
      Returns zero if the part is massless.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getDryMass()

      The mass of the part, not including any resources it contains, in kilograms.
      Returns zero if the part is massless.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getShielded()

      Whether the part is shielded from the exterior of the vessel, for example by a fairing.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getDynamicPressure()

      The dynamic pressure acting on the part, in Pascals.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getStaticPressure()

      The static pressure acting on the part, in Pascals. Below the waterline this
      includes the pressure of the water.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDisplacement()

      The volume of water the part displaces when fully submerged, in :math:`\mathrm{m^{3}}`.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph


      .. note::

         See :meth:`SpaceCenter.Part.getDisplacedVolume` for the volume it is displacing now.

   .. method:: getBuoyancyMultiplier()

      The multiplier applied to the buoyant force on the part. One for most parts.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph

   .. method:: buoyantForceAt(density, gravity)

      The buoyant force on the part when fully submerged in a fluid of the given
      density, in Newtons.

      :param density: The density of the fluid, in :math:`\mathrm{kg/m^{3}}`.
      :type density: ``number``
      :param gravity: The acceleration due to gravity, in :math:`\mathrm{m/s^{2}}`.
      :type gravity: ``number``
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph


      .. note::

         Applies :func:`SpaceCenter.getBuoyancyScalar` and
         :meth:`SpaceCenter.Part.getBuoyancyMultiplier`, so the result is what the game would do to the
         part rather than what
         `Archimedes' principle <https://en.wikipedia.org/wiki/Archimedes%27_principle>`_ alone gives.

   .. method:: getSplashed()

      Whether the part is in contact with water.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getSubmergedPortion()

      The fraction of the part below the waterline, between 0 and 1.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDisplacedVolume()

      The volume of water the part is displacing, in :math:`\mathrm{m^{3}}`.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDepth()

      The depth of the part below the waterline, in meters, measured at
      :meth:`SpaceCenter.Part.centerOfDisplacement`. Negative above the waterline. Returns zero
      if the body the vessel is at has no ocean.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getMinDepth()

      The depth of the shallowest point of the part below the waterline, in meters.
      Returns zero if the body the vessel is at has no ocean.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getMaxDepth()

      The depth of the deepest point of the part below the waterline, in meters.
      Returns zero if the body the vessel is at has no ocean.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The game ramps the buoyant force in over the first fraction of a meter of this
         depth.

   .. method:: getSubmergedDynamicPressure()

      The dynamic pressure of the water acting on the part, in Pascals.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getSubmergedDragMultiplier()

      The multiplier applied to the drag on the part while it is submerged.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The game sets this high on splashdown and eases it down as the part moves through
         the water. It climbs back once the part slows to a crawl, so a hull under way
         reads lower than one lying still.

   .. method:: getSubmergedLiftMultiplier()

      The multiplier applied to the lift on the part while it is submerged.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getWaterAngularDragMultiplier()

      The multiplier applied to the angular drag on the part while it is submerged.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph


      .. note::

         Part of the part's configuration rather than a live readout, so it reads the same
         in the editor and at a body with no ocean.

   .. method:: getImpactTolerance()

      The crash tolerance of the part, in :math:`\mathrm{m/s}`.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getBreakingForce()

      The breaking force of the part's attachments, in :math:`\mathrm{kN}`.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph


      .. note::

         The joint to the parent part takes the lower breaking force of the two parts,
         scaled by the size of the attachment node. See :meth:`SpaceCenter.Part.getJointBreakForce`.

   .. method:: getBreakingTorque()

      The breaking torque of the part's attachments, in :math:`\mathrm{kN \cdot m}`.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight, Editor Vab, Editor Sph


      .. note::

         The joint to the parent part takes the lower breaking torque of the two parts,
         scaled by the size of the attachment node. See :meth:`SpaceCenter.Part.getJointBreakTorque`.

   .. method:: getJointBreakForce()

      The force that breaks the joint to the parent part, in :math:`\mathrm{kN}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints. It is infinite for a short time after
         the vessel loads, such as just after launch. The root part and a physicsless
         part have no joint to their parent.

   .. method:: getJointBreakTorque()

      The torque that breaks the joint to the parent part, in :math:`\mathrm{kN \cdot m}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints. It is infinite for a short time after
         the vessel loads. On a stack node of size 2 or more, the physics joints sit apart
         around the node. A bending moment then breaks the joint when one physics joint's
         force exceeds its share of :meth:`SpaceCenter.Part.getJointBreakForce`, usually at a much
         larger moment than this torque.

   .. method:: getJointSpring()

      The spring constant of the joint to the parent part against translation, in
      :math:`\mathrm{kN/m}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints. A rigid attachment locks the joint, and
         this spring then has no effect.

   .. method:: getJointDamper()

      The damping constant of the joint to the parent part against translation, in
      :math:`\mathrm{kN \cdot s/m}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints. The stock game sets it to zero, and
         mods such as Kerbal Joint Reinforcement change it.

   .. method:: getJointAngularSpring()

      The spring constant of the joint to the parent part against bending, in
      :math:`\mathrm{kN \cdot m/rad}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints, about the two axes perpendicular to the
         joint axis. The joint is far stiffer against twisting about its axis. On a stack
         node of size 2 or more, the physics joints sit apart around the node, and the joint
         bends much less than this spring gives. A rigid attachment makes it infinite.

   .. method:: getJointAngularDamper()

      The damping constant of the joint to the parent part against bending, in
      :math:`\mathrm{kN \cdot m \cdot s/rad}`.
      Throws an exception if the part has no joint to its parent part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         The sum over the joint's physics joints. The stock game sets it to zero, and
         mods such as Kerbal Joint Reinforcement change it.

   .. method:: getTemperature()

      Temperature of the part, in Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getSkinTemperature()

      Temperature of the skin of the part, in Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getMaxTemperature()

      Maximum temperature that the part can survive, in Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getMaxSkinTemperature()

      Maximum temperature that the skin of the part can survive, in Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getMaxPressure()

      Maximum pressure that the part can survive, in Pascals.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

      .. note::

         With part pressure limits enabled in the difficulty settings, the part is destroyed
         when :meth:`SpaceCenter.Part.getStaticPressure` plus :meth:`SpaceCenter.Part.getDynamicPressure` exceeds this.

   .. method:: getThermalMass()

      A measure of how much energy it takes to increase the internal temperature of the part,
      in Joules per Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalSkinMass()

      A measure of how much energy it takes to increase the skin temperature of the part,
      in Joules per Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalResourceMass()

      A measure of how much energy it takes to increase the temperature of the resources
      contained in the part, in Joules per Kelvin.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalConductionFlux()

      The rate at which heat energy is conducting into or out of the part via contact with
      other parts. Measured in energy per unit time, or power, in Watts.
      A positive value means the part is gaining heat energy, and negative means it is
      losing heat energy.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalConvectionFlux()

      The rate at which heat energy is convecting into or out of the part from the
      surrounding atmosphere. Measured in energy per unit time, or power, in Watts.
      A positive value means the part is gaining heat energy, and negative means it is
      losing heat energy.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalRadiationFlux()

      The rate at which heat energy is radiating into or out of the part from the surrounding
      environment. Measured in energy per unit time, or power, in Watts.
      A positive value means the part is gaining heat energy, and negative means it is
      losing heat energy.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalInternalFlux()

      The rate at which heat energy is begin generated by the part.
      For example, some engines generate heat by combusting fuel.
      Measured in energy per unit time, or power, in Watts.
      A positive value means the part is gaining heat energy, and negative means it is losing
      heat energy.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThermalSkinToInternalFlux()

      The rate at which heat energy is transferring between the part's skin and its internals.
      Measured in energy per unit time, or power, in Watts.
      A positive value means the part's internals are gaining heat energy,
      and negative means its skin is gaining heat energy.

      :Property: Read-only, cannot be set
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getCrewCapacity()

      The number of crew members that can occupy the part.

      :Property: Read-only, cannot be set
      :rtype: ``number``
   

   .. method:: getCrew()

      The crew members occupying the part.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.CrewMember`
      :Game Scenes: Flight

Module
------


.. class:: Module

   This can be used to interact with a specific part module. This includes part modules in
   stock KSP, and those added by mods.

   In KSP, each part has zero or more
   `PartModules <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation#MODULES>`_
   associated with it. Each one contains some of the functionality of the part.
   For example, an engine has a "ModuleEngines" part module that contains all the
   functionality of an engine.

   .. method:: getName()

      Name of the PartModule. For example, "ModuleEngines".

      :Property: Read-only, cannot be set
      :rtype: ``string``
   

   .. method:: getPart()

      The part that contains this module.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.Part`
   

   .. method:: getConfig()

      The static configuration of the module, as found in the part's
      `cfg file <https://wiki.kerbalspaceprogram.com/wiki/CFG_File_Documentation#MODULES>`_.
      This provides access to data that is not exposed as a field, such as the
      resources produced by a generator. Returns ``null`` if the module's
      configuration node cannot be found.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.ConfigNode`
   

   .. method:: getFieldList()

      A list of all the fields of the module, including those not visible in the right-click
      menu of the part. Filter by :meth:`SpaceCenter.PartField.getVisible` to get just the visible ones.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.PartField`
   

   .. method:: getEventList()

      A list of all the events of the module, including those not currently visible or active.
      Events are the clickable buttons visible in the right-click menu of the part. Filter by
      :meth:`SpaceCenter.PartEvent.getVisible` and :meth:`SpaceCenter.PartEvent.getActive` to get just the ones
      shown in the menu.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.PartEvent`
   

   .. method:: getActionList()

      A list of all the actions of the module. These are the parts actions that can be assigned
      to action groups in the in-game editor.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.PartAction`

Config Node
-----------


.. class:: ConfigNode

   Represents a configuration node, as found in a part's configuration file. A node has a
   name, a set of named values and a set of child nodes. This is used to access the
   static configuration of a part or part module, for example via
   :meth:`SpaceCenter.Part.getConfig` and :meth:`SpaceCenter.Module.getConfig`.

   .. method:: getName()

      The name of the configuration node. For example "MODULE".

      :Property: Read-only, cannot be set
      :rtype: ``string``
   

   .. method:: getValues()

      The values stored in the node, as a dictionary mapping names to values.

      :Property: Read-only, cannot be set
      :rtype: ``Map`` from ``string`` to ``string``
   

      .. note::

         If a name appears more than once, only the first value is included. Use
         :meth:`SpaceCenter.ConfigNode.findValues` to get all of the values with a given name.

   .. method:: hasValue(name)

      Returns ``true`` if the node has a value with the given name.

      :param name: Name of the value.
      :type name: ``string``
      :rtype: ``boolean``
   

   .. method:: getValue(name)

      Returns the value with the given name. If there is more than one value with
      the given name, the first is returned. Throws an exception if there is no
      value with the given name.

      :param name: Name of the value.
      :type name: ``string``
      :rtype: ``string``
   

   .. method:: findValues(name)

      Returns all of the values with the given name, as a list.

      :param name: Name of the values.
      :type name: ``string``
      :rtype: ``Array`` of ``string``
   

   .. method:: getNodes()

      The child nodes contained in this node.

      :Property: Read-only, cannot be set
      :rtype: ``Array`` of :class:`SpaceCenter.ConfigNode`
   

   .. method:: hasNode(name)

      Returns ``true`` if the node has a child node with the given name.

      :param name: Name of the child node.
      :type name: ``string``
      :rtype: ``boolean``
   

   .. method:: getNode(name)

      Returns the child node with the given name. If there is more than one child
      node with the given name, the first is returned. Throws an exception if there
      is no child node with the given name.

      :param name: Name of the child node.
      :type name: ``string``
      :rtype: :class:`SpaceCenter.ConfigNode`
   

   .. method:: findNodes(name)

      Returns all of the child nodes with the given name, as a list.

      :param name: Name of the child nodes.
      :type name: ``string``
      :rtype: ``Array`` of :class:`SpaceCenter.ConfigNode`

      The part is fully retracted. A cargo bay in this state is closed and locked.


   .. attribute:: deploying

      The part is being deployed. A cargo bay in this state is opening.


   .. attribute:: retracting

      The part is being retracted. A cargo bay in this state is closing.


   .. attribute:: broken

      The part is broken. Cargo bays and resource harvesters never report
      this state, as the game does not track damage for them.

      :rtype: ``number``

      The position at which the thruster generates thrust, in the given reference frame.
      For gimballed engines, this takes into account the current rotation of the gimbal.

      :param referenceFrame: The reference frame that the returned position vector is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The position as a vector.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight

   .. method:: thrustDirection(referenceFrame)

      The direction of the force generated by the thruster, in the given reference frame.
      This is opposite to the direction in which the thruster expels propellant.
      For gimballed engines, this takes into account the current rotation of the gimbal.

      :param referenceFrame: The reference frame that the returned direction is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The direction as a unit vector.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight

   .. method:: getThrustReferenceFrame()

      A reference frame that is fixed relative to the thruster and orientated with
      its thrust direction (:meth:`SpaceCenter.Thruster.thrustDirection`).
      For gimballed engines, this takes into account the current rotation of the gimbal.

      * The origin is at the position of thrust for this thruster
        (:meth:`SpaceCenter.Thruster.thrustPosition`).
      * The axes rotate with the thrust direction.
        This is the direction in which the thruster expels propellant, including any gimballing.
      * The y-axis points along the thrust direction.
      * The x-axis and z-axis are perpendicular to the thrust direction.

      :Property: Read-only, cannot be set
      :rtype: :class:`SpaceCenter.ReferenceFrame`
      :Game Scenes: Flight

   .. method:: getGimballed()

      Whether the thruster is gimballed.

      :Property: Read-only, cannot be set
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getGimbalAngle()

   .. method:: initialThrustPosition(referenceFrame)

      The position at which the thruster generates thrust, when the engine is in its
      initial position (no gimballing), in the given reference frame.

      :param referenceFrame: The reference frame that the returned position vector is in.
      :type referenceFrame: :class:`SpaceCenter.ReferenceFrame`
      :returns: The position as a vector.
      :rtype: ``[number, number, number]``
      :Game Scenes: Flight


      .. note::

         This position can move when the gimbal rotates. This is because the thrust position and
         gimbal position are not necessarily the same.

   .. method:: initialThrustDirection(referenceFrame)
