AscentAutopilot
===============


.. class:: AscentAutopilot

   The ascent autopilot.

   .. note::

      See the `MechJeb wiki <https://github.com/MuMech/MechJeb2/wiki/Ascent-Guidance>`_
      for how to set up this autopilot.

   .. method:: getEnabled()
               setEnabled(value)

      Whether the autopilot is enabled. Enabling it engages the autopilot of the selected
      ascent path, and disabling it disengages the autopilots of both paths.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getStatus()

      The autopilot status, which depends on the selected ascent path.

      :Property: Read-only, cannot be set
      :rtype: ``string``
      :Game Scenes: Flight

   .. method:: getAscentPathIndex()
               setAscentPathIndex(value)

      The selected ascent path: 0 for :class:`MechJeb.AscentClassic` or 2 for
      :class:`MechJeb.AscentPVG`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         MechJeb 2.15 removed the stock-style gravity turn path, which was 1. Setting any other
         value throws an exception.

   .. method:: getAscentPathClassic()

      The settings of the classic ascent profile.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.AscentClassic`
      :Game Scenes: Flight

   .. method:: getAscentPathPVG()

      The settings of the Primer Vector Guidance (RSS/RO) profile.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.AscentPVG`
      :Game Scenes: Flight

   .. method:: getDesiredInclination()
               setDesiredInclination(value)

      The inclination of the final circular orbit, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDesiredOrbitAltitude()
               setDesiredOrbitAltitude(value)

      The altitude of the final circular orbit, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getThrustController()

      The thrust controller. The same as :func:`MechJeb.getThrustController`.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.ThrustController`
      :Game Scenes: Flight

   .. method:: getForceRoll()
               setForceRoll(value)

      Whether the autopilot controls the roll.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getTurnRoll()
               setTurnRoll(value)

      The roll during the turn, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentAutopilot.getForceRoll`.

   .. method:: getVerticalRoll()
               setVerticalRoll(value)

      The roll during the vertical climb, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentAutopilot.getForceRoll`.

   .. method:: getLimitAoA()
               setLimitAoA(value)

      Whether to limit the angle of attack.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getMaxAoA()
               setMaxAoA(value)

      The largest angle of attack, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentAutopilot.getLimitAoA`.

   .. method:: getAoALimitFadeoutPressure()
               setAoALimitFadeoutPressure(value)

      The dynamic pressure below which the angle of attack limit fades out, in pascals.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentAutopilot.getLimitAoA`.

   .. method:: getCorrectiveSteering()
               setCorrectiveSteering(value)

      Whether the autopilot steers by the velocity vector rather than the position vector.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         It is more accurate, though large craft may do better without it.

   .. method:: getCorrectiveSteeringGain()
               setCorrectiveSteeringGain(value)

      The gain of the corrective steering.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentAutopilot.getCorrectiveSteering`.

   .. method:: getAutostage()
               setAutostage(value)

      Whether the autopilot stages when the current stage runs out of fuel.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getStagingController()

      The staging controller. The same as :func:`MechJeb.getStagingController`.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.StagingController`
      :Game Scenes: Flight

   .. method:: getAutodeploySolarPanels()
               setAutodeploySolarPanels(value)

      Whether to deploy the solar panels when the ascent finishes.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getAutoDeployAntennas()
               setAutoDeployAntennas(value)

      Whether to deploy the antennas when the ascent finishes.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getSkipCircularization()
               setSkipCircularization(value)

      Whether to skip the circularization burn.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getWarpCountDown()
               setWarpCountDown(value)

      The time before a timed launch at which time warp stops, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getLaunchLANDifference()
               setLaunchLANDifference(value)

      The difference from the target's longitude of the ascending node of a launch into the
      target's plane, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getLaunchPhaseAngle()
               setLaunchPhaseAngle(value)

      The phase angle to the target of a launch to rendezvous, in degrees.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getLaunchMode()

      The launch mode, which gives whether the autopilot is waiting for a timed launch.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.AscentLaunchMode`
      :Game Scenes: Flight

   .. method:: abortTimedLaunch()

      Abort a timed launch that has not started yet. Throws an exception if the launch mode
      is :attr:`MechJeb.AscentLaunchMode.unknown`.

      :Game Scenes: Flight

   .. method:: launchToRendezvous()

      Launch to rendezvous with the target. Throws an exception if there is no target, or
      the ascent path is PVG.

      :Game Scenes: Flight

   .. method:: launchToTargetPlane()

      Launch into the plane of the target. Throws an exception if there is no target.

      :Game Scenes: Flight



.. class:: AscentLaunchMode

   The launch mode of the ascent autopilot. See :meth:`MechJeb.AscentAutopilot.getLaunchMode`.


   .. attribute:: normal

      The autopilot is not performing a timed launch.


   .. attribute:: rendezvous

      A timed launch to rendezvous with the target vessel.


   .. attribute:: targetPlane

      A timed launch into the plane of the target.


   .. attribute:: unknown

      A timed launch of another kind, started from MechJeb's window.

AscentPVG
---------


.. class:: AscentPVG

   The Primer Vector Guidance (RSS/RO) profile.

   .. method:: getAttachAltFlag()
               setAttachAltFlag(value)

      Whether the orbit is attached at :meth:`MechJeb.AscentPVG.getDesiredAttachAlt`.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight


      .. note::

         MechJeb reads this setting only when its PVG settings window has an early shutoff
         stage. Without one, MechJeb always attaches the orbit.

   .. method:: getDesiredApoapsis()
               setDesiredApoapsis(value)

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getDesiredAttachAlt()
               setDesiredAttachAlt(value)

      The altitude at which the orbit is attached, in meters.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.AscentPVG.getAttachAltFlag`, unless MechJeb's PVG settings window has no early
         shutoff stage.

   .. method:: getDynamicPressureTrigger()
