StagingController
=================


.. class:: StagingController

   The staging controller, which stages when a stage runs out of fuel.

               setEnabled(value)

      Whether the module is enabled.

      :Property: Can be read or written
      :rtype: ``boolean``

   .. method:: getAutostagingOnce()

      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getAutostagePreDelay()
               setAutostagePreDelay(value)

      The delay before each staging, in seconds.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight

   .. method:: getClampAutoStageThrustPct()

      The fraction of full thrust at which the controller releases the launch clamps.

      :rtype: ``number``
      :Game Scenes: Flight

      :rtype: ``number``
