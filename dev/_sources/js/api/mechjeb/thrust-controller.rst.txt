ThrustController
================


.. class:: ThrustController

   The thrust controller, which limits the throttle.

   .. method:: getDifferentialThrottle()
               setDifferentialThrottle(value)

      Whether the controller throttles the engines differentially to steer.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getDifferentialThrottleStatus()

      The result of the differential throttle.

      :Property: Read-only, cannot be set
      :rtype: :class:`MechJeb.DifferentialThrottleStatus`
      :Game Scenes: Flight

   .. method:: getElectricThrottle()
               setElectricThrottle(value)

      Whether to limit the throttle of electric engines to the available power.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getElectricThrottleHi()
               setElectricThrottleHi(value)

      The charge level at which electric engines run at full throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getElectricThrottle`.

   .. method:: getElectricThrottleLo()
               setElectricThrottleLo(value)

      The charge level at which electric engines stop, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getElectricThrottle`.

   .. method:: getFlameoutSafetyPct()
               setFlameoutSafetyPct(value)

      The safety margin of the jet engines' air intake, as a percentage.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getLimitToPreventFlameout`.

   .. method:: getLimitAcceleration()
               setLimitAcceleration(value)

      Whether to limit the acceleration.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitDynamicPressure()
               setLimitDynamicPressure(value)

      Whether to limit the dynamic pressure.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitThrottle()
               setLimitThrottle(value)

      Whether to limit the throttle.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitToPreventFlameout()
               setLimitToPreventFlameout(value)

      Whether to limit the throttle to keep jet engines from flaming out.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimitToPreventOverheats()
               setLimitToPreventOverheats(value)

      Whether to limit the throttle to keep parts from overheating.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getLimiterMinThrottle()
               setLimiterMinThrottle(value)

      Whether to keep the throttle above :meth:`MechJeb.ThrustController.getMinThrottle`.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getManageIntakes()
               setManageIntakes(value)

      Whether the controller opens and closes the air intakes.

      :Property: Can be read or written
      :rtype: ``boolean``
      :Game Scenes: Flight

   .. method:: getMaxAcceleration()
               setMaxAcceleration(value)

      The largest acceleration, in :math:`\mathrm{m/s^{2}}`.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getLimitAcceleration`.

   .. method:: getMaxDynamicPressure()
               setMaxDynamicPressure(value)

      The largest dynamic pressure, in pascals.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getLimitDynamicPressure`.

   .. method:: getMaxThrottle()
               setMaxThrottle(value)

      The largest throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getLimitThrottle`.

   .. method:: getMinThrottle()
               setMinThrottle(value)

      The smallest throttle, between 0 and 1.

      :Property: Can be read or written
      :rtype: ``number``
      :Game Scenes: Flight


      .. note::

         Requires :meth:`MechJeb.ThrustController.getLimiterMinThrottle`.



.. class:: DifferentialThrottleStatus

   The result of the differential throttle. See
   :meth:`MechJeb.ThrustController.getDifferentialThrottleStatus`.


   .. attribute:: allEnginesOff

      All the engines are off.


   .. attribute:: moreEnginesRequired

      The vessel needs more engines.


   .. attribute:: solverFailed

      The solver found no solution.


   .. attribute:: success

      The throttles balance the thrust.
