Panel
=====


.. type:: krpc_UI_Panel_t

   A container for user interface elements.
   Added to a :type:`krpc_UI_Canvas_t` or another panel.

   .. function:: krpc_error_t krpc_UI_Panel_RectTransform(krpc_connection_t connection, krpc_UI_RectTransform_t * result)

      The rect transform for the UI object.

   

   .. function:: krpc_error_t krpc_UI_Panel_LayoutElement(krpc_connection_t connection, krpc_UI_LayoutElement_t * result)

      How much space the UI object asks a layout for.

   

      .. note::

         Only has an effect when the object is in a panel that has a layout. A canvas is
         not inside a layout and does not have one.

   .. function:: krpc_error_t krpc_UI_Panel_Style(krpc_connection_t connection, krpc_UI_PanelStyle_t * result)
   .. function:: void krpc_UI_Panel_set_Style(krpc_UI_PanelStyle_t value)

      How the background of the panel is drawn. A box is the frame to group related
      controls in, and is how a group box is made.

   

   .. function:: krpc_error_t krpc_UI_Panel_Color(krpc_connection_t connection, krpc_tuple_double_double_double_double_t * result)
   .. function:: void krpc_UI_Panel_set_Color(const krpc_tuple_double_double_double_double_t * value)

      The color the background of the panel is tinted with, as
      (red, green, blue, alpha). An alpha of 0 is fully transparent and 1 is fully
      opaque.

   

      .. note::

         Has no effect while the style of the panel is :macro:`KRPC_UI_PANELSTYLE_NONE`,
         as the panel is then not drawn at all.

   .. function:: krpc_error_t krpc_UI_Panel_Draggable(krpc_connection_t connection, bool * result)
   .. function:: void krpc_UI_Panel_set_Draggable(bool value)

      Whether the user can move the panel by dragging it.

   

      .. note::

         Dragging anywhere on the panel moves it, including over the elements it
         contains, unless one of them takes the pointer for itself. Give a panel a title
         bar of its own if only part of it should move it.
         A panel whose style is :macro:`KRPC_UI_PANELSTYLE_NONE` is not drawn, so it takes
         no pointer events of its own and can only be dragged by the elements it
         contains.

   .. function:: krpc_error_t krpc_UI_Panel_Visible(krpc_connection_t connection, bool * result)
   .. function:: void krpc_UI_Panel_set_Visible(bool value)

      Whether the UI object is visible.

   

      .. note::

         This is the object's own setting, which is what it was last set to. An object is
         only drawn when everything it is inside is visible as well, so an interface can
         be built with its parts visible, inside a panel that is not, and shown all at
         once by making that panel visible.

   .. function:: krpc_error_t krpc_UI_Panel_AddPanel(krpc_connection_t connection, krpc_UI_Panel_t * result, bool visible)

      Create a panel within this object.

      :Parameters:

       * **visible** -- Whether the new panel is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddText(krpc_connection_t connection, krpc_UI_Text_t * result, const char * content, bool visible)

      Add text to this object.

      :Parameters:

       * **content** -- The text.
       * **visible** -- Whether the text is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddInputField(krpc_connection_t connection, krpc_UI_InputField_t * result, bool visible)

      Add an input field to this object.

      :Parameters:

       * **visible** -- Whether the input field is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddButton(krpc_connection_t connection, krpc_UI_Button_t * result, const char * content, bool visible)

      Add a button to this object.

      :Parameters:

       * **content** -- The label for the button.
       * **visible** -- Whether the button is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddToggle(krpc_connection_t connection, krpc_UI_Toggle_t * result, const char * content, bool visible)

      Add a toggle to this object.

      :Parameters:

       * **content** -- The label for the toggle.
       * **visible** -- Whether the toggle is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddToggleGroup(krpc_connection_t connection, krpc_UI_ToggleGroup_t * result)

      Add a toggle group to this object, to make a set of toggles into radio buttons.


   

      .. note::

         The group is not drawn and does not take up any space. The toggles that belong
         to it can be added anywhere.

   .. function:: krpc_error_t krpc_UI_Panel_AddSlider(krpc_connection_t connection, krpc_UI_Slider_t * result, bool vertical, bool visible)

      Add a slider to this object.

      :Parameters:

       * **vertical** -- Whether the slider runs from bottom to top, rather than from left to right.
       * **visible** -- Whether the slider is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddDropdown(krpc_connection_t connection, krpc_UI_Dropdown_t * result, bool visible)

      Add a dropdown to this object.

      :Parameters:

       * **visible** -- Whether the dropdown is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddImage(krpc_connection_t connection, krpc_UI_Image_t * result, bool visible)

      Add an image to this object.

      :Parameters:

       * **visible** -- Whether the image is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddScrollView(krpc_connection_t connection, krpc_UI_ScrollView_t * result, bool visible)

      Add a scroll view to this object.

      :Parameters:

       * **visible** -- Whether the scroll view is visible.

   

   .. function:: krpc_error_t krpc_UI_Panel_Layout(krpc_connection_t connection, krpc_UI_Layout_t * result)

      The layout that arranges the elements of the panel, or ``nullptr`` if they are
      positioned by hand.

   

   .. function:: krpc_error_t krpc_UI_Panel_AddHorizontalLayout(krpc_connection_t connection, krpc_UI_Layout_t * result)

      Arrange the elements of the panel in a row.


   

   .. function:: krpc_error_t krpc_UI_Panel_AddVerticalLayout(krpc_connection_t connection, krpc_UI_Layout_t * result)

      Arrange the elements of the panel in a column.


   

   .. function:: krpc_error_t krpc_UI_Panel_AddGridLayout(krpc_connection_t connection, krpc_UI_Layout_t * result)

      Arrange the elements of the panel in a grid of equally sized cells.


   

      .. note::

         The number of columns follows from the size of the panel and the size of a cell.
         Use :func:`krpc_UI_Layout_Constraint` to fix it instead.

   .. function:: krpc_error_t krpc_UI_Panel_SizeFitter(krpc_connection_t connection, krpc_UI_SizeFitter_t * result)

      Sizes the panel to fit what it contains.

   

      .. note::

         Both directions start out unconstrained, which leaves the size of the panel
         alone.

   .. function:: krpc_error_t krpc_UI_Panel_BringToFront(krpc_connection_t connection)

      Draw the panel in front of the other elements beside it. Elements are drawn
      in the order they were added, so of two overlapping panels the newer hides
      part of the older until the older is brought to the front.


   

      .. note::

         A draggable panel also brings itself to the front when the user starts
         dragging it, the way a window comes to the front when it is clicked.

   .. function:: krpc_error_t krpc_UI_Panel_Remove(krpc_connection_t connection)

      Remove the UI object.


   



.. type:: krpc_UI_PanelStyle_t

   How the background of a panel is drawn.


   .. macro:: KRPC_UI_PANELSTYLE_WINDOW

      As a window, the heavier of the two frames the game uses.


   .. macro:: KRPC_UI_PANELSTYLE_BOX

      As a box, the lighter frame the game groups related controls in.


   .. macro:: KRPC_UI_PANELSTYLE_NONE

      Not drawn at all, leaving whatever is behind the panel showing through.
