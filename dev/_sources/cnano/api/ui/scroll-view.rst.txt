Scroll View
===========


.. type:: krpc_UI_ScrollView_t

   A view onto a panel that is larger than the space available for it, with scroll bars
   to move around it.
   Added to a :type:`krpc_UI_Canvas_t` or a :type:`krpc_UI_Panel_t`.

   .. note::

      Add the elements to :func:`krpc_UI_ScrollView_Content`, not to the scroll view itself. Giving
      the content a layout and setting its size fitter to the preferred size is the
      simplest way to have it grow to hold what is put in it.

   .. function:: krpc_error_t krpc_UI_ScrollView_RectTransform(krpc_connection_t connection, krpc_UI_RectTransform_t * result)

      The rect transform for the UI object.

   

   .. function:: krpc_error_t krpc_UI_ScrollView_LayoutElement(krpc_connection_t connection, krpc_UI_LayoutElement_t * result)

      How much space the UI object asks a layout for.

   

      .. note::

         Only has an effect when the object is in a panel that has a layout. A canvas is
         not inside a layout and does not have one.

   .. function:: krpc_error_t krpc_UI_ScrollView_Visible(krpc_connection_t connection, bool * result)
   .. function:: void krpc_UI_ScrollView_set_Visible(bool value)

      Whether the UI object is visible.

   

      .. note::

         This is the object's own setting, which is what it was last set to. An object is
         only drawn when everything it is inside is visible as well, so an interface can
         be built with its parts visible, inside a panel that is not, and shown all at
         once by making that panel visible.

   .. function:: krpc_error_t krpc_UI_ScrollView_Content(krpc_connection_t connection, krpc_UI_Panel_t * result)

      The panel that is scrolled, which the elements to show are added to.

   

   .. function:: krpc_error_t krpc_UI_ScrollView_Horizontal(krpc_connection_t connection, bool * result)
   .. function:: void krpc_UI_ScrollView_set_Horizontal(bool value)

      Whether the view can be scrolled from side to side.

   

   .. function:: krpc_error_t krpc_UI_ScrollView_Vertical(krpc_connection_t connection, bool * result)
   .. function:: void krpc_UI_ScrollView_set_Vertical(bool value)

      Whether the view can be scrolled up and down.

   

   .. function:: krpc_error_t krpc_UI_ScrollView_Remove(krpc_connection_t connection)

      Remove the UI object.
