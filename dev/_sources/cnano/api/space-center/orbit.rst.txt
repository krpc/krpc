Orbit
=====


.. type:: krpc_SpaceCenter_Orbit_t

   Describes an orbit. For example, the orbit of a vessel, obtained by calling
   :func:`krpc_SpaceCenter_Vessel_Orbit`, or a celestial body, obtained by calling
   :func:`krpc_SpaceCenter_CelestialBody_Orbit`.

   .. function:: krpc_error_t krpc_SpaceCenter_Orbit_CreateFromPositionAndVelocity(krpc_connection_t connection, krpc_SpaceCenter_Orbit_t * result, krpc_SpaceCenter_CelestialBody_t body, const krpc_tuple_double_double_double_t * position, const krpc_tuple_double_double_double_t * velocity, double ut, krpc_SpaceCenter_ReferenceFrame_t referenceFrame)

      Create the orbit that passes through a given position at a given velocity.
      The orbit coasts freely under the gravity of the body being orbited, so it
      describes where an object left to fall from that position and velocity would
      be at any later time.

      :Parameters:

       * **body** -- The celestial body being orbited.
       * **position** -- The position, as a position vector.
       * **velocity** -- The velocity, as a vector pointing in the direction of travel, whose magnitude is the speed in meters per second.
       * **ut** -- The universal time, in seconds, at which the object is at *position* traveling at *velocity*.
       * **referenceFrame** -- The reference frame that *position* and *velocity* are in. Defaults to :func:`krpc_SpaceCenter_CelestialBody_NonRotatingReferenceFrame` of *body*.

   

      .. note::

         The orbit is a single conic around *body*. It never changes
         sphere of influence, so :func:`krpc_SpaceCenter_Orbit_NextOrbit` is ``nullptr``, and no
         atmosphere slows it. A vessel held on rails follows its own orbit exactly,
         while one inside the physics bubble is simulated and drifts from it a little.

         :func:`krpc_SpaceCenter_Orbit_Radius`, :func:`krpc_SpaceCenter_Orbit_Speed`, :func:`krpc_SpaceCenter_Orbit_Position`,
         :func:`krpc_SpaceCenter_Orbit_Velocity` and the like describe the orbit at
         *ut* and stay there. Use :func:`krpc_SpaceCenter_Orbit_RadiusAt`,
         :func:`krpc_SpaceCenter_Orbit_SpeedAt`, :func:`krpc_SpaceCenter_Orbit_PositionAt`, :func:`krpc_SpaceCenter_Orbit_VelocityAt` and
         :func:`krpc_SpaceCenter_Orbit_TrueAnomalyAtUT` for another time, and
         :func:`krpc_SpaceCenter_Orbit_ReferenceFrame` and :func:`krpc_SpaceCenter_Orbit_OrbitalReferenceFrame` to follow
         the orbit as time passes.

         The orbit is held until :func:`krpc_SpaceCenter_Orbit_Remove` is called on it or the client
         that created it disconnects. Remove each one created by a script that creates
         them repeatedly, for example once per update.

   .. function:: krpc_error_t krpc_SpaceCenter_Orbit_CreateFromOrbitalElements(krpc_connection_t connection, krpc_SpaceCenter_Orbit_t * result, krpc_SpaceCenter_CelestialBody_t body, double semiMajorAxis, double eccentricity, double inclination, double longitudeOfAscendingNode, double argumentOfPeriapsis, double meanAnomalyAtEpoch, double epoch)

      Create the orbit with the given
      `orbital elements <https://en.wikipedia.org/wiki/Orbital_elements>`_
      around a given body. The orbit coasts freely under the gravity of that body,
      so it describes where an object on it would be at any time.

      :Parameters:

       * **body** -- The celestial body being orbited.
       * **semiMajorAxis** -- The semi-major axis of the orbit, in meters. Positive for an ellipse and negative for a hyperbola.
       * **eccentricity** -- The eccentricity of the orbit. Below one for an ellipse and above one for a hyperbola.
       * **inclination** -- The inclination of the orbit, in radians.
       * **longitudeOfAscendingNode** -- The longitude of the ascending node, in radians.
       * **argumentOfPeriapsis** -- The argument of periapsis, in radians.
       * **meanAnomalyAtEpoch** -- The mean anomaly at *epoch*, in radians.
       * **epoch** -- The universal time, in seconds, that *meanAnomalyAtEpoch* is measured at.

   

      .. note::

         The orbit is a single conic around *body*. It never changes
         sphere of influence, so :func:`krpc_SpaceCenter_Orbit_NextOrbit` is ``nullptr``, and no
         atmosphere slows it.

         The angles are measured against the reference plane and direction that
         :func:`krpc_SpaceCenter_Orbit_Inclination`, :func:`krpc_SpaceCenter_Orbit_LongitudeOfAscendingNode` and
         :func:`krpc_SpaceCenter_Orbit_ArgumentOfPeriapsis` report them against.
         :func:`krpc_SpaceCenter_Orbit_ReferencePlaneNormal` and :func:`krpc_SpaceCenter_Orbit_ReferencePlaneDirection`
         give these as vectors in a reference frame.

         :func:`krpc_SpaceCenter_Orbit_Radius`, :func:`krpc_SpaceCenter_Orbit_Speed`, :func:`krpc_SpaceCenter_Orbit_Position`,
         :func:`krpc_SpaceCenter_Orbit_Velocity` and the like describe the orbit at
         *epoch* and stay there. Use :func:`krpc_SpaceCenter_Orbit_RadiusAt`,
         :func:`krpc_SpaceCenter_Orbit_SpeedAt`, :func:`krpc_SpaceCenter_Orbit_PositionAt`, :func:`krpc_SpaceCenter_Orbit_VelocityAt` and
         :func:`krpc_SpaceCenter_Orbit_TrueAnomalyAtUT` for another time, and
         :func:`krpc_SpaceCenter_Orbit_ReferenceFrame` and :func:`krpc_SpaceCenter_Orbit_OrbitalReferenceFrame` to follow
         the orbit as time passes.

         The orbit is held until :func:`krpc_SpaceCenter_Orbit_Remove` is called on it or the client
         that created it disconnects. Remove each one created by a script that creates
         them repeatedly, for example once per update.

   .. function:: krpc_error_t krpc_SpaceCenter_Orbit_Remove(krpc_connection_t connection)

      Remove the orbit, releasing the memory the server holds for it.


   

      .. note::

         Only an orbit created by :func:`krpc_SpaceCenter_Orbit_CreateFromPositionAndVelocity` or
         :func:`krpc_SpaceCenter_Orbit_CreateFromOrbitalElements` can be removed. Every other orbit
         belongs to something in the game, and the server holds one of each.

         Any further use of this object throws an exception, as does use of a
         reference frame defined against it. An orbit belongs to the client that
         created it, and is removed when that client disconnects.

   .. function:: krpc_error_t krpc_SpaceCenter_Orbit_ReferenceFrame(krpc_connection_t connection, krpc_SpaceCenter_ReferenceFrame_t * result)

      The reference frame that moves along the orbit, and is orientated in a fixed
      direction.

      * The origin is at the point the orbit has reached at the
        current time.
      * The axes do not rotate. They point in the same fixed
        directions as those of
        :func:`krpc_SpaceCenter_CelestialBody_NonRotatingReferenceFrame` of
        :func:`krpc_SpaceCenter_Orbit_Body`.

   

      .. note::

         For the orbit of a vessel, the origin is the point the vessel's orbit has
         reached rather than the vessel's own center of mass. The two are a few meters
         apart, as a vessel inside the physics bubble is simulated rather than being
         held on its orbit.

   .. function:: krpc_error_t krpc_SpaceCenter_Orbit_OrbitalReferenceFrame(krpc_connection_t connection, krpc_SpaceCenter_ReferenceFrame_t * result)

      The reference frame that moves along the orbit, and is orientated with its
      prograde/normal/radial directions.

      * The origin is at the point the orbit has reached at the
        current time.
      * The axes rotate with the orbital prograde/normal/radial
        directions.
      * The x-axis points in the orbital anti-radial direction.
      * The y-axis points in the orbital prograde direction.
      * The z-axis points in the orbital normal direction.

   

      .. note::

         For the orbit of a vessel, the origin is the point the vessel's orbit has
         reached rather than the vessel's own center of mass, which is what
         :func:`krpc_SpaceCenter_Vessel_OrbitalReferenceFrame` is centered on.
