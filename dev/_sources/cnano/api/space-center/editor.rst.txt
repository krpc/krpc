   .. function:: krpc_error_t krpc_SpaceCenter_Editor_LoadVessel(krpc_connection_t connection, krpc_SpaceCenter_Editor_t instance, const char * craftDirectory, const char * name)

      Load a vessel from a craft file into the editor, replacing the vessel that
      is currently being constructed.

      :Parameters:

       * **craftDirectory** -- Name of the directory in the current saves "Ships" directory, that contains the craft file. For example ``"VAB"`` or ``"SPH"``.
       * **name** -- Name of the vessel to load. This is the name of the ".craft" file in the save directory, without the ".craft" file extension.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         The vessel is loaded into whichever editor is open, regardless of which
         directory it came from. Its delta-v figures are recalculated in the
         background afterwards; see :func:`krpc_SpaceCenter_EditorVessel_DeltaVReady`.

   .. function:: krpc_error_t krpc_SpaceCenter_Editor_LaunchVessel(krpc_connection_t connection, krpc_SpaceCenter_Editor_t instance, const char * launchSite, const krpc_list_string_t * crew, bool recover, const char * flagUrl)

      Launch the vessel that is being constructed, from the given launch site.

      :Parameters:

       * **launchSite** -- Name of the launch site. For example ``"LaunchPad"`` or ``"Runway"``.
       * **crew** -- The Kerbals to place in the vessel, by name. Controls how the vessel is crewed, as described in the remarks.
       * **recover** -- If true and there is a vessel on the launch site, recover it before launching.
       * **flagUrl** -- If not ``nullptr``, the asset URL of the mission flag to use for the launch.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         The vessel being constructed is not a craft file, so it is written to the editor's
         auto-saved craft file and that is launched, as the game's own launch button does.
         The vessel's own craft file, if it was loaded from one, is left alone.
         The *crew* parameter works as it does for
         :func:`krpc_SpaceCenter_LaunchVessel`, and takes precedence over the crew assigned
         in the editor.
         Throws an exception if any of the games pre-flight checks fail.

   .. function:: krpc_error_t krpc_SpaceCenter_Editor_DeltaVBody(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t * returnValue, krpc_SpaceCenter_Editor_t instance)
   .. function:: krpc_error_t krpc_SpaceCenter_Editor_set_DeltaVBody(krpc_connection_t connection, krpc_SpaceCenter_Editor_t instance, krpc_SpaceCenter_CelestialBody_t value)

      The body whose gravity and atmosphere the vessel's delta-v, thrust, TWR and
      specific impulse figures assume.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         This and :func:`krpc_SpaceCenter_Editor_DeltaVAltitude` are what :func:`krpc_SpaceCenter_EditorVessel_DeltaV`,
         :func:`krpc_SpaceCenter_Stage_DeltaV` and the other current-situation figures are
         computed for. The body sets the gravity the thrust-to-weight ratios are
         against, and, with the altitude, the atmospheric pressure and density the
         specific impulses and thrusts are against.
         This is global game state rather than editor state: the same setting backs
         the game's delta-v readout in flight, and it persists across scene changes.
         Setting it asks the game to re-run the simulation and returns straight away;
         the figures are out of date until :func:`krpc_SpaceCenter_EditorVessel_DeltaVReady` is
         true again.

   .. function:: krpc_error_t krpc_SpaceCenter_Editor_DeltaVAltitude(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_Editor_t instance)
   .. function:: krpc_error_t krpc_SpaceCenter_Editor_set_DeltaVAltitude(krpc_connection_t connection, krpc_SpaceCenter_Editor_t instance, double value)

      The altitude above :func:`krpc_SpaceCenter_Editor_DeltaVBody`, in meters, that the vessel's
      delta-v, thrust, TWR and specific impulse figures assume. The atmospheric
      pressure and density at this altitude are what the figures are computed for,
      so raising it from zero to above the body's atmosphere moves them from the
      vessel's sea-level figures to its vacuum ones.
      Setting it asks the game to re-run the simulation and returns straight away;
      the figures are out of date until :func:`krpc_SpaceCenter_EditorVessel_DeltaVReady` is
      true again.

      :Game Scenes: Editor Vab, Editor Sph

   .. function:: krpc_error_t krpc_SpaceCenter_Editor_DeltaVSituation(krpc_connection_t connection, krpc_SpaceCenter_DeltaVSituation_t * returnValue, krpc_SpaceCenter_Editor_t instance)
   .. function:: krpc_error_t krpc_SpaceCenter_Editor_set_DeltaVSituation(krpc_connection_t connection, krpc_SpaceCenter_Editor_t instance, krpc_SpaceCenter_DeltaVSituation_t value)

      Which situation the game's own delta-v readout shows figures for.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         This selects which column the game's own delta-v app displays, and nothing
         else. It does not affect anything kRPC reports: the current-situation
         figures follow :func:`krpc_SpaceCenter_Editor_DeltaVBody` and :func:`krpc_SpaceCenter_Editor_DeltaVAltitude`
         whatever this is set to, and the sea-level and vacuum figures are reported
         directly as :func:`krpc_SpaceCenter_EditorVessel_SeaLevelDeltaV` and
         :func:`krpc_SpaceCenter_EditorVessel_VacuumDeltaV`. It is here for completeness with the
         app.

   .. function:: krpc_error_t krpc_SpaceCenter_EditorVessel_ReferenceFrame(krpc_connection_t connection, krpc_SpaceCenter_ReferenceFrame_t * returnValue, krpc_SpaceCenter_EditorVessel_t instance)

      The reference frame that is fixed relative to the vessel,
      and orientated with the vessel.

      * The origin is at the center of mass of the vessel.
      * The axes rotate with the vessel.
      * The x-axis points out to the right of the vessel.
      * The y-axis points in the forward direction of the vessel.
      * The z-axis points out of the bottom off the vessel.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         The axes are those of the root part. This is the frame
         :func:`krpc_SpaceCenter_Vessel_ReferenceFrame` gives at launch, with the root part as the
         control point.

   .. function:: krpc_error_t krpc_SpaceCenter_EditorVessel_SurfaceReferenceFrame(krpc_connection_t connection, krpc_SpaceCenter_ReferenceFrame_t * returnValue, krpc_SpaceCenter_EditorVessel_t instance)

      The reference frame that is fixed relative to the vessel,
      and orientated with the vertical of the editor.

      * The origin is at the center of mass of the vessel.
      * The axes are fixed in the editor.
      * The x-axis points upwards.
      * The y-axis and z-axis are horizontal.

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         This is the vessel as it stands in the editor, and as it stands at launch. The
         editor has no north or east, so the horizontal axes are fixed in the editor.

.. type:: krpc_SpaceCenter_SimulatedFlight_t

   Used to simulate the vessel in the editor in flight. The counterpart of
   :type:`krpc_SpaceCenter_Flight_t`. All of the information returned by this class is given in
   the reference frame passed to :func:`krpc_SpaceCenter_EditorVessel_Flight`, or in
   :func:`krpc_SpaceCenter_SimulatedFlight_SurfaceReferenceFrame` if none was passed.
   Obtained by calling :func:`krpc_SpaceCenter_EditorVessel_Flight`.

   .. note::

      The simulated attitude is set by :func:`krpc_SpaceCenter_SimulatedFlight_SurfaceReferenceFrame`, and belongs to
      this object. The vessel is read from the editor on each call, so the object follows
      every edit.

      points upwards, and gravity acts along the negative x-axis. Defaults to

      :Game Scenes: Editor Vab, Editor Sph


      .. note::

         Only the rotation of the frame is used. A frame created relative to
