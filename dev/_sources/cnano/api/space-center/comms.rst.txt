   .. function:: krpc_error_t krpc_SpaceCenter_Comms_CanTransmitScience(krpc_connection_t connection, bool * returnValue, krpc_SpaceCenter_Comms_t instance)

      Whether the vessel can transmit science data to KSC.

      :Game Scenes: Flight

   .. function:: krpc_error_t krpc_SpaceCenter_Comms_SignalStrength(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_Comms_t instance)

      Signal strength to KSC.

      :Game Scenes: Flight

   .. function:: krpc_error_t krpc_SpaceCenter_Comms_SignalDelay(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_Comms_t instance)

.. type:: krpc_SpaceCenter_CommLink_t

   Represents a communication link between two nodes in the network.

   .. macro:: KRPC_CLASS_SPACECENTER_COMMLINK

      The service and class ids of the class, for :func:`krpc_KRPC_Type_ClassTypeById`.

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_Type(krpc_connection_t connection, krpc_SpaceCenter_CommLinkType_t * returnValue, krpc_SpaceCenter_CommLink_t instance)

      The type of link.

   

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_SignalStrength(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_CommLink_t instance)

      Signal strength of the link.

   

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_Start(krpc_connection_t connection, krpc_SpaceCenter_CommNode_t * returnValue, krpc_SpaceCenter_CommLink_t instance)

      Start point of the link.

   

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_End(krpc_connection_t connection, krpc_SpaceCenter_CommNode_t * returnValue, krpc_SpaceCenter_CommLink_t instance)

      End point of the link.

   

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_ForwardDataRate(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_CommLink_t instance)

      The data rate from :func:`krpc_SpaceCenter_CommLink_Start` to :func:`krpc_SpaceCenter_CommLink_End`, in bits per second.

   

      .. note::

         Requires RealAntennas.

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_ReverseDataRate(krpc_connection_t connection, double * returnValue, krpc_SpaceCenter_CommLink_t instance)

      The data rate from :func:`krpc_SpaceCenter_CommLink_End` to :func:`krpc_SpaceCenter_CommLink_Start`, in bits per second.

   

      .. note::

         Requires RealAntennas.

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_StartAntenna(krpc_connection_t connection, krpc_SpaceCenter_Antenna_t * returnValue, krpc_SpaceCenter_CommLink_t instance)

      The antenna at :func:`krpc_SpaceCenter_CommLink_Start` that transmits over the link, or ``nullptr`` if
      :func:`krpc_SpaceCenter_CommLink_Start` is a ground station or an unloaded vessel.

   

      .. note::

         Requires RealAntennas.

   .. function:: krpc_error_t krpc_SpaceCenter_CommLink_EndAntenna(krpc_connection_t connection, krpc_SpaceCenter_Antenna_t * returnValue, krpc_SpaceCenter_CommLink_t instance)

      The antenna at :func:`krpc_SpaceCenter_CommLink_End` that receives over the link, or ``nullptr`` if
      :func:`krpc_SpaceCenter_CommLink_End` is a ground station or an unloaded vessel.

   

      .. note::

         Requires RealAntennas.



.. type:: krpc_SpaceCenter_CommLinkType_t

   The type of a communication link.
   See :func:`krpc_SpaceCenter_CommLink_Type`.

   .. macro:: KRPC_ENUMERATION_SPACECENTER_COMMLINKTYPE

      The service and enumeration ids of the enumeration, for
      :func:`krpc_KRPC_Type_EnumerationTypeById` and :func:`krpc_KRPC_Expression_ConstantEnumById`.


   .. macro:: KRPC_SPACECENTER_COMMLINKTYPE_HOME

      Link is to a base station on Kerbin.


   .. macro:: KRPC_SPACECENTER_COMMLINKTYPE_CONTROL

      Link is to a control source, for example a manned spacecraft.


   .. macro:: KRPC_SPACECENTER_COMMLINKTYPE_RELAY

      Link is to a relay satellite.
