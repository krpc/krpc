Debug
=====


Provides functionality to modify the state of the simulation directly, in ways
the game normally does not allow: teleporting a vessel, setting its attitude,
refilling its tanks and enabling the game's cheat options.

.. note::

   Everything in this service is cheating. It has the same effect on a save as the
   game's own debug menu (Alt+F12), and the same consequences: contracts, records and
   career progress made with it are not earned. It is intended for setting up a
   scenario to fly or a script to test, without flying there first.



.. function:: krpc_error_t krpc_Debug_SetCircularOrbit(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t body, double altitude)

   Move the active vessel onto a circular orbit around a body.

   :Parameters:

    * **body** -- Body to orbit.
    * **altitude** -- Altitude of the orbit, in meters above sea level.

   :Game Scenes: Flight





.. function:: krpc_error_t krpc_Debug_SetOrbit(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t body, double semiMajorAxis, double eccentricity, double inclination, double longitudeOfAscendingNode, double argumentOfPeriapsis, double meanAnomalyAtEpoch, double epoch)

   Move the active vessel onto the orbit with the given orbital elements. The angles use
   the same units and conventions as :type:`krpc_SpaceCenter_Orbit_t`.

   :Parameters:

    * **body** -- Body to orbit.
    * **semiMajorAxis** -- Semi-major axis of the orbit, in meters.
    * **eccentricity** -- Eccentricity of the orbit.
    * **inclination** -- Inclination of the orbit, in radians.
    * **longitudeOfAscendingNode** -- Longitude of the ascending node, in radians.
    * **argumentOfPeriapsis** -- Argument of periapsis, in radians.
    * **meanAnomalyAtEpoch** -- Mean anomaly at epoch, in radians.
    * **epoch** -- Universal time of the epoch, in seconds.

   :Game Scenes: Flight





.. function:: krpc_error_t krpc_Debug_SetLanded(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t body, double latitude, double longitude, double altitude)

   Place the active vessel on the surface of a body at the given latitude and longitude,
   and wait for it to come to rest.

   :Parameters:

    * **body** -- Body to land on.
    * **latitude** -- Latitude in degrees.
    * **longitude** -- Longitude in degrees.
    * **altitude** -- Height above the terrain to settle at, in meters. Defaults to 0, resting on the surface.

   :Game Scenes: Flight





.. function:: krpc_error_t krpc_Debug_SetFlight(krpc_connection_t connection, krpc_SpaceCenter_CelestialBody_t body, double latitude, double longitude, double altitude, double speed, double heading, double pitch, double roll, double angleOfAttack)

   Place the active vessel in atmospheric flight over the given point: at the given altitude
   and airspeed, pointing along the given heading at the given pitch and roll, and
   let physics resume so that it is flying. Use this to set up an in-air scenario
   without flying the craft up from the runway.

   :Parameters:

    * **body** -- Body to fly over.
    * **latitude** -- Latitude in degrees.
    * **longitude** -- Longitude in degrees.
    * **altitude** -- Altitude in meters above sea level.
    * **speed** -- Airspeed in meters per second, relative to the surface.
    * **heading** -- Compass heading to point along, in degrees (90 is east).
    * **pitch** -- Pitch above the horizon, in degrees. Defaults to 0 (level).
    * **roll** -- Roll, in degrees. Defaults to 0 (wings level).
    * **angleOfAttack** -- Angle of attack in degrees: how far the airspeed vector sits below the nose, in the pitch plane. 0 (the default) puts the airspeed along the nose; a positive value gives a nose-up attitude relative to the flight path, so the flight-path angle is *pitch* minus this.

   :Game Scenes: Flight


   .. note::

      The pitch, heading and roll match those reported by the vessel's
      :type:`krpc_SpaceCenter_Flight_t`.




.. function:: krpc_error_t krpc_Debug_SetPosition(krpc_connection_t connection, const krpc_tuple_double_double_double_t * position, krpc_SpaceCenter_ReferenceFrame_t referenceFrame)

   Move the active vessel to the given position, leaving its velocity as it is. To put it
   alongside another vessel, pass a position in that vessel's reference frame.

   :Parameters:

    * **position** -- Position of the vessel's center of mass, in meters.
    * **referenceFrame** -- Reference frame the position is in. Defaults to the reference frame of the body being orbited.

   :Game Scenes: Flight


   .. note::

      This is the inverse of :func:`krpc_SpaceCenter_Vessel_Position` in the same
      reference frame.




.. function:: krpc_error_t krpc_Debug_SetVelocity(krpc_connection_t connection, const krpc_tuple_double_double_double_t * velocity, krpc_SpaceCenter_ReferenceFrame_t referenceFrame)

   Set the velocity of the active vessel, leaving it where it is. The vessel is moved onto the
   orbit that passes through its current position at the new velocity, so this works
   in orbit and in the atmosphere alike.

   :Parameters:

    * **velocity** -- Velocity in meters per second.
    * **referenceFrame** -- Reference frame the velocity is in. Defaults to the reference frame of the body being orbited, which rotates with it, so a zero velocity leaves the vessel at rest relative to the ground.

   :Game Scenes: Flight


   .. note::

      This is the inverse of :func:`krpc_SpaceCenter_Vessel_Velocity` in the same
      reference frame.




.. function:: krpc_error_t krpc_Debug_SetPitchHeadingRoll(krpc_connection_t connection, double pitch, double heading, double roll, krpc_SpaceCenter_ReferenceFrame_t referenceFrame, krpc_SpaceCenter_Vessel_t vessel)

   Set the attitude of a vessel to the given pitch, heading and roll in the given
   reference frame, and stop it rotating. Lets a script start from a fixed, still
   pose without first flying the autopilot there.

   :Parameters:

    * **pitch** -- Target pitch, in degrees.
    * **heading** -- Target heading, in degrees.
    * **roll** -- Target roll, in degrees.
    * **referenceFrame** -- Reference frame the angles are in. Defaults to the vessel's surface reference frame.
    * **vessel** -- Vessel to rotate. Defaults to the active vessel.

   :Game Scenes: Flight


   .. note::

      The angles match those reported by the vessel's
      :type:`krpc_SpaceCenter_Flight_t`.




.. function:: krpc_error_t krpc_Debug_SetDirection(krpc_connection_t connection, const krpc_tuple_double_double_double_t * direction, double roll, krpc_SpaceCenter_ReferenceFrame_t referenceFrame, krpc_SpaceCenter_Vessel_t vessel)

   Point a vessel along the given direction in the given reference frame, and stop it
   rotating. This is :func:`krpc_Debug_SetPitchHeadingRoll` with a pointing vector instead
   of a pitch and heading, matching the attitude the autopilot holds for the same
   target direction and roll.

   :Parameters:

    * **direction** -- Direction to point the nose of the vessel in.
    * **roll** -- Target roll, in degrees, or ``NaN`` to leave the roll uncontrolled.
    * **referenceFrame** -- Reference frame the direction and roll are in. Defaults to the vessel's surface reference frame.
    * **vessel** -- Vessel to rotate. Defaults to the active vessel.

   :Game Scenes: Flight





.. function:: krpc_error_t krpc_Debug_ApplyRotation(krpc_connection_t connection, double angle, const krpc_tuple_double_double_double_t * axis, krpc_SpaceCenter_Vessel_t vessel)

   Rotate a vessel about the given axis, in its own reference frame, by the given angle.

   :Parameters:

    * **angle** -- Angle to rotate by, in degrees.
    * **axis** -- Axis to rotate about.
    * **vessel** -- Vessel to rotate. Defaults to the active vessel.

   :Game Scenes: Flight





.. function:: krpc_error_t krpc_Debug_SetAngularVelocity(krpc_connection_t connection, const krpc_tuple_double_double_double_t * angularVelocity, krpc_SpaceCenter_ReferenceFrame_t referenceFrame, krpc_SpaceCenter_Vessel_t vessel)

   Set the angular velocity of a vessel, expressed in the given reference frame. Pass a
   zero vector to stop the vessel rotating.

   :Parameters:

    * **angularVelocity** -- Angular velocity, in radians per second. The direction is the axis of rotation and the magnitude is the rate.
    * **referenceFrame** -- Reference frame the angular velocity is in. Defaults to the vessel's surface reference frame.
    * **vessel** -- Vessel to rotate. Defaults to the active vessel.

   :Game Scenes: Flight


   .. note::

      The whole vessel is put into a rigid rotation about its center of mass, so it spins in
      place rather than shearing apart or translating.
