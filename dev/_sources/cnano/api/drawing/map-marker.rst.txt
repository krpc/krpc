MapMarker
=========


.. type:: krpc_Drawing_MapMarker_t

   :func:`krpc_Drawing_AddMapMarker`.

      Reference frame that the position of the marker is in.

      :Game Scenes: Flight, Tracking Station

      Whether the marker is visible.

      :Game Scenes: Flight, Tracking Station
