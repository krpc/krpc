Migration from KRPC.MechJeb 0.7.1
=================================

kRPC 0.8 adds the MechJeb service, which Genhis' KRPC.MechJeb 0.7.1 provided before. The
service follows MechJeb's windows, so some 0.7.1 members moved or were renamed. 0.7.1 names
are given as in C#.
