.. type:: krpc_MechJeb_TranslatronMode_t

   The mode of Translatron. See :func:`krpc_MechJeb_Translatron_Mode`.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_OFF

      Off.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_KEEPORBITAL

      Hold the orbital speed.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_KEEPSURFACE

      Hold the surface speed.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_KEEPVERTICAL

      Hold the vertical speed.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_KEEPRELATIVE

      Unused. MechJeb 2.15 has no such mode.


   .. macro:: KRPC_MECHJEB_TRANSLATRONMODE_DIRECT

      Set by MechJeb's autopilots. Cannot be set.
