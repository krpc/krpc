.. type:: krpc_MechJeb_SmartRCSMode_t

   The mode of Smart RCS. See :func:`krpc_MechJeb_SmartRCS_Mode`.

   .. macro:: KRPC_ENUMERATION_MECHJEB_SMARTRCSMODE

      The service and enumeration ids of the enumeration, for
      :func:`krpc_KRPC_Type_EnumerationTypeById` and :func:`krpc_KRPC_Expression_ConstantEnumById`.


   .. macro:: KRPC_MECHJEB_SMARTRCSMODE_OFF

      Off.


   .. macro:: KRPC_MECHJEB_SMARTRCSMODE_ZERORELATIVEVELOCITY

      Hold zero velocity relative to the target.


   .. macro:: KRPC_MECHJEB_SMARTRCSMODE_ZEROVELOCITY

      Hold zero velocity. MechJeb 2.15 removed this mode.
