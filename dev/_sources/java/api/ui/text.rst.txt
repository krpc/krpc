Text
====


.. type:: public class Text

   A text label.
   Added to a :type:`Canvas` or a :type:`Panel`.

   .. method:: RectTransform getRectTransform()


      The rect transform for the UI object.

   

   .. method:: LayoutElement getLayoutElement()


      How much space the UI object asks a layout for.

   

      .. note::

         Only has an effect when the object is in a panel that has a layout. A canvas is
         not inside a layout and does not have one.

   .. method:: boolean getVisible()

   .. method:: void setVisible(boolean value)

      Whether the UI object is visible.

   

      .. note::

         This is the object's own setting, which is what it was last set to. An object is
         only drawn when everything it is inside is visible as well, so an interface can
         be built with its parts visible, inside a panel that is not, and shown all at
         once by making that panel visible.

   .. method:: String getContent()

   .. method:: void setContent(String value)

      The text string

   

   .. method:: boolean getWordWrap()

   .. method:: void setWordWrap(boolean value)

      Whether the text wraps onto further lines when it is wider than the space it
      has. When wrapping is off, the text carries on past the edge instead, and a
      label asked for its preferred size asks for a single line, so a value that
      changes does not reflow a layout.

   

   .. method:: String getFont()

   .. method:: void setFont(String value)

      Name of the font

   

      .. note::

         Empty if the game provided no font to draw the text with, in which case it is
         not drawn. See :meth:`Text.getAvailableFonts()` for the names that can be set.

   .. method:: java.util.List<String> getAvailableFonts()


      A list of all available fonts.

   

   .. method:: int getSize()

   .. method:: void setSize(int value)

      Font size.

   

   .. method:: FontStyle getStyle()

   .. method:: void setStyle(FontStyle value)

      Font style.

   

   .. method:: org.javatuples.Quartet<Double,Double,Double,Double> getColor()

   .. method:: void setColor(org.javatuples.Quartet<Double,Double,Double,Double> value)

      The color the text is drawn in, as (red, green, blue, alpha). An alpha of 0 is
      fully transparent and 1 is fully opaque.

   

   .. method:: TextAnchor getAlignment()

   .. method:: void setAlignment(TextAnchor value)

      Alignment.

   

   .. method:: float getLineSpacing()

   .. method:: void setLineSpacing(float value)

      Line spacing.

   

   .. method:: void remove()

      Remove the UI object.
