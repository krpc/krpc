Layout
======


.. type:: public class Layout

   Arranges the elements of a panel automatically, so that they do not have to be
   positioned one by one. See :meth:`Panel.addHorizontalLayout()`,
   :meth:`Panel.addVerticalLayout()` and :meth:`Panel.addGridLayout()`.

   .. method:: float getSpacing()

   .. method:: void setSpacing(float value)

      The gap left between the elements, in pixels. A grid layout uses it in both
      directions.

   

   .. method:: org.javatuples.Quartet<Integer,Integer,Integer,Integer> getPadding()

   .. method:: void setPadding(org.javatuples.Quartet<Integer,Integer,Integer,Integer> value)

      The gap left inside the edges of the panel, in whole pixels, as
      (left, right, top, bottom).

   

   .. method:: TextAnchor getChildAlignment()

   .. method:: void setChildAlignment(TextAnchor value)

      Where the elements are placed within the space the layout has to fill.

   

   .. method:: org.javatuples.Pair<Double,Double> getCellSize()

   .. method:: void setCellSize(org.javatuples.Pair<Double,Double> value)

      The size of each cell of a grid layout, in pixels.

   

      .. note::

         Only applies to a grid layout. Throws an exception for the other layouts, whose
         elements are sized individually using their layout elements.

   .. method:: GridConstraint getConstraint()

   .. method:: void setConstraint(GridConstraint value)

      What fixes the shape of a grid layout.

   

      .. note::

         Only applies to a grid layout. Throws an exception for the other layouts.

   .. method:: int getConstraintCount()

   .. method:: void setConstraintCount(int value)

      The number of columns or rows that :meth:`Layout.getConstraint()` fixes, ignored when
      the constraint is :meth:`GridConstraint.FLEXIBLE`.

   

      .. note::

         Only applies to a grid layout. Throws an exception for the other layouts.



.. type:: public enum GridConstraint

   What fixes the shape of a grid layout.


   .. field:: public GridConstraint FLEXIBLE

      Fit as many columns and rows as the size of the panel allows.


   .. field:: public GridConstraint FIXED_COLUMN_COUNT

      Use a fixed number of columns, and as many rows as are needed.


   .. field:: public GridConstraint FIXED_ROW_COUNT

      Use a fixed number of rows, and as many columns as are needed.
