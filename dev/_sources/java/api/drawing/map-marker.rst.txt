MapMarker
=========


.. type:: public class MapMarker

   A marker drawn in the map view, with one of the game's own map icons. Created using
   :meth:`addMapMarker(org.javatuples.Triplet<Double,Double,Double>, SpaceCenter.ReferenceFrame, MapMarkerIcon, String, boolean)`.

   .. method:: org.javatuples.Triplet<Double,Double,Double> getPosition()

   .. method:: void setPosition(org.javatuples.Triplet<Double,Double,Double> value)

      Position of the marker.

      :Game Scenes: Flight, Tracking Station

   .. method:: SpaceCenter.ReferenceFrame getReferenceFrame()

   .. method:: void setReferenceFrame(SpaceCenter.ReferenceFrame value)

      Reference frame that the position of the marker is in.

      :Game Scenes: Flight, Tracking Station

   .. method:: boolean getVisible()

   .. method:: void setVisible(boolean value)

      Whether the marker is visible.

      :Game Scenes: Flight, Tracking Station

   .. method:: MapMarkerIcon getIcon()

   .. method:: void setIcon(MapMarkerIcon value)

      The icon that the marker is drawn with.

      :Game Scenes: Flight, Tracking Station

   .. method:: Image getImage()

   .. method:: void setImage(Image value)

      The image that the marker is drawn with in place of its icon, or null to draw the
      icon.

      :Game Scenes: Flight, Tracking Station

   .. method:: String getCaption()

   .. method:: void setCaption(String value)

      The caption shown when the mouse is over the marker.

      :Game Scenes: Flight, Tracking Station

   .. method:: org.javatuples.Triplet<Double,Double,Double> getColor()

   .. method:: void setColor(org.javatuples.Triplet<Double,Double,Double> value)

      The color of the marker.

      :Game Scenes: Flight, Tracking Station

   .. method:: void remove()

      Remove the marker.

      :Game Scenes: Flight, Tracking Station
