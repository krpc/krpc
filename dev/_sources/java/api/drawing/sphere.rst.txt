Sphere
======


.. type:: public class Sphere

   A solid sphere. Created using :meth:`addSphere(org.javatuples.Triplet<Double,Double,Double>, double, SpaceCenter.ReferenceFrame, boolean)`.

   .. note::

      The sphere is drawn with an additive material, so a darker color draws it more
      transparent.
