StagingController
=================


.. type:: public class StagingController

   The staging controller, which stages when a stage runs out of fuel.

   .. method:: boolean getEnabled()

   .. method:: void setEnabled(boolean value)

      Whether the module is enabled.

      :Game Scenes: Flight

   .. method:: boolean getAutostagingOnce()

   .. method:: void setAutostagingOnce(boolean value)

      Whether the controller disables itself after one staging.

      :Game Scenes: Flight


      .. note::

         Requires the controller to be enabled.

   .. method:: int getAutostageLimit()

   .. method:: void setAutostageLimit(int value)

      The last stage the controller activates.

      :Game Scenes: Flight

   .. method:: double getAutostagePostDelay()

   .. method:: void setAutostagePostDelay(double value)

      The delay after each staging, in seconds.

      :Game Scenes: Flight

   .. method:: double getAutostagePreDelay()

   .. method:: void setAutostagePreDelay(double value)

      The delay before each staging, in seconds.

      :Game Scenes: Flight

   .. method:: double getClampAutoStageThrustPct()

   .. method:: void setClampAutoStageThrustPct(double value)

      The fraction of full thrust at which the controller releases the launch clamps.

      :Game Scenes: Flight

   .. method:: double getFairingMaxAerothermalFlux()

   .. method:: void setFairingMaxAerothermalFlux(double value)

      The largest aerothermal flux at which the controller jettisons a fairing, in
      :math:`\mathrm{W/m^{2}}`.

      :Game Scenes: Flight

   .. method:: double getFairingMaxDynamicPressure()

   .. method:: void setFairingMaxDynamicPressure(double value)

      The largest dynamic pressure at which the controller jettisons a fairing, in pascals.

      :Game Scenes: Flight

   .. method:: double getFairingMinAltitude()

   .. method:: void setFairingMinAltitude(double value)

      The lowest altitude at which the controller jettisons a fairing, in meters.

      :Game Scenes: Flight

   .. method:: boolean getHotStaging()

   .. method:: void setHotStaging(boolean value)

      Whether the controller ignites the next stage before the current one burns out.

      :Game Scenes: Flight

   .. method:: double getHotStagingLeadTime()

   .. method:: void setHotStagingLeadTime(double value)

      The time before burnout at which a hot staging happens, in seconds.

      :Game Scenes: Flight


      .. note::

         Requires :meth:`StagingController.getHotStaging()`.
