ManeuverPlanner
===============


.. type:: public class ManeuverPlanner

   The maneuver planner, which makes maneuver nodes for its operations.

   .. note::

      MechJeb shares the operations, and most of their settings, between vessels.

TimeSelector
------------


.. type:: public class TimeSelector

   The time of a maneuver.

   .. method:: double getCircularizeAltitude()

   .. method:: void setCircularizeAltitude(double value)

      The altitude, in meters.

      :Game Scenes: Flight


      .. note::

         Applies to :field:`TimeReference.ALTITUDE`.

   .. method:: double getLeadTime()

   .. method:: void setLeadTime(double value)

      The time from now, in seconds.

      :Game Scenes: Flight


      .. note::

         Applies to :field:`TimeReference.X_FROM_NOW`.

   .. method:: TimeReference getTimeReference()

   .. method:: void setTimeReference(TimeReference value)

      The time reference. Throws an exception if set to a reference the operation does
      not allow.

      :Game Scenes: Flight



.. type:: public enum TimeReference

   The time reference of a maneuver. See :meth:`TimeSelector.getTimeReference()`.


   .. field:: public TimeReference ALTITUDE

      At :meth:`TimeSelector.getCircularizeAltitude()`.


   .. field:: public TimeReference APOAPSIS

      At the next apoapsis.


   .. field:: public TimeReference CLOSEST_APPROACH

      At the closest approach to the target.


   .. field:: public TimeReference COMPUTED

      At the optimum time.


   .. field:: public TimeReference EQ_ASCENDING

      At the equatorial ascending node.


   .. field:: public TimeReference EQ_DESCENDING

      At the equatorial descending node.


   .. field:: public TimeReference EQ_HIGHEST_AD

      At the cheaper of the equatorial ascending and descending nodes.


   .. field:: public TimeReference EQ_NEAREST_AD

      At the nearer of the equatorial ascending and descending nodes.


   .. field:: public TimeReference PERIAPSIS

      At the next periapsis.


   .. field:: public TimeReference REL_ASCENDING

      At the next ascending node with the target.


   .. field:: public TimeReference REL_DESCENDING

      At the next descending node with the target.


   .. field:: public TimeReference REL_HIGHEST_AD

      At the cheaper of the ascending and descending nodes with the target.


   .. field:: public TimeReference REL_NEAREST_AD

      At the nearer of the ascending and descending nodes with the target.


   .. field:: public TimeReference X_FROM_NOW

      After :meth:`TimeSelector.getLeadTime()`.

^^^^^^^^^^^^^^^^^^^^

      To raise the periapsis to the apoapsis, set the time to :field:`TimeReference.APOAPSIS`, and to lower the apoapsis to the periapsis, set it to :field:`TimeReference.PERIAPSIS`. These are the cheapest.

OperationResonantOrbit
^^^^^^^^^^^^^^^^^^^^^^


.. type:: public class OperationResonantOrbit

   Change to a resonant orbit, to place satellites in a constellation.

   .. note::

      Start from an orbit in the plane of the constellation. To deploy satellites, set the
      denominator to their number. A numerator one less than the denominator is the cheapest,
      though not the fastest. The two numbers must have no common factor.

   .. method:: String getErrorMessage()


      The warning from the last call to ``MakeNodes``, or an empty string.

      :Game Scenes: Flight

   .. method:: SpaceCenter.Node makeNode()

      .. warning:: Deprecated. Use ``MakeNodes`` instead.

      Make the maneuver nodes of the operation, and return the first one.

      :returns: The first maneuver node.
      :Game Scenes: Flight

   .. method:: java.util.List<SpaceCenter.Node> makeNodes()

      Make the maneuver nodes of the operation. Throws an :type:`OperationException`
      if the operation cannot make them.

      :returns: The maneuver nodes.
      :Game Scenes: Flight


      .. note::

         A warning may be left in ``ErrorMessage``.

   .. method:: int getResonanceDenominator()

   .. method:: void setResonanceDenominator(int value)

      The denominator of the ratio of the new orbital period to the current one.

      :Game Scenes: Flight

   .. method:: int getResonanceNumerator()

   .. method:: void setResonanceNumerator(int value)

      The numerator of the ratio of the new orbital period to the current one.

      :Game Scenes: Flight

   .. method:: TimeSelector getTimeSelector()


      The time of the maneuver.

      :Game Scenes: Flight

OperationTransfer
^^^^^^^^^^^^^^^^^


.. type:: public class OperationTransfer

   A bi-impulsive (Hohmann) transfer to the target, within one sphere of influence. It
   suits a rendezvous with a vessel or a transfer to a moon.

   .. note::

      Despite the name, the transfer is often uni-impulsive. It happens at the selected time,
      or at the optimum time.

   .. method:: String getErrorMessage()


      The warning from the last call to ``MakeNodes``, or an empty string.

      :Game Scenes: Flight

   .. method:: SpaceCenter.Node makeNode()

      .. warning:: Deprecated. Use ``MakeNodes`` instead.

      Make the maneuver nodes of the operation, and return the first one.

      :returns: The first maneuver node.
      :Game Scenes: Flight

   .. method:: java.util.List<SpaceCenter.Node> makeNodes()

      Make the maneuver nodes of the operation. Throws an :type:`OperationException`
      if the operation cannot make them.

      :returns: The maneuver nodes.
      :Game Scenes: Flight


      .. note::

         A warning may be left in ``ErrorMessage``.

   .. method:: boolean getInterceptOnly()

   .. method:: void setInterceptOnly(boolean value)

      Whether to plan only the intercept, with no capture burn, for an impact or a flyby.

      :Game Scenes: Flight

   .. method:: boolean getSimpleTransfer()

   .. method:: void setSimpleTransfer(boolean value)

      Whether the transfer is coplanar.

      :Game Scenes: Flight

   .. method:: TimeSelector getTimeSelector()


      The time of the maneuver.

      :Game Scenes: Flight
