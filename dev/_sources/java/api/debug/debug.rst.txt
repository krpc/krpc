.. package:: krpc.client.services.Debug

Debug
=====


.. type:: public class Debug

   Provides functionality to modify the state of the simulation directly, in ways
   the game normally does not allow: teleporting a vessel, setting its attitude,
   refilling its tanks and enabling the game's cheat options.

   .. note::

      Everything in this service is cheating. It has the same effect on a save as the
      game's own debug menu (Alt+F12), and the same consequences: contracts, records and
      career progress made with it are not earned. It is intended for setting up a
      scenario to fly or a script to test, without flying there first.

   .. method:: void setCircularOrbit(SpaceCenter.CelestialBody body, double altitude)

      Move the active vessel onto a circular orbit around a body.

      :param SpaceCenter.CelestialBody body: Body to orbit.
      :param double altitude: Altitude of the orbit, in meters above sea level.
      :Game Scenes: Flight

   .. method:: void setOrbit(SpaceCenter.CelestialBody body, double semiMajorAxis, double eccentricity, double inclination, double longitudeOfAscendingNode, double argumentOfPeriapsis, double meanAnomalyAtEpoch, double epoch)

      Move the active vessel onto the orbit with the given orbital elements. The angles use
      the same units and conventions as :type:`SpaceCenter.Orbit`.

      :param SpaceCenter.CelestialBody body: Body to orbit.
      :param double semiMajorAxis: Semi-major axis of the orbit, in meters.
      :param double eccentricity: Eccentricity of the orbit.
      :param double inclination: Inclination of the orbit, in radians.
      :param double longitudeOfAscendingNode: Longitude of the ascending node, in radians.
      :param double argumentOfPeriapsis: Argument of periapsis, in radians.
      :param double meanAnomalyAtEpoch: Mean anomaly at epoch, in radians.
      :param double epoch: Universal time of the epoch, in seconds.
      :Game Scenes: Flight

   .. method:: void setLanded(SpaceCenter.CelestialBody body, double latitude, double longitude, double altitude)

      Place the active vessel on the surface of a body at the given latitude and longitude,
      and wait for it to come to rest.

      :param SpaceCenter.CelestialBody body: Body to land on.
      :param double latitude: Latitude in degrees.
      :param double longitude: Longitude in degrees.
      :param double altitude: Height above the terrain to settle at, in meters. Defaults to 0, resting on the surface.
      :Game Scenes: Flight

   .. method:: void setFlight(SpaceCenter.CelestialBody body, double latitude, double longitude, double altitude, double speed, double heading, double pitch, double roll, double angleOfAttack)

      Place the active vessel in atmospheric flight over the given point: at the given altitude
      and airspeed, pointing along the given heading at the given pitch and roll, and
      let physics resume so that it is flying. Use this to set up an in-air scenario
      without flying the craft up from the runway.

      :param SpaceCenter.CelestialBody body: Body to fly over.
      :param double latitude: Latitude in degrees.
      :param double longitude: Longitude in degrees.
      :param double altitude: Altitude in meters above sea level.
      :param double speed: Airspeed in meters per second, relative to the surface.
      :param double heading: Compass heading to point along, in degrees (90 is east).
      :param double pitch: Pitch above the horizon, in degrees. Defaults to 0 (level).
      :param double roll: Roll, in degrees. Defaults to 0 (wings level).
      :param double angleOfAttack: Angle of attack in degrees: how far the airspeed vector sits below the nose, in the pitch plane. 0 (the default) puts the airspeed along the nose; a positive value gives a nose-up attitude relative to the flight path, so the flight-path angle is *pitch* minus this.
      :Game Scenes: Flight


      .. note::

         The pitch, heading and roll match those reported by the vessel's
         :type:`SpaceCenter.Flight`.

   .. method:: void setPosition(org.javatuples.Triplet<Double,Double,Double> position, SpaceCenter.ReferenceFrame referenceFrame)

      Move the active vessel to the given position, leaving its velocity as it is. To put it
      alongside another vessel, pass a position in that vessel's reference frame.

      :param org.javatuples.Triplet<Double,Double,Double> position: Position of the vessel's center of mass, in meters.
      :param SpaceCenter.ReferenceFrame referenceFrame: Reference frame the position is in. Defaults to the reference frame of the body being orbited.
      :Game Scenes: Flight


      .. note::

         This is the inverse of :meth:`SpaceCenter.Vessel.position(SpaceCenter.ReferenceFrame)` in the same
         reference frame.

   .. method:: void setVelocity(org.javatuples.Triplet<Double,Double,Double> velocity, SpaceCenter.ReferenceFrame referenceFrame)

      Set the velocity of the active vessel, leaving it where it is. The vessel is moved onto the
      orbit that passes through its current position at the new velocity, so this works
      in orbit and in the atmosphere alike.

      :param org.javatuples.Triplet<Double,Double,Double> velocity: Velocity in meters per second.
      :param SpaceCenter.ReferenceFrame referenceFrame: Reference frame the velocity is in. Defaults to the reference frame of the body being orbited, which rotates with it, so a zero velocity leaves the vessel at rest relative to the ground.
      :Game Scenes: Flight


      .. note::

         This is the inverse of :meth:`SpaceCenter.Vessel.velocity(SpaceCenter.ReferenceFrame)` in the same
         reference frame.

   .. method:: void setPitchHeadingRoll(double pitch, double heading, double roll, SpaceCenter.ReferenceFrame referenceFrame, SpaceCenter.Vessel vessel)

      Set the attitude of a vessel to the given pitch, heading and roll in the given
      reference frame, and stop it rotating. Lets a script start from a fixed, still
      pose without first flying the autopilot there.

      :param double pitch: Target pitch, in degrees.
      :param double heading: Target heading, in degrees.
      :param double roll: Target roll, in degrees.
      :param SpaceCenter.ReferenceFrame referenceFrame: Reference frame the angles are in. Defaults to the vessel's surface reference frame.
      :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.
      :Game Scenes: Flight


      .. note::

         The angles match those reported by the vessel's
         :type:`SpaceCenter.Flight`.

   .. method:: void setDirection(org.javatuples.Triplet<Double,Double,Double> direction, double roll, SpaceCenter.ReferenceFrame referenceFrame, SpaceCenter.Vessel vessel)

      Point a vessel along the given direction in the given reference frame, and stop it
      rotating. This is :meth:`setPitchHeadingRoll(double, double, double, SpaceCenter.ReferenceFrame, SpaceCenter.Vessel)` with a pointing vector instead
      of a pitch and heading, matching the attitude the autopilot holds for the same
      target direction and roll.

      :param org.javatuples.Triplet<Double,Double,Double> direction: Direction to point the nose of the vessel in.
      :param double roll: Target roll, in degrees, or ``NaN`` to leave the roll uncontrolled.
      :param SpaceCenter.ReferenceFrame referenceFrame: Reference frame the direction and roll are in. Defaults to the vessel's surface reference frame.
      :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.
      :Game Scenes: Flight

   .. method:: void applyRotation(double angle, org.javatuples.Triplet<Double,Double,Double> axis, SpaceCenter.Vessel vessel)

      Rotate a vessel about the given axis, in its own reference frame, by the given angle.

      :param double angle: Angle to rotate by, in degrees.
      :param org.javatuples.Triplet<Double,Double,Double> axis: Axis to rotate about.
      :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.
      :Game Scenes: Flight

   .. method:: void setAngularVelocity(org.javatuples.Triplet<Double,Double,Double> angularVelocity, SpaceCenter.ReferenceFrame referenceFrame, SpaceCenter.Vessel vessel)

      Set the angular velocity of a vessel, expressed in the given reference frame. Pass a
      zero vector to stop the vessel rotating.

      :param org.javatuples.Triplet<Double,Double,Double> angularVelocity: Angular velocity, in radians per second. The direction is the axis of rotation and the magnitude is the rate.
      :param SpaceCenter.ReferenceFrame referenceFrame: Reference frame the angular velocity is in. Defaults to the vessel's surface reference frame.
      :param SpaceCenter.Vessel vessel: Vessel to rotate. Defaults to the active vessel.
      :Game Scenes: Flight


      .. note::

         The whole vessel is put into a rigid rotation about its center of mass, so it spins in
         place rather than shearing apart or translating.

   .. method:: void fillAllResources(SpaceCenter.Vessel vessel)

      Fill every resource tank on a vessel to its maximum capacity.

      :param SpaceCenter.Vessel vessel: Vessel to fill. Defaults to the active vessel.
      :Game Scenes: Flight

   .. method:: void fillResources(String resourceName, SpaceCenter.Vessel vessel)

      Fill the tanks of a single resource on a vessel to their maximum capacity.

      :param String resourceName: Name of the resource to fill, for example ``"LiquidFuel"``.
      :param SpaceCenter.Vessel vessel: Vessel to fill. Defaults to the active vessel.
      :Game Scenes: Flight
