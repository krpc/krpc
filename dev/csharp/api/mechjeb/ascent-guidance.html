AscentGuidance#

class AscentGuidance#

The Ascent Guidance window, which flies the vessel to orbit.

Note

See the MechJeb wiki for how to set up this autopilot.

bool Enabled { get; set; }#

Whether the module is enabled.

Game Scenes:

Flight

string Status { get; }#

The autopilot status, which depends on the selected ascent path.

Game Scenes:

Flight

AscentType AscentType { get; set; }#

The ascent path.

Game Scenes:

Flight

AscentSettings Settings { get; }#

The Ascent Settings window.

Game Scenes:

Flight

PVGSettings PVGSettings { get; }#

The PVG Settings window, with the settings of the AscentType.PVG path.

Game Scenes:

Flight

ClassicPath ClassicPath { get; }#

The Ascent Path Editor window, with the settings of the AscentType.Classic path.

Game Scenes:

Flight

double DesiredOrbitAltitude { get; set; }#

The altitude of the final circular orbit, in meters.

Game Scenes:

Flight

double DesiredApoapsis { get; set; }#

The target apoapsis, in meters.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path.

bool AttachAltFlag { get; set; }#

Whether the orbit is attached at AscentGuidance.DesiredAttachAlt.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path, with an early shutoff stage, set by PVGSettings.OptimizeStageFlag and PVGSettings.OptimizeStage. Without one, MechJeb always attaches the orbit.

double DesiredAttachAlt { get; set; }#

The altitude at which the orbit is attached, in meters.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path. Requires AscentGuidance.AttachAltFlag, unless there is no early shutoff stage. See PVGSettings.OptimizeStage.

double DesiredFPA { get; set; }#

The flight path angle at orbit insertion, in degrees.

Game Scenes:

Flight

Note

Applies on the AscentType.PVG path, when there is no early shutoff stage. See PVGSettings.OptimizeStage.

double DesiredInclination { get; set; }#

The inclination of the final circular orbit, in degrees.

Game Scenes:

Flight

AscentLaunchMode LaunchMode { get; }#

The launch mode, which gives whether the autopilot is waiting for a timed launch.

Game Scenes:

Flight

void LaunchToRendezvous ()#

Launch to rendezvous with the target. Throws an exception if there is no target, or the ascent path is PVG.

Game Scenes:

Flight

double LaunchPhaseAngle { get; set; }#

The phase angle to the target of a launch to rendezvous, in degrees.

Game Scenes:

Flight

void LaunchToTargetPlane ()#

Launch into the plane of the target. Throws an exception if there is no target.

Game Scenes:

Flight

double LaunchLANDifference { get; set; }#

The difference from the target’s longitude of the ascending node of a launch into the target’s plane, in degrees.

Game Scenes:

Flight

void LaunchToMatchLan ()#

Launch into the plane of the target, at the time the target’s longitude of the ascending node, less AscentGuidance.LaunchLANDifference, passes overhead. Keeps AscentGuidance.DesiredInclination. Throws an exception if there is no target, or the ascent path is not AscentType.PVG.

Game Scenes:

Flight

void LaunchToLan ()#

Launch into the plane with longitude of the ascending node AscentGuidance.DesiredLan and inclination AscentGuidance.DesiredInclination. Throws an exception if the ascent path is not AscentType.PVG.

Game Scenes:

Flight

double DesiredLan { get; set; }#

The longitude of the ascending node of a launch to a LAN, in degrees. See AscentGuidance.LaunchToLan.

Game Scenes:

Flight

void AbortTimedLaunch ()#

Abort a timed launch that has not started yet. Throws an exception if the launch mode is AscentLaunchMode.Unknown.

Game Scenes:

Flight

int WarpCountDown { get; set; }#

The time before a timed launch at which time warp stops, in seconds.

Game Scenes:

Flight

bool OverrideWarpToPlane { get; set; }#

Whether a timed launch launches at once, rather than at the time it computes.

Game Scenes:

Flight

enum AscentType#

The ascent path. See AscentGuidance.AscentType.

Classic#

The classic ascent path. See AscentGuidance.ClassicPath.

PVG#

Primer Vector Guidance, for RSS/RO. See AscentGuidance.PVGSettings.

enum AscentLaunchMode#

The launch mode of the ascent autopilot. See AscentGuidance.LaunchMode.

Normal#

The autopilot is not performing a timed launch.

Rendezvous#

A timed launch to rendezvous with the target vessel.

TargetPlane#

A timed launch into the plane of the target.

MatchLan#

A timed launch to the target’s longitude of the ascending node. See AscentGuidance.LaunchToMatchLan.

Lan#

A timed launch to a longitude of the ascending node. See AscentGuidance.LaunchToLan.

Unknown#

A timed launch of another kind, started from MechJeb’s window.

AscentSettings#

class AscentSettings#

The Ascent Settings window, which holds the settings shared by the ascent paths.

bool ForceRoll { get; set; }#

Whether the autopilot controls the roll.

Game Scenes:

Flight

double VerticalRoll { get; set; }#

The roll during the vertical climb, in degrees.

Game Scenes:

Flight

Note

Requires AscentSettings.ForceRoll.

double TurnRoll { get; set; }#

The roll during the turn, in degrees.

Game Scenes:

Flight

Note

Requires AscentSettings.ForceRoll.

double RollAltitude { get; set; }#

The altitude above which the autopilot controls the roll, in meters.

Game Scenes:

Flight

Note

Requires AscentSettings.ForceRoll.

bool LimitAngleOfAttack { get; set; }#

Whether to limit the angle of attack.

Game Scenes:

Flight

Note

Applies on the AscentType.Classic path.

double MaxAngleOfAttack { get; set; }#

The largest angle of attack, in degrees.

Game Scenes:

Flight

Note

Requires AscentSettings.LimitAngleOfAttack, and applies on the AscentType.Classic path.

double AngleOfAttackLimitFadeoutPressure { get; set; }#

The dynamic pressure below which the angle of attack limit fades out, in pascals.

Game Scenes:

Flight

Note

Requires AscentSettings.LimitAngleOfAttack, and applies on the AscentType.Classic path.

bool LimitingAngleOfAttack { get; }#

Whether the angle of attack limit is limiting the steering.

Game Scenes:

Flight

double CurrentMaxAngleOfAttack { get; }#

The largest angle of attack the limit allows now, in degrees.

Game Scenes:

Flight

bool CorrectiveSteering { get; set; }#

Whether the autopilot steers by the velocity vector rather than the position vector.

Game Scenes:

Flight

Note

It is more accurate, though large craft may do better without it. Applies on the AscentType.Classic path.

double CorrectiveSteeringGain { get; set; }#

The gain of the corrective steering.

Game Scenes:

Flight

Note

Requires AscentSettings.CorrectiveSteering, and applies on the AscentType.Classic path.

bool Autostage { get; set; }#

Whether the autopilot stages when the current stage runs out of fuel.

Game Scenes:

Flight

Autostaging Staging { get; }#

The autostaging settings. The same object as Utilities.Staging.

Game Scenes:

Flight

ThrustLimiter Thrust { get; }#

The throttle limiters. The same object as Utilities.Thrust.

Game Scenes:

Flight

bool AutodeploySolarPanels { get; set; }#

Whether to deploy the solar panels when the ascent finishes.

Game Scenes:

Flight

bool AutoDeployAntennas { get; set; }#

Whether to deploy the antennas when the ascent finishes.

Game Scenes:

Flight

bool Autowarp { get; set; }#

Whether to warp time during the ascent.

Game Scenes:

Flight

Note

The same setting as ManeuverPlanner.Autowarp.

bool SkipCircularization { get; set; }#

Whether to skip the circularization burn.

Game Scenes:

Flight

PVGSettings#

class PVGSettings#

The PVG Settings window, which holds the settings of the Primer Vector Guidance ascent path.

double DynamicPressureTrigger { get; set; }#

The dynamic pressure below which guidance starts, in pascals.

Game Scenes:

Flight

bool FixedCoast { get; set; }#

Whether the coast has a fixed length.

Game Scenes:

Flight

Note

Requires PVGSettings.CoastStageFlag.

double FixedCoastLength { get; set; }#

The length of the coast, in seconds.

Game Scenes:

Flight

Note

Requires PVGSettings.FixedCoast.

double MinDeltaV { get; set; }#

The smallest delta-v of a stage that guidance plans with, in \(\mathrm{m/s}\).

Game Scenes:

Flight

int LastStage { get; set; }#

The last stage that guidance plans with.

Game Scenes:

Flight

bool OptimizeStageFlag { get; set; }#

Whether guidance may shut off PVGSettings.OptimizeStage early.

Game Scenes:

Flight

int OptimizeStage { get; set; }#

The stage that guidance may shut off early.

Game Scenes:

Flight

Note

Requires PVGSettings.OptimizeStageFlag. -1 is no stage.

bool UnguidedStagesFlag { get; set; }#

Whether guidance leaves PVGSettings.UnguidedStages unguided.

Game Scenes:

Flight

IList<int> UnguidedStages { get; set; }#

The stages that guidance leaves unguided.

Game Scenes:

Flight

Note

Requires PVGSettings.UnguidedStagesFlag.

bool CoastStageFlag { get; set; }#

Whether guidance coasts in PVGSettings.CoastStage.

Game Scenes:

Flight

int CoastStage { get; set; }#

The stage before or after which guidance coasts.

Game Scenes:

Flight

Note
