AscentAutopilot#

class AscentAutopilot#

The ascent autopilot.

Note

See the MechJeb wiki for how to set up this autopilot.

bool Enabled { get; set; }#

Whether the autopilot is enabled. Enabling it engages the autopilot of the selected ascent path, and disabling it disengages the autopilots of both paths.

Game Scenes:

Flight

string Status { get; }#

The autopilot status, which depends on the selected ascent path.

Game Scenes:

Flight

int AscentPathIndex { get; set; }#

The selected ascent path: 0 for AscentClassic or 2 for AscentPVG.

Game Scenes:

Flight

Note

MechJeb 2.15 removed the stock-style gravity turn path, which was 1. Setting any other value throws an exception.

AscentClassic AscentPathClassic { get; }#

The settings of the classic ascent profile.

Game Scenes:

Flight

AscentPVG AscentPathPVG { get; }#

The settings of the Primer Vector Guidance (RSS/RO) profile.

Game Scenes:

Flight

double DesiredInclination { get; set; }#

The inclination of the final circular orbit, in degrees.

Game Scenes:

Flight

double DesiredOrbitAltitude { get; set; }#

The altitude of the final circular orbit, in meters.

Game Scenes:

Flight

ThrustController ThrustController { get; }#

The thrust controller. The same as MechJeb.ThrustController.

Game Scenes:

Flight

bool ForceRoll { get; set; }#

Whether the autopilot controls the roll.

Game Scenes:

Flight

double TurnRoll { get; set; }#

The roll during the turn, in degrees.

Game Scenes:

Flight

Note

Requires AscentAutopilot.ForceRoll.

double VerticalRoll { get; set; }#

The roll during the vertical climb, in degrees.

Game Scenes:

Flight

Note

Requires AscentAutopilot.ForceRoll.

bool LimitAoA { get; set; }#

Whether to limit the angle of attack.

Game Scenes:

Flight

double MaxAoA { get; set; }#

The largest angle of attack, in degrees.

Game Scenes:

Flight

Note

Requires AscentAutopilot.LimitAoA.

double AoALimitFadeoutPressure { get; set; }#

The dynamic pressure below which the angle of attack limit fades out, in pascals.

Game Scenes:

Flight

Note

Requires AscentAutopilot.LimitAoA.

bool CorrectiveSteering { get; set; }#

Whether the autopilot steers by the velocity vector rather than the position vector.

Game Scenes:

Flight

Note

It is more accurate, though large craft may do better without it.

double CorrectiveSteeringGain { get; set; }#

The gain of the corrective steering.

Game Scenes:

Flight

Note

Requires AscentAutopilot.CorrectiveSteering.

bool Autostage { get; set; }#

Whether the autopilot stages when the current stage runs out of fuel.

Game Scenes:

Flight

StagingController StagingController { get; }#

The staging controller. The same as MechJeb.StagingController.

Game Scenes:

Flight

bool AutodeploySolarPanels { get; set; }#

Whether to deploy the solar panels when the ascent finishes.

Game Scenes:

Flight

bool AutoDeployAntennas { get; set; }#

Whether to deploy the antennas when the ascent finishes.

Game Scenes:

Flight

bool SkipCircularization { get; set; }#

Whether to skip the circularization burn.

Game Scenes:

Flight

int WarpCountDown { get; set; }#

The time before a timed launch at which time warp stops, in seconds.

Game Scenes:

Flight

double LaunchLANDifference { get; set; }#

The difference from the target’s longitude of the ascending node of a launch into the target’s plane, in degrees.

Game Scenes:

Flight

double LaunchPhaseAngle { get; set; }#

The phase angle to the target of a launch to rendezvous, in degrees.

Game Scenes:

Flight

AscentLaunchMode LaunchMode { get; }#

The launch mode, which gives whether the autopilot is waiting for a timed launch.

Game Scenes:

Flight

void AbortTimedLaunch ()#

Abort a timed launch that has not started yet. Throws an exception if the launch mode is AscentLaunchMode.Unknown.

Game Scenes:

Flight

void LaunchToRendezvous ()#

Launch to rendezvous with the target. Throws an exception if there is no target, or the ascent path is PVG.

Game Scenes:

Flight

void LaunchToTargetPlane ()#

Launch into the plane of the target. Throws an exception if there is no target.

Game Scenes:

Flight

enum AscentLaunchMode#

The launch mode of the ascent autopilot. See AscentAutopilot.LaunchMode.

Normal#

The autopilot is not performing a timed launch.

Rendezvous#

A timed launch to rendezvous with the target vessel.

TargetPlane#

A timed launch into the plane of the target.

Unknown#

A timed launch of another kind, started from MechJeb’s window.

AscentClassic#

class AscentClassic#

The classic ascent profile.

bool AutoPath { get; set; }#

Whether the autopilot chooses the turn altitudes and speed.

Game Scenes:

Flight

float AutoTurnPercent { get; set; }#

The altitude at which an automatic turn starts, as a fraction of the height of the atmosphere.

Game Scenes:

Flight

Note

Requires AscentClassic.AutoPath.

float AutoTurnSpeedFactor { get; set; }#

The factor that sets the speed at which an automatic turn starts.

Game Scenes:

Flight

Note

Requires AscentClassic.AutoPath.

double AutoTurnStartAltitude { get; }#

The altitude at which an automatic turn starts, in meters.

Game Scenes:

Flight

double AutoTurnStartVelocity { get; }#

The speed at which an automatic turn starts, in \(\mathrm{m/s}\).

Game Scenes:

Flight

double AutoTurnEndAltitude { get; }#

The altitude at which an automatic turn ends, in meters.

Game Scenes:

Flight

double TurnStartAltitude { get; set; }#

The altitude at which the turn starts, in meters.

Game Scenes:

Flight

double TurnStartVelocity { get; set; }#

The speed at which the turn starts, in \(\mathrm{m/s}\).

Game Scenes:

Flight

double TurnEndAltitude { get; set; }#

The altitude at which the turn ends, in meters.

Game Scenes:

Flight

double TurnEndAngle { get; set; }#

The final flight path angle, in degrees.

Game Scenes:

Flight

double TurnShapeExponent { get; set; }#

The steepness of the turn, between 0 and 1.

Game Scenes:

Flight

AscentPVG#

class AscentPVG#

The Primer Vector Guidance (RSS/RO) profile.

bool AttachAltFlag { get; set; }#

Whether the orbit is attached at AscentPVG.DesiredAttachAlt.

Game Scenes:

Flight

Note

MechJeb reads this setting only when its PVG settings window has an early shutoff stage. Without one, MechJeb always attaches the orbit.

double DesiredApoapsis { get; set; }#

The target apoapsis, in meters.

Game Scenes:

Flight

double DesiredAttachAlt { get; set; }#

The altitude at which the orbit is attached, in meters.

Game Scenes:

Flight

Note

Requires AscentPVG.AttachAltFlag, unless MechJeb’s PVG settings window has no early shutoff stage.

double DynamicPressureTrigger { get; set; }#

The dynamic pressure below which guidance starts, in pascals.

Game Scenes:

Flight

bool FixedCoast { get; set; }#

Whether the coast has a fixed length.

Game Scenes:

Flight

double FixedCoastLength { get; set; }#

The length of the coast, in seconds.

Game Scenes:

Flight

Note

Requires AscentPVG.FixedCoast.

double PitchRate { get; set; }#

The pitch rate of the booster, in \(\mathrm{deg/s}\).

Game Scenes:

Flight

double PitchStartVelocity { get; set; }#

The speed at which the booster starts to pitch over, in \(\mathrm{m/s}\).

Game Scenes:

Flight

int StagingTrigger { get; set; }#

The stage after which guidance starts.

Game Scenes:

Flight

Note

Requires AscentPVG.StagingTriggerFlag.

bool StagingTriggerFlag { get; set; }#

Whether guidance starts after AscentPVG.StagingTrigger.

Game Scenes:

Flight
