SmartASS#

class SmartASS#

The Smart A.S.S. window, which points the vessel in a chosen direction.

SmartASSInterfaceMode InterfaceMode { get; set; }#

The mode of the window, which selects its buttons and nothing else. Throws an exception if set to SmartASSInterfaceMode.Automatic.

Game Scenes:

Flight

SmartASSAutopilotMode AutopilotMode { get; set; }#

The autopilot mode. Throws an exception if set to SmartASSAutopilotMode.Automatic.

Game Scenes:

Flight

Note

Call SmartASS.Update to apply a change.

void Update (bool resetPID)#

Apply the settings.

Parameters:

  • resetPID – Whether to reset the attitude controller. Use it only if the vessel does not follow the new settings.

Game Scenes:

Flight

bool ForceYaw { get; set; }#

Whether the autopilot controls the yaw in the SmartASSAutopilotMode.Surface, SmartASSAutopilotMode.SurfacePrograde and SmartASSAutopilotMode.SurfaceRetrograde modes.

Game Scenes:

Flight

bool ForcePitch { get; set; }#

Whether the autopilot controls the pitch in the SmartASSAutopilotMode.Surface, SmartASSAutopilotMode.SurfacePrograde and SmartASSAutopilotMode.SurfaceRetrograde modes.

Game Scenes:

Flight

bool ForceRoll { get; set; }#

Whether the autopilot controls the roll.

Game Scenes:

Flight

double SurfaceHeading { get; set; }#

The heading, in degrees.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.Surface mode.

double SurfacePitch { get; set; }#

The pitch above the horizon, in degrees. 90 is straight up.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.Surface mode.

double SurfaceRoll { get; set; }#

The roll, in degrees. 0 is top side up.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.Surface mode.

double SurfaceVelYaw { get; set; }#

The yaw from the surface velocity, in degrees.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.SurfacePrograde and SmartASSAutopilotMode.SurfaceRetrograde modes.

double SurfaceVelPitch { get; set; }#

The pitch from the surface velocity, in degrees.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.SurfacePrograde and SmartASSAutopilotMode.SurfaceRetrograde modes.

double SurfaceVelRoll { get; set; }#

The roll, in degrees. 0 is top side up.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.SurfacePrograde and SmartASSAutopilotMode.SurfaceRetrograde modes.

AttitudeReference AdvancedReference { get; set; }#

The reference frame of SmartASS.AdvancedDirection. Throws an exception if MechJeb uses a reference this enumeration lacks.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.Advanced mode.

Direction AdvancedDirection { get; set; }#

The direction in SmartASS.AdvancedReference.

Game Scenes:

Flight

Note

Applies in the SmartASSAutopilotMode.Advanced mode.

enum SmartASSInterfaceMode#

The mode of the Smart A.S.S. window. See SmartASS.InterfaceMode.

Orbital#

The orbital modes.

Surface#

The surface modes.

Target#

The target modes.

Advanced#

The advanced mode.

Automatic#

Set by MechJeb’s autopilots. Cannot be set.

enum SmartASSAutopilotMode#

The autopilot mode of Smart A.S.S. See SmartASS.AutopilotMode.

Off#

Off.

KillRot#

Stop the vessel’s rotation.

Node#

Point at the next maneuver node.

Advanced#

Point in the direction set by SmartASS.AdvancedReference and SmartASS.AdvancedDirection.

Automatic#

Set by MechJeb’s autopilots. Cannot be set.

Prograde#

Point orbital prograde.

Retrograde#

Point orbital retrograde.

NormalPlus#

Point orbit normal.

NormalMinus#

Point orbit anti-normal.

RadialPlus#

Point radially outward.

RadialMinus#

Point radially inward.

SurfacePrograde#

Point along the surface velocity.

SurfaceRetrograde#

Point against the surface velocity.

HorizontalPlus#

Point along the horizontal surface velocity.

HorizontalMinus#

Point against the horizontal surface velocity.

Surface#

Point in the direction set by SmartASS.SurfaceHeading, SmartASS.SurfacePitch and SmartASS.SurfaceRoll.

VerticalPlus#

Point up, normal to the surface.

TargetPlus#

Point at the target.

TargetMinus#

Point away from the target.

RelativePlus#

Point along the velocity relative to the target.

RelativeMinus#

Point against the velocity relative to the target.

ParallelPlus#

Point parallel to the target’s orientation. For a docking port, along its axis and away from it.

ParallelMinus#

Point antiparallel to the target’s orientation. For a docking port, along its axis and toward it.

enum AttitudeReference#

A reference frame of Smart A.S.S. See SmartASS.AdvancedReference.

Inertial#

The world coordinate system.

Orbit#

Forward is prograde, left is normal and up is radial out.

OrbitHorizontal#

Forward is the orbital velocity projected onto the surface, and up is the surface normal.

SurfaceNorth#

Forward is north, left is west and up is the surface normal.

SurfaceVelocity#

Forward is the surface velocity, and up is the surface normal perpendicular to it.

Target#

Forward is toward the target, and up is the vessel’s heading perpendicular to it.

RelativeVelocity#

Forward is the velocity relative to the target.

TargetOrientation#

Forward is the direction the target faces, and up is the target’s up.

ManeuverNode#

Forward is the burn direction of the next maneuver node.

Sun#

Forward is the orbital velocity of the body that orbits the sun, and up is radial out of that orbit.

SurfaceHorizontal#

Forward is the horizontal surface velocity, and up is the surface normal.

enum Direction#

A direction of Smart A.S.S. See SmartASS.AdvancedDirection.

Forward#

Forward.

Back#

Back.

Up#

Up.

Down#

Down.

Right#

Right.

Left#

Left.
