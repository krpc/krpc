Expressions#

The nodes a server side function is built from, and the types they work with. See the server side functions tutorial for how a function is assembled and run.

class Expression#

A server side expression.

Note

Numeric operands of differing types are converted to a common type.

Type ReturnType { get; }#

The type of the value the expression evaluates to. Throws an exception if the value cannot be sent to a client.

Game Scenes:

All

Note

A function created with Expression.Lambda evaluates to the value it returns. A lazily evaluated collection, such as from Expression.Select, is sent once converted by Expression.ToList or Expression.ToSet.

Boolean HasReturnType { get; }#

Whether the expression evaluates to a value.

Game Scenes:

All

Note

An expression with no value has no Expression.ReturnType. An empty collection and no value both encode to an empty sequence of bytes.

IList<Type> ParameterTypes { get; }#

The types of the function’s parameters.

Game Scenes:

All

Note

Empty for a function that is not created with Expression.Lambda.

All

Note

The instance the call is made on, and the values of its arguments, are fixed when the expression is created. A call to a procedure with no return value is evaluated for its effects, as a statement in a Expression.Block. A collection the procedure returns is copied, as a client would receive it.

Game Scenes:
