Editor#

class Editor#

Provides access to the vehicle assembly building and space plane hangar. Obtained by calling SpaceCenter.Editor.

EditorFacility Facility { get; }#

The editor that is currently open.

Game Scenes:

Editor Vab, Editor Sph

EditorVessel Vessel { get; }#

The vessel that is being constructed.

Game Scenes:

Editor Vab, Editor Sph

Note

An editor that has not had a vessel loaded into it holds an empty vessel, with no parts, rather than nothing at all.

void LoadVessel (String craftDirectory, String name)#

Load a vessel from a craft file into the editor, replacing the vessel that is currently being constructed.

Parameters:

  • craftDirectory – Name of the directory in the current saves “Ships” directory, that contains the craft file. For example "VAB" or "SPH".

  • name – Name of the vessel to load. This is the name of the “.craft” file in the save directory, without the “.craft” file extension.

Game Scenes:

Editor Vab, Editor Sph

Note

The vessel is loaded into whichever editor is open, regardless of which directory it came from. Its delta-v figures are recalculated in the background afterwards; see EditorVessel.DeltaVReady.

void LaunchVessel (String launchSite, IList<String> crew, Boolean recover = true, String flagUrl = "")#

Launch the vessel that is being constructed, from the given launch site.

Parameters:

  • launchSite – Name of the launch site. For example "LaunchPad" or "Runway".

  • crew – The Kerbals to place in the vessel, by name. Controls how the vessel is crewed, as described in the remarks.

  • recover – If true and there is a vessel on the launch site, recover it before launching.

  • flagUrl – If not null, the asset URL of the mission flag to use for the launch.

Game Scenes:

Editor Vab, Editor Sph

Note

The vessel being constructed is not a craft file, so it is written to the editor’s auto-saved craft file and that is launched, as the game’s own launch button does. The vessel’s own craft file, if it was loaded from one, is left alone. The crew parameter works as it does for SpaceCenter.LaunchVessel, and takes precedence over the crew assigned in the editor. Throws an exception if any of the games pre-flight checks fail.

CelestialBody DeltaVBody { get; set; }#

The body whose gravity and atmosphere the vessel’s delta-v, thrust, TWR and specific impulse figures assume.

Game Scenes:

Editor Vab, Editor Sph

Note

This and Editor.DeltaVAltitude are what EditorVessel.DeltaV, Stage.DeltaV and the other current-situation figures are computed for. The body sets the gravity the thrust-to-weight ratios are against, and, with the altitude, the atmospheric pressure and density the specific impulses and thrusts are against. This is global game state rather than editor state: the same setting backs the game’s delta-v readout in flight, and it persists across scene changes. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until EditorVessel.DeltaVReady is true again.

Double DeltaVAltitude { get; set; }#

The altitude above Editor.DeltaVBody, in meters, that the vessel’s delta-v, thrust, TWR and specific impulse figures assume. The atmospheric pressure and density at this altitude are what the figures are computed for, so raising it from zero to above the body’s atmosphere moves them from the vessel’s sea-level figures to its vacuum ones. Setting it asks the game to re-run the simulation and returns straight away; the figures are out of date until EditorVessel.DeltaVReady is true again.

Game Scenes:

Editor Vab, Editor Sph

DeltaVSituation DeltaVSituation { get; set; }#

Which situation the game’s own delta-v readout shows figures for.

Game Scenes:

Editor Vab, Editor Sph

Note

This selects which column the game’s own delta-v app displays, and nothing else. It does not affect anything kRPC reports: the current-situation figures follow Editor.DeltaVBody and Editor.DeltaVAltitude whatever this is set to, and the sea-level and vacuum figures are reported directly as EditorVessel.SeaLevelDeltaV and EditorVessel.VacuumDeltaV. It is here for completeness with the app.

enum DeltaVSituation#

The situation the game’s own delta-v readout shows figures for. See Editor.DeltaVSituation.

SeaLevel#

At sea level on the selected body.

Altitude#

At the selected altitude on the selected body.

Vacuum#

In vacuum.

Parts Parts { get; }#

A Parts object, that can be used to interact with the parts that make up the vessel.

Game Scenes:

Editor Vab, Editor Sph

Note

Only the parts of Part that describe the design are available in the editor. Those that need a vessel in flight or running physics, such as Part.Position and the thermal members, are restricted to the flight scene.

Resources Resources { get; }#

A EditorVessel.Resources object for the resources the vessel can hold.

Game Scenes:

Editor Vab, Editor Sph

Note

This is a view of what the vessel can hold as designed. The flow-state members work, as they are part of the design, but nothing here reports how a resource would be drawn on in flight.

IList<Stage> Stages { get; }#

Activation (burn) stages for the vessel, in ascending stage order. This does not include the -1 stage (parts with no staging icon), as it carries no delta-v; use EditorVessel.StageAt with -1 to get those parts.

Game Scenes:

Editor Vab, Editor Sph

Stage StageAt (Int32 stage)#

The activation stage with the given number. Pass -1 to get the parts that are never activated (those with no staging icon).

Parameters:

  • stage – Get activation stage at this index.

Game Scenes:

Editor Vab, Editor Sph

IList<Stage> DecoupleStages { get; }#

Decouple stages for the vessel, in ascending stage order. The -1 stage, containing the parts that are never decoupled and remain on the vessel, is included first when any such parts exist.

Game Scenes:

Editor Vab, Editor Sph

Stage DecoupleStageAt (Int32 stage)#

The decouple stage with the given number. Pass -1 to get the parts that are never decoupled and remain on the vessel after all stages have fired.

Parameters:

  • stage – Get decouple stage at this index.

Game Scenes:

Editor Vab, Editor Sph

Boolean DeltaVReady { get; }#

Whether the stock delta-v figures for the vessel have been calculated.

Game Scenes:

Editor Vab, Editor Sph

Note

The game recalculates them in the background whenever the vessel changes, and whenever Editor.DeltaVBody or Editor.DeltaVAltitude is set, and they are out of date until it has finished. Reading EditorVessel.DeltaV, or any delta-v member of a Stage, before then raises an error rather than returning a stale figure. Poll this after changing anything the figures depend on.
